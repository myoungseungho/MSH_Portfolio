매직 넘버 제거

의미 없는 숫자를 이름 있는 상수로

Part 1. 매직 넘버가 뭐야?

코드에 숫자 쓰면 안 돼?

의미 설명 없이 등장하는 숫자가 문제야.

왜 하필 그 숫자인지 알 수 없어서 "마법처럼" 동작한다고 해서 매직 넘버야.

// 이 숫자들은 대체 뭘 의미하는 거야? if (pPC->GetLevel() >= 50) { pPC->AddGold(100000); pPC->SetFlag(0x0010); } for (int i = 0; i < 8; i++) { pParty->GetMember(i)->AddExp(500); } if (nDamage > 9999) { nDamage = 9999; }
뭐가 문제인데?

6개월 뒤에 이 코드를 보면:

"50은 뭐지? 100000은? 8은 파티원 수인가? 9999는 왜?"

Part 2. 우리 프로젝트의 매직 넘버들

조선협객전 코드에도 많아?

실제로 발견된 것들:

매직 넘버 추정 의미 권장 상수명
60000 자동 저장 주기 (ms) TIME_AUTO_PC_SAVE
2000 스킬 틱 간격 (ms) TIME_SKILL_EVENT_TICK
256 인벤토리 최대 크기 MAX_INVENTORY_SIZE
0x0001 캐릭터 상태 플래그 FLAG_CHARACTER_DEAD
8 최대 파티원 수 MAX_PARTY_MEMBERS
좋은 소식!

우리 프로젝트의 TIDefineServer.h에는 이미 많은 상수가 정의되어 있어.
문제는 코드 곳곳에서 상수 대신 숫자를 직접 쓰는 경우가 있다는 거야.

Part 3. 어떻게 바꾸면 돼?

Before/After 보여줘

던전 입장 체크 코드를 리팩토링해보자:

// ❌ Before - 매직 넘버 가득 void CDungeonManager::CheckEntry(CGamePC* pPC) { if (pPC->GetLevel() < 50) return; if (pPC->GetPartyCount() > 8) return; if (pPC->GetGold() < 100000) return; if (GetTickCount() - m_dwLastEnter < 1800000) return; EnterDungeon(pPC); }
// ✅ After - 의미있는 상수 // TIDefineServer.h에 정의 #define DUNGEON_MIN_LEVEL 50 #define MAX_PARTY_MEMBERS 8 #define DUNGEON_ENTRY_FEE 100000 #define DUNGEON_COOLTIME_MS (30 * 60 * 1000) void CDungeonManager::CheckEntry(CGamePC* pPC) { if (pPC->GetLevel() < DUNGEON_MIN_LEVEL) return; if (pPC->GetPartyCount() > MAX_PARTY_MEMBERS) return; if (pPC->GetGold() < DUNGEON_ENTRY_FEE) return; if (GetTickCount() - m_dwLastEnter < DUNGEON_COOLTIME_MS) return; EnterDungeon(pPC); }
1800000을 왜 계산식으로 썼어?

(30 * 60 * 1000)이라고 쓰면 "30분"임을 바로 알 수 있어!

Part 4. 좋은 상수 정의법

상수 이름은 어떻게 지어?

몇 가지 원칙이 있어:

✅ 좋은 상수 정의

• 의미를 담은 이름: MAX_PARTY_MEMBERS (O) vs EIGHT (X)
• 단위 명시: TIMEOUT_MS, DISTANCE_METERS
• 관련 상수 그룹화: DUNGEON_ 접두어로 던전 관련 상수 묶기
• 계산식 표현: #define HOUR_MS (60 * 60 * 1000)
// ❌ 나쁜 예: 3600000이 뭔지 모름 #define SESSION_TIMEOUT 3600000 // ✅ 좋은 예: 1시간임을 알 수 있음 #define SESSION_TIMEOUT_MS (1 * 60 * 60 * 1000) // 1시간 // ✅ 더 좋은 예: 상수 재사용 #define MINUTE_MS (60 * 1000) #define HOUR_MS (60 * MINUTE_MS) #define SESSION_TIMEOUT_MS (1 * HOUR_MS)

Part 5. 0과 1은 매직 넘버야?

for문에서 0부터 시작하는 것도 바꿔야 해?

상황에 따라 달라.

// ✅ OK: 명백한 의미 for (int i = 0; i < count; i++) // 0부터 시작 if (strlen(str) == 0) // 빈 문자열 return arr[0]; // 첫 번째 요소 // ❌ 상수화 필요: 의미가 불명확 if (pPC->GetState() == 0) // 0이 무슨 상태? pPC->SetFlag(1); // 1이 무슨 플래그? if (type == 1) // 1이 무슨 타입?
핵심 기준

"이 숫자가 왜 이 값인지" 설명이 필요하면 상수로 만들어야 해.
배열 인덱스 0이나 루프 시작값 0은 프로그래밍 관례라서 괜찮아.

핵심 정리: 매직 넘버 제거

  • 의미 없는 숫자 → 이름 있는 상수로
  • 상수명에 의미를 담아라 (EIGHT 말고 MAX_PARTY)
  • 시간 상수는 계산식으로 표현 (30 * 60 * 1000)
  • 관련 상수는 접두어로 그룹화
  • 0, 1도 의미가 불명확하면 상수화
