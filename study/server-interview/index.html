게임 서버 실전 면접 100문

"OO이 뭐냐"가 아니라 "너라면 어떻게 풀래" — 정답 없는 시나리오에 트레이드오프로 답한다

이 문서는

요즘 서버 면접은 용어를 묻지 않습니다. "100만 명에게 우편을 어떻게 보낼래?"처럼 정답 없는 상황을 던지고, 후보가 순진한 첫 안 → 터지는 지점 → 개선 → 트레이드오프 → 상황별 최적해로 가는 사고 과정을 봅니다.

그래서 이 100문은 각 질문마다 1차 답변 + 면접관의 꼬리질문(도피로 막기) + 각 꼬리에 대한 답 + "면접관이 보는 것"까지 풀어 썼습니다. 실제 MMORPG(C++/IOCP/TCP) 운영에서 부딪힌 문제 위에서요.
