오디오 압축의 선택

WAV, OGG, ADPCM, Opus - 게임 오디오 최적화의 핵심

Part 1. 개념 이해 - 게임 오디오의 특수성

게임 오디오는 왜 특별해?

게임 오디오는 실시간 재생, 동시 다발적, 인터랙티브라는 세 가지 특성을 가집니다. 음악 플레이어와 달리 예측 불가능한 타이밍에 재생됩니다!

├─────────────────────────────────────────────────────────────────────┤

│   │ 1곡 → 2곡 → 3곡    │            │ BGM + SFX 20개     │          │

오디오 압축이 뭐야?

오디오 압축은 원본 PCM 데이터를 더 작은 크기로 인코딩하는 것입니다. 크게 무손실(Lossless)과 손실(Lossy)로 나뉩니다.

┌─────────────────────────────────────────────────────────────────────┐
│                    오디오 데이터 구조                                 │
├─────────────────────────────────────────────────────────────────────┤
│                                                                      │
│   원본 PCM (Pulse Code Modulation)                                   │
│   ─────────────────────────────────                                  │
│                                                                      │
│   Sample Rate: 44100 Hz (1초에 44100번 샘플링)                       │
│   Bit Depth: 16bit (각 샘플당 16비트 = 65536단계)                    │
│   Channels: 2 (스테레오)                                             │
│                                                                      │
│   1초 = 44100 × 16bit × 2ch = 1,411,200 bits = 176.4 KB             │
│   1분 = 10.6 MB                                                      │
│   10분 BGM = 106 MB! 😱                                              │
│                                                                      │
│   ┌──────────────────────────────────────────────────────┐          │
│   │ 파형 (1초)                                            │          │
│   │                                                       │          │
│   │      ╱╲    ╱╲╱╲       ╱╲                             │          │
│   │  ───╱──╲──╱────╲─────╱──╲─── ...  × 44100 샘플       │          │
│   │         ╲╱      ╲╱                                    │          │
│   │                                                       │          │
│   │  각 점 = 1 샘플 = 16bit 정수 (-32768 ~ +32767)        │          │
│   └──────────────────────────────────────────────────────┘          │
│                                                                      │
│   압축 방식:                                                         │
│   ──────────                                                         │
│                                                                      │
│   [무손실] FLAC, ALAC                                                │
│           • 원본 100% 복원 가능                                      │
│           • 압축률: 50-60% (절반 정도)                               │
│           • 용도: 마스터 보관, 오디오파일                            │
│                                                                      │
│   [손실] OGG, MP3, AAC, ADPCM                                        │
│          • 사람이 못 듣는 정보 제거                                  │
│          • 압축률: 10-25% (1/4 ~ 1/10)                               │
│          • 용도: 게임, 스트리밍, 일반 재생                           │
│                                                                      │
└─────────────────────────────────────────────────────────────────────┘

Part 2. 주요 포맷 비교 - WAV, OGG, MP3, ADPCM, Opus

WAV (PCM)의 특징은?

WAV는 비압축 PCM 데이터를 담는 컨테이너입니다. 최고 품질이지만 파일 크기가 거대합니다.

┌─────────────────────────────────────────────────────────────────────┐
│                    WAV (PCM) 특성                                    │
├─────────────────────────────────────────────────────────────────────┤
│                                                                      │
│   장점:                           단점:                              │
│   ─────                           ─────                              │
│   • 무손실 원본 품질               • 거대한 파일 크기                 │
│   • 디코딩 불필요 (CPU 0%)         • 메모리 사용량 ↑↑                │
│   • 지연 시간 0ms                  • 저장 공간 비효율                 │
│   • 모든 플랫폼 지원               • 스트리밍에 부적합                │
│                                                                      │
│   적합한 용도:                                                       │
│   ──────────────                                                     │
│   ✓ 짧은 SFX (< 1초): 총소리, 발소리, UI 클릭                       │
│   ✓ 빠른 반응 필요: 대시, 점프, 공격                                │
│   ✓ 자주 재생되는 소리                                               │
│   ✓ 에디터/개발용 원본                                               │
│                                                                      │
│   부적합한 용도:                                                     │
│   ────────────────                                                   │
│   ✗ BGM (분 단위)                                                    │
│   ✗ 음성 대사                                                        │
│   ✗ 환경음                                                           │
│                                                                      │
│   파일 크기 예시 (스테레오 44.1kHz 16bit):                           │
│   • 0.5초 SFX: 88 KB                                                 │
│   • 3분 BGM: 31.8 MB                                                 │
│                                                                      │
└─────────────────────────────────────────────────────────────────────┘

OGG Vorbis는?

OGG Vorbis는 오픈소스 손실 압축 포맷으로, 게임에서 가장 많이 사용됩니다. MP3보다 품질이 좋고 로열티가 없습니다!

┌─────────────────────────────────────────────────────────────────────┐
│                    OGG Vorbis 특성                                   │
├─────────────────────────────────────────────────────────────────────┤
│                                                                      │
│   장점:                           단점:                              │
│   ─────                           ─────                              │
│   • 높은 압축률 (1/10~1/8)         • 디코딩 CPU 비용                  │
│   • 좋은 음질 (128kbps ≈ MP3 192)  • 지연 시간 발생 가능              │
│   • 로열티 프리 (무료!)            • 하드웨어 가속 제한적             │
│   • 가변 비트레이트 (VBR)          • 정밀 루프 포인트 어려움          │
│   • 스트리밍에 적합                                                  │
│                                                                      │
│   비트레이트별 품질:                                                 │
│   ──────────────────                                                 │
│   • 64 kbps: 음성 대화용 (충분)                                      │
│   • 96 kbps: 일반 SFX (좋음)                                         │
│   • 128 kbps: BGM 권장 (훌륭)                                        │
│   • 192 kbps: 고품질 음악                                            │
│   • 320 kbps: 거의 원본급                                            │
│                                                                      │
│   적합한 용도:                                                       │
│   ──────────────                                                     │
│   ✓ BGM (메인): 3~5분 음악                                           │
│   ✓ 환경음: 바람, 물, 도시 배경                                      │
│   ✓ 음성 대사: NPC 대화                                              │
│   ✓ 긴 SFX: 폭발 잔향, 비명                                          │
│                                                                      │
│   파일 크기 예시 (128kbps):                                          │
│   • 3분 BGM: 2.9 MB (WAV 31.8MB의 9%)                                │
│   • 10초 음성: 160 KB                                                │
│                                                                      │
└─────────────────────────────────────────────────────────────────────┘

ADPCM은 뭐가 다른가?

ADPCM (Adaptive Differential PCM)은 고정 압축률과 빠른 디코딩이 특징입니다. OGG와 WAV 사이의 절충안!

┌─────────────────────────────────────────────────────────────────────┐
│                    ADPCM 특성                                        │
├─────────────────────────────────────────────────────────────────────┤
│                                                                      │
│   원리: 인접 샘플 간의 "차이"만 저장                                 │
│   ─────────────────────────────────                                  │
│                                                                      │
│   PCM:    [1000] [1050] [1020] [1080] ...  16bit × N                 │
│   ADPCM:  [1000] [+50]  [-30]  [+60]  ...  4bit × N + 초기값         │
│                                                                      │
│   압축률: 고정 3.5:1 (16bit → 4bit + 오버헤드)                       │
│                                                                      │
│   장점:                           단점:                              │
│   ─────                           ─────                              │
│   • 매우 빠른 디코딩 (CPU ↓)      • OGG보다 큰 파일                  │
│   • 고정 압축률 (예측 가능)        • 품질 제한 (노이즈 가능)          │
│   • 정밀 샘플 접근 가능            • 고음질 음악에 부적합             │
│   • 루프 포인트 정확               • 스트리밍보다 비효율              │
│   • 하드웨어 지원 많음                                               │
│                                                                      │
│   적합한 용도:                                                       │
│   ──────────────                                                     │
│   ✓ 중간 길이 SFX (1~5초)                                            │
│   ✓ 자주 재생되는 효과음                                             │
│   ✓ 루프 환경음                                                      │
│   ✓ 복잡한 동시 재생 장면                                            │
│                                                                      │
│   비교 (3분 스테레오 44.1kHz):                                       │
│   ──────────────────────────                                         │
│   • WAV:   31.8 MB (원본)                                            │
│   • ADPCM:  9.1 MB (3.5배 압축)                                      │
│   • OGG:    2.9 MB (11배 압축)                                       │
│                                                                      │
└─────────────────────────────────────────────────────────────────────┘
💡 ADPCM을 선택해야 할 때:
  • 총소리처럼 동시에 여러 개 재생되는 사운드
  • CPU가 부족한 모바일에서 빠른 디코딩 필요
  • 정확한 루프 포인트가 필요한 반복음
최신 포맷 Opus는?

Opus는 2012년 표준화된 차세대 오디오 코덱입니다. 음성과 음악 모두에서 최고 품질!

┌─────────────────────────────────────────────────────────────────────┐
│                    Opus 코덱 특성                                    │
├─────────────────────────────────────────────────────────────────────┤
│                                                                      │
│   특징:                                                              │
│   ──────                                                             │
│   • IETF 표준 (RFC 6716)                                             │
│   • 로열티 프리                                                      │
│   • 6 kbps ~ 510 kbps 지원                                           │
│   • 음성(SILK) + 음악(CELT) 하이브리드                               │
│   • 저지연 (최소 2.5ms 프레임)                                       │
│                                                                      │
│   품질 비교 (같은 비트레이트):                                       │
│   ──────────────────────────                                         │
│                                                                      │
│   비트레이트    MP3      OGG      Opus                               │
│   ─────────   ─────    ─────    ──────                               │
│   64 kbps     음성용    보통      우수                                │
│   96 kbps     보통      좋음      매우 좋음                           │
│   128 kbps    좋음      우수      거의 원본                           │
│   192 kbps    우수      원본급    원본급                              │

│   적합한 용도:                                                       │
│   ──────────────                                                     │
│   ✓ 음성 채팅 (저비트레이트에서 최강)                                │
│   ✓ 스트리밍 BGM                                                     │
│   ✓ 용량 민감한 모바일 게임                                          │
│   ✓ WebRTC 실시간 오디오                                             │
│                                                                      │
│   단점:                                                              │
│   ──────                                                             │
│   • 일부 구형 플랫폼 미지원                                          │
│   • Unity 기본 미지원 (플러그인 필요)                                │
│   • 디코딩 CPU 비용은 OGG와 비슷                                     │
│                                                                      │
└─────────────────────────────────────────────────────────────────────┘

Part 4. 메모리와 CPU 트레이드오프

Load Type에 따른 차이는?

면접에서 예상되는 질문들은?
🎯 예상 질문과 모범 답변:

Q1: WAV, OGG, ADPCM 차이점과 사용처를 설명하세요.

A: "WAV는 비압축으로 파일 크기가 크지만 디코딩 비용이 없어 짧은 SFX에 적합합니다. OGG는 손실 압축으로 파일 크기가 1/10 수준이지만 디코딩 CPU 비용이 있어 BGM이나 긴 오디오에 적합합니다. ADPCM은 고정 3.5:1 압축으로 OGG보다 빠르게 디코딩되어, 동시에 많이 재생되는 중간 길이 SFX에 적합합니다."

Q2: Unity에서 Load Type 차이점은?

A: "Decompress On Load는 로드 시 전체를 PCM으로 풀어 메모리에 저장하여 재생 시 CPU 비용이 없습니다. Compressed In Memory는 압축 상태로 메모리에 유지하고 재생 시 실시간 디코딩합니다. Streaming은 디스크에서 필요할 때만 읽어 메모리를 최소화하지만 I/O 부하가 있습니다."

Q3: 모바일 게임 오디오 최적화 방법은?

A: "첫째, OGG 품질을 50-70%로 낮춥니다. 둘째, 음성은 모노 + 22kHz로 변환합니다. 셋째, 동시 재생 채널을 8-16개로 제한합니다. 넷째, 짧은 SFX는 ADPCM으로 CPU 부하를 줄입니다."

Q4: 샘플레이트를 낮추면 어떤 영향이 있나요?

A: "나이퀴스트 정리에 따라 샘플레이트의 절반 주파수까지만 재현됩니다. 44kHz → 22kHz로 낮추면 11kHz 이상 고음이 손실되지만, 음성(8kHz 이하)에는 충분합니다. 파일 크기는 비례해서 절반으로 줄어듭니다."

핵심 정리

  • WAV (PCM): 무압축, 즉시 재생, 짧은 SFX용
  • OGG Vorbis: 1/10 압축, 고품질, BGM/음성용
  • ADPCM: 3.5:1 압축, 빠른 디코딩, 중간 SFX용
  • Opus: 차세대 코덱, 저비트레이트 최강
  • Load Type: Decompress(빠름) / Compressed(균형) / Streaming(메모리 최소)
  • 모노 변환: 3D 오디오, 음성, UI → 용량 50% 절감
  • 샘플레이트: 음성 22kHz 충분, 음악 44kHz 유지
