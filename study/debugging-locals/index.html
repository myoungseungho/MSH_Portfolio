Locals 창이 뭐야?

지역 변수 자동 표시 — 현재 스코프의 모든 변수를 한눈에

Part 1. Locals vs Watch

Watch랑 뭐가 달라?

Locals는 현재 함수의 모든 지역 변수를 자동으로 보여준다.

Watch는 내가 등록한 것만 보여준다.

항목LocalsWatch
등록자동수동
범위현재 함수만전역 가능
표현식불가가능
용도빠른 확인추적 감시

Part 2. 열기

어떻게 열어?

Debug → Windows → Locals (Ctrl+Alt+V, L)

Part 3. 활용 팁

값이 바뀌면 알 수 있어?

변경된 값은 빨간색으로 하이라이트된다.

Step 할 때마다 어떤 값이 바뀌었는지 바로 파악 가능.

// Step 실행 시 nHP = 100; // ← 빨간색 하이라이트 (방금 바뀜) nMP = 50; // ← 일반 (안 바뀜) nHP = 80; // ← Step 후 다시 빨간색

핵심 정리

  • Ctrl+Alt+V, L로 Locals 창 열기
  • 현재 함수의 모든 지역 변수 자동 표시
  • 변경된 값은 빨간색 하이라이트
  • this 포인터도 자동으로 보임
