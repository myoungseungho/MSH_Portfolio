Debug vs Release — 왜 같은 코드가 다르게 동작하는가

Part 1. Debug와 Release의 차이

같은 코드인데 왜 다르게 동작해?

컴파일러가 생성하는 기계어 코드가 완전히 다르기 때문이다.

항목DebugRelease
최적화없음 (/Od)최대 (/O2)
인라인안 함적극적
변수 위치메모리에 유지레지스터 또는 제거
메모리 초기화0xCC/0xCD로 채움쓰레기 값
assert동작제거됨

Part 2. 흔한 원인들

1. 미초기화 변수

Debug에서는 0xCCCCCCCC로 채워져서 조건문이 특정 방향으로 동작하지만, Release에서는 쓰레기 값이라 다른 결과가 나올 수 있다.

int bFlag; // 미초기화 if (bFlag) // Debug: 0xCC → true // Release: 0 or 1 → 불확정!
2. 타이밍 차이

Debug가 느려서 레이스 컨디션이 안 나타나다가 Release에서 나타남.

3. 인라인으로 인한 동작 변화

함수 호출 순서, 스택 배치가 달라져서 버그가 숨거나 나타남.

Part 3. 릴리즈 디버깅 방법

Release에서 디버깅하려면?

1. PDB 생성: Release에서도 /Zi, /DEBUG 옵션으로 심볼 생성

2. 부분 최적화 끄기: 문제 함수에 #pragma optimize("", off)

3. 로깅 추가: printf/OutputDebugString으로 추적

// 특정 함수만 최적화 끄기 #pragma optimize("", off) void ProblematicFunction() { // 이 함수는 최적화 안 됨 } #pragma optimize("", on)

핵심 정리

  • 미초기화 변수가 가장 흔한 원인
  • 타이밍 차이로 레이스 컨디션 발생
  • 인라인/최적화로 코드 동작 변화
  • Release에도 PDB 생성해서 디버깅 가능하게
