Part 1. Profiler 종류

Profiler측정 대상용도
CPU Usage 함수별 실행 시간 느린 함수 찾기
Memory Usage 힙 할당 내역 메모리 누수, 과다 할당
GPU Usage GPU 렌더링 그래픽 병목

Part 2. CPU Profiler 실행

어떻게 실행해?

Debug → Performance Profiler (Alt+F2)

CPU Usage 체크 → Start

// CPU Profiler 결과 예시 Function Self CPU Total CPU ------------------------------------------------ CPlayer::Update() 45.2% 52.1% ← 병목! └─ PathFinding() 35.8% 35.8% ← 여기가 문제 CMonster::Think() 8.3% 12.4% CWorld::Tick() 5.1% 85.2% // Self CPU: 이 함수 자체에서 소요된 시간 // Total CPU: 하위 호출 포함 전체 시간

Part 4. 핫 패스 분석

결과를 어떻게 해석해?

Hot Path를 따라가면 가장 시간을 많이 쓰는 경로를 알 수 있다.

🔥 아이콘이 붙은 함수들이 최적화 대상.

// Hot Path 뷰 🔥 main() [100%] 🔥 CWorld::Tick() [85%] 🔥 CPlayer::Update() [52%] 🔥 PathFinding() [35%] ← 여기 최적화! FindNearestNode() [20%] CalculatePath() [15%] CollisionCheck() [10%] CMonster::Think() [12%]

핵심 정리

  • Alt+F2로 Performance Profiler 열기
  • CPU Usage = 느린 함수 찾기
  • Memory Usage = 누수/과다 할당 찾기
  • Hot Path 따라가면 병목 발견
