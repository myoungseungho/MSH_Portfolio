Application Verifier

힙 손상 즉시 탐지 — Windows SDK 도구

Part 1. Application Verifier란?

힙 손상이 delete에서 터지는데 원인을 못 찾겠어

Application Verifier는 Windows SDK에 포함된 런타임 검증 도구.

힙 손상, 락 문제 등을 발생 즉시 잡아준다.

Part 2. 설치 및 실행

어디서 실행해?

Windows SDK 설치 시 포함됨.

시작 메뉴 → Application Verifier 검색

// 설정 방법 1. Application Verifier 실행 2. File → Add Application → exe 선택 3. Tests 목록에서 체크: ✅ Basics → Heaps (가장 중요!) ✅ Basics → Handles ✅ Basics → Locks 4. Save → 앱 실행 // exe와 같은 이름의 설정이 레지스트리에 저장됨 // 해당 exe 실행 시 자동으로 검증 시작

Part 3. PageHeap (Full)

Heaps 옵션이 뭘 해?

PageHeap은 각 힙 할당을 별도 페이지에 배치한다.

오버런 즉시 Access Violation 발생!

// 일반 힙 구조 [Header][Data......][Header][Data......][Header] ↑ 오버런해도 바로 옆에 있는 데이터를 덮어쓸 뿐 크래시 안 남 (나중에 delete에서 터짐) // PageHeap 구조 [Data......][Guard Page ❌][Data......][Guard Page ❌] ↑ 오버런하면 Guard Page 접근 → 즉시 크래시! // 오버런 발생 시점에 바로 멈춤!

Part 4. 디버거 연결

VS에서 어떻게 같이 쓰?

1. Application Verifier 설정 완료

2. VS에서 Debug로 실행 (F5)

3. 오류 발생 시 VS에서 바로 멈춤

// VS Output 창에 메시지 출력 VERIFIER STOP 00000008: pid 0x1234: Corrupted heap block detected. This verifier stop is continuable. After debugging it use `go' to continue. // Call Stack에서 손상 발생 위치 바로 확인!

Part 5. 주의사항

단점은?

1. 매우 느려짐 (10~100배)

2. 메모리 사용량 증가 (페이지 단위 할당)

3. 문제 재현 후 반드시 설정 해제

핵심 정리

  • Application Verifier = Windows 런타임 검증 도구
  • PageHeap으로 오버런 즉시 감지
  • 힙 손상 발생 시점에서 멈춤
  • 느려지므로 문제 재현 후 해제
