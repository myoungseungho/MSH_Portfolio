변수 값이 이상해요

Watch 창 제대로 쓰는 법 — 포맷 지정자, 표현식 평가

Part 1. Watch 창 열기

Watch 창은 어떻게 열어?

Debug → Windows → Watch (Ctrl+Alt+W, 1~4)

Watch 1~4까지 4개의 탭을 쓸 수 있다.

Part 2. 포맷 지정자

16진수로 보고 싶어

변수명 뒤에 콤마 + 포맷 지정자를 붙인다.

지정자의미예시
,d10진수value,d → 255
,x16진수value,x → 0xff
,o8진수value,o → 0377
,b2진수value,b → 11111111
,sASCII 문자열pStr,s
,su유니코드 문자열pWStr,su
,na배열 펼치지 않기arr,na
,[N]배열 N개만 표시arr,[100]

Part 3. 표현식 평가

계산식도 넣을 수 있어?

Watch 창에는 C++ 표현식을 넣을 수 있다.

// Watch 창에 입력 가능한 것들 pPlayer->m_nHP // 멤버 접근 pPlayer->GetLevel() // 함수 호출 (부작용 주의!) &pPlayer->m_nHP // 주소 얻기 (CMonster*)pEntity // 캐스팅 sizeof(CPlayer) // 크기 pArray[5] // 배열 인덱스 a + b * 2 // 연산

핵심 정리

  • Ctrl+Alt+W, 1로 Watch 창 열기
  • ,x로 16진수, ,d로 10진수 표시
  • 표현식을 넣어서 계산 결과 확인 가능
  • Shift+F9로 QuickWatch 빠르게 열기
