Lua - 게임에 스크립트 언어를 심는 법

왜 게임에 스크립트 언어가 필요하고, 어떻게 연동할까?

Part 1. 왜 스크립트 언어가 필요해?

게임에 왜 스크립트 언어를 넣어?

빠른 반복 개발과 비프로그래머 참여를 위해서예요!

비유: 레고 vs 철골 건물

C++ (엔진) = 철골 건물

  • 한번 만들면 튼튼함
  • 수정하려면? 설계도 수정 → 철거 → 재건축
  • 시간이 오래 걸림

Lua (스크립트) = 레고 블록

  • 마음대로 끼웠다 뺐다
  • 수정하면? 바로 적용!
  • 비개발자도 조립 가능
스크립트 언어의 장점: ┌─────────────────────────────────────────────────────────────┐ │ │ │ [1] 빠른 반복 (Hot Reload) │ │ ───────────────────────────────────────────── │ │ C++ 수정: 코드 수정 → 컴파일(수 분) → 서버 재시작 │ │ Lua 수정: 코드 수정 → 바로 적용! (서버 재시작 없음) │ │ │ │ [2] 비프로그래머 참여 │ │ ───────────────────────────────────────────── │ │ 기획자: "몬스터 체력 100으로 바꿔주세요" │ │ C++: 프로그래머가 수정 → 빌드 → 배포 │ │ Lua: 기획자가 직접 수정 가능! │ │ │ │ [3] 안전한 실행 환경 │ │ ───────────────────────────────────────────── │ │ 스크립트 버그 → 스크립트만 중단, 서버는 계속 동작 │ │ C++ 버그 → 서버 크래시 가능성 │ │ │ │ [4] 유연한 컨텐츠 제작 │ │ ───────────────────────────────────────────── │ │ 퀘스트, AI, 이벤트 등을 스크립트로 정의 │ │ 패치 없이 서버 업데이트 가능 │ │ │ └─────────────────────────────────────────────────────────────┘
왜 하필 Lua야?
언어 크기 속도 임베딩 난이도 게임 채택
Lua ~200KB 빠름 쉬움 WoW, Roblox...
Python 수십MB 보통 보통 일부
JavaScript 수십MB 빠름 어려움 웹 게임
C# (Mono) 수십MB 빠름 보통 Unity
Lua가 인기 있는 이유
• 전체 인터프리터가 ~200KB (초경량)
• C와 연동이 매우 쉬움
• 라이센스 자유로움 (MIT)
• WoW, Roblox, Angry Birds 등 검증된 사례

Part 2. Lua 기초 문법

Lua 문법이 어려워?

아니요! 아주 간단합니다. 기획자도 배우기 쉬워요.

-- 변수 (타입 선언 없음!) name = "Dragon" hp = 100 isAlive = true -- 조건문 if hp > 0 then isAlive = true else isAlive = false end -- 반복문 for i = 1, 10 do print(i) end -- 함수 function Attack(target, damage) target.hp = target.hp - damage return target.hp end -- 테이블 (만능 자료구조!) monster = { name = "Dragon", hp = 500, skills = {"불뿜기", "꼬리치기"} } print(monster.name) -- "Dragon" print(monster.skills[1]) -- "불뿜기" (인덱스 1부터!)
Lua 테이블이 뭐야?

Lua의 유일한 자료구조예요. 배열, 딕셔너리, 객체를 다 표현해요!

-- 배열처럼 items = {"검", "방패", "물약"} print(items[1]) -- "검" -- 딕셔너리처럼 stats = {hp = 100, mp = 50, str = 20} print(stats["hp"]) -- 100 print(stats.hp) -- 100 (같은 의미) -- 객체처럼 (메서드 포함) Player = { name = "Hero", hp = 100, TakeDamage = function(self, damage) self.hp = self.hp - damage end } -- 메서드 호출 (: 사용하면 self 자동 전달) Player:TakeDamage(30) print(Player.hp) -- 70

Part 3. C++과 Lua 연동

C++에서 Lua를 어떻게 실행해?

Lua C API를 사용해서 스택 기반으로 통신해요!

// Lua 초기화 및 스크립트 실행 #include int main() { // 1. Lua 상태 생성 lua_State* L = luaL_newstate(); luaL_openlibs(L); // 표준 라이브러리 로드 // 2. Lua 파일 실행 if (luaL_dofile(L, "script.lua") != LUA_OK) { printf("Lua 에러: %s\n", lua_tostring(L, -1)); } // 3. 정리 lua_close(L); return 0; }
스택이 뭐야?

C++과 Lua가 데이터를 주고받는 통로예요!

Lua 스택 개념: ┌─────────────────────────────────────────────────────────────┐ │ │ │ C++ [스택] Lua │ │ ───── ──── ─── │ │ │ │ C++에서 값을 넣음: ┌─────────┐ │ │ lua_pushinteger(L,10) │ 10 │ ← top (-1) │ │ lua_pushstring(L,"Hi") │ "Hi" │ ← -2 │ │ │ ... │ │ │ └─────────┘ │ │ │ │ Lua 함수 호출: │ │ lua_pcall(L, 2, 1, 0) 2개 인자 전달, 1개 결과 받음 │ │ │ │ 결과 읽기: │ │ int result = lua_tointeger(L, -1); 스택 맨 위에서 읽음 │ │ lua_pop(L, 1); 스택에서 제거 │ │ │ │ 인덱스 규칙: │ │ • 양수: 바닥부터 (1, 2, 3...) │ │ • 음수: 꼭대기부터 (-1, -2, -3...) │ │ │ └─────────────────────────────────────────────────────────────┘
// C++에서 Lua 함수 호출 // script.lua: // function Add(a, b) // return a + b // end int CallLuaAdd(lua_State* L, int a, int b) { // 1. 함수 이름으로 함수를 스택에 푸시 lua_getglobal(L, "Add"); // 2. 인자들을 스택에 푸시 lua_pushinteger(L, a); lua_pushinteger(L, b); // 3. 함수 호출 (인자 2개, 반환값 1개) if (lua_pcall(L, 2, 1, 0) != LUA_OK) { printf("에러: %s\n", lua_tostring(L, -1)); return 0; } // 4. 결과 읽기 int result = lua_tointeger(L, -1); lua_pop(L, 1); // 스택 정리 return result; } // 사용 int sum = CallLuaAdd(L, 10, 20); // 30

Part 4. C++ 함수를 Lua에 노출

반대로 Lua에서 C++ 함수를 부를 수 있어?

네! C++ 함수를 Lua에 등록하면 됩니다.

// C++ 함수 정의 (lua_CFunction 형식) int LuaSpawnMonster(lua_State* L) { // 스택에서 인자 읽기 const char* name = lua_tostring(L, 1); int hp = lua_tointeger(L, 2); int x = lua_tointeger(L, 3); int y = lua_tointeger(L, 4); // C++ 로직 실행 int monsterId = g_MonsterManager.Spawn(name, hp, x, y); // 결과를 스택에 푸시 lua_pushinteger(L, monsterId); return 1; // 반환값 개수 } // Lua에 함수 등록 lua_register(L, "SpawnMonster", LuaSpawnMonster); // 이제 Lua에서 사용 가능! // local id = SpawnMonster("Dragon", 500, 100, 200)
C++ ↔ Lua 양방향 통신: ┌─────────────────────────────────────────────────────────────┐ │ │ │ [C++ → Lua] │ │ ───────────────────────────────────────────── │ │ 1. lua_getglobal(L, "함수명") // 함수 찾기 │ │ 2. lua_push*(L, 인자) // 인자 전달 │ │ 3. lua_pcall(L, n, m, 0) // 호출 │ │ 4. lua_to*(L, -1) // 결과 읽기 │ │ │ │ [Lua → C++] │ │ ───────────────────────────────────────────── │ │ 1. C++ 함수 정의 (lua_CFunction) │ │ 2. lua_register(L, "이름", 함수) // 등록 │ │ 3. Lua에서 이름()으로 호출 │ │ 4. C++ 함수 내에서 lua_to*로 인자 읽음 │ │ 5. lua_push*로 결과 반환 │ │ │ └─────────────────────────────────────────────────────────────┘

Part 5. 게임 서버 실전 패턴

실제 게임에서 어떻게 써?
게임 서버 Lua 활용 영역: ┌─────────────────────────────────────────────────────────────┐ │ │ │ [퀘스트 스크립트] │ │ ───────────────────────────────────────────── │ │ Quest_1001 = { │ │ name = "드래곤 토벌", │ │ condition = function(player) │ │ return player.level >= 10 │ │ end, │ │ onComplete = function(player) │ │ GiveItem(player, "용의검", 1) │ │ GiveExp(player, 1000) │ │ end │ │ } │ │ │ │ [AI 스크립트] │ │ ───────────────────────────────────────────── │ │ function OnThink(monster) │ │ local target = FindNearestPlayer(monster, 10) │ │ if target then │ │ Attack(monster, target) │ │ else │ │ Patrol(monster) │ │ end │ │ end │ │ │ │ [이벤트 스크립트] │ │ ───────────────────────────────────────────── │ │ Event_Christmas = { │ │ start = "2024-12-24", │ │ reward = {gold = 1000, item = "선물상자"} │ │ } │ │ │ └─────────────────────────────────────────────────────────────┘
Hot Reload는 어떻게 해?

서버 재시작 없이 스크립트 갱신!

// Hot Reload 구현 class LuaScriptManager { lua_State* L; public: void ReloadScript(const char* filename) { // 1. 파일 다시 로드 if (luaL_dofile(L, filename) != LUA_OK) { Log("Reload 실패: %s", lua_tostring(L, -1)); return; } Log("스크립트 리로드 완료: %s", filename); } // GM 명령어로 호출 void OnGMCommand(const char* cmd) { if (strcmp(cmd, "/reload quest") == 0) { ReloadScript("scripts/quest.lua"); } } }; // 파일 감시로 자동 리로드 void WatchScripts() { while (true) { if (FileModified("scripts/quest.lua")) { scriptManager.ReloadScript("scripts/quest.lua"); } Sleep(1000); } }

Part 6. 성능과 보안

Lua가 느리지 않아?

순수 Lua는 C++보다 느리지만, 적절히 사용하면 문제없어요!

작업 순수 Lua LuaJIT C++
숫자 연산 ~30x 느림 ~2x 느림 1x
테이블 접근 ~10x 느림 ~3x 느림 1x
함수 호출 ~50x 느림 ~5x 느림 1x
성능 최적화 가이드
• LuaJIT 사용: 10배 이상 빨라짐
• Hot path는 C++로: 전투 계산, 물리 등
• Lua는 로직만: AI 결정, 퀘스트 조건 등
• 호출 빈도 낮추기: 매 틱 → 0.5초 간격
보안 문제는 없어?

스크립트에서 위험한 기능을 제한해야 해요!

// 안전한 Lua 환경 설정 void SetupSandbox(lua_State* L) { // 위험한 함수 제거 lua_pushnil(L); lua_setglobal(L, "os"); // OS 접근 차단 lua_pushnil(L); lua_setglobal(L, "io"); // 파일 접근 차단 lua_pushnil(L); lua_setglobal(L, "loadfile"); // 외부 파일 로드 차단 // 허용된 함수만 노출 lua_register(L, "GetPlayerHP", SafeGetPlayerHP); lua_register(L, "GiveItem", SafeGiveItem); } // 실행 시간 제한 void LuaHook(lua_State* L, lua_Debug* ar) { static int count = 0; if (++count > 1000000) { luaL_error(L, "스크립트 실행 시간 초과"); } } lua_sethook(L, LuaHook, LUA_MASKCOUNT, 10000);

Part 7. 면접에서 물어보면?

"게임에서 스크립트 언어를 쓰는 이유는?"

✅ 핵심 답변 포인트

1. 빠른 반복 개발

"컴파일 없이 바로 적용되어 퀘스트, AI, 이벤트 등을 빠르게 수정할 수 있습니다. Hot Reload로 서버 재시작 없이 갱신 가능합니다."

2. 비프로그래머 참여

"기획자가 직접 컨텐츠를 수정할 수 있어 개발 병목을 줄입니다."

3. 안전한 실행

"스크립트 버그가 서버 크래시로 이어지지 않고, 샌드박스로 위험한 기능을 제한할 수 있습니다."

4. 역할 분리

"핵심 로직(전투, 물리)은 C++로, 컨텐츠 로직(퀘스트, AI)은 Lua로 분리하여 각각의 장점을 활용합니다."

핵심 숫자는?
핵심 숫자 정리: ┌─────────────────────────────────────────────────────────────┐ │ │ │ [Lua 특성] │ │ • 전체 크기: ~200KB (초경량) │ │ • 메모리 사용: 수십KB per state │ │ │ │ [성능 (vs C++)] │ │ • 순수 Lua: 10~50배 느림 │ │ • LuaJIT: 2~5배 느림 │ │ • C++ 호출 오버헤드: ~100 cycles │ │ │ │ [게임 서버 기준] │ │ • AI Think 호출: 0.5~1초 간격이면 OK │ │ • 퀘스트 검사: 이벤트 시점만이면 OK │ │ • Hot path (틱 로직): C++로! │ │ │ │ [채택 사례] │ │ • WoW: UI, 애드온 │ │ • Roblox: 게임 전체 │ │ • Angry Birds: 레벨 스크립트 │ │ │ └─────────────────────────────────────────────────────────────┘

핵심 정리

  • 스크립트 필요성: 빠른 반복, 비프로그래머 참여, 안전한 실행
  • Lua 선택 이유: 초경량 (~200KB), C 연동 쉬움, 검증된 사례
  • 스택 기반 통신: push로 전달, pop으로 읽기
  • 양방향 연동: C++→Lua (pcall), Lua→C++ (register)
  • Hot Reload: 서버 재시작 없이 스크립트 갱신
  • 성능 최적화: LuaJIT 사용, hot path는 C++로
  • 보안: 샌드박스로 위험 함수 제한, 실행 시간 제한
  • 역할 분리: 엔진=C++, 컨텐츠=Lua
