움직이면 시간이 흐른다 - 어떻게 구현할까?

SUPERHOT의 시간-입력 동기화 시스템

Part 1. "Time moves only when you move"

SUPERHOT은 뭐가 특별해?

슬로건이 모든 걸 설명해:

"Time moves only when you move"


플레이어가 움직이면 → 시간이 흐름

플레이어가 멈추면 → 시간도 (거의) 멈춤

완전히 멈춰?

완전히는 아니야.


안 움직여도 시간이 아주 천천히 흘러.

약 1~5% 속도로.


이래야 적 총알이 날아오는 게 보이고,

전술적으로 계획을 세울 수 있으니까.

⏱️ 비유: 턴제 + 액션의 융합

• 체스: 내 차례에만 생각하고 움직임 (턴제)
• 슈팅 게임: 모든 게 실시간으로 진행 (액션)

• SUPERHOT: 내 움직임이 "턴"이 되는 액션 게임
→ 생각할 시간 + 액션의 긴장감을 동시에
이게 기술적으로 어떻게 가능해?

핵심은 Time.timeScale을 동적으로 조절하는 거야.


플레이어 움직임 감지 → 시간 속도 조절

이 간단한 아이디어가 전부야.

Part 2. 플레이어 움직임 감지

"움직임"을 어떻게 정의해?

여러 입력을 종합해서 판단해:


• 이동: WASD, 조이스틱

• 시점 회전: 마우스 움직임

• 액션: 발사, 던지기, 펀치

마우스만 움직여도 시간이 흘러?

맞아. 주변을 둘러보기만 해도.


근데 가중치가 달라:

• 이동 = 시간 빠르게

• 시점 회전 = 시간 중간 속도

• 정지 = 시간 아주 느리게

// 플레이어 움직임 강도 계산 float CalculateMovementIntensity() { float intensity = 0; // 1. 이동 입력 (WASD) Vector2 moveInput = new Vector2( Input.GetAxis("Horizontal"), Input.GetAxis("Vertical") ); intensity += moveInput.magnitude * MOVE_WEIGHT; // 0~1 // 2. 마우스 이동 (시점 회전) Vector2 mouseInput = new Vector2( Input.GetAxis("Mouse X"), Input.GetAxis("Mouse Y") ); intensity += mouseInput.magnitude * LOOK_WEIGHT; // 3. 액션 (발사, 던지기) if (Input.GetButton("Fire")) { intensity += ACTION_WEIGHT; } return Mathf.Clamp01(intensity); // 0~1로 제한 }
입력 없음 → intensity = 0.0 → 시간 거의 멈춤 마우스만 조금 → intensity = 0.3 → 시간 천천히 걷기 → intensity = 0.6 → 시간 보통 달리기 + 발사 → intensity = 1.0 → 시간 실시간

움직임 강도에 따라 시간 속도가 연속적으로 변함

Part 3. Time.timeScale 조절

Unity의 Time.timeScale이 뭐야?

게임 내 시간 흐름 속도를 조절하는 변수야.


• timeScale = 1.0 → 정상 속도

• timeScale = 0.5 → 절반 속도 (슬로우 모션)

• timeScale = 0.0 → 완전 정지 (일시정지)

뭐가 영향받아?

Time.deltaTime을 쓰는 모든 것이 영향받아.


• 물리 시뮬레이션

• 애니메이션

• 파티클 시스템

• 타이머

// SUPERHOT 스타일 시간 조절 void UpdateTimeScale() { float intensity = CalculateMovementIntensity(); // 최소 시간 속도 (완전히 멈추지 않음) float minTimeScale = 0.02f; // 2% // 목표 시간 속도 계산 float targetTimeScale = Mathf.Lerp(minTimeScale, 1.0f, intensity); // 부드럽게 전환 (즉시 변하면 어색함) Time.timeScale = Mathf.Lerp( Time.timeScale, targetTimeScale, Time.unscaledDeltaTime * TRANSITION_SPEED ); }
Time.unscaledDeltaTime은 뭐야?

timeScale의 영향을 안 받는 deltaTime.


timeScale이 0.02여도 unscaledDeltaTime은 정상이야.

UI 애니메이션이나 시간 조절 로직에 사용해.

변수 timeScale 영향 용도
Time.deltaTime 영향받음 게임 로직, 물리
Time.unscaledDeltaTime 영향 안 받음 UI, 시간 조절 로직
Time.fixedDeltaTime 비례해서 조절해야 함 물리 업데이트

Part 4. 시간 영향 안 받는 것들

플레이어는 느려지면 안 되잖아?

맞아. 플레이어 입력은 항상 실시간이어야 해.


안 그러면 마우스 움직였는데 화면이 0.02배 속도로 반응하면...

게임이 안 돼.

어떻게 분리해?

시간 영향 받는 것 / 안 받는 것을 구분해서 처리해.

// 적 이동 (시간 영향 받음) void EnemyUpdate() { // deltaTime 사용 → timeScale 영향 transform.position += velocity * Time.deltaTime; } // 플레이어 카메라 (시간 영향 안 받음) void PlayerLookUpdate() { // unscaledDeltaTime 사용 → 항상 실시간 float mouseX = Input.GetAxis("Mouse X") * sensitivity; transform.Rotate(0, mouseX, 0); } // 플레이어 이동 (하이브리드) void PlayerMoveUpdate() { // 입력은 실시간으로 받되 Vector3 input = GetMoveInput(); // unscaled // 실제 이동은 시간 영향 받을 수도? // SUPERHOT은 플레이어 이동도 즉각 반응함 controller.Move(input * speed * Time.unscaledDeltaTime); }

Part 5. 물리 엔진과 슬로우 모션

물리 엔진은 어떻게 처리해?

Unity 물리는 fixedDeltaTime 간격으로 업데이트돼.


timeScale을 바꾸면 fixedDeltaTime도 같이 조절해야

물리가 자연스럽게 느려져.

// 물리도 함께 느리게 void UpdateTimeScale() { float targetTimeScale = CalculateTargetTimeScale(); Time.timeScale = targetTimeScale; // fixedDeltaTime도 비례해서 조절 Time.fixedDeltaTime = 0.02f * targetTimeScale; }
총알이 느려지면 궤적이 보여?

그게 SUPERHOT의 매력이야.


총알이 천천히 날아오니까:

• 피할 수 있어

• 날아오는 궤적이 보여

• 근데 빨리 움직이면 적도 빨라짐 → 긴장감

총알에 트레일 효과는 어떻게?

Trail Renderer + 시간 보정.


슬로우 모션일 때 트레일이 더 길게 남아야 자연스러워.

// 총알 트레일 void UpdateBulletTrail() { TrailRenderer trail = GetComponent<TrailRenderer>(); // 시간이 느릴수록 트레일 지속시간 증가 // (실제 시간으로는 같아 보이게) trail.time = BASE_TRAIL_TIME / Time.timeScale; }

Part 6. 오디오도 느려져야 할까?

소리도 슬로우 모션으로 재생해?

선택적으로.


모든 소리를 느리게 하면 이상해.

SUPERHOT은 효과음만 느리게, 음악은 정상 속도.

소리를 어떻게 느리게 해?

AudioSource.pitch를 조절해.


pitch = 0.5 → 절반 속도, 낮은 음

pitch = 1.0 → 정상

// 효과음 피치 조절 public class TimeAffectedAudio : MonoBehaviour { AudioSource audioSource; void Update() { // 시간 스케일에 맞춰 피치 조절 audioSource.pitch = Mathf.Max(Time.timeScale, 0.1f); } } // 음악은 영향 안 받게 public class MusicPlayer : MonoBehaviour { AudioSource musicSource; void Start() { // 음악은 항상 정상 피치 musicSource.pitch = 1.0f; } }
오디오 종류 시간 영향 이유
총소리 영향받음 (느리게) 슬로우 모션 몰입감
발소리 영향받음 (느리게) 움직임과 동기화
배경음악 영향 안 받음 느린 음악은 이상함
UI 효과음 영향 안 받음 피드백은 즉각적이어야

📌 핵심 정리

  • 움직임 감지 - 이동, 시점 회전, 액션 입력을 종합해 "강도" 계산
  • Time.timeScale - 움직임 강도에 따라 0.02~1.0 사이로 동적 조절
  • 최소 시간 - 완전히 멈추지 않고 2~5% 속도는 유지 (전술 계획용)
  • 예외 처리 - 플레이어 입력, UI는 unscaledDeltaTime으로 실시간 반응
  • 물리 동기화 - fixedDeltaTime도 timeScale에 비례해서 조절
  • 오디오 - 효과음은 pitch 조절로 느리게, 음악은 정상 속도 유지
