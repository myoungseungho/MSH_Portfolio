# Noita 스타일 픽셀 물리 시뮬레이션 - Win32 GDI

## 빌드 방법

### Visual Studio 2022

1. **솔루션 열기**
   - `NoitaPixelPhysics.sln` 더블클릭

2. **빌드 & 실행**
   - F5 누르기 (또는 Ctrl+F5)

### 커맨드라인

```bash
build.bat   # 빌드
run.bat     # 실행
```

---

## 사용 방법

### 조작법
- **마우스 드래그**: 물질 그리기
- **키보드**:
  - `1`: 모래 (SAND)
  - `2`: 물 (WATER)
  - `3`: 돌 (STONE)
  - `4`: 불 (FIRE)
  - `0`: 지우개 (EMPTY)

### 실험해보기
1. **모래 쌓기**: `1` 누르고 위쪽에 모래 그리기 → 아래로 떨어짐
2. **물 붓기**: `2` 누르고 물 그리기 → 옆으로 퍼짐
3. **댐 만들기**: `3`으로 돌 벽 만들고 물 가두기
4. **불 놓기**: `4`로 모래에 불 붙이기 → 번짐
5. **소화**: 불에 물 붓기 → 증기 발생

## 구현된 기능

### ✅ 물질 타입
- **SAND (모래)**: 아래 + 대각선 낙하
- **WATER (물)**: 아래 + 대각선 + 옆으로 퍼짐
- **STONE (돌)**: 정적 (안 움직임)
- **FIRE (불)**: 위로 상승, 모래 점화, 수명 제한
- **STEAM (증기)**: 위로 상승, 수명 제한

### ✅ 물리 시뮬레이션
- Cellular Automata 방식
- 중력 (아래로)
- 밀도 차이 (모래 > 물)
- 랜덤 방향 (편향 제거)

### ✅ 화학 반응
- 물 + 불 = 증기
- 불 + 모래 = 불 확산 (점화)

### ✅ 최적화
- **청크 시스템** (16×16)
  - 활성 청크만 업데이트
  - Sleep 메커니즘 (10프레임 동안 변화 없으면 비활성화)
- **중복 업데이트 방지**
  - 플래그로 한 프레임에 한 번만 업데이트
- **이웃 청크 활성화**
  - 픽셀 이동 시 주변 청크 깨우기

## 성능

- **해상도**: 200×150 그리드 (30,000 픽셀)
- **청크**: 16×16 (총 117개 청크)
- **FPS**: ~60 (Sleep 16ms)

실제 활성 픽셀이 적을수록 성능 향상:
- 빈 화면: ~0.1% CPU
- 모래 1000개: ~2% CPU
- 전체 화면 물: ~10% CPU

## 코드 구조

```
main_simple.cpp (전체 코드 ~600줄)
├─ 설정 및 전역 변수
├─ Pixel 구조체
├─ Chunk 구조체
├─ 그리드 함수 (IsEmpty, MovePixel, ActivateChunk...)
├─ 물질별 업데이트 (UpdateSand, UpdateWater, UpdateFire...)
├─ 메인 업데이트 루프 (청크 기반)
├─ 렌더링 (Grid → Bitmap → BitBlt)
├─ 마우스 입력
└─ GDI 초기화 / 윈도우 프로시저
```

## 확장 아이디어

- OIL (기름): 물보다 가볍고 불에 잘 탐

- 폭발 효과

### 렌더링 개선
- DirectX/OpenGL로 GPU 가속
- 파티클 효과
- 라이팅 효과

## 문제 해결

### 빌드 에러
→ Windows SDK 설치 필요 (Visual Studio Installer에서 추가)

### 실행 시 검은 화면
→ 윈도우가 제대로 생성되지 않은 것. 관리자 권한으로 실행 시도

### 너무 느림
→ `main_simple.cpp`에서 `0.016`을 `0.033`으로 변경 (30 FPS)
