# 게임에 적용된 기술

게임들이 **어떤 기술로 어떤 콘텐츠를 구현했는지** 분석하는 스터디입니다.

## 목표

- 게임의 핵심 기술 이해하기
- 구현 원리 파악하기
- 직접 구현해보면서 배우기
- 0부터 시작하는 단계별 학습

## 학습 방식

각 게임 분석은 다음 구조로 진행됩니다:

### 📋 01_개요.md
- 게임 소개
- 핵심 특징
- 기술적 도전 과제

### 🔬 02_기술분석.md
- 사용된 핵심 기술
- 왜 이 기술이 필요했나
- 기술적 trade-off

### ⚙️ 03_구현원리.md
- 핵심 알고리즘
- 데이터 구조
- 시스템 아키텍처

### 📚 04_단계별구현.md
- Level 0: 개념 이해
- Level 1: 최소 구현 (MVP)
- Level 2: 기능 추가
- Level 3: 최적화
- Level 4: 고급 기능

### 🔗 05_참고자료.md
- 공식 문서
- 개발자 강연
- 오픈소스 구현
- 참고 논문

## 학습 원칙

### 1. 직접 구현하기
- 읽기만 하지 않기
- 각 단계마다 코드 작성
- 실행 가능한 프로토타입 만들기

### 2. 근본부터 이해하기
- "왜?"를 계속 묻기
- 핵심 원리 파악
- 겉핥기 금지

### 3. 단계별 접근
- 한 번에 완성하려 하지 않기
- 작은 것부터 차근차근
- 각 단계마다 작동하는 것 만들기

### 4. 실험하기
- 코드 바꿔보기
- 극단적으로 테스트하기
- 한계 찾아보기
