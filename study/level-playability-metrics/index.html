레벨 디자인 품질을 어떻게 수치로 판정할까?

동선, 시야, 전투 흐름을 플레이 가능성 지표로 바꾸는 기준

레벨 병목을 찾는 관점

이 주제는 왜 자꾸 추상적으로 느껴질까?

레벨은 예뻐도 못 지나가면 실패야. 플레이 가능성을 먼저 측정해야 해.

핵심: 추상 판단을 기준어와 지표로 쪼개면 초보자도 바로 실행할 수 있어.

놀이공원 동선 비유

지도는 예쁜데 길이 막히면 바로 불만이 쌓이듯, 레벨도 동선이 먼저야.

시각화: 문제를 구조화하는 시작점

모호한 목표를 구조화하면 에이전트가 같은 방향으로 움직인다.

지금까지 한 줄 요약: 오해를 먼저 분해해야 학습 속도가 붙는다.

레벨 분석 용어 카드

처음 보는 용어가 많으면 어디서부터 읽어야 해?

아래 용어 카드에서 각 개념을 정의 → 필요 이유 → 미사용 리스크 순서로 읽으면 된다.

이 순서가 정리되면 직무가 달라도 같은 문장으로 대화할 수 있다.

동선 완주율 (Path Completion)

정의: 시작점에서 목표까지 도달한 비율

왜 필요: 길막 구간을 조기 탐지하려고

없으면: 출시 직전 이동 불가 구간이 터짐

시야 가림률 (Occlusion Rate)

정의: 핵심 정보가 오브젝트에 가려지는 비율

왜 필요: 전투 가독성을 유지하려고

없으면: 피격 원인을 못 보는 상황이 증가

전투 재진입 시간 (Re-entry Time)

정의: 이탈 후 전투 흐름으로 복귀하는 시간

왜 필요: 몰입 끊김을 줄이려고

없으면: 재도전 피로도가 급상승

시각화: 용어 정렬 이후

용어 오해가 줄어들면 수정 요청의 왕복이 줄어든다.

지금까지 한 줄 요약: 용어 정의를 합의해야 지표가 제대로 작동한다.

플레이 가능성 지표

지표는 어떻게 정해야 초보자도 바로 쓸 수 있어?

처음엔 5개 내외가 좋아. 너무 많으면 운영이 무거워져.

측정 가능 + 행동 연결 가능 조건을 충족하는 지표만 남겨야 실제로 굴러간다.

  • 동선 완주율: 플레이봇 시나리오 성공률 (목표: 95% 이상, 미달 시: 실패 구간 경로 재배치)
  • 길막 발생률: 충돌/낙하로 진행 중단된 비율 (목표: 3% 이하, 미달 시: 충돌체와 점프 구간 보정)
  • 시야 가림률: 핵심 대상 가림 비율 (목표: 20% 이하, 미달 시: 오브젝트 밀도 재조정)
  • 재진입 시간: 복귀까지 평균 시간 (목표: 12초 이하, 미달 시: 리스폰/루트 단축)
  • 재시도 이탈률: 재도전 직후 이탈 비율 (목표: 10% 이하, 미달 시: 난이도 곡선 완화)

시각화: 지표 기반 판정 루프

지표는 보고용 숫자가 아니라 다음 행동을 정하는 기준이다.

리워크 실행 절차

그래서 지금 당장 어떤 순서로 실행하면 돼?

아래 순서를 그대로 작업 티켓으로 나눠 실행하면 된다.

각 단계 완료 시 지표를 다시 측정해서 통과 여부를 확인한다.

  1. 핵심 동선 시나리오 20개 정의
  2. 플레이봇 로그로 성공/실패 분류
  3. 가림률 카메라로 전투 장면 채점
  4. 병목 구간 자동 티켓 발행
  5. 수정 후 동일 시나리오 재검증

시각화: 실행 루프가 고정된 상태

순서가 고정되면 에이전트가 밤에도 같은 리듬으로 협업한다.

지금까지 한 줄 요약: 실행 순서와 통과 기준을 함께 고정해야 자동 협업이 유지된다.

검수 시나리오 연습

주차학습/실행산출물
1주차동선 시나리오 작성동선 테스트셋
2주차가시성 규칙 정리시야 체크표
3주차플레이봇 계측 연결레벨 지표판
4주차병목 구간 반복 튜닝개선 로그
주차는 고정 규칙이 아니라 추천 순서다. 현재 팀 상황에 맞게 압축해서 써도 된다.

📌 핵심 정리

  • 레벨 품질은 미감보다 플레이 가능성 지표가 우선
  • 완주율/가림률/재진입 시간을 고정하면 병목이 드러남
  • 플레이봇 + 사람 리뷰 조합이 가장 효율적
  • 병목 티켓 자동화로 야간 개선 효율이 올라감
