소스 없이 중단점 걸기

함수 중단점 — 이름만 알면 된다

Part 1. 함수 중단점이란?

소스 파일을 안 열고 중단점을 걸 수 있어?

함수 이름만 알면 중단점을 걸 수 있다.

소스 파일이 열려 있지 않아도, 파일 위치를 몰라도 된다.

Part 2. 설정 방법

어떻게 설정해?

Debug → New Breakpoint → Function Breakpoint

또는 Ctrl+B

// 함수 이름 형식 // 일반 함수 DoSomething // 클래스 멤버 함수 CPlayer::TakeDamage // 네임스페이스 포함 MyGame::CPlayer::TakeDamage // 오버로드된 함수 (파라미터 지정) CPlayer::SetHP(int) // 모든 오버로드 CPlayer::SetHP

Part 3. 활용 사례

언제 쓰면 좋아?

1. 파일 위치를 모를 때

2. 가상 함수를 모든 파생 클래스에서 잡고 싶을 때

3. 템플릿 함수의 특정 인스턴스화를 잡을 때

4. DLL 함수를 잡고 싶을 때

// 예: malloc 호출을 모두 잡고 싶다 함수 이름: malloc // 예: 특정 클래스의 소멸자를 잡고 싶다 함수 이름: CPlayer::~CPlayer // 예: Windows API 호출을 잡고 싶다 함수 이름: CreateFileW

Part 4. 주의사항

심볼이 필요해?

PDB 심볼이 있어야 함수 이름으로 찾을 수 있다.

Windows DLL은 Microsoft Symbol Server에서 다운로드 가능.

핵심 정리

  • Ctrl+B로 함수 중단점 설정
  • 함수 이름만 알면 됨
  • 가상 함수, DLL 함수에도 사용 가능
  • PDB 심볼 필요
