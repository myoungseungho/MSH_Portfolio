STL 코드로 들어가지 않게

Just My Code — 내 코드만 디버깅하기

Part 1. 문제 상황

F11 눌렀더니 vector 내부로 들어갔어

Step Into(F11)는 모든 함수로 진입한다.

STL, 라이브러리, Windows API 내부까지 다 들어간다.

// 이 줄에서 F11 누르면... m_vecPlayers.push_back(pPlayer); // vector의 내부 구현으로 들어감 // _Vector_alloc → allocator → ... // 원래 보고 싶던 건 pPlayer가 잘 들어가는지인데!

Part 2. Just My Code 설정

해결 방법은?

Tools → Options → Debugging → General

✅ Enable Just My Code 체크

// Just My Code 켜면 m_vecPlayers.push_back(pPlayer); // F11 → 다음 줄로 DoSomething(); // F11 → DoSomething 안으로 // 내 코드만 Step Into 됨!

Part 3. 일시적으로 끄기

가끔은 라이브러리 코드도 보고 싶어

Call Stack에서 [External Code] 더블클릭하면 볼 수 있다.

또는 특정 함수에서 Shift+Alt+F11 (Step Into Specific)

Part 4. 추가 필터링

특정 모듈만 건너뛰고 싶어

Debug → Options → Debugging → Symbols에서 모듈별 설정 가능.

또는 .natstepfilter 파일로 커스텀 필터 정의.

// .natstepfilter 예시 (XML) <StepFilter> <Function>std::*</Function> <Function>boost::*</Function> </StepFilter>

핵심 정리

  • Just My Code = STL/라이브러리 건너뛰기
  • Options → Debugging → Enable Just My Code
  • 외부 코드 보려면 [External Code] 더블클릭
  • Step Into Specific으로 선택적 진입
