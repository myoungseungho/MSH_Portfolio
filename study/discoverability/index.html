왜 내 사이트는 Google에 안 뜰까?

공개와 발견은 다르다 - 웹의 발견 가능성 (Discoverability)

Part 1. Google은 웹사이트를 어떻게 알까?

Google에서 "맛있는 피자집"을 검색하면 수백만 개의 결과가 나오잖아. Google은 이걸 어떻게 미리 알고 있어?

Googlebot이라는 프로그램(크롤러)이 24시간 자동으로 웹사이트를 돌아다니면서 수집해.

링크 → 링크 → 링크 타고 계속 이동하면서 페이지를 발견하고 저장해.

Googlebot의 동작 방식: 1. 이미 알고 있는 사이트 방문 2. 페이지 내용 수집 (색인) 3. 페이지 안의 링크 발견 4. 새 링크로 이동 5. 1~4 반복 (무한루프)
그러면 Googlebot이 처음 어디서부터 출발해? 내 GitHub Pages 같은 새 사이트는 어떻게 발견해?

여기서 핵심 개념이 나와:

"공개"와 "발견 가능"은 다른 개념이야.

상태 의미
공개됨 (Public) URL 알면 누구나 접근 가능 ✅
발견 가능 (Discoverable) Googlebot이 찾아올 수 있음 ❓

Part 2. 흔한 오해 - "공개했으니 검색되겠지?"

난 GitHub Pages가 한번 올려두면, 다른 컴퓨터에서도 도메인 입력하면 들어갈 수 있으니까 '공개'되었다고 생각해서 자동으로 Google이 가져올 수 있다고 생각했거든.

그게 핵심 오해야!

🏪 비유: 가게 오픈

당신이 서울 한복판에 가게를 열었어. 문은 열려있고, 누구나 들어올 수 있어. (공개)

그런데 간판도 없고, 지도 앱에도 안 뜨고, 아무도 이 가게를 소개해준 적이 없어.

사람들이 이 가게를 어떻게 알고 찾아와?
그래도 Google이 인터넷 세계 전체를 다 체크할 수 있는 거 아니야?

불가능해. 인터넷에는 "전체 웹사이트 목록"이 존재하지 않아.

있는 것 없는 것
개별 서버에 있는 파일들 중앙 관리 목록
각자 만든 URL들 "누가 뭘 만들었는지" 전체 명단
🏠 비유: 비밀 방

전 세계 모든 사람이 자기 집 지하실에 비밀 방을 만들 수 있어.
그 방 주소(URL)는 본인만 알고 있어.

어떤 기관도 "전 세계 비밀 방 목록"을 갖고 있지 않아.
누군가 알려주거나, 다른 방에서 링크로 연결해줘야 발견됨.

Part 3. 어떻게 발견될 수 있을까?

그러면 Googlebot이 내 사이트를 발견하게 하려면 어떻게 해야 해?

두 가지 방법이 있어:

1. 다른 사이트에서 링크 걸어주기 (자동 발견)

2. Google에 직접 알려주기 (수동 등록)

근데 네이버 블로그나 유튜브는 따로 등록 안 해도 검색에 잘 뜨잖아?

왜냐면 링크 체인이 연결되어 있거든:

유튜브 예시: youtube.com (메인) ← Google이 이미 앎 ↓ 링크 youtube.com/feed/trending (인기 영상) ↓ 링크 youtube.com/watch?v=내영상 (당신의 영상) → Googlebot이 링크 타고 타고 → 자동으로 도착!
당신의 GitHub Pages: ??? ↓ 링크 없음 myoungseungho.github.io/MSH_Portfolio (외딴 섬) → 아무도 링크를 안 걸어줬으니 Googlebot이 올 방법이 없음!
플랫폼 왜 자동 발견?
유튜브, 네이버 블로그 메인 사이트 → 내 콘텐츠로 링크 연결됨
개인 GitHub Pages 아무 데서도 링크 안 걸림 = 외딴 섬

Part 4. 해결 방법 - Google Search Console

그러면 직접 Google한테 알려주면 되는 거네?

정확해!

Google Search Console = Google한테 직접 "내 사이트 여기 있어요!" 알려주는 곳

할 일 의미
소유권 확인 (HTML 파일) "이 사이트 제 거 맞아요" 증명
sitemap.xml 제출 "제 사이트 페이지 목록이에요" 전달
색인 생성 요청 "지금 바로 와서 봐주세요!" 요청

🛠️ 실습: GitHub Pages를 Google에 등록하기

  1. Google Search Console 접속
  2. "URL 접두어"로 사이트 주소 등록
  3. 소유권 확인 (HTML 파일 업로드)
  4. 왼쪽 메뉴 "Sitemaps" → sitemap.xml 제출
  5. "URL 검사" → 메인 URL 입력 → "색인 생성 요청"

보통 1~7일 후 Google 검색에 나타남

Part 5. 추가로 해주면 좋은 것들 (SEO)

Search Console 등록만 하면 끝이야?

기본은 끝이야. 근데 검색 결과에서 더 잘 보이려면 몇 가지 더 해주면 좋아:

추가 작업 효과
<meta name="description"> 검색 결과에 설명 표시
<meta property="og:*"> SNS 공유 시 미리보기
sitemap.xml 페이지 목록을 Google에 전달
robots.txt 크롤러에게 허용/차단 지시
<!-- SEO 메타 태그 예시 --> <meta name="description" content="게임 서버 개발자 포트폴리오"> <meta name="keywords" content="게임서버, MMORPG, C++"> <!-- Open Graph (SNS 공유용) --> <meta property="og:title" content="MSH Portfolio"> <meta property="og:description" content="게임 서버 개발 학습 기록">

📌 핵심 정리: 발견 가능성 (Discoverability)

  • 공개 ≠ 발견 - URL로 접근 가능해도 검색엔진은 모를 수 있음
  • Googlebot은 링크를 타고 이동하며 새 페이지를 발견
  • 외딴 섬처럼 링크가 없으면 발견 불가능
  • 해결책 1: 다른 사이트에서 링크 받기 (자연 발견)
  • 해결책 2: Google Search Console에 직접 등록
  • SEO: 발견된 후 검색 순위를 높이는 최적화
