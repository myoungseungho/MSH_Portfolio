Part 1. PS5 SSD의 혁신

PS5 SSD가 특별해?

읽기 속도: 5.5GB/s (압축 시 9GB/s)

PC NVMe보다 빠른 건 아닌데...

전용 하드웨어가 차이를 만듦!

PS5 스토리지 아키텍처: ┌──────────────────────────────────────┐ │ PS5 SSD (825GB) │ │ 5.5GB/s │ └──────────────────────────────────────┘ ↓ ┌──────────────────────────────────────┐ │ 전용 I/O 컨트롤러 (Kraken) │ │ • 하드웨어 압축 해제 (22GB/s) │ │ • DMA 컨트롤러 │ │ • 메모리 매핑 유닛 │ └──────────────────────────────────────┘ ↓ ┌──────────────────────────────────────┐ │ GPU / RAM (16GB GDDR6) │ └──────────────────────────────────────┘ → CPU 개입 없이 직접 전송!

Part 3. 게임 설계 변화

게임이 어떻게 달라져?

• 로딩 화면 거의 없음

• 순간이동 가능 (래칫 & 클랭크)

• 스트리밍 제약 없이 오픈월드

핵심 정리

  • PS5 SSD = 5.5GB/s + 전용 하드웨어
  • Kraken 하드웨어 압축 해제
  • CPU 부담 0
  • 로딩 화면 거의 없음
