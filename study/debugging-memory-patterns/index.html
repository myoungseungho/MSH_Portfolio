0xCDCDCDCD가 뭐예요?

메모리 패턴 읽기 — Debug 빌드가 남기는 힌트들

Part 1. 왜 이상한 값이 들어있어?

변수 값이 0xCCCCCCCC인데 이게 뭐야?

Debug 빌드에서 Visual Studio는 메모리 상태를 알려주는 특수 패턴을 채워넣는다.

이 패턴을 보면 "이 메모리가 어떤 상태인지" 바로 알 수 있다.

Part 2. 메모리 패턴 총정리

패턴 의미 언제?
0xCCCCCCCC 초기화 안 된 스택 변수 지역 변수 선언만 하고 초기화 안 함
0xCDCDCDCD 초기화 안 된 힙 메모리 new/malloc 후 값을 안 넣음
0xDDDDDDDD 해제된 힙 메모리 delete/free 후 접근 (use-after-free)
0xFEEEFEEE 해제된 힙 (HeapFree) Windows 힙에서 해제된 메모리
0xABABABAB 힙 가드 바이트 (뒤쪽) 버퍼 오버런 감지용 경계
0xBAADF00D LocalAlloc 미초기화 LocalAlloc(LMEM_FIXED) 후
0xFDFDFDFD 힙 가드 바이트 (앞쪽) 힙 블록 앞의 노맨스 랜드

Part 3. 실전 활용

크래시 났는데 값이 0xCCCCCCCC야

지역 변수를 초기화 안 하고 사용했다!

// 문제 코드 void DoSomething() { int* pValue; // 초기화 안 함 → 0xCCCCCCCC *pValue = 10; // 크래시! 0xCCCCCCCC 주소에 쓰려고 함 } // 해결 void DoSomething() { int* pValue = nullptr; // 초기화! // 또는 int* pValue = GetValue(); }
값이 0xDDDDDDDD야

이미 해제된 메모리를 사용하고 있다! (Use-After-Free)

// 문제 코드 CPlayer* pPlayer = new CPlayer(); delete pPlayer; pPlayer->DoSomething(); // 0xDDDDDDDD 접근 → 크래시 // 해결 delete pPlayer; pPlayer = nullptr; // 해제 후 nullptr로! if (pPlayer) pPlayer->DoSomething(); // nullptr 체크
값이 0xFEEEFEEE야

마찬가지로 해제된 메모리다. Windows 힙 매니저가 남긴 패턴.

값이 0xABABABAB야

버퍼 오버런이 의심된다. 배열 경계를 넘어서 썼을 가능성.

// 문제 코드 char buffer[10]; strcpy(buffer, "This is too long!"); // 10바이트 넘음 // 버퍼 뒤쪽의 가드 바이트(0xABABABAB)가 덮어써짐 // → 힙 손상 감지됨

Part 4. 암기법

CC = "Clean" 스택 (아직 안 씀) CD = "Clean" 힙 (new 했지만 안 씀) DD = "Dead" 힙 (죽은 메모리 = 해제됨) FE = "FrEEd" (해제됨) AB = "ABuse" 감지용 (경계 침범 감지) FD = "FenDer" 앞쪽 (앞 경계)

Part 5. Release에서는?

Release 빌드에서도 이 패턴이 보여?

아니다. 이 패턴은 Debug 빌드 전용이다.

Release에서는 이전에 있던 쓰레기 값(garbage)이 그대로 들어있다.

그래서 Debug에서 잘 되다가 Release에서 크래시 나는 경우가 있다!

// Debug에서는 우연히 동작하는 코드 int* pValue; // Debug: 0xCCCCCCCC (명확히 잘못된 값) // Release: 0x00000000일 수도 있음 (우연히 동작!) if (pValue) // Debug: false (0xCC...는 0이 아님) // Release: 때에 따라 다름 // → Debug에서 발견 못 한 버그가 Release에서 터짐

핵심 정리

  • 0xCC = 스택 미초기화 (지역 변수 초기화 안 함)
  • 0xCD = 힙 미초기화 (new 후 값 안 넣음)
  • 0xDD = 해제된 힙 (use-after-free)
  • 0xFE = 해제된 힙 (Windows 힙)
  • 0xAB/0xFD = 힙 가드 (버퍼 오버런 감지)
  • Release에서는 이 패턴 없음 → 다른 버그로 나타남
