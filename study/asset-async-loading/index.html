Part 1. 비동기 로딩이란?

비동기가 뭐야?

로딩을 요청하고 게임은 계속 진행

백그라운드 스레드에서 로딩

완료되면 콜백으로 알려줌

// 비동기 로딩 void Update() { if (NeedNewTexture() && !isLoading) { isLoading = true; // 요청만 하고 바로 리턴 LoadTextureAsync("big.dds", OnTextureLoaded); // 게임은 계속 돌아감! } } void OnTextureLoaded(Texture* tex) { isLoading = false; UseTexture(tex); }

Part 2. 원리

어떻게 동시에 되지?

메인 스레드: 게임 로직 실행

로딩 스레드: 파일 읽기

완료 시 메인 스레드에 통보

스레드 구조: 메인 스레드 (게임 로직) │ Update │ Update │ Update │ Update │ Update │ ↓ 요청 ├──────────────────────────────────────┐ │ │ 로딩 스레드 │ │░░░░░│████████ 파일 읽기 ████████│░░░░░│ │ ↓ 완료 │ 콜백 호출 ◀────┘ → 게임은 안 멈추고 로딩 진행!

Part 3. 주의점

어려운 점은?

1. 로딩 완료 전에 사용하면 안 됨

2. 스레드 안전성 고려

3. 콜백 지옥 주의

// 잘못된 코드 LoadTextureAsync("tex.dds", callback); UseTexture(tex); // ❌ 아직 안 됐는데! // 올바른 코드 LoadTextureAsync("tex.dds", [](Texture* tex) { UseTexture(tex); // ✅ 완료 후 사용 });

Part 4. 로딩 상태

로딩 중인지 어떻게 알아?

로딩 핸들로 상태 체크

또는 플레이스홀더 사용

// 핸들 방식 LoadHandle handle = LoadAsync("tex.dds"); void Update() { if (handle.IsComplete()) { tex = handle.GetResult(); } else { // 로딩 중 - 플레이스홀더 표시 DrawPlaceholder(); } }
