프로그레스 바의 거짓말

진짜 vs 가짜 진행률

Part 1. 진행률의 진실

프로그레스 바가 정확해?

사실 대부분 가짜입니다!

실제 진행률 측정이 어렵기 때문

실제 로딩 vs 표시 진행률: 실제: │░░░░░░██████████████████████████│ ↑ 느림 빠름 ↑ 표시: │████████████████████████████████│ 일정한 속도로 보이게 조작 → 플레이어가 답답하지 않게!

Part 2. 왜 측정이 어려워?

진짜 진행률은 왜 못 보여줘?

1. 파일마다 로딩 시간이 다름

2. 압축 해제 시간 예측 어려움

3. 디스크 상태에 따라 다름

// 파일 개수 기반 (부정확) progress = loadedFiles / totalFiles; // 문제: 1KB 파일이나 1GB 파일이나 1개 // 바이트 기반 (좀 나음) progress = loadedBytes / totalBytes; // 문제: 압축 해제 시간은 별개

Part 3. UX 트릭

그래서 어떻게 해?

1. 빠르게 시작 - 0%에서 50%는 빨리

2. 느리게 마무리 - 90%~100%는 천천히

3. 애니메이션 - 뭔가 움직이게

심리적 프로그레스 바: 실제: ░░░░░░░░░░░░░░░░░████████████████████████ 느림 (초기화) 빠름 (파일 로딩) 보정 후: █████████████████████████████████████████░░░ 빠르게 시작 느리게 마무리 → 처음에 진행되는 느낌! → 마지막에 "거의 다 됐다" 느낌!

Part 4. 다른 방법들

진행률 말고 다른 건?

• 스피너 - 돌아가는 아이콘

• 현재 작업 표시 - "텍스처 로딩 중..."

• 진행률 없이 팁만

핵심 정리

  • 대부분의 진행률은 가짜
  • 실제 로딩 시간 예측 어려움
  • 빠르게 시작, 느리게 마무리 트릭
  • 움직이는 게 중요 (멈춤 ≠ 좋음)
