프로그램이 멈췄어요

무한 루프 탐지 — Break All로 현재 위치 확인

Part 1. 증상

프로그램이 아무 반응이 없어요

두 가지 가능성:

1. 무한 루프 - CPU 100% 사용

2. 데드락 - CPU 0% (스레드가 대기 중)

Part 2. 무한 루프 찾기

어디서 돌고 있는지 어떻게 알아?

1. 실행 중에 Debug → Break All (Ctrl+Alt+Break)

2. 프로그램이 멈추고 현재 실행 위치가 표시됨

3. Call Stack에서 어떤 루프인지 확인

// 흔한 무한 루프 패턴 // 1. 탈출 조건 실수 while (i < 100) { DoSomething(); // i++ 빠뜨림! } // 2. 잘못된 조건 while (pNode != nullptr) { pNode = pNode; // pNode = pNode->next 여야 함! } // 3. 음수 인덱스 for (int i = 10; i >= 0; i++) // i-- 여야 함! { arr[i] = 0; }

Part 3. 루프 디버깅 팁

어떤 값 때문에 안 끝나는지 어떻게 알아?

1. Break All로 멈춘 후 Watch 창에서 루프 변수 확인

2. 종료 조건 표현식을 Watch에 추가

3. 조건부 중단점으로 특정 상태에서 멈추기

// Watch 창에 추가할 것들 i // 현재 인덱스 i < 100 // 조건 결과 (true/false) pNode // 현재 노드 pNode->next // 다음 노드 (nullptr이어야 끝남) iteration_count++ // 실행할 때마다 증가 (몇 번 돌았나)

Part 4. 예방

무한 루프 방지 코드

개발 중에는 안전장치를 넣어두자.

// 안전장치가 있는 루프 int nSafetyCounter = 0; const int MAX_ITERATIONS = 10000; while (pNode != nullptr) { if (++nSafetyCounter > MAX_ITERATIONS) { LOG_ERROR("Possible infinite loop detected!"); ASSERT(false); break; } pNode = pNode->next; }

핵심 정리

  • Ctrl+Alt+Break로 실행 중인 프로그램 멈추기
  • 멈춘 후 Call Stack에서 위치 확인
  • Watch 창에서 루프 변수와 종료 조건 확인
  • 개발 중 안전장치로 예방
