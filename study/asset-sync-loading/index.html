동기 로딩 - 멈추고 기다려

Load() 호출하면 프레임 멈춤

Part 1. 동기 로딩이란?

동기 로딩이 뭐야?

Load() 호출하면 완료될 때까지 기다린다

그 동안 게임은 완전히 멈춤

가장 단순한 방식

// 동기 로딩 void Update() { if (NeedNewTexture()) { // 이 줄에서 0.5초 멈춤! Texture* tex = LoadTexture("big_texture.dds"); // 로딩 끝나야 여기로 옴 UseTexture(tex); } }

Part 2. 문제점

왜 문제야?

로딩하는 동안 프레임이 멈춤

60FPS 게임에서 0.5초 = 30프레임 스킵!

플레이어는 "렉 걸린다"고 느낌

프레임 타임라인: 정상: │16ms│16ms│16ms│16ms│16ms│16ms│ ↑ ↑ ↑ ↑ ↑ ↑ F1 F2 F3 F4 F5 F6 동기 로딩 발생: │16ms│16ms│█████ 500ms █████│16ms│ ↑ ↑ ↑ F1 F2 멈춤! F3 → 30프레임 손실, 화면 버벅임

Part 3. 언제 써?

쓸 때가 있어?

1. 로딩 화면 - 어차피 대기 중

2. 게임 시작 시 - 필수 리소스

3. 디버그/테스트 - 간단하니까

// 적절한 동기 로딩 사용 void LoadingScreen() { ShowLoadingUI(); // 로딩 화면이니까 동기 로딩 OK LoadTexture("player.dds"); LoadMesh("player.fbx"); LoadSound("bgm.ogg"); HideLoadingUI(); StartGame(); }

Part 4. 코드 비교

구현이 어떻게 달라?

동기: 한 줄로 끝

비동기: 요청 + 콜백 필요

// 동기 (간단) Texture* tex = LoadTexture(path); Use(tex); // 비동기 (복잡) LoadTextureAsync(path, [](Texture* tex) { Use(tex); });

핵심 정리

  • 동기 로딩 = 완료까지 대기
  • 로딩 중 프레임 멈춤 (렉)
  • 로딩 화면에서는 OK
  • 게임 중에는 비동기 필요
