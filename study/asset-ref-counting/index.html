Reference Counting

아무도 안 쓰면 해제

Part 1. Reference Counting이란?

레퍼런스 카운팅이 뭐야?

리소스를 몇 군데서 사용하는지 세는 것

카운트가 0이 되면 → 메모리 해제

// 텍스처를 여러 오브젝트가 공유 Texture* tex = LoadTexture("shared.dds"); // refCount = 1 obj1->SetTexture(tex); // refCount = 2 obj2->SetTexture(tex); // refCount = 3 delete obj1; // refCount = 2 delete obj2; // refCount = 1 delete obj3; // refCount = 0 → 텍스처 해제!

Part 2. 동작 원리

어떻게 세?

참조할 때 AddRef() → 카운트 +1

해제할 때 Release() → 카운트 -1

0이 되면 실제 삭제

Reference Counting 흐름: LoadTexture() ↓ ┌─────────────┐ │ refCount: 1 │ ← 생성 └─────────────┘ ↓ AddRef() ┌─────────────┐ │ refCount: 2 │ ← 참조 추가 └─────────────┘ ↓ Release() ┌─────────────┐ │ refCount: 1 │ ← 참조 해제 └─────────────┘ ↓ Release() ┌─────────────┐ │ refCount: 0 │ → DELETE! └─────────────┘

Part 3. 스마트 포인터

C++에서는?

std::shared_ptr이 자동으로 해줌

수동으로 AddRef/Release 안 해도 됨

// shared_ptr 사용 auto tex = std::make_shared(); // refCount = 1 { auto copy = tex; // refCount = 2 } // 스코프 끝 → refCount = 1 tex = nullptr; // refCount = 0 → 자동 삭제!

핵심 정리

  • 사용 횟수를 카운트
  • 카운트 0 → 메모리 해제
  • shared_ptr이 자동 관리
  • 여러 오브젝트가 리소스 공유 가능
