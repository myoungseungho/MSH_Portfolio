애니메이션 변형

수백 명 NPC가 다 다르게 움직이는 비밀

Part 1. 왜 변형이 필요해?

NPC들이 다 똑같이 움직이면 뭐가 문제야?

군무하는 것처럼 어색해 보여!

변형 없는 NPC들: 시간 0.0초: ┌─────────────────────────────────────────┐ │ 🚶 🚶 🚶 🚶 🚶 🚶 🚶 🚶 │ │ (모두 왼발 내밀기) │ └─────────────────────────────────────────┘ 시간 0.5초: ┌─────────────────────────────────────────┐ │ 🚶 🚶 🚶 🚶 🚶 🚶 🚶 🚶 │ │ (모두 오른발 내밀기) │ └─────────────────────────────────────────┘ "군인 훈련처럼 완벽하게 맞춰서 걷네..." "NPC가 아니라 복제 로봇 같아" 변형 적용 후: ┌─────────────────────────────────────────┐ │ 🚶‍ 🚶 🚶 🚶‍ 🚶 🚶 🚶‍ 🚶 │ │ 빠름 느림 보통 보통 빠름 느림 보통 빠름 │ │ (각자 다른 속도와 타이밍) │ └─────────────────────────────────────────┘ "각자 살아있는 것처럼 보여!"

Part 2. 시작 오프셋

가장 간단한 방법이 뭐야?

시작 시간 오프셋(Time Offset)이 가장 쉬워:

시작 오프셋: 같은 걷기 애니메이션 (2초 루프): ┌──────────────────────────────────────────┐ │ │ │ 원본: ├──────────────┤ (0.0초 시작) │ │ NPC 1: ├──────────────┤ (0.0초 시작) │ │ NPC 2: ├──────────────┤ (0.3초 시작)│ │ NPC 3: ├──────────────┤ (0.7초) │ │ NPC 4: ──────┤ (1.2초 시작, 뒤에서 루프)│ │ │ │ 같은 시간에 보면: │ │ NPC 1: 왼발 내밀기 │ │ NPC 2: 양발 모으기 │ │ NPC 3: 오른발 내밀기 │ │ NPC 4: 왼발 올리기 │ │ │ │ 같은 애니메이션인데 다 달라 보임! │ └──────────────────────────────────────────┘
// 시작 오프셋 적용 class AnimationVariation { void SpawnNPC(NPC* npc) { // 랜덤 시작 오프셋 (0 ~ 애니메이션 길이) float animLength = walkAnimation->GetDuration(); float randomOffset = Random::Range(0, animLength); npc->animator->SetTimeOffset(randomOffset); // 또는 ID 기반 (재현 가능) float deterministicOffset = (npc->id % 100) / 100.0f * animLength; npc->animator->SetTimeOffset(deterministicOffset); } }; // Unity에서 void Start() { Animator anim = GetComponent<Animator>(); AnimatorStateInfo state = anim.GetCurrentAnimatorStateInfo(0); // 랜덤 시작점 anim.Play(state.fullPathHash, 0, Random.value); }

Part 3. 속도 변형

걷는 속도도 다르게 할 수 있어?

재생 속도(Playback Speed)를 조절해:

속도 변형: 기준 속도 1.0x: ┌──────────────────────────────────────────┐ │ NPC 1: 0.85x (느리게) - 피곤한 노인 │ │ NPC 2: 1.0x (보통) - 일반인 │ │ NPC 3: 1.15x (빠르게) - 급한 직장인 │ │ NPC 4: 0.95x (살짝) - 여유로운 사람 │ └──────────────────────────────────────────┘ 속도 변형 범위: ┌──────────────────────────────────────────┐ │ 너무 느림 (0.5x) → 슬로모션처럼 어색 │ │ 적정 범위 (0.85~1.15x) → 자연스러움 │ │ 너무 빠름 (1.5x) → 급하게 보임, 어색 │ └──────────────────────────────────────────┘
// 속도 변형 void ApplySpeedVariation(NPC* npc) { // 기본 속도의 ±15% 변형 float baseSpeed = 1.0f; float variation = 0.15f; // 가우시안 분포 (중앙값 근처가 많음) float speed = baseSpeed + Random::Gaussian(0, variation); // 범위 제한 speed = Clamp(speed, 0.85f, 1.15f); npc->animator->SetSpeed(speed); // 이동 속도도 같이 조절! (안 그러면 발 미끄러짐) npc->moveSpeed = npc->baseMoveSpeed * speed; } // 캐릭터 특성에 따른 속도 void ApplyCharacterBasedSpeed(NPC* npc) { switch (npc->type) { case NPCType::ELDERLY: npc->animSpeed = Random::Range(0.7f, 0.85f); break; case NPCType::CHILD: npc->animSpeed = Random::Range(1.1f, 1.3f); // 아이는 빠르게 break; case NPCType::SOLDIER: npc->animSpeed = 1.0f; // 군인은 일정하게 break; default: npc->animSpeed = Random::Range(0.9f, 1.1f); } }

Part 4. Additive 노이즈

좀 더 자연스럽게 할 수 없어?

Additive 노이즈로 미세한 움직임을 추가해:

Additive 노이즈: 기본 걷기 + 노이즈: ┌──────────────────────────────────────────┐ │ │ │ 기본 걷기: 규칙적인 동작 │ │ + 머리 노이즈: 살짝 고개 흔들림 │ │ + 어깨 노이즈: 어깨 살짝 들썩임 │ │ + 팔 노이즈: 팔 흔들림 변형 │ │ ───────────────────────────── │ │ 결과: 자연스러운 걷기! │ │ │ └──────────────────────────────────────────┘ Perlin Noise 기반: ┌──────────────────────────────────────────┐ │ ↗↘ ↗ │ │ ↗ ↘ ↗ ↘ │ │ ──────────────────────→ 시간 │ │ │ │ 노이즈 값이 부드럽게 변하므로 │ │ 갑자기 튀지 않고 자연스러움 │ └──────────────────────────────────────────┘
// Perlin Noise 기반 Additive 노이즈 class AnimationNoise { struct NoiseChannel { float frequency; // 변화 빈도 float amplitude; // 변화 크기 float phase; // 시작 위상 (NPC별로 다르게) }; // 각 뼈대별 노이즈 설정 std::map<std::string, NoiseChannel> boneNoise = { {"Head", {0.5f, 3.0f, 0}}, // 머리: 느리게, 3도 {"Spine", {0.3f, 2.0f, 0}}, // 척추: 더 느리게, 2도 {"LeftArm", {1.0f, 5.0f, 0}}, // 팔: 빠르게, 5도 {"RightArm", {1.0f, 5.0f, 0}}, }; void ApplyNoise(Skeleton* skeleton, float time, int npcId) { for (auto& [boneName, channel] : boneNoise) { Bone* bone = skeleton->FindBone(boneName); if (!bone) continue; // NPC별로 다른 위상 float phase = channel.phase + npcId * 0.1f; // Perlin Noise (부드러운 노이즈) float noiseX = PerlinNoise(time * channel.frequency + phase); float noiseY = PerlinNoise(time * channel.frequency + phase + 100); float noiseZ = PerlinNoise(time * channel.frequency + phase + 200); // -1~1 범위를 각도로 변환 Vector3 rotation( noiseX * channel.amplitude, noiseY * channel.amplitude, noiseZ * channel.amplitude ); // Additive로 적용 bone->localRotation *= Quaternion::Euler(rotation); } } };

Part 5. 절차적 변형

더 다양하게 할 수는 없어?

절차적 변형(Procedural Variation)으로 더 다양한 표현이 가능해:

절차적 변형 기법들: 1. 팔 흔들림 변형 ┌──────────────────────────────────────────┐ │ 원본: 팔을 크게 흔듦 │ │ 변형: 팔 흔들림 크기를 0.5~1.5배 조절 │ │ │ │ 🚶 (큰 팔 흔들림) vs 🚶 (작은 팔 흔들림)│ └──────────────────────────────────────────┘ 2. 걸음폭 변형 ┌──────────────────────────────────────────┐ │ 원본: 표준 걸음폭 │ │ 변형: 걸음폭을 크게/작게 │ │ │ │ 성큼성큼 vs 종종걸음 │ └──────────────────────────────────────────┘ 3. 상체 기울기 ┌──────────────────────────────────────────┐ │ 원본: 똑바로 서서 걸음 │ │ 변형: 살짝 앞으로/뒤로 기울임 │ │ │ │ 급한 사람 (앞으로) vs 느긋한 사람 (뒤로)│ └──────────────────────────────────────────┘
// 절차적 변형 시스템 class ProceduralVariation { struct VariationParams { float armSwingScale; // 팔 흔들림 배율 float strideScale; // 걸음폭 배율 float spineLean; // 상체 기울기 float headBob; // 머리 흔들림 float hipSway; // 골반 흔들림 }; VariationParams GenerateParams(int seed) { Random::SetSeed(seed); VariationParams params; params.armSwingScale = Random::Range(0.7f, 1.3f); params.strideScale = Random::Range(0.9f, 1.1f); params.spineLean = Random::Range(-5.0f, 5.0f); // -5 ~ +5도 params.headBob = Random::Range(0.5f, 1.5f); params.hipSway = Random::Range(0.8f, 1.2f); return params; } void ApplyVariation(Skeleton* skeleton, Animation* anim, VariationParams& params) { // 팔 흔들림 조절 Bone* leftArm = skeleton->FindBone("LeftUpperArm"); Bone* rightArm = skeleton->FindBone("RightUpperArm"); // 원본 회전에서 중립 위치를 빼서 "흔들림"만 추출 Quaternion leftSwing = leftArm->rotation * Inverse(leftArm->bindPose); Quaternion rightSwing = rightArm->rotation * Inverse(rightArm->bindPose); // 흔들림에 배율 적용 leftArm->rotation = leftArm->bindPose * Slerp(Identity, leftSwing, params.armSwingScale); rightArm->rotation = rightArm->bindPose * Slerp(Identity, rightSwing, params.armSwingScale); // 상체 기울기 Bone* spine = skeleton->FindBone("Spine"); spine->rotation *= Quaternion::AngleAxis(params.spineLean, Vector3::Right); // 머리 흔들림 Bone* head = skeleton->FindBone("Head"); float headOffset = sin(time * 2.0f) * params.headBob; head->rotation *= Quaternion::AngleAxis(headOffset, Vector3::Right); } };

Part 6. 실제 적용 전략

수백 명을 다 다르게 하면 성능이?

전략적으로 적용해야 해:

성능 최적화 전략: 1. 거리 기반 변형 LOD ┌──────────────────────────────────────────┐ │ 가까움 (<10m): │ │ - 시작 오프셋 ✓ │ │ - 속도 변형 ✓ │ │ - Additive 노이즈 ✓ │ │ - 절차적 변형 ✓ │ │ │ │ 중간 (10~30m): │ │ - 시작 오프셋 ✓ │ │ - 속도 변형 ✓ │ │ - Additive 노이즈 ✓ (간소화) │ │ - 절차적 변형 ✗ │ │ │ │ 멀리 (>30m): │ │ - 시작 오프셋 ✓ │ │ - 속도 변형 ✗ │ │ - Additive 노이즈 ✗ │ │ - 절차적 변형 ✗ │ └──────────────────────────────────────────┘ 2. 변형 풀(Pool) 사용 ┌──────────────────────────────────────────┐ │ 미리 20~30가지 변형 조합을 준비 │ │ NPC 스폰 시 풀에서 랜덤 선택 │ │ │ │ 장점: 런타임 계산 최소화 │ │ 단점: 완전 랜덤은 아님 │ └──────────────────────────────────────────┘
// 완성된 변형 시스템 class CrowdAnimationSystem { // 변형 프리셋 풀 std::vector<VariationParams> presetPool; void Initialize() { // 30가지 프리셋 미리 생성 for (int i = 0; i < 30; i++) { presetPool.push_back(GenerateParams(i * 12345)); } } void SetupNPC(NPC* npc) { // 1. 시작 오프셋 (항상 적용, 저비용) float offset = Random::Range(0, npc->walkAnim->duration); npc->animator->SetTimeOffset(offset); // 2. 속도 변형 (항상 적용, 저비용) npc->animator->SetSpeed(Random::Range(0.9f, 1.1f)); // 3. 변형 프리셋 할당 int presetIndex = npc->id % presetPool.size(); npc->variationParams = &presetPool[presetIndex]; } void Update() { for (NPC* npc : activeNPCs) { float distance = DistanceToCamera(npc); if (distance < 10.0f) { // 가까우면 모든 변형 적용 ApplyFullVariation(npc); } else if (distance < 30.0f) { // 중간이면 간소화된 변형 ApplySimpleVariation(npc); } // 멀리면 기본 오프셋만 (SetupNPC에서 이미 적용) } } void ApplyFullVariation(NPC* npc) { // Additive 노이즈 animNoise.ApplyNoise(npc->skeleton, time, npc->id); // 절차적 변형 proceduralVar.ApplyVariation(npc->skeleton, npc->variationParams); } void ApplySimpleVariation(NPC* npc) { // 간소화된 노이즈 (머리만) animNoise.ApplyHeadNoiseOnly(npc->skeleton, time, npc->id); } };

핵심 정리

  • 변형 없으면 NPC들이 군무처럼 어색해 보임
  • 시작 오프셋: 가장 쉬움, 같은 애니메이션을 다른 시점에서 시작
  • 속도 변형: 0.85~1.15배 범위가 자연스러움
  • Additive 노이즈: Perlin Noise로 미세한 움직임 추가
  • 절차적 변형: 팔 흔들림, 상체 기울기 등 파라미터화
  • 거리 기반 LOD: 가까운 NPC만 복잡한 변형 적용
  • 프리셋 풀: 미리 생성해서 런타임 비용 절감
