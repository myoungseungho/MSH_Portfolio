LRU 캐시

오래된 놈부터 버려

Part 1. LRU 캐시란?

LRU가 뭐야?

Least Recently Used = 가장 오래 안 쓴 것

메모리가 부족하면 오래된 것부터 삭제

LRU 캐시 동작: 메모리 한도: 100MB [A:20MB] [B:30MB] [C:25MB] [D:25MB] = 100MB (꽉 참) ↑ 가장 오래됨 새로운 E(30MB) 로딩 필요! → A 삭제 (가장 오래 안 씀) → [B:30MB] [C:25MB] [D:25MB] [E:30MB] = 110MB? → 아직 부족하면 B도 삭제!

Part 2. 구현

어떻게 만들어?

더블 링크드 리스트 + 해시맵

최근 사용 → 앞으로 이동

삭제 → 뒤에서부터

class LRUCache { std::list accessOrder; std::unordered_map cache; void Access(Key key) { // 맨 앞으로 이동 (최근 사용) MoveToFront(key); } void Evict() { // 맨 뒤 삭제 (가장 오래됨) RemoveBack(); } };

핵심 정리

  • LRU = 가장 오래 안 쓴 것
  • 메모리 부족 시 오래된 것 삭제
  • 리스트 + 해시맵으로 구현
  • O(1) 접근, O(1) 삭제
