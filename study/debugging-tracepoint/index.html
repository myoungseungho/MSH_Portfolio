printf 디버깅은 그만

Tracepoint — 코드 수정 없이 로그 찍기

Part 1. 문제 상황

로그 찍으려면 코드 수정하고 다시 빌드해야 해

printf나 로그 코드를 추가하면:

1. 코드 수정 → 빌드 → 실행 → 테스트

2. 다시 지우고 → 빌드

→ 시간 낭비!

Part 2. Tracepoint 설정

Tracepoint가 뭐야?

멈추지 않고 메시지만 출력하는 중단점이다.

중단점 우클릭 → Actions → "Log a message"

// 설정 방법 1. 중단점 설정 (F9) 2. 중단점 우클릭 → Actions 3. "Log a message to Output Window" 체크 4. 메시지 입력 5. ✅ "Continue execution" 체크 (멈추지 않음) // 중단점 모양이 ◇ (다이아몬드)로 바뀜

Part 3. 메시지 형식

변수 값도 출력할 수 있어?

{변수명} 형식으로 변수 값을 출력할 수 있다.

특수 키워드도 사용 가능.

// 메시지 예시 // 변수 출력 "Player HP = {m_nHP}, MP = {m_nMP}" // 특수 키워드 $FUNCTION - 현재 함수 이름 $CALLER - 호출한 함수 이름 $CALLSTACK - 전체 콜스택 $TID - 스레드 ID $PID - 프로세스 ID $TICK - 밀리초 타임스탬프 // 실전 예시 "[$TID] $FUNCTION: pPlayer={pPlayer}, HP={pPlayer->m_nHP}"

Part 4. 출력 확인

어디서 볼 수 있어?

Output 창 (Ctrl+Alt+O)에서 확인.

"Show output from" 드롭다운에서 "Debug" 선택.

// Output 창 예시 [1234] CPlayer::TakeDamage: pPlayer=0x12345678, HP=100 [1234] CPlayer::TakeDamage: pPlayer=0x12345678, HP=90 [1234] CPlayer::TakeDamage: pPlayer=0x12345678, HP=80 [5678] CMonster::Attack: damage=10, target=0x12345678

핵심 정리

  • Tracepoint = 멈추지 않는 중단점
  • {변수명}으로 값 출력
  • $FUNCTION, $TID 등 특수 키워드
  • Output 창 (Ctrl+Alt+O)에서 확인
