모든 스레드의 호출 스택 한눈에

Parallel Stacks — 멀티스레드 시각화

Part 1. 문제 상황

스레드가 10개인데 각각 뭐 하는지 모르겠어

Threads 창에서 하나씩 클릭하면서 Call Stack 보기 → 너무 느림!

Parallel Stacks는 모든 스레드를 한 화면에 보여준다.

Part 2. 열기

어떻게 열어?

Debug → Windows → Parallel Stacks

또는 Ctrl+Shift+D, S

Part 3. 읽는 법

이 그래프가 뭐야?

각 상자 = 함수, 화살표 = 호출 관계

상자 안의 숫자 = 그 함수에 있는 스레드 수

// Parallel Stacks 해석 ┌─────────────────────────────────────┐ │ main() [1 thread] │ └──────────────┬──────────────────────┘ │ ┌──────────┴──────────┐ ▼ ▼ ┌─────────┐ ┌─────────────────┐ │ Thread │ │ WorkerThread │ │ Pool[4] │ │ [5 threads] │ └────┬────┘ └────────┬────────┘ │ │ ▼ ▼ ┌─────────┐ ┌─────────────────┐ │WaitFor- │ │ ProcessTask() │ │SingleOb │ │ [5 threads] │ └─────────┘ └─────────────────┘ // 해석: // - 1개 스레드는 main() // - 4개는 ThreadPool에서 대기 중 // - 5개는 WorkerThread에서 ProcessTask() 실행 중

Part 4. 활용

뭘 확인할 수 있어?

1. 데드락 탐지: 여러 스레드가 서로 다른 락에서 대기

2. 병목 확인: 많은 스레드가 같은 함수에 몰려있음

3. 구조 이해: 전체 스레드 구조를 시각적으로 파악

// 데드락 패턴 예시 Thread 1: Lock(A) → WaitForLock(B) Thread 2: Lock(B) → WaitForLock(A) // Parallel Stacks에서 보면: // 두 스레드가 각각 다른 WaitForLock에서 멈춰있음 // → 데드락!

핵심 정리

  • Ctrl+Shift+D, S로 열기
  • 모든 스레드의 콜스택을 한 화면에
  • 상자 = 함수, 숫자 = 스레드 수
  • 데드락, 병목 탐지에 유용
