F10, F11 차이가 뭐야?

Step Over, Step Into — 함수 안으로 들어갈지 말지

Part 1. Step 명령어 총정리

키명령동작언제 쓰나
F10 Step Over 함수 호출을 건너뜀 이 함수 안은 안 봐도 될 때
F11 Step Into 함수 안으로 진입 이 함수 내부를 보고 싶을 때
Shift+F11 Step Out 현재 함수를 빠져나감 이 함수 나머지는 안 봐도 될 때

Part 2. 시각적으로 이해하기

void Main() { int a = 10; // ← 여기서 멈춤 DoSomething(); // F10: 이 줄 전체 실행, 다음으로 // F11: DoSomething() 안으로 진입 int b = 20; } void DoSomething() { int x = 1; // ← F11 누르면 여기로 옴 int y = 2; // ← Shift+F11 누르면 Main()으로 돌아감 }

Part 3. 자주 하는 실수

F11 눌렀는데 이상한 코드로 들어가요

STL이나 라이브러리 코드로 들어간 거다.

Shift+F11로 빠져나오거나, Just My Code를 켜서 방지.

Part 4. 고급: Run to Cursor

특정 줄까지 한 번에 가고 싶어

원하는 줄에서 Ctrl+F10 (Run to Cursor)

임시 중단점을 찍고 F5 누르는 것과 같은 효과.

핵심 정리

  • F10 = 건너뛰기 (함수 안 안 봄)
  • F11 = 들어가기 (함수 안으로)
  • Shift+F11 = 나오기 (현재 함수 탈출)
  • Ctrl+F10 = 커서까지 실행
