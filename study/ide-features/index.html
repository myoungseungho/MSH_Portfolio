IDE 기능 Top 10

개발자가 원하는 IDE 기능

Part 1. 코드 자동완성

자동완성이 왜 중요해?

타이핑 시간 단축과 API 탐색이 핵심입니다:

자동완성의 가치: +----------------------------------------------------------+ | | | 자동완성 없이: | | +----------------------------------------------------+ | | | 1. 함수명 기억해야 함 | | | | 2. 파라미터 순서 기억해야 함 | | | | 3. 오타 가능성 | | | | 4. 문서 찾아봐야 함 | | | +----------------------------------------------------+ | | | | 자동완성 있으면: | | +----------------------------------------------------+ | | | player.Get... | | | | | | | | | +-> GetHealth() : int | | | | +-> GetPosition() : Vector3 | | | | +-> GetInventory() : Inventory* | | | | +-> GetSkillLevel(int) : int | | | | | | | | API 목록 + 타입 정보 + 문서가 한눈에! | | | +----------------------------------------------------+ | | | +----------------------------------------------------------+ 좋은 자동완성의 특징: - 퍼지 매칭: "gethlth" -> GetHealth() - 컨텍스트 인식: 현재 타입에 맞는 것만 - 사용 빈도 학습: 자주 쓰는 것 우선 - 스니펫: for -> for 루프 전체 생성

Part 2. 리팩토링 도구

리팩토링 도구가 뭘 해줘?

코드 구조 변경을 안전하게 자동화합니다:

필수 리팩토링 기능: +----------------------------------------------------------+ | | | 1. Rename (이름 변경) | | +----------------------------------------------------+ | | | 변수/함수/클래스 이름 변경 | | | | 모든 참조 자동 업데이트 | | | | 주석, 문자열 내 참조도 확인 | | | +----------------------------------------------------+ | | | | 2. Extract Method (메서드 추출) | | +----------------------------------------------------+ | | | 선택한 코드 블록 -> 새 함수로 추출 | | | | 파라미터 자동 결정 | | | | 원래 위치에 함수 호출로 대체 | | | +----------------------------------------------------+ | | | | 3. Extract Variable (변수 추출) | | +----------------------------------------------------+ | | | 복잡한 표현식 -> 이름 있는 변수로 | | | | 가독성 향상 | | | +----------------------------------------------------+ | | | | 4. Inline (인라인화) | | +----------------------------------------------------+ | | | 변수/함수를 호출 위치에 펼치기 | | | | Extract의 반대 | | | +----------------------------------------------------+ | | | | 5. Move (이동) | | +----------------------------------------------------+ | | | 클래스/함수를 다른 파일로 이동 | | | | include/import 자동 업데이트 | | | +----------------------------------------------------+ | | | +----------------------------------------------------------+
// Extract Method 예시 // Before: 긴 함수 void ProcessOrder(Order* order) { // 유효성 검사 (20줄) if (order->items.empty()) return; if (order->customer == nullptr) return; if (order->totalPrice < 0) return; // ... 더 많은 검사 // 결제 처리 (15줄) auto payment = CreatePayment(order); payment->Process(); // ... // 배송 처리 (15줄) auto shipping = CreateShipping(order); shipping->Schedule(); // ... } // After: Extract Method 적용 void ProcessOrder(Order* order) { if (!ValidateOrder(order)) return; // 추출됨 ProcessPayment(order); // 추출됨 ScheduleShipping(order); // 추출됨 } bool ValidateOrder(Order* order) { if (order->items.empty()) return false; if (order->customer == nullptr) return false; if (order->totalPrice < 0) return false; return true; }

Part 3. 디버거 통합

IDE 디버거가 왜 좋아?

코드와 실행 상태를 동시에 볼 수 있습니다:

IDE 통합 디버거: +----------------------------------------------------------+ | [파일] [편집] [디버그] [실행] | |----------------------------------------------------------| | 코드 에디터 | 변수 창 | | ----------------------------- | --------------------- | | void Attack(Enemy* e) { | this: | | int dmg = CalcDamage(); | hp: 100 | | -> e->TakeDamage(dmg); | mp: 50 | | if (e->IsDead()) { | e: | | OnKill(e); | hp: 25 | | } | defense: 10 | | } | dmg: 45 | | | | | ----------------------------- | --------------------- | | 호출 스택 | 감시 창 | | ----------------------------- | --------------------- | | > Attack (Player.cpp:42) | e->hp: 25 | | OnClick (UI.cpp:128) | dmg - e->defense: 35 | | EventLoop (Main.cpp:55) | | |----------------------------------------------------------| | [계속] [중단] [스텝오버] [스텝인] [스텝아웃] | +----------------------------------------------------------+ 핵심 기능: - 변수 호버: 커서 올리면 현재 값 표시 - 조건부 브레이크포인트: hp < 10일 때만 멈춤 - Watch 표현식: 복잡한 조건 실시간 감시 - Edit and Continue: 디버깅 중 코드 수정

Part 4. 코드 탐색

큰 프로젝트에서 코드 어떻게 찾아?

코드 탐색 기능이 생산성을 크게 좌우합니다:

코드 탐색 기능: +----------------------------------------------------------+ | | | 1. Go to Definition (정의로 이동) | | +----------------------------------------------------+ | | | 함수 호출 -> F12 -> 함수 정의 위치로 | | | | 변수 사용 -> F12 -> 변수 선언 위치로 | | | +----------------------------------------------------+ | | | | 2. Find All References (모든 참조 찾기) | | +----------------------------------------------------+ | | | 함수 선택 -> Shift+F12 -> 이 함수 호출하는 모든 곳 | | | | 변수 선택 -> 이 변수 사용하는 모든 곳 | | | +----------------------------------------------------+ | | | | 3. Go to Symbol (심볼로 이동) | | +----------------------------------------------------+ | | | Ctrl+T -> "Player" 입력 -> 모든 Player 관련 심볼 | | | | 클래스, 함수, 변수 전부 검색 | | | +----------------------------------------------------+ | | | | 4. Go to File (파일로 이동) | | +----------------------------------------------------+ | | | Ctrl+P -> "player" 입력 -> Player 관련 파일 목록 | | | | 퍼지 매칭 지원 | | | +----------------------------------------------------+ | | | | 5. Call Hierarchy (호출 계층) | | +----------------------------------------------------+ | | | 함수 선택 -> 이 함수를 호출하는 함수들 | | | | -> 이 함수가 호출하는 함수들 | | | +----------------------------------------------------+ | | | +----------------------------------------------------------+ 자주 쓰는 단축키 (VS Code): - F12: 정의로 이동 - Shift+F12: 모든 참조 - Ctrl+T: 심볼 검색 - Ctrl+P: 파일 검색 - Ctrl+Shift+O: 현재 파일 심볼

개발자가 원하는 IDE 기능 Top 10

  • 1. 자동완성: 퍼지 매칭, 컨텍스트 인식
  • 2. 리팩토링: Rename, Extract, Move
  • 3. 디버거 통합: 변수 보기, 브레이크포인트
  • 4. 코드 탐색: Go to Definition, Find References
  • 5. 게임 특화: 셰이더 편집, 에셋 미리보기
  • 6. Git 통합: blame, diff, merge
  • 7. 코드 포맷터: 자동 포맷, 스타일 가이드
  • 8. 정적 분석: 잠재적 버그 경고
  • 9. 테스트 러너: 테스트 실행 및 결과
  • 10. 터미널 통합: 빌드, 스크립트 실행
