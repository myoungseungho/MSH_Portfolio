Part 4. 동적 우선순위

우선순위가 바뀌어?

로딩 큐를 실시간 재정렬

void UpdatePriorities() { for (auto& request : loadQueue) { float dist = Distance(player, request.position); request.priority = CalculatePriority(dist); } // 우선순위 순으로 재정렬 SortByPriority(loadQueue); }

핵심 정리

  • 플레이어가 보는 것 먼저
  • 거리 기반 우선순위 계산
  • 플레이어 이동 시 실시간 재정렬
