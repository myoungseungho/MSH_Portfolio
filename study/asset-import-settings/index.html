임포트 설정의 중요성

같은 원본 에셋이라도 임포트 설정에 따라 메모리와 품질이 10배 이상 차이남

Part 1. 개념: 임포트 설정이란

임포트 설정(Import Settings)이 뭐야?

원본 에셋 파일을 엔진 내부 포맷으로 변환할 때 적용하는 설정이야. 같은 4096x4096 PNG 파일이라도 설정에 따라 런타임 메모리가 64MB가 될 수도 있고 4MB가 될 수도 있어.

[임포트 설정의 영향]

원본 파일: character_diffuse.png (4096×4096, 32bit RGBA)
파일 크기: 약 64MB (비압축)

┌─────────────────────────────────────────────────────────────┐
│                    임포트 설정 비교                          │
├─────────────────────────────────────────────────────────────┤
│ 설정 A (기본값)                                             │
│ ├── Format: RGBA32 (비압축)                                 │
│ ├── Max Size: 4096                                          │
│ ├── Mipmaps: 활성화                                         │
│ └── 런타임 메모리: ~85MB (밉맵 포함)                        │
│                                                              │
│ 설정 B (모바일 최적화)                                      │
│ ├── Format: ASTC 6x6                                        │
│ ├── Max Size: 2048                                          │
│ ├── Mipmaps: 활성화                                         │
│ └── 런타임 메모리: ~7MB (12배 절감!)                        │
│                                                              │
│ 설정 C (UI 아틀라스용)                                      │
│ ├── Format: RGBA Crunched ETC2                              │
│ ├── Max Size: 2048                                          │
│ ├── Mipmaps: 비활성화                                       │
│ └── 런타임 메모리: ~5MB                                     │
└─────────────────────────────────────────────────────────────┘

같은 원본 → 설정에 따라 17배 차이!

플랫폼별로 다른 설정을 적용할 수 있어?

Platform Override로 플랫폼마다 최적 설정을 지정할 수 있어:

[플랫폼별 텍스처 설정 예시]

Default (기본값)
├── Max Size: 2048
├── Format: RGBA32
└── Compression: Normal Quality

Android Override
├── Max Size: 1024          ← 모바일은 더 작게
├── Format: ASTC 6x6        ← 최신 압축
└── Compression: High Quality

iOS Override
├── Max Size: 1024
├── Format: ASTC 6x6
└── Compression: High Quality

Standalone (PC) Override
├── Max Size: 4096          ← PC는 크게 허용
├── Format: DXT5            ← 데스크톱 압축
└── Compression: Normal Quality

Switch Override
├── Max Size: 512           ← 메모리 제한
├── Format: ASTC 8x8        ← 더 높은 압축률
└── Compression: High Quality

[빌드 시 동작]
Android 빌드 → Android Override 적용
iOS 빌드 → iOS Override 적용
Override 없으면 → Default 사용

Part 2. 왜 필요해: 최적화 영향

잘못된 임포트 설정이 얼마나 영향을 줘?

프로젝트 전체 빌드 크기와 메모리의 60~80%가 텍스처야. 임포트 설정 하나가 수백 MB 차이를 만들어:

[실제 프로젝트 분석 - 모바일 RPG 사례]

◆ 최적화 전 (기본 설정)
텍스처 에셋: 1,200개
├── 캐릭터 텍스처: 200개 × 평균 8MB = 1,600MB
├── 환경 텍스처: 500개 × 평균 4MB = 2,000MB
├── UI 텍스처: 300개 × 평균 2MB = 600MB
└── 이펙트 텍스처: 200개 × 평균 1MB = 200MB
총 텍스처 메모리: 4,400MB (4.3GB!)

◆ 최적화 후 (맞춤 설정)
├── 캐릭터: ASTC 4x4, 1024 → 200개 × 1.5MB = 300MB
├── 환경: ASTC 6x6, 512 → 500개 × 0.5MB = 250MB
├── UI: ASTC 4x4, 압축, No Mipmap → 300개 × 0.3MB = 90MB
└── 이펙트: ASTC 8x8, 256 → 200개 × 0.1MB = 20MB
총 텍스처 메모리: 660MB (6.6배 감소!)

[빌드 크기 변화]
최적화 전: APK 1.8GB → 스토어 업로드 불가 (150MB 제한)
최적화 후: APK 450MB → AAB로 분할 가능

[성능 영향]
├── GPU 대역폭: 압축 텍스처는 전송량 감소
├── 로딩 시간: 작은 파일 = 빠른 I/O
└── 배터리: 메모리 접근 감소 = 전력 절약
어떤 설정이 가장 중요해?

Part 3. 실전 적용: 텍스처 임포트 설정

텍스처 압축 포맷을 어떻게 선택해?

플랫폼과 용도에 따라 최적 압축 포맷이 달라:

[플랫폼별 권장 텍스처 포맷]

┌─────────────────────────────────────────────────────────────┐
│                        PC / Standalone                       │
├─────────────────────────────────────────────────────────────┤

┌─────────────────────────────────────────────────────────────┐
│                     Android / iOS (최신)                     │
├─────────────────────────────────────────────────────────────┤
│ 일반 텍스처       │ ASTC 4x4 ~ 8x8    │ 2~8 bits/pixel   │
│ UI (고품질)       │ ASTC 4x4          │ 8 bits/pixel      │
│ 배경 (저품질 OK)  │ ASTC 8x8          │ 2 bits/pixel      │

│ RGBA (알파 있음)   │ ETC2 RGBA         │ 8 bits/pixel      │

코드로 텍스처 설정을 자동화하려면?
using UnityEditor; using UnityEngine; using System.IO; /// <summary> /// 폴더 기반 텍스처 임포트 자동화 /// </summary> public class TextureImportAutomation : AssetPostprocessor { void OnPreprocessTexture() { TextureImporter importer = (TextureImporter)assetImporter; string path = assetPath.ToLower(); // 폴더 경로로 용도 판별 if (path.Contains("/characters/")) { ApplyCharacterSettings(importer); } else if (path.Contains("/ui/") || path.Contains("/sprites/")) { ApplyUISettings(importer); } else if (path.Contains("/environments/")) { ApplyEnvironmentSettings(importer); } else if (path.Contains("/effects/") || path.Contains("/vfx/")) { ApplyEffectSettings(importer); } // 파일명으로 Normal Map 판별 if (path.Contains("_normal") || path.Contains("_n.")) { ApplyNormalMapSettings(importer); } } private void ApplyCharacterSettings(TextureImporter importer) { importer.textureType = TextureImporterType.Default; importer.sRGBTexture = true; importer.mipmapEnabled = true; importer.isReadable = false; importer.streamingMipmaps = true; // Default 설정 importer.maxTextureSize = 2048; importer.textureCompression = TextureImporterCompression.Compressed; // Android 오버라이드 var androidSettings = new TextureImporterPlatformSettings { name = "Android", overridden = true, maxTextureSize = 1024, format = TextureImporterFormat.ASTC_4x4, compressionQuality = (int)TextureCompressionQuality.Normal }; importer.SetPlatformTextureSettings(androidSettings); // iOS 오버라이드 var iosSettings = new TextureImporterPlatformSettings { name = "iPhone", overridden = true, maxTextureSize = 1024, format = TextureImporterFormat.ASTC_4x4, compressionQuality = (int)TextureCompressionQuality.Normal }; importer.SetPlatformTextureSettings(iosSettings); // PC 오버라이드 var pcSettings = new TextureImporterPlatformSettings { name = "Standalone", overridden = true, maxTextureSize = 2048, format = TextureImporterFormat.BC7, compressionQuality = (int)TextureCompressionQuality.Normal }; importer.SetPlatformTextureSettings(pcSettings); Debug.Log($"[TextureImport] 캐릭터 설정 적용: {assetPath}"); } private void ApplyUISettings(TextureImporter importer) { importer.textureType = TextureImporterType.Sprite; importer.sRGBTexture = true; importer.mipmapEnabled = false; // UI는 밉맵 불필요! importer.isReadable = false; // UI는 품질 우선 importer.textureCompression = TextureImporterCompression.CompressedHQ; // 원본 크기 유지 (UI 선명도) importer.maxTextureSize = 4096; // 모바일에서도 높은 품질 var mobileSettings = new TextureImporterPlatformSettings { name = "Android", overridden = true, maxTextureSize = 2048, format = TextureImporterFormat.ASTC_4x4, compressionQuality = (int)TextureCompressionQuality.Best }; importer.SetPlatformTextureSettings(mobileSettings); Debug.Log($"[TextureImport] UI 설정 적용: {assetPath}"); } private void ApplyEnvironmentSettings(TextureImporter importer) { importer.textureType = TextureImporterType.Default; importer.mipmapEnabled = true; importer.streamingMipmaps = true; importer.isReadable = false; // 환경은 압축률 우선 var mobileSettings = new TextureImporterPlatformSettings { name = "Android", overridden = true, maxTextureSize = 512, format = TextureImporterFormat.ASTC_6x6, compressionQuality = (int)TextureCompressionQuality.Normal }; importer.SetPlatformTextureSettings(mobileSettings); } private void ApplyEffectSettings(TextureImporter importer) { importer.textureType = TextureImporterType.Default; importer.mipmapEnabled = true; importer.wrapMode = TextureWrapMode.Clamp; // 이펙트는 작게 importer.maxTextureSize = 256; var mobileSettings = new TextureImporterPlatformSettings { name = "Android", overridden = true, maxTextureSize = 256, format = TextureImporterFormat.ASTC_8x8 }; importer.SetPlatformTextureSettings(mobileSettings); } private void ApplyNormalMapSettings(TextureImporter importer) { importer.textureType = TextureImporterType.NormalMap; importer.sRGBTexture = false; // Normal Map은 Linear! importer.mipmapEnabled = true; Debug.Log($"[TextureImport] Normal Map 설정 적용: {assetPath}"); } }

Part 4. 심화 개념: 모델 임포트 설정

모델(FBX) 임포트 설정에서 중요한 건 뭐야?

모델 임포트는 메시, 리깅, 애니메이션 세 가지 영역이 있어:

├────────────────────────────────────────────────────────────┤
│ Import Animation        │ 애니메이션 데이터 포함 여부     │
│ Anim. Compression       │ Off / Keyframe / Optimal        │
│ Rotation Error         │ 압축 허용 오차 (0.5° 권장)      │
│ Position Error         │ 압축 허용 오차                   │
│ Scale Error            │ 압축 허용 오차                   │
│ Remove Constant Curves │ 변화 없는 키 제거 (크기↓)       │
└────────────────────────────────────────────────────────────┘
모델 임포트 자동화 코드는?
using UnityEditor; using UnityEngine; public class ModelImportAutomation : AssetPostprocessor { void OnPreprocessModel() { ModelImporter importer = (ModelImporter)assetImporter; string path = assetPath.ToLower(); // 공통 설정 importer.importVisibility = false; importer.importCameras = false; importer.importLights = false; importer.meshCompression = ModelImporterMeshCompression.Medium; importer.isReadable = false; importer.meshOptimizationFlags = MeshOptimizationFlags.Everything; // 폴더 기반 분류 if (path.Contains("/characters/")) { ApplyCharacterModelSettings(importer); } else if (path.Contains("/environment/") || path.Contains("/props/")) { ApplyStaticModelSettings(importer); } } private void ApplyCharacterModelSettings(ModelImporter importer) { // 캐릭터는 Humanoid 리깅 importer.animationType = ModelImporterAnimationType.Human; // 애니메이션 임포트 importer.importAnimation = true; importer.animationCompression = ModelImporterAnimationCompression.Optimal; // BlendShape (표정) 필요시만 if (assetPath.Contains("_face")) { importer.importBlendShapes = true; } else { importer.importBlendShapes = false; } Debug.Log($"[ModelImport] 캐릭터 설정 적용: {assetPath}"); } private void ApplyStaticModelSettings(ModelImporter importer) { // 정적 오브젝트는 리깅 불필요 importer.animationType = ModelImporterAnimationType.None; importer.importAnimation = false; importer.importBlendShapes = false; // 높은 압축률 importer.meshCompression = ModelImporterMeshCompression.High; Debug.Log($"[ModelImport] 정적 모델 설정 적용: {assetPath}"); } // 애니메이션 클립 후처리 void OnPostprocessAnimation(GameObject root, AnimationClip clip) { // 루프 설정 자동화 if (clip.name.Contains("idle") || clip.name.Contains("walk") || clip.name.Contains("run")) { AnimationClipSettings settings = AnimationUtility.GetAnimationClipSettings(clip); settings.loopTime = true; AnimationUtility.SetAnimationClipSettings(clip, settings); } } }

Part 5. 고급 패턴: 오디오 임포트 설정

오디오 임포트에서 가장 중요한 설정은?

Load Type이 메모리 사용 패턴을 결정해:

[오디오 Load Type 비교]

◆ Decompress On Load
┌────────────────────────────────────────────────────────────┐
│ 동작: 로드 시 완전히 압축 해제 → 메모리에 PCM 저장        │
│ 메모리: 원본 크기 (큼)                                     │
│ CPU: 재생 시 0, 로드 시 높음                               │
│ 지연: 로드 시 지연, 재생 즉시                              │
│ 용도: 짧고 자주 재생 (UI 사운드, 발걸음)                   │
└────────────────────────────────────────────────────────────┘

◆ Compressed In Memory
┌────────────────────────────────────────────────────────────┐
│ 동작: 압축 상태로 메모리 → 재생 시 실시간 디코딩          │
│ 메모리: 압축 크기 (작음)                                   │
│ CPU: 재생 시 디코딩 부하                                   │
│ 지연: 로드 빠름, 재생 시 약간 지연                        │
│ 용도: 중간 길이 사운드 (대사, 스킬 효과음)                 │
└────────────────────────────────────────────────────────────┘

◆ Streaming
┌────────────────────────────────────────────────────────────┐
│ 동작: 디스크에서 실시간 읽기 + 디코딩                     │
│ 메모리: 버퍼만 (~200KB)                                   │
│ CPU: 재생 시 I/O + 디코딩 부하                            │
│ 지연: 시작 시 버퍼링 필요                                 │
│ 용도: BGM, 긴 대사 (1분 이상)                              │
└────────────────────────────────────────────────────────────┘

[권장 설정 매트릭스]
┌────────────────────────────────────────────────────────────┐
│ 사운드 유형       │ 길이      │ Load Type        │ Format │
├────────────────────────────────────────────────────────────┤
│ UI 클릭/알림     │ < 1초     │ Decompress       │ ADPCM  │
│ 발걸음/타격      │ < 2초     │ Decompress       │ ADPCM  │
│ 스킬 효과음      │ 2~10초   │ Compressed       │ Vorbis │
│ 캐릭터 대사      │ 5~30초   │ Compressed       │ Vorbis │
│ BGM              │ > 1분     │ Streaming        │ Vorbis │
│ 환경음 루프      │ 10~60초  │ Streaming        │ Vorbis │
└────────────────────────────────────────────────────────────┘
오디오 임포트 자동화는?
using UnityEditor; using UnityEngine; public class AudioImportAutomation : AssetPostprocessor { void OnPreprocessAudio() { AudioImporter importer = (AudioImporter)assetImporter; string path = assetPath.ToLower(); // 폴더 기반 분류 if (path.Contains("/bgm/") || path.Contains("/music/")) { ApplyBGMSettings(importer); } else if (path.Contains("/sfx/") || path.Contains("/effects/")) { ApplySFXSettings(importer); } else if (path.Contains("/voice/") || path.Contains("/dialogue/")) { ApplyVoiceSettings(importer); } else if (path.Contains("/ui/")) { ApplyUISettings(importer); } } private void ApplyBGMSettings(AudioImporter importer) { importer.loadInBackground = true; importer.preloadAudioData = false; // Default 설정 var defaultSettings = importer.defaultSampleSettings; defaultSettings.loadType = AudioClipLoadType.Streaming; defaultSettings.compressionFormat = AudioCompressionFormat.Vorbis; defaultSettings.quality = 0.5f; // 50% (BGM은 품질 중요) importer.defaultSampleSettings = defaultSettings; // 모바일 오버라이드 var mobileSettings = defaultSettings; mobileSettings.quality = 0.35f; // 모바일은 더 압축 importer.SetOverrideSampleSettings("Android", mobileSettings); importer.SetOverrideSampleSettings("iPhone", mobileSettings); Debug.Log($"[AudioImport] BGM 설정 적용: {assetPath}"); } private void ApplySFXSettings(AudioImporter importer) { importer.loadInBackground = false; importer.preloadAudioData = true; var defaultSettings = importer.defaultSampleSettings; defaultSettings.loadType = AudioClipLoadType.DecompressOnLoad; defaultSettings.compressionFormat = AudioCompressionFormat.ADPCM; importer.defaultSampleSettings = defaultSettings; // 스테레오가 불필요한 SFX는 모노로 importer.forceToMono = true; Debug.Log($"[AudioImport] SFX 설정 적용: {assetPath}"); } private void ApplyVoiceSettings(AudioImporter importer) { importer.loadInBackground = true; importer.preloadAudioData = false; importer.forceToMono = true; // 대사는 모노로 충분 var defaultSettings = importer.defaultSampleSettings; defaultSettings.loadType = AudioClipLoadType.CompressedInMemory; defaultSettings.compressionFormat = AudioCompressionFormat.Vorbis; defaultSettings.quality = 0.4f; // 샘플레이트 낮추기 (대사는 22kHz로 충분) defaultSettings.sampleRateSetting = AudioSampleRateSetting.OverrideSampleRate; defaultSettings.sampleRateOverride = 22050; importer.defaultSampleSettings = defaultSettings; Debug.Log($"[AudioImport] Voice 설정 적용: {assetPath}"); } private void ApplyUISettings(AudioImporter importer) { importer.loadInBackground = false; importer.preloadAudioData = true; importer.forceToMono = true; var defaultSettings = importer.defaultSampleSettings; defaultSettings.loadType = AudioClipLoadType.DecompressOnLoad; defaultSettings.compressionFormat = AudioCompressionFormat.ADPCM; // UI 사운드는 작게 defaultSettings.sampleRateSetting = AudioSampleRateSetting.OverrideSampleRate; defaultSettings.sampleRateOverride = 22050; importer.defaultSampleSettings = defaultSettings; Debug.Log($"[AudioImport] UI 사운드 설정 적용: {assetPath}"); } }

Part 6. 실무 패턴: 프리셋과 일괄 적용

팀에서 일관된 설정을 유지하려면?

Preset 시스템과 AssetPostprocessor를 조합해:

[임포트 설정 일관성 유지 전략]

◆ 방법 1: Unity Preset 시스템
  Assets/Presets/
  ├── Texture_Character.preset    ← 캐릭터 텍스처 설정
  ├── Texture_UI.preset           ← UI 텍스처 설정
  ├── Texture_Environment.preset  ← 환경 텍스처 설정
  ├── Model_Character.preset      ← 캐릭터 모델 설정
  ├── Model_Static.preset         ← 정적 모델 설정
  └── Audio_BGM.preset            ← BGM 오디오 설정

  사용법:
  1. Inspector에서 설정 조정
  2. 우클릭 → Create Preset
  3. 다른 에셋에 Preset 드래그&드롭

◆ 방법 2: Preset Manager (자동 적용)
  Edit → Project Settings → Preset Manager

  [Add Default Preset]
  Filter: Assets/Textures/Characters/
  Preset: Texture_Character.preset

  → 해당 경로의 새 에셋에 자동 적용!

◆ 방법 3: AssetPostprocessor (코드 기반)
  - 가장 유연함
  - 버전 관리 용이 (.cs 파일)
  - 복잡한 로직 가능

[권장 조합]
├── Preset: 기본값 정의 + 수동 적용
├── Preset Manager: 폴더 기반 자동 적용
└── AssetPostprocessor: 복잡한 규칙 처리

using UnityEditor; using UnityEngine; using System.IO; using System.Linq; public class BulkReimporter { [MenuItem("Tools/Reimport/All Textures in Characters")] public static void ReimportCharacterTextures() { ReimportAssetsInFolder("Assets/Textures/Characters", "*.png", "*.tga", "*.jpg"); } [MenuItem("Tools/Reimport/All Models")] public static void ReimportAllModels() { ReimportAssetsInFolder("Assets/Models", "*.fbx", "*.obj"); } [MenuItem("Tools/Reimport/All Audio")] public static void ReimportAllAudio() { ReimportAssetsInFolder("Assets/Audio", "*.wav", "*.mp3", "*.ogg"); } private static void ReimportAssetsInFolder( string folderPath, params string[] patterns) { if (!Directory.Exists(folderPath)) { Debug.LogError($"폴더 없음: {folderPath}"); return; } var files = patterns .SelectMany(p => Directory.GetFiles(folderPath, p, SearchOption.AllDirectories)) .Distinct() .ToArray(); int total = files.Length; int processed = 0; try { AssetDatabase.StartAssetEditing(); // 배치 모드 foreach (var file in files) { string assetPath = file.Replace("\\", "/"); if (EditorUtility.DisplayCancelableProgressBar( "Reimporting Assets", $"Processing: {Path.GetFileName(file)}", (float)processed / total)) { break; } AssetDatabase.ImportAsset(assetPath, ImportAssetOptions.ForceUpdate); processed++; } } finally { AssetDatabase.StopAssetEditing(); EditorUtility.ClearProgressBar(); } Debug.Log($"재임포트 완료: {processed}/{total}개 에셋"); } } // 설정 변경 후 일괄 적용 도구 public class ImportSettingsValidator { [MenuItem("Tools/Validate/Check Texture Settings")] public static void ValidateTextureSettings() { var guids = AssetDatabase.FindAssets("t:Texture2D", new[] { "Assets/Textures" }); int issues = 0; foreach (var guid in guids) { string path = AssetDatabase.GUIDToAssetPath(guid); var importer = AssetImporter.GetAtPath(path) as TextureImporter; if (importer == null) continue; // Read/Write 체크 if (importer.isReadable) { Debug.LogWarning($"[Warning] Read/Write 활성화: {path}"); issues++; } // UI 텍스처에 Mipmap 체크 if (path.Contains("/UI/") && importer.mipmapEnabled) { Debug.LogWarning($"[Warning] UI에 Mipmap 활성화: {path}"); issues++; } // 과도한 Max Size 체크 if (importer.maxTextureSize > 2048 && !path.Contains("/UI/")) { Debug.LogWarning( $"[Warning] Max Size > 2048: {path} ({importer.maxTextureSize})"); issues++; } } Debug.Log($"검사 완료: {guids.Length}개 텍스처, {issues}개 이슈"); } }

Part 7. 종합 정리: 임포트 설정 체크리스트

실무에서 바로 쓸 수 있는 체크리스트 있어?
[에셋 임포트 설정 완전 체크리스트]

□ 프로젝트 초기 설정
  ├── □ 폴더 구조 정의 (용도별 분류)
  ├── □ 프리셋 생성 (유형별 기본 설정)
  ├── □ Preset Manager 설정 (자동 적용)
  └── □ AssetPostprocessor 작성 (복잡한 규칙)

□ 텍스처 설정
  ├── □ 용도에 맞는 Texture Type 선택
  ├── □ sRGB: 색상=ON, 데이터=OFF
  ├── □ Max Size: 플랫폼별 적절히
  ├── □ Format: 플랫폼 최적 압축
  ├── □ Mipmaps: 3D=ON, UI=OFF
  ├── □ Read/Write: 반드시 OFF (필요시만)
  └── □ Streaming Mipmaps: 큰 텍스처에 활성화

□ 모델 설정
  ├── □ Animation Type: 용도에 맞게 (None/Generic/Humanoid)
  ├── □ Mesh Compression: Medium 이상
  ├── □ Read/Write: OFF
  ├── □ Optimize Mesh: ON
  ├── □ Import BlendShapes: 필요시만
  └── □ Import Visibility/Cameras/Lights: OFF

□ 오디오 설정
  ├── □ Load Type: 길이/용도에 맞게
  ├── □ Compression Format: 용도별 선택
  ├── □ Quality: 균형점 찾기 (0.3~0.5)
  ├── □ Force Mono: 스테레오 불필요시
  └── □ Sample Rate Override: 대사/UI는 22kHz

□ 검증 및 유지보수
  ├── □ 정기적 설정 검증 스크립트 실행
  ├── □ 빌드 크기 리포트 확인
  ├── □ 새 에셋 추가 시 설정 확인
  └── □ .meta 파일 버전 관리 필수
💡 핵심 원칙 3가지:
  1. 용도별 분류: 폴더 구조로 용도 구분, 자동화 기반 마련
  2. 플랫폼 최적화: Override로 플랫폼별 맞춤 설정
  3. 자동화 필수: 수동 설정은 실수의 원인, AssetPostprocessor 활용

핵심 요약: 임포트 설정의 중요성

  • 영향력: 같은 원본이라도 설정에 따라 메모리 10배 이상 차이
  • 텍스처: Max Size, Format, Mipmaps, Read/Write가 핵심
  • 모델: Animation Type, Mesh Compression, Read/Write 체크
  • 오디오: Load Type이 메모리 패턴 결정 (Decompress/Compressed/Streaming)
  • 자동화: AssetPostprocessor로 폴더 기반 자동 설정
  • 일관성: Preset + Preset Manager + 검증 스크립트 조합
