"로딩 중..." 화면의 역사

카트리지에서 SSD까지

Part 1. 카트리지 시대

옛날 게임은 로딩이 없었어?

카트리지는 ROM이라 즉시 접근 가능

CPU가 직접 읽을 수 있어서 로딩 불필요

패미컴, 슈퍼패미컴, N64 시절

카트리지 구조: ┌─────────────────────────────────┐ │ 카트리지 (ROM) │ │ ┌─────────────────────────┐ │ │ │ 게임 데이터 (수 MB) │ │ │ │ 직접 주소 접근 가능 │ │ │ └─────────────────────────┘ │ └─────────────────────────────────┘ ↓ 직접 연결 ┌─────────────────────────────────┐ │ CPU / GPU │ │ (로딩 없이 바로 읽기) │ └─────────────────────────────────┘

Part 2. CD-ROM 시대

CD가 나오면서 바뀌었어?

CD는 용량은 큰데 읽기 속도가 느림

150KB/s ~ 1.2MB/s (1x~8x)

"로딩 중..." 화면의 시작!

읽기 속도 비교: 카트리지 ████████████████████████ 빠름 (직접 접근) CD-ROM ████ 느림 (150KB/s ~ 1.2MB/s) → 데이터를 RAM으로 복사해야 함 → 복사하는 동안 "로딩 중..."

Part 3. HDD/SSD 시대

요즘은?

HDD: 100~200MB/s

SATA SSD: 500MB/s

NVMe SSD: 3,000~7,000MB/s

속도 진화: CD-ROM │█ │ 1MB/s HDD │████████ │ 150MB/s SATA SSD │██████████████████ │ 500MB/s NVMe SSD │████████████████████████████████│ 5,000MB/s+ PS5 SSD │████████████████████████████████│ 5,500MB/s + 전용 압축 해제 하드웨어!

Part 4. 미래

로딩이 완전히 사라질까?

PS5/최신 PC: 거의 즉시 로딩

DirectStorage: GPU가 직접 SSD에서 읽기

하지만 용량도 같이 커져서... 전쟁은 계속!

핵심 정리

  • 카트리지 = ROM, 로딩 불필요
  • CD-ROM부터 "로딩 중..." 시작
  • NVMe SSD는 5,000MB/s+
  • PS5: 전용 하드웨어로 거의 즉시 로딩
