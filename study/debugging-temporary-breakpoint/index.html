임시 중단점 — 깔끔한 디버깅 세션

Part 1. 임시 중단점이란?

한 번 확인하고 나면 중단점 지우는 게 귀찮아

임시 중단점은 한 번 hit되면 자동으로 삭제된다.

디버깅 세션을 깔끔하게 유지할 수 있다.

Part 2. 설정 방법

방법단축키/메뉴설명
Run to Cursor Ctrl+F10 커서 위치까지 실행 (가장 흔히 사용)
Temporary Breakpoint Debug → Toggle Temporary Breakpoint 명시적 임시 중단점
Hit Count = 1 중단점 Conditions에서 설정 1번 후 비활성화 (삭제는 안 됨)

Part 3. Run to Cursor 활용

Ctrl+F10 자주 쓰면 되겠네?

Ctrl+F10은 가장 자주 쓰는 디버깅 명령 중 하나.

"여기까지 빠르게 가고 싶다" → Ctrl+F10

void ProcessGame() { InitSystem(); // ← 현재 위치 LoadData(); PrepareResources(); StartMainLoop(); // ← 여기까지 가고 싶다 Cleanup(); } // 방법 1: F10 3번 눌러서 한 줄씩 // 방법 2: StartMainLoop()에 커서 두고 Ctrl+F10 한 번! // 임시 중단점이 StartMainLoop()에 설정되고 // 거기까지 실행된 후 중단점 삭제됨

Part 4. 활용 팁

언제 쓰면 좋아?

1. 초기화 코드 건너뛰기 - 관심 없는 부분 빠르게 통과

2. 루프 중간에서 탈출 - 특정 반복에서 빠져나오기

3. 일회성 확인 - "여기 한 번만 보면 될 것 같은데"

핵심 정리

  • Ctrl+F10 = Run to Cursor (가장 유용)
  • 한 번 hit 후 자동 삭제
  • 중단점 정리할 필요 없음
  • 초기화 코드 건너뛸 때 편리
