Part 1. 문제 상황

게임 켜면 왜 이렇게 오래 걸려?

가장 단순한 방법: 게임 시작할 때 모든 리소스를 메모리에 올린다

텍스처, 모델, 사운드, 애니메이션... 전부 다!

// 가장 무식한 로딩 방식 void GameStart() { LoadAllTextures(); // 2GB → 30초 LoadAllMeshes(); // 1GB → 20초 LoadAllSounds(); // 500MB → 10초 LoadAllAnimations(); // 300MB → 5초 StartGame(); // 총 65초 후 시작! }

Part 3. 현대에는 불가능

지금은 왜 안 돼?

1. 게임 용량 100GB+

2. RAM은 16~32GB

3. 플레이어 인내심 한계 (3초 법칙)

용량 vs 메모리: 게임 ████████████████████████████████ 150GB RAM ████████ 32GB → 전부 올리는 건 물리적으로 불가능!
