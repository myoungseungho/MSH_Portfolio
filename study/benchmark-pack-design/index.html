레퍼런스 수집, 샷 카드, 통과 조건을 표준화하는 방법

벤치마크 기준을 먼저 고정하기

이 주제는 왜 자꾸 추상적으로 느껴질까?

벤치마크는 많이 모으는 게 아니라 같은 기준으로 다시 쓸 수 있게 만드는 게 핵심이야.

핵심: 추상 판단을 기준어와 지표로 쪼개면 초보자도 바로 실행할 수 있어.

요리 레시피 카드 비유

사진만 많아도 같은 맛이 안 나와. 재료/온도/시간 카드가 있어야 재현 가능해.

시각화: 문제를 구조화하는 시작점

모호한 목표를 구조화하면 에이전트가 같은 방향으로 움직인다.

지금까지 한 줄 요약: 오해를 먼저 분해해야 학습 속도가 붙는다.

벤치마크 용어 카드

처음 보는 용어가 많으면 어디서부터 읽어야 해?

아래 표에서 각 용어를 정의 → 왜 필요한지 → 없으면 생기는 문제 순서로 읽으면 된다.

이 순서가 정리되면 직무가 달라도 같은 문장으로 대화할 수 있다.

용어10초 정의왜 필요한가없으면 생기는 문제
벤치마크 팩 (Benchmark Pack)품질 비교 기준으로 쓰는 참조 묶음팀 전체가 같은 기준으로 판단하려고사람마다 기준이 달라 수정이 무한 반복됨
샷 카드 (Shot Card)카메라 위치/태그/촬영 조건을 적은 규격 카드누가 수집해도 같은 화면을 얻으려고무작위 캡처가 쌓여 비교가 어려워짐
수용 기준 (Acceptance Criteria)통과/반려를 나누는 최소 기준값완료 여부를 감이 아닌 숫자로 판정하려고끝난 작업이 다음 단계에서 되돌아옴

시각화: 용어 정렬 이후

용어 오해가 줄어들면 수정 요청의 왕복이 줄어든다.

지금까지 한 줄 요약: 용어 정의를 합의해야 지표가 제대로 작동한다.

운영 지표판

지표는 어떻게 정해야 초보자도 바로 쓸 수 있어?

처음엔 5개 내외가 좋아. 너무 많으면 운영이 무거워져.

측정 가능 + 행동 연결 가능 조건을 충족하는 지표만 남겨야 실제로 굴러간다.

지표정의목표미달 시 액션
샷 커버리지율필수 장면 목록 대비 확보된 샷 비율90% 이상미달 태그 구간 추가 수집
태그 정확도샷 태그와 실제 장면 의미의 일치율95% 이상오분류 태그 규칙 재학습
중복률유사 샷이 전체에서 차지하는 비율25% 이하중복 제거 필터 강화
재촬영률품질 미달로 다시 찍은 비율15% 이하샷 카드 조건 보정
갱신 지연일최신 팩 발행까지 걸린 지연 일수2일 이하야간 수집 배치 우선순위 상향
[검증 게이트 예시] 1) PR 생성 시 자동 측정 2) 야간 배치 종료 시 재측정 3) 기준 미달 항목 자동 반려 4) 동일 시나리오 재검증 통과 후 병합

시각화: 지표 기반 판정 루프

지표는 보고용 숫자가 아니라 다음 행동을 정하는 기준이다.

주간 실행 루틴

그래서 지금 당장 어떤 순서로 실행하면 돼?

아래 순서를 그대로 작업 티켓으로 나눠 실행하면 된다.

각 단계 완료 시 지표를 다시 측정해서 통과 여부를 확인한다.

  1. 장면 카탈로그 40개 확정
  2. 샷 카드 템플릿 작성(앵커/시간대/태그)
  3. 수집 에이전트가 1차 캡처 수행
  4. 검증 에이전트가 정확도/중복률 점검
  5. 미달 샷 자동 재촬영 후 vN 팩 발행

시각화: 실행 루프가 고정된 상태

순서가 고정되면 에이전트가 밤에도 같은 리듬으로 협업한다.

지금까지 한 줄 요약: 실행 순서와 통과 기준을 함께 고정해야 자동 협업이 유지된다.

📌 핵심 정리

  • 벤치마크는 양이 아니라 재현 가능한 규격이 핵심
  • 샷 카드/수용 기준을 먼저 고정하면 재작업이 줄어듦
  • 커버리지율/정확도/중복률 3지표로 품질을 안정화
  • 수집-검증-재촬영 루프를 자동화하면 밤에도 품질이 쌓임
