Part 1. 어떤 방법들이 있어?

NPC에 LLM 붙이는 방법이 뭐가 있어?

크게 4가지 방법이 있어!

방법 설명 장점 단점
1. 폐쇄형 API
(OpenAI, Claude)		 클라우드에 요청 - 바로 쓸 수 있음
- 품질 최고 		- API 비용
- 인터넷 필요
2. 오픈소스 LLM
(Llama, Mistral)		 내 컴퓨터에서 실행 - 무료!
- 오프라인 가능 		- GPU 필요
- 설치 필요
3. 파인튜닝 캐릭터 스타일로 학습 - 캐릭터 일관성 - 어려움
- 데이터 필요
4. RAG 지식 DB 검색 + 생성 - 정확한 정보 - 추가 구현 필요
🎯 1인 개발자 추천 순서

1 OpenAI API로 빠르게 프로토타입
2 작동 확인 후 Ollama로 무료 전환
3 품질 부족하면 파인튜닝 고려

Part 2. 공학적 기준: 뭘 보고 선택해?

게임에서 중요한 기술 요소가 뭐야?

3가지 핵심 기준!

  • 레이턴시 (응답 속도)
  • 비용
  • 품질 (캐릭터 일관성)

1레이턴시 (응답 속도)

유저 기대치:

├── 즉각 반응: < 200ms (기존 정형 응답 수준)
├── 수용 가능: < 1초  (약간의 타이핑 연출 가능)
├── 불편함:   1~2초  (로딩 표시 필요)
└── 이탈:     > 3초  (게임 흐름 끊김)
방식 평균 레이턴시 비고
GPT-4o 800ms ~ 2s 네트워크 + 처리 시간
GPT-4o-mini 300ms ~ 800ms 가벼운 모델, 추천!
Llama 8B (로컬) 100 ~ 300ms GPU 성능에 따라
Llama 8B (Ollama) 200 ~ 500ms CPU로도 가능

💡 해결책: 스트리밍 출력

글자가 하나씩 나오는 타이핑 효과!

체감 레이턴시를 확 줄일 수 있어.

2비용

실제로 얼마나 들어?

인디 게임 기준 (동시 접속 100명)

가정:
- NPC 대화: 1회/2분/유저
- 평균 토큰: 입력 150 + 출력 80 = 230 토큰

시간당: 100명 × 30회 × 230 = 69만 토큰
일일:   69만 × 24시간 = 1,656만 토큰
월간:   1,656만 × 30일 = 약 5억 토큰
방식 월 비용 (5억 토큰) 평가
GPT-4o ~$7,500 (약 1,000만원) 프로덕션 불가
GPT-4o-mini ~$375 (약 50만원) 소규모 서비스 가능
Claude 3.5 Haiku ~$500 (약 65만원) 소규모 서비스 가능
Llama 8B (자체 GPU) RTX 4090 전기세 (~5만원) 가장 경제적!
📊 결론

프로토타입 → API (빠른 검증)
프로덕션 → 자체 호스팅 (비용 통제)

3품질 (캐릭터 일관성)

좋은 NPC AI의 조건:

├── ✅ 세계관에 맞는 말투 유지
├── ✅ 캐릭터 성격 일관성
├── ✅ 금지된 주제 회피 (현대 기술, 메타 발언)
├── ✅ 적절한 길이의 답변
└── ✅ 게임 내 정보와 일치

시스템 프롬프트 ⭐⭐⭐ 쉬움
Few-shot 예시 ⭐⭐⭐ 쉬움

Part 3. 세계관 유지: 어떻게 통제해?

중세 NPC가 "컴퓨터"라고 말하면 안 되잖아?

시스템 프롬프트가 핵심!

시스템 프롬프트 예시:

당신은 중세 판타지 세계 '아르케니아'의 대장장이 '볼란'입니다.

[캐릭터 설정]
- 나이: 52세, 성별: 남성
- 성격: 과묵하지만 일에 대한 자부심이 강함
- 말투: "~하지", "~다네", 반말 사용
- 전문 분야: 무기 제작, 방어구 수리

[알고 있는 것]
- 마을의 역사와 주민들
- 무기와 방어구의 특성
- 광산과 광석 지식

[절대 모르는 것 - 언급 금지]
- 전기, 컴퓨터, 인터넷, 자동차 등 현대 기술
- 다른 게임이나 현실 세계
- 자신이 NPC라는 사실

[대화 규칙]
- 3문장 이내로 답변
- 모르는 질문은 "글쎄, 그건 잘 모르겠네"
- 절대 사과하지 않음 (AI 티 나는 행동)

[대화 예시]
유저: "좋은 검 추천해줘"
볼란: "오크 사냥이라면 강철검이 낫지. 10골드다."

유저: "인터넷이 뭐야?"
볼란: "뭔 소린지 모르겠네. 술이라도 마셨나?"

출력 가드레일 (후처리)

금지어 필터 (C# 예시):

string[] forbiddenWords = {
    "컴퓨터", "인터넷", "스마트폰", "전기", "자동차",
    "죄송합니다", "AI", "언어모델", "도와드릴게요"
};

string FilterResponse(string text) {
    foreach (var word in forbiddenWords) {
        if (text.Contains(word)) {
            return "글쎄, 그건 잘 모르겠네.";  // 대체 응답
        }
    }
    return text;
}

Part 4. 실전! OpenAI API + Unity

가장 쉬운 방법이 뭐야?

OpenAI API = 가장 빠른 프로토타입!

10분 안에 NPC가 말하게 만들 수 있어.

1API 키 발급

1. https://platform.openai.com 접속
2. 로그인 또는 회원가입
3. 좌측 메뉴 → API Keys
4. "Create new secret key" 클릭
5. 키 복사해서 안전한 곳에 저장!

⚠️ 키는 절대 공개 저장소에 올리지 마!

2Unity 프로젝트 설정

NPCDialogueManager.cs

using UnityEngine;
using UnityEngine.Networking;
using System.Collections;
using System.Text;

public class NPCDialogueManager : MonoBehaviour
{
    [SerializeField] private string apiKey = "sk-...";  // 여기에 키 입력

    [TextArea(10, 20)]
    [SerializeField] private string systemPrompt = @"
당신은 중세 판타지 세계의 대장장이 '볼란'입니다.
- 말투: 반말, ~하지, ~다네
- 성격: 과묵, 무뚝뚝
- 3문장 이내로 답변
- 현대 기술 모름";

    public IEnumerator SendMessage(string playerInput, System.Action<string> onResponse)
    {
        string requestBody = $@"{{
            ""model"": ""gpt-4o-mini"",
            ""messages"": [
                {{""role"": ""system"", ""content"": ""{EscapeJson(systemPrompt)}""}},
                {{""role"": ""user"", ""content"": ""{EscapeJson(playerInput)}""}}
            ],
            ""max_tokens"": 150
        }}";

        using (UnityWebRequest request = new UnityWebRequest(
            "https://api.openai.com/v1/chat/completions", "POST"))
        {
            byte[] bodyRaw = Encoding.UTF8.GetBytes(requestBody);
            request.uploadHandler = new UploadHandlerRaw(bodyRaw);
            request.downloadHandler = new DownloadHandlerBuffer();
            request.SetRequestHeader("Content-Type", "application/json");
            request.SetRequestHeader("Authorization", $"Bearer {apiKey}");

            yield return request.SendWebRequest();

            if (request.result == UnityWebRequest.Result.Success)
            {
                // 간단한 JSON 파싱 (실제로는 JsonUtility 사용 권장)
                string response = request.downloadHandler.text;
                int start = response.IndexOf("\"content\":\"") + 11;
                int end = response.IndexOf("\"", start);
                string content = response.Substring(start, end - start);
                content = content.Replace("\\n", "\n").Replace("\\\"", "\"");

                onResponse?.Invoke(content);
            }
            else
            {
                onResponse?.Invoke("(NPC가 응답하지 않습니다)");
                Debug.LogError(request.error);
            }
        }
    }

    private string EscapeJson(string text)
    {
        return text.Replace("\\", "\\\\")
                   .Replace("\"", "\\\"")
                   .Replace("\n", "\\n")
                   .Replace("\r", "\\r");
    }
}

3테스트용 UI

NPCTestUI.cs

using UnityEngine;
using UnityEngine.UI;
using TMPro;

public class NPCTestUI : MonoBehaviour
{
    [SerializeField] private TMP_InputField inputField;
    [SerializeField] private TMP_Text npcText;
    [SerializeField] private Button sendButton;
    [SerializeField] private NPCDialogueManager dialogueManager;

    private void Start()
    {
        sendButton.onClick.AddListener(OnSendClicked);
        inputField.onSubmit.AddListener((_) => OnSendClicked());
    }

    private void OnSendClicked()
    {
        string input = inputField.text.Trim();
        if (string.IsNullOrEmpty(input)) return;

        inputField.text = "";
        npcText.text = "볼란: (생각 중...)";
        sendButton.interactable = false;

        StartCoroutine(dialogueManager.SendMessage(input, (response) => {
            npcText.text = $"볼란: {response}";
            sendButton.interactable = true;
        }));
    }
}

Part 5. 실전! Ollama + Unity (무료!)

무료로 하고 싶은데?

Ollama = 내 컴퓨터에서 LLM 실행!

API 비용 0원, 인터넷 없이도 가능.

1Ollama 설치

서버 실행:
ollama serve

→ http://localhost:11434 에서 동작!

2Unity 연결

OllamaManager.cs

using UnityEngine;
using UnityEngine.Networking;
using System.Collections;
using System.Text;

public class OllamaManager : MonoBehaviour
{
    private const string OLLAMA_URL = "http://localhost:11434/api/generate";

    [TextArea(10, 20)]
    [SerializeField] private string systemPrompt = @"
당신은 중세 판타지 세계의 대장장이 '볼란'입니다.
말투: 반말, ~하지, ~다네
성격: 과묵하고 무뚝뚝
3문장 이내로 답변하세요.";

    public IEnumerator SendMessage(string playerInput, System.Action<string> onResponse)
    {
        string fullPrompt = $"[시스템]\n{systemPrompt}\n\n[유저]\n{playerInput}\n\n[볼란]";

        string requestBody = $@"{{
            ""model"": ""llama3.1:8b"",
            ""prompt"": ""{EscapeJson(fullPrompt)}"",
            ""stream"": false
        }}";

        using (UnityWebRequest request = new UnityWebRequest(OLLAMA_URL, "POST"))
        {
            byte[] bodyRaw = Encoding.UTF8.GetBytes(requestBody);
            request.uploadHandler = new UploadHandlerRaw(bodyRaw);
            request.downloadHandler = new DownloadHandlerBuffer();
            request.SetRequestHeader("Content-Type", "application/json");

            yield return request.SendWebRequest();

            if (request.result == UnityWebRequest.Result.Success)
            {
                string json = request.downloadHandler.text;
                // "response": "..." 파싱
                int start = json.IndexOf("\"response\":\"") + 12;
                int end = json.IndexOf("\"", start);
                string response = json.Substring(start, end - start);
                response = response.Replace("\\n", "\n");

                onResponse?.Invoke(response);
            }
            else
            {
                onResponse?.Invoke("(NPC가 응답하지 않습니다)");
                Debug.LogError(request.error);
            }
        }
    }

    private string EscapeJson(string text)
    {
        return text.Replace("\\", "\\\\")
                   .Replace("\"", "\\\"")
                   .Replace("\n", "\\n");
    }
}

Part 8. 테스트 시나리오

뭘 테스트해야 해?

NPC가 제대로 작동하는지 확인하는 4가지 시나리오!

[테스트 1: 정상 대화]

유저: "좋은 검 있어?"
기대: 무기 관련 자연스러운 답변
예시: "강철검이 있지. 10골드다."

→ PASS: 캐릭터답게 대답함

[테스트 2: 세계관 위반 시도]

유저: "컴퓨터 게임 추천해줘"
기대: 모른다고 하거나 무시
예시: "뭔 소린지 모르겠네."

→ PASS: 현대 기술 언급 안 함
→ FAIL: "요즘 인기있는 게임은..." (필터링 필요)

[테스트 3: 캐릭터 일관성]

유저: "너 누구야?"
기대: 대장장이로서 자기소개
예시: "난 볼란. 이 마을 대장장이지."

→ PASS: 설정대로 답변
→ FAIL: "저는 AI 언어모델입니다" (시스템 프롬프트 강화)

[테스트 4: 대화 맥락 유지]

유저: "강철검 얼마야?"
NPC: "10골드다."
유저: "그거 살게"
기대: 이전 대화 기억하고 응답
예시: "좋아, 강철검 가져가게."

→ PASS: 맥락 유지
→ FAIL: "뭘 사시겠습니까?" (히스토리 관리 필요)
