데이터 파이프라인 용어 카드

처음 보는 용어가 많으면 어디서부터 읽어야 해?

아래 표에서 각 용어를 정의 → 왜 필요한지 → 없으면 생기는 문제 순서로 읽으면 된다.

이 순서가 정리되면 직무가 달라도 같은 문장으로 대화할 수 있다.

용어10초 정의왜 필요한가없으면 생기는 문제
정본 (Source of Truth)최종 신뢰 원본 저장소충돌 시 복구 기준을 명확히 하려고저장소마다 다른 정답을 주장
적재 지연 (Ingest Lag)이벤트 발생부터 저장 완료까지 지연실시간 운영 의사결정 가치를 유지하려고대시보드가 과거 데이터로 오판 유도
정합성 배치 (Reconciliation Job)정본과 파생 데이터 차이를 비교/복구하는 작업데이터 드리프트를 주기적으로 교정하려고누적 오차가 장기 장애로 확산

정합성/지연 운영 지표

지표는 어떻게 정해야 초보자도 바로 쓸 수 있어?

처음엔 5개 내외가 좋아. 너무 많으면 운영이 무거워져.

측정 가능 + 행동 연결 가능 조건을 충족하는 지표만 남겨야 실제로 굴러간다.

지표는 보고용 숫자가 아니라 다음 행동을 정하는 기준이다.

데이터 복구 실행 절차

그래서 지금 당장 어떤 순서로 실행하면 돼?

아래 순서를 그대로 작업 티켓으로 나눠 실행하면 된다.

각 단계 완료 시 지표를 다시 측정해서 통과 여부를 확인한다.

  1. 엔티티별 정본 저장소 선언
  2. 로그 스키마 버전 고정
  3. 적재 지연 알림 임계값 설정
  4. 정합성 배치 주기 실행
  5. 불일치 건 자동 재처리 + 리포트
