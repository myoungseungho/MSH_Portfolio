스타일 1: 카드형 (현재)

스타일 2: 아코디언 (그라데이션)

왜 코어 x 2인가?

보라색 그라데이션 헤더로 시선을 끄는 스타일. 화살표가 회전하는 애니메이션 포함.

스타일 3: 미니멀 라인

왜 코어 x 2인가?

왼쪽 초록색 라인으로 포인트를 주는 미니멀한 스타일. 화살표가 방향 전환.

스타일 4: 말풍선 (Tooltip)

왜 코어 x 2인가?

버튼처럼 생긴 트리거와 말풍선 형태의 내용. 호버시 살짝 떠오르는 효과.

스타일 5: 다크 테마

왜 코어 x 2인가?

개발자 친화적인 다크 테마. 코드 블록과 잘 어울림.

스타일 6: 네온 글로우

왜 코어 x 2인가?

사이버펑크 느낌의 네온 글로우 효과. 테크니컬한 느낌 강조.

스타일 7: 노트/메모

왜 코어 x 2인가?

포스트잇이나 메모장 느낌의 친근한 스타일. 팁이나 부가 설명에 적합.
