인벤토리 UI

인벤토리가 편한 게임의 공통점

Part 1. 정렬과 필터링

아이템 100개 있는데 원하는 거 어떻게 찾아?

정렬(Sort)과 필터(Filter)가 핵심입니다:

정렬 옵션 (Sort): +----------------------------------------------------------+ | | | 기본 정렬 옵션: | | +----------------------------------------------------+ | | | [획득순] [이름순] [등급순] [레벨순] [가격순] | | | +----------------------------------------------------+ | | | | 게임별 특수 정렬: | | +----------------------------------------------------+ | | | RPG: [장착가능 우선] [강화 레벨순] [세트 그룹] | | | | 수집형: [미보유 우선] [진화단계순] [컬렉션순] | | | | 생존: [사용빈도순] [무게순] [내구도순] | | | +----------------------------------------------------+ | | | +----------------------------------------------------------+ 필터 옵션 (Filter): +----------------------------------------------------------+ | | | 카테고리 필터: | | +----------------------------------------------------+ | | | [전체] [무기] [방어구] [장신구] [소비] [재료] [기타] | | | +----------------------------------------------------+ | | | | 조합 필터 (AND 조건): | | +----------------------------------------------------+ | | | 카테고리: [방어구] | | | | 등급: [전설] [영웅] <- 복수 선택 가능 | | | | 레벨: [50-60] | | | | 옵션: [치명타] 포함 | | | +----------------------------------------------------+ | | | 결과: 조건에 맞는 3개 아이템 | | | +----------------------------------------------------+ | | | +----------------------------------------------------------+ 좋은 인벤토리 = 2클릭 이내에 원하는 아이템 도달
// 인벤토리 정렬/필터 시스템 class InventoryFilter { // 필터 조건 struct FilterCriteria { std::set<ItemCategory> categories; std::set<ItemRarity> rarities; int minLevel = 0; int maxLevel = 999; std::string searchText; std::set<ItemOption> requiredOptions; }; // 정렬 기준 enum SortKey { SORT_ACQUIRED, // 획득순 SORT_NAME, // 이름순 SORT_RARITY, // 등급순 SORT_LEVEL, // 레벨순 SORT_PRICE, // 가격순 SORT_EQUIPPABLE // 장착가능 우선 }; public: std::vector<Item*> ApplyFilter(const std::vector<Item*>& items, const FilterCriteria& filter) { std::vector<Item*> result; for (auto* item : items) { // 카테고리 필터 if (!filter.categories.empty() && filter.categories.find(item->category) == filter.categories.end()) continue; // 등급 필터 if (!filter.rarities.empty() && filter.rarities.find(item->rarity) == filter.rarities.end()) continue; // 레벨 필터 if (item->level < filter.minLevel || item->level > filter.maxLevel) continue; // 검색어 필터 if (!filter.searchText.empty() && item->name.find(filter.searchText) == std::string::npos) continue; // 필수 옵션 필터 if (!HasAllOptions(item, filter.requiredOptions)) continue; result.push_back(item); } return result; } void ApplySort(std::vector<Item*>& items, SortKey key, bool ascending) { std::sort(items.begin(), items.end(), [key, ascending](Item* a, Item* b) { int result = 0; switch (key) { case SORT_RARITY: result = (int)a->rarity - (int)b->rarity; break; case SORT_LEVEL: result = a->level - b->level; break; case SORT_EQUIPPABLE: result = CanEquip(a) - CanEquip(b); break; // ... 기타 정렬 } return ascending ? result < 0 : result > 0; }); } };
검색 기능은 어떻게 만들어?

실시간 검색과 자동완성이 핵심입니다:

검색 UX 패턴: +----------------------------------------------------------+ | | | [검색: 전설_______________] [X] | | +----------------------------------------------------+ | | | 최근 검색: 전설 투구, 전설 도끼 | | | | 추천: 전설 세트, 전설 무기, 전설 방어구 | | | +----------------------------------------------------+ | | | | 검색 결과 (3개): | | +----------------------------------------------------+ | | | [아이콘] 전설 불꽃의 검 Lv.60 ATK +500 | | | | [아이콘] 전설 얼음의 방패 Lv.58 DEF +300 | | | | [아이콘] 전설 번개의 반지 Lv.55 SPD +50 | | | +----------------------------------------------------+ | | | +----------------------------------------------------------+ 검색 개선 포인트: 1. 실시간 검색 (입력할 때마다 필터링) 2. 검색어 하이라이트 3. 최근 검색어 저장 4. 검색 결과 0개면 유사 아이템 추천

Part 2. 드래그 앤 드롭 vs 클릭

아이템 옮기는 방식 뭐가 좋아?

플랫폼과 상황에 따라 다릅니다:

조작 방식 비교: +----------------------------------------------------------+ | | | 드래그 앤 드롭 (Drag & Drop): | | +----------------------------------------------------+ | | | 장점: | | | | - 직관적 (물건 집어서 옮기기) | | | | - 위치 지정 자유로움 | | | | - PC에서 마우스로 빠름 | | | | | | | | 단점: | | | | - 모바일에서 손가락 가림 | | | | - 실수로 잘못된 곳에 놓기 | | | | - 접근성 문제 (마우스 없으면 어려움) | | | +----------------------------------------------------+ | | | | 클릭 방식 (Click to Select): | | +----------------------------------------------------+ | | | 장점: | | | | - 모바일에서 정확함 | | | | - 키보드/컨트롤러 지원 쉬움 | | | | - 확인 단계 추가 가능 | | | | | | | | 단점: | | | | - 클릭 수 증가 (선택 -> 액션 선택 -> 대상 선택) | | | | - PC에서 느리게 느껴질 수 있음 | | | +----------------------------------------------------+ | | | +----------------------------------------------------------+ 플랫폼별 권장: +----------------------------------------------------------+ | PC: 드래그 기본 + 우클릭 컨텍스트 메뉴 | | 콘솔: 클릭 기본 + 숄더 버튼으로 빠른 이동 | | 모바일: 클릭 기본 + 롱프레스로 드래그 옵션 | | 크로스: 두 방식 모두 지원 (사용자 선택) | +----------------------------------------------------------+
// 하이브리드 아이템 이동 시스템 class ItemInteraction { Item* m_selectedItem = nullptr; Item* m_draggedItem = nullptr; Vector2 m_dragOffset; public: void OnItemClick(Item* item) { if (m_selectedItem == nullptr) { // 첫 번째 클릭: 선택 m_selectedItem = item; ShowItemOptions(item); // 사용, 장착, 버리기 등 } else if (m_selectedItem == item) { // 같은 아이템 다시 클릭: 선택 해제 m_selectedItem = nullptr; } else { // 다른 아이템 클릭: 위치 교환 SwapItems(m_selectedItem, item); m_selectedItem = nullptr; } } void OnSlotClick(InventorySlot* slot) { if (m_selectedItem != nullptr && slot->IsEmpty()) { // 빈 슬롯 클릭: 이동 MoveItem(m_selectedItem, slot); m_selectedItem = nullptr; } } void OnDragStart(Item* item, Vector2 touchPos) { m_draggedItem = item; m_dragOffset = touchPos - item->GetPosition(); item->SetDragging(true); } void OnDragMove(Vector2 touchPos) { if (m_draggedItem) { m_draggedItem->SetPosition(touchPos - m_dragOffset); // 드롭 가능 영역 하이라이트 auto* hoverSlot = GetSlotAt(touchPos); if (hoverSlot) { hoverSlot->SetHighlight(true); } } } void OnDragEnd(Vector2 touchPos) { if (m_draggedItem) { auto* targetSlot = GetSlotAt(touchPos); if (targetSlot && targetSlot->CanAccept(m_draggedItem)) { MoveItem(m_draggedItem, targetSlot); } else { // 원래 위치로 복귀 애니메이션 m_draggedItem->AnimateToOriginalPosition(); } m_draggedItem->SetDragging(false); m_draggedItem = nullptr; } } };

Part 3. 그리드 vs 리스트

인벤토리를 격자로 보여줘야 해, 목록으로 보여줘야 해?

아이템 특성과 정보량에 따라 선택합니다:

그리드 뷰 (Grid View): +----------------------------------------------------------+ | +----+ +----+ +----+ +----+ +----+ | | |[검]| |[방]| |[반]| |[물]| |[돌]| | | | 60 | | 58 | | 55 | | x5 | |x10 | | | +----+ +----+ +----+ +----+ +----+ | | +----+ +----+ +----+ +----+ +----+ | | |[갑]| |[장]| |[열]| | | | | | | | 62 | | 50 | | x3 | | | | | | | +----+ +----+ +----+ +----+ +----+ | | | | 장점: 한눈에 많은 아이템, 아이콘으로 빠른 인식 | | 단점: 상세 정보 표시 어려움 | | 적합: 아이콘이 중요한 게임, 소비/재료 아이템 | +----------------------------------------------------------+ 리스트 뷰 (List View): +----------------------------------------------------------+ | +----------------------------------------------------+ | | | [검] 전설 불꽃의 검 Lv.60 ATK+500 치명타+10% | | | +----------------------------------------------------+ | | | [방] 전설 얼음의 방패 Lv.58 DEF+300 빙결저항 | | | +----------------------------------------------------+ | | | [반] 전설 번개의 반지 Lv.55 SPD+50 공속+5% | | | +----------------------------------------------------+ | | | | 장점: 상세 정보 한눈에, 비교하기 쉬움 | | 단점: 한 화면에 적은 아이템 | | 적합: 장비 비교가 중요한 RPG, 복잡한 옵션 | +----------------------------------------------------------+ 최선책: 둘 다 제공하고 사용자가 전환
// 뷰 모드 전환 시스템 class InventoryView { enum ViewMode { GRID, LIST, COMPACT_LIST }; ViewMode m_currentMode = GRID; // 아이템당 표시 정보 struct ItemDisplay { bool showIcon = true; bool showName = true; bool showLevel = true; bool showStats = false; bool showRarity = true; bool showQuantity = true; }; ItemDisplay GetDisplayForMode(ViewMode mode) { ItemDisplay display; switch (mode) { case GRID: // 아이콘 중심, 최소 정보 display.showName = false; display.showStats = false; break; case LIST: // 모든 정보 표시 display.showName = true; display.showStats = true; break; case COMPACT_LIST: // 중간 (이름 + 레벨만) display.showName = true; display.showStats = false; break; } return display; } void Render(const std::vector<Item*>& items) { auto display = GetDisplayForMode(m_currentMode); for (auto* item : items) { if (m_currentMode == GRID) { RenderGridCell(item, display); } else { RenderListRow(item, display); } } } };

Part 4. 비교 기능과 툴팁

장비 비교를 어떻게 보여줘?

즉시 비교가 핵심입니다. 장비 위에 마우스 올리면 현재 장착 아이템과 자동 비교:

장비 비교 툴팁: +----------------------------------------------------------+ | | | [인벤토리의 새 아이템] [현재 장착 아이템] | | +----------------------+ +----------------------+ | | | 전설 불꽃의 검 | | 영웅 강철 검 | | | | Lv.60 필요 | | Lv.55 (장착중) | | | | | | | | | | 공격력: 500 | | 공격력: 380 | | | | +120 증가 | | | | | | | | | | | | 치명타: 10% | | 치명타: 5% | | | | +5% 증가 | | | | | | | | | | | | 공격속도: 1.2 | | 공격속도: 1.5 | | | | -0.3 감소 | | | | | +----------------------+ +----------------------+ | | | | [장착하기] [판매하기] [분해하기] | | | +----------------------------------------------------------+ 비교 표시 규칙: - 증가: 녹색 + 위 화살표 - 감소: 빨간색 + 아래 화살표 - 동일: 회색 또는 표시 안 함 - 새 옵션: 별도 강조
// 장비 비교 시스템 class EquipmentCompare { struct StatDiff { std::string statName; float oldValue; float newValue; float difference; bool isPositive; }; public: std::vector<StatDiff> Compare(const Equipment* newItem, const Equipment* equipped) { std::vector<StatDiff> diffs; // 모든 스탯 비교 auto stats = {"ATK", "DEF", "HP", "CritRate", "CritDmg", "Speed"}; for (const auto& stat : stats) { float newVal = newItem->GetStat(stat); float oldVal = equipped ? equipped->GetStat(stat) : 0; if (newVal != oldVal) { StatDiff diff; diff.statName = stat; diff.oldValue = oldVal; diff.newValue = newVal; diff.difference = newVal - oldVal; diff.isPositive = diff.difference > 0; diffs.push_back(diff); } } return diffs; } void RenderCompareTooltip(const Equipment* newItem, const Equipment* equipped) { auto diffs = Compare(newItem, equipped); // 왼쪽: 새 아이템 RenderItemCard(newItem, LEFT_SIDE); // 오른쪽: 현재 장착 if (equipped) { RenderItemCard(equipped, RIGHT_SIDE); } // 차이 표시 for (const auto& diff : diffs) { Color color = diff.isPositive ? COLOR_GREEN : COLOR_RED; std::string prefix = diff.isPositive ? "+" : ""; DrawText(diff.statName + ": " + prefix + std::to_string(diff.difference), color); } } };
툴팁에 뭘 보여줘야 해?

계층적 정보 공개(Progressive Disclosure)를 적용합니다:

툴팁 정보 계층: +----------------------------------------------------------+ | | | Level 1 - 즉시 표시 (호버): | | +----------------------------------------------------+ | | | 전설 불꽃의 검 | | | | Lv.60 양손검 | | | | 공격력: 500 | | | +----------------------------------------------------+ | | | | Level 2 - 상세 (1초 대기 또는 Shift 키): | | +----------------------------------------------------+ | | | [Level 1 내용] | | | | + 부가 옵션: | | | | 치명타 확률 +10% | | | | 보스 피해 +15% | | | | + 세트 효과: 불꽃의 분노 (2/4) | | | +----------------------------------------------------+ | | | | Level 3 - 전체 (우클릭 또는 아이템 상세보기): | | +----------------------------------------------------+ | | | [Level 2 내용] | | | | + 획득 경로: 화염 용 레이드 | | | | + 강화 이력: +10 (최대) | | | | + 거래 가능 여부: 귀속 | | | | + 예상 판매가: 150,000골드 | | | | + 로어/설명: "고대 화염 용의 이빨로..." | | | +----------------------------------------------------+ | | | +----------------------------------------------------------+ 핵심: 처음엔 핵심만, 필요하면 더 볼 수 있게

Part 5. 편의 기능

인벤토리 편의 기능 뭐가 있어?

사용자 경험을 크게 향상시키는 편의 기능들:

인벤토리 편의 기능: +----------------------------------------------------------+ | | | 1. 자동 정렬 (Auto Sort) | | +----------------------------------------------------+ | | | [자동 정렬] 버튼 -> 규칙에 따라 정렬 | | | | 예: 등급순 -> 종류순 -> 레벨순 | | | | 빈 슬롯 압축 (앞으로 당기기) | | | +----------------------------------------------------+ | | | | 2. 일괄 선택/처리 | | +----------------------------------------------------+ | | | [일반 등급 전체 선택] -> [일괄 판매] | | | | [재료 전체 선택] -> [일괄 보관함 이동] | | | +----------------------------------------------------+ | | | | 3. 빠른 장착/사용 | | +----------------------------------------------------+ | | | 더블클릭 -> 장비면 장착, 소비품이면 사용 | | | | 우클릭 -> 컨텍스트 메뉴 (장착/사용/판매/버리기) | | | +----------------------------------------------------+ | | | | 4. 잠금 기능 | | +----------------------------------------------------+ | | | 중요 아이템 잠금 -> 판매/버리기 방지 | | | | 실수 방지 | | | +----------------------------------------------------+ | | | | 5. 최근 획득 표시 | | +----------------------------------------------------+ | | | [NEW] 배지 또는 반짝임 효과 | | | | 어떤 아이템이 새로 들어왔는지 한눈에 | | | +----------------------------------------------------+ | | | +----------------------------------------------------------+
// 편의 기능 구현 class InventoryConvenience { // 자동 정렬 void AutoSort() { std::sort(m_items.begin(), m_items.end(), [](Item* a, Item* b) { // 1차: 등급 (높은순) if (a->rarity != b->rarity) return a->rarity > b->rarity; // 2차: 종류 if (a->category != b->category) return a->category < b->category; // 3차: 레벨 (높은순) return a->level > b->level; }); // 슬롯 재배치 (압축) RepackSlots(); } // 일괄 선택 void SelectByFilter(std::function<bool(Item*)> filter) { m_selectedItems.clear(); for (auto* item : m_items) { if (!item->IsLocked() && filter(item)) { m_selectedItems.insert(item); } } } // 일괄 판매 void SellSelected() { for (auto* item : m_selectedItems) { if (item->CanSell()) { AddGold(item->GetSellPrice()); RemoveItem(item); } } m_selectedItems.clear(); } // 잠금 토글 void ToggleLock(Item* item) { item->SetLocked(!item->IsLocked()); } // 새 아이템 표시 void MarkAsNew(Item* item) { item->SetNewFlag(true); item->SetNewTime(Time::Now()); } void ClearNewFlag(Item* item) { item->SetNewFlag(false); } // 3초 이상 본 아이템은 NEW 해제 void UpdateNewFlags() { for (auto* item : m_items) { if (item->IsNew() && Time::Now() - item->GetNewTime() > 3.0f && item->WasViewed()) { ClearNewFlag(item); } } } };

Part 6. 인벤토리 용량과 확장

인벤토리 꽉 차면 어떻게 해?

용량 관리는 게임 디자인의 일부입니다:

인벤토리 용량 전략: +----------------------------------------------------------+ | | | 1. 경고 시스템 | | +----------------------------------------------------+ | | | 80% 차면: "인벤토리가 거의 찼습니다" 알림 | | | | 100% 차면: 새 아이템 획득 시 선택 강제 | | | | [새 아이템] vs [기존 아이템] 중 버릴 것 선택 | | | +----------------------------------------------------+ | | | | 2. 확장 방법 | | +----------------------------------------------------+ | | | 유료: 캐시로 슬롯 확장 (수익화) | | | | 무료: 퀘스트 보상, 업적으로 확장 | | | | 게임플레이: 가방 아이템 장착 | | | +----------------------------------------------------+ | | | | 3. 보관함 분리 | | +----------------------------------------------------+ | | | 인벤토리: 캐릭터 휴대 (제한적) | | | | 창고: 계정 공유, 대용량 (마을에서만 접근) | | | | 우편함: 임시 보관 (기간 제한) | | | +----------------------------------------------------+ | | | | 4. 자동 처분 | | +----------------------------------------------------+ | | | 설정: "일반 등급 자동 분해" ON/OFF | | | | 자동 줍기 필터: 영웅 이상만 획득 | | | +----------------------------------------------------+ | | | +----------------------------------------------------------+
// 인벤토리 용량 관리 class InventoryCapacity { int m_maxSlots = 100; int m_usedSlots = 0; public: bool CanAddItem() { return m_usedSlots < m_maxSlots; } float GetFillRatio() { return (float)m_usedSlots / m_maxSlots; } void CheckCapacityWarning() { float ratio = GetFillRatio(); if (ratio >= 1.0f) { ShowFullInventoryPopup(); } else if (ratio >= 0.9f) { ShowWarning("인벤토리가 거의 찼습니다! (90%)"); } else if (ratio >= 0.8f) { ShowNotice("인벤토리 정리를 권장합니다 (80%)"); } } // 아이템 획득 시 가득 찼을 때 void OnItemPickup(Item* newItem) { if (!CanAddItem()) { // 선택 팝업: 새 아이템 vs 기존 아이템 ShowItemReplacePopup(newItem, [this, newItem](Item* discarded) { if (discarded == newItem) { // 새 아이템 버림 DropItem(newItem); } else { // 기존 아이템 버리고 새 것 추가 RemoveItem(discarded); DropItem(discarded); AddItem(newItem); } }); } else { AddItem(newItem); } } // 자동 분해 설정 void SetAutoDisassemble(ItemRarity minRarity) { m_autoDisassembleThreshold = minRarity; } void OnItemDrop(Item* item) { if (item->rarity < m_autoDisassembleThreshold) { // 설정된 등급 미만은 자동 분해 DisassembleItem(item); ShowFloatingText("자동 분해: " + item->name); } else { AddItem(item); } } };

핵심 정리

  • 정렬/필터: 2클릭 이내에 원하는 아이템 도달
