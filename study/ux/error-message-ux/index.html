에러 메시지 UX

에러 메시지가 유저 친화적인 게임의 특징

Part 1. 기술적 에러 vs 사용자 친화적 메시지

"Error 0x80070005"라고 뜨면 뭘 해야 해?

아무것도 모르겠죠. 이것이 나쁜 에러 메시지의 전형입니다:

나쁜 에러 메시지 vs 좋은 에러 메시지: +----------------------------------------------------------+ | | | 나쁜 예시 (기술적): | | +----------------------------------------------------+ | | | Error: 0x80070005 | | | | An unexpected error has occurred. | | | | [OK] | | | +----------------------------------------------------+ | | | | 문제: | | - 사용자가 무엇이 잘못됐는지 모름 | | - 어떻게 해결해야 하는지 모름 | | - 기술 지식 필요 | | | +----------------------------------------------------------+ | | | 좋은 예시 (사용자 친화적): | | +----------------------------------------------------+ | | | 서버에 연결할 수 없습니다 | | | | | | | | 인터넷 연결을 확인해 주세요. | | | | 문제가 계속되면 잠시 후 다시 시도해 주세요. | | | | | | | | [다시 시도] [설정 열기] [고객센터] | | | | | | | | 오류 코드: NET-1001 (문의 시 알려주세요) | | | +----------------------------------------------------+ | | | | 장점: | | - 무엇이 문제인지 명확 | | - 해결 방법 안내 | | - 액션 버튼 제공 | | - 필요 시 기술 정보도 포함 | | | +----------------------------------------------------------+
좋은 에러 메시지의 구성 요소가 뭐야?

4가지 필수 요소가 있습니다:

좋은 에러 메시지의 4요소: +----------------------------------------------------------+ | | | 1. What (무엇이 문제인가) | | +----------------------------------------------------+ | | | "서버에 연결할 수 없습니다" | | | | "결제가 완료되지 않았습니다" | | | | "파일을 저장할 수 없습니다" | | | +----------------------------------------------------+ | | | | 2. Why (왜 발생했는가) - 선택적 | | +----------------------------------------------------+ | | | "인터넷 연결이 불안정합니다" | | | | "카드 한도가 초과되었습니다" | | | | "저장 공간이 부족합니다" | | | +----------------------------------------------------+ | | | | 3. How (어떻게 해결하는가) | | +----------------------------------------------------+ | | | "Wi-Fi 또는 모바일 데이터를 확인해 주세요" | | | | "다른 결제 수단을 이용해 주세요" | | | | "불필요한 파일을 삭제해 주세요" | | | +----------------------------------------------------+ | | | | 4. Action (무엇을 할 수 있는가) | | +----------------------------------------------------+ | | | [다시 시도] [설정] [취소] | | | | [다른 카드] [나중에] [고객센터] | | | | [저장공간 관리] [다른 위치 선택] [취소] | | | +----------------------------------------------------+ | | | +----------------------------------------------------------+
// 사용자 친화적 에러 메시지 시스템 struct UserFriendlyError { std::string title; // What: 제목 std::string description; // Why: 설명 (선택) std::string solution; // How: 해결 방법 std::vector<Action> actions; // 액션 버튼들 std::string errorCode; // 기술 참조용 static UserFriendlyError FromTechnicalError(int code) { UserFriendlyError error; switch (code) { case 0x80070005: // ACCESS_DENIED error.title = "접근이 거부되었습니다"; error.description = "이 작업을 수행할 권한이 없습니다."; error.solution = "관리자 권한으로 게임을 실행해 보세요."; error.actions = { {"관리자로 실행", ACTION_RUN_AS_ADMIN}, {"취소", ACTION_CANCEL} }; error.errorCode = "SYS-1005"; break; case NETWORK_TIMEOUT: error.title = "서버 응답이 없습니다"; error.description = "서버가 바쁘거나 연결이 불안정합니다."; error.solution = "잠시 후 다시 시도해 주세요."; error.actions = { {"다시 시도", ACTION_RETRY}, {"오프라인 모드", ACTION_OFFLINE}, {"취소", ACTION_CANCEL} }; error.errorCode = "NET-2001"; break; // ... 기타 에러 } return error; } };

Part 2. 문제 해결 안내

사용자가 직접 해결할 수 있게 어떻게 도와줘?

단계별 가이드와 자동 진단을 제공합니다:

문제 해결 가이드 패턴: +----------------------------------------------------------+ | | | 1. 간단한 해결책 먼저 | | +----------------------------------------------------+ | | | 연결 문제가 발생했습니다. | | | | | | | | 다음을 확인해 주세요: | | | | [ ] 인터넷이 연결되어 있나요? | | | | [ ] 다른 앱은 정상 작동하나요? | | | | [ ] VPN을 사용 중이라면 끄고 시도해 보세요 | | | | | | | | [네트워크 진단 실행] [다시 시도] | | | +----------------------------------------------------+ | | | | 2. 자동 진단 결과 | | +----------------------------------------------------+ | | | 네트워크 진단 결과: | | | | | | | | [OK] 인터넷 연결 | | | | [OK] DNS 확인 | | | | [X] 게임 서버 연결 <- 여기가 문제 | | | | | | | | 서버 점검 중일 수 있습니다. | | | | 점검 일정: 오늘 14:00-16:00 | | | | | | | | [점검 공지 보기] [알림 받기] | | | +----------------------------------------------------+ | | | +----------------------------------------------------------+
// 자동 진단 시스템 class DiagnosticRunner { struct DiagStep { std::string name; std::function<bool()> check; std::string successMsg; std::string failureMsg; std::string solution; }; public: void RunNetworkDiagnostic(std::function<void(DiagResult)> callback) { std::vector<DiagStep> steps = { { "인터넷 연결", []() { return CheckInternetConnection(); }, "인터넷이 연결되어 있습니다.", "인터넷에 연결되어 있지 않습니다.", "Wi-Fi 또는 이더넷 연결을 확인해 주세요." }, { "DNS 확인", []() { return ResolveDNS("game.server.com"); }, "DNS가 정상 작동합니다.", "DNS 조회에 실패했습니다.", "DNS 설정을 8.8.8.8로 변경해 보세요." }, { "게임 서버 연결", []() { return PingGameServer(); }, "게임 서버에 연결 가능합니다.", "게임 서버에 연결할 수 없습니다.", "서버 점검 중이거나 방화벽 설정을 확인해 주세요." }, { "포트 접근", []() { return CheckPort(7777); }, "게임 포트가 열려 있습니다.", "게임 포트가 차단되어 있습니다.", "방화벽에서 포트 7777을 허용해 주세요." } }; DiagResult result; for (const auto& step : steps) { bool passed = step.check(); result.steps.push_back({ step.name, passed, passed ? step.successMsg : step.failureMsg, passed ? "" : step.solution }); if (!passed) { result.failedStep = step.name; result.suggestedSolution = step.solution; break; // 첫 번째 실패에서 멈춤 } } callback(result); } };

// 에러 코드 시스템 namespace ErrorCode { // 카테고리 enum Category { NETWORK = 1000, AUTH = 2000, PAYMENT = 3000, GAME = 4000, DATA = 5000, SYSTEM = 6000 }; // 네트워크 에러 constexpr int NET_CONNECTION_FAILED = NETWORK + 1; constexpr int NET_TIMEOUT = NETWORK + 2; constexpr int NET_DISCONNECTED = NETWORK + 3; constexpr int NET_VERSION_MISMATCH = NETWORK + 20; // 인증 에러 constexpr int AUTH_INVALID_ID = AUTH + 1; constexpr int AUTH_WRONG_PASSWORD = AUTH + 2; constexpr int AUTH_ACCOUNT_BANNED = AUTH + 3; constexpr int AUTH_SESSION_EXPIRED = AUTH + 10; constexpr int AUTH_DUPLICATE_LOGIN = AUTH + 20; // 문자열 변환 std::string ToString(int code) { int category = (code / 1000) * 1000; int number = code % 1000; std::string prefix; switch (category) { case NETWORK: prefix = "NET"; break; case AUTH: prefix = "AUTH"; break; case PAYMENT: prefix = "PAY"; break; case GAME: prefix = "GAME"; break; case DATA: prefix = "DATA"; break; case SYSTEM: prefix = "SYS"; break; } return prefix + "-" + std::to_string(code); } // 카테고리 분류 bool IsNetworkError(int code) { return code >= NETWORK && code < AUTH; } bool IsRecoverable(int code) { // 재시도로 해결 가능한 에러 return code == NET_TIMEOUT || code == NET_DISCONNECTED; } }
