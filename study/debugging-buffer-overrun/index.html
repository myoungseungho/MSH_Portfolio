버퍼 오버런

배열 범위 밖 접근 — 보안 취약점의 시작

Part 1. 버퍼 오버런이란?

버퍼 오버런이 뭐야?

배열(버퍼)의 할당된 범위를 넘어서 읽거나 쓰는 것.

인접한 메모리를 덮어써서 데이터 손상이나 크래시를 유발.

char buffer[10]; // 오버런 (쓰기) buffer[10] = 'X'; // 인덱스 0~9만 유효한데 10에 접근! // 문자열 오버런 strcpy(buffer, "This is way too long"); // 10바이트 넘음

Part 2. 왜 위험해?

즉시 크래시 안 나는데?

오버런은 즉시 크래시하지 않을 수 있다.

인접 메모리에 뭐가 있느냐에 따라 다르다:

// 스택 오버런 예시 void Vulnerable() { char buffer[10]; int importantFlag = 1; // buffer 바로 뒤에 있음 strcpy(buffer, "AAAAAAAAAAAAAA"); // buffer 넘침 // importantFlag가 'AAAA'로 덮어써짐! // importantFlag = 0x41414141 (= "AAAA") if (importantFlag) // 예상과 다른 동작! { // ... } }

Part 3. 탐지 방법

어떻게 찾아?

1. AddressSanitizer (ASan) - 가장 강력

2. Application Verifier - Windows 전용

3. Debug Heap - CRT 가드 바이트 (0xAB, 0xFD)

// AddressSanitizer 사용 // 프로젝트 속성 → C/C++ → General // Enable Address Sanitizer: Yes (/fsanitize=address) // 실행 시 오버런 즉시 감지: ==ERROR: AddressSanitizer: stack-buffer-overflow WRITE of size 1 at 0x... thread T0 #0 main example.cpp:5

Part 4. 예방

어떻게 방지해?

1. 안전한 함수 사용 (strcpy_s, strncpy)

2. std::string, std::vector 사용

3. 범위 검사 습관화

// 위험한 코드 char buf[10]; strcpy(buf, input); // 길이 체크 없음! buf[index] = value; // 범위 체크 없음! // 안전한 코드 char buf[10]; strcpy_s(buf, sizeof(buf), input); // 크기 제한 if (index < 10) buf[index] = value; // 범위 체크 // 더 좋은 코드 - STL 사용 std::string str = input; // 자동 관리 std::vector vec(10); vec.at(index) = value; // 범위 체크 + 예외

핵심 정리

  • 버퍼 오버런 = 배열 범위 밖 접근
  • 즉시 크래시 안 날 수 있음 (더 위험)
  • ASan으로 탐지, 안전한 함수로 예방
  • 가능하면 std::string, std::vector 사용
