STEP 7 — 경계 걸친 광역기(AoE)

STEP 5는 한 대상을 라우팅했다. 광역기는 공간(원)을 라우팅한다. 원이 여러 칸에 걸치면, 각 칸 주인이 자기 몬스터만 판정한다.

STEP 7의 목적

STEP 5(위치 투명 라우팅)의 결핍 하나 — "한 번에 한 대상만" —을 푼다. 광역기는 대상이 아니라 범위(중심·반경)다. 그 원이 여러 칸(여러 주인)에 걸칠 때, "각자 주인이 자기 것만 판정"이라는 헌법을 공간으로 확장한다.

🎥 실제 작동 — 3D 뷰어 (STEP 7)

지휘관 뷰(전 월드 자유 이동)에서 크로스헤어가 가리키는 땅의 한 점에 광역기를 겨눈다. 미리보기 원이 걸치는 칸은 노란 테두리로 강조된다. 좌클릭하면 폭발이 경계에 걸친 여러 칸(여러 색) 몬스터를 동시에 격추 — 각 칸 주인이 자기 몬스터만 판정한 결과다. 우상단 미니맵에도 조준 원이 표시된다.

✅ 지금 되는 것

· 광역기는 대상이 아니라 원(중심·반경)으로 전송(CM_AOE) — 진입 서버가 원이 겹친 칸들을 계산

· 겹친 각 칸으로 확산(STEP 6 멀티홉 재사용) → 각 주인이 "내 몬스터 중 반경 안"만 판정

· 비인접 칸도 멀티홉으로 확산. 실측: [Z4] 확산: 칸 Z8 담당분 → 다음 홉 Z5 → [Z8] AoE 격추 M108

❌ 아직 안 되는 것 (다음 단계에서)

· 이주 도중인 대상에 AoE가 닿을 때의 레이스(옛/새 주인 중복·유실) → 상태 핸드오프 완성편에서

Part 1. 왜 AoE는 라우팅의 '공간 버전'인가

STEP 5에서 대상 하나는 이미 라우팅했잖아. 광역기는 뭐가 다르지?

STEP 5는 대상 id를 보냈다 — "저 M105 때려". 시스템이 그 하나의 주인을 찾았다. 광역기는 대상이 없다. 중심과 반경(원)만 있다.

그 원은 여러 칸(여러 주인)에 걸칠 수 있다. 그런데 헌법은 그대로다 — "각자 주인이 자기 것만 판정". 그래서 원을 칸별로 쪼개, 각 주인에게 "이 원 안의 네 몬스터를 판정하라"고 보낸다. 대상 하나의 라우팅이 공간의 라우팅으로 커진 것뿐이다.

// 원(중심 cx,cy 반경 r)이 칸 z와 겹치는가 — 진입 서버가 '어느 칸들로 확산할지' 판단 bool CircleHitsZone(float cx, float cy, float r, int z) { float zx = (z%Cols)*Cell, zy = (z/Cols)*Cell; float px = Clamp(cx, zx, zx+Cell), py = Clamp(cy, zy, zy+Cell); // 사각형에서 가장 가까운 점 return (cx-px)*(cx-px) + (cy-py)*(cy-py) <= r*r; }

Part 2. 진입 서버가 확산 → 각 주인이 판정

누가 '어느 칸에 걸쳤는지'를 계산해? 그리고 먼 칸은 어떻게 닿아?

내가 선 칸(진입 서버)이 계산한다. 원이 겹친 칸을 전부 골라, 내 칸이면 내가 판정, 남의 칸이면 그 주인에게 라우팅. 인접이 아니면 STEP 6의 멀티홉이 그대로 데려다준다.

받은 서버는 딱 하나만 한다 — 내 몬스터 중 원 안의 것만 데미지. 어느 몬스터가 어느 칸 소유인지 고민할 필요가 없다. 각자 자기 것만 보니까.

// 진입: 원이 겹친 '모든 칸'에 각자 판정하도록 확산 for (int z = 0; z < 9; z++) { if (!CircleHitsZone(cx, cy, r, z)) continue; if (z == myZone) JudgeAoe(cx, cy, r, dmg); // 내 칸은 내가 else Forward(NextHop(myZone, z), new AoeMsg(cx,cy,r,dmg, targetZone:z)); // 남의 칸 → 멀티홉 } // 각 주인의 판정: 내 몬스터 중 반경 안의 것만 void JudgeAoe(cx, cy, r, dmg) { foreach (m in myMonsters) if (dist2(m, (cx,cy)) <= r*r) m.HP -= dmg; // 죽으면 SM_KILL 전파(STEP 5와 동일) }
실측 — 존4에서 4칸 모서리(20,20)에 광역기 (반경 8) [Z4] AoE 진입: 중심(20,20) r8 → 겹친 칸으로 확산 [Z4] AoE 데미지! M104 100→40 ← 내 칸은 내가 [Z4] AoE 확산: 칸 Z5 담당분 → 다음 홉 Z5 [Z4] AoE 확산: 칸 Z8 담당분 → 다음 홉 Z5 ← Z8은 비인접 → 멀티홉 [Z5] AoE 데미지! M105 100→40→0 → 💥 격추 (주인 Z5) [Z8] AoE 데미지! M108 100→40→0 → 💥 격추 (주인 Z8) ← 각자 자기 것만

★ 이야기로

민수가 4칸이 만나는 모서리에 광역기를 던진다. 폭발의 원은 네 나라의 땅을 동시에 밟는다. 하지만 누가 죽는지는 각 나라가 스스로 정한다 — 초록 나라는 자기 늑대를, 파란 나라는 자기 늑대를. 민수는 "여기 반경 6에 데미지"라고만 외쳤을 뿐, 어느 나라에 몇 마리가 있는지 몰랐다.

이게 STEP 5의 "누구에게만 남기고 어디로는 지운다"가 공간으로 자란 모습이다. 대상 하나였던 라우팅이, 원 하나로 여러 주인에게 동시에 갈라져 배달된다. 헌법은 한 글자도 바뀌지 않았다 — 보인다(클라)·안다(이웃)·정한다(주인).
