칼로 베면 메시가 진짜 잘리게 만드는 법

Procedural Mesh, Break Constraints, Skinning, Lattice Deformer

메시가 뭐야?

메시 (Mesh) = 3D 모델을 구성하는 삼각형 조각들의 집합

게임 속 캐릭터, 무기, 건물 모두 메시로 만들어져 있어.

생각해봐. 종이로 만든 입체 모형처럼 삼각형을 수천 개 붙여서 사람 모양을 만드는 거야.

📐 비유: 종이 공예

입체 종이 인형을 만든다고 생각해봐.

1. 삼각형 종이를 수백 개 준비
2. 각 삼각형을 풀로 붙임
3. 붙이면 사람 모양 완성!

메시도 똑같아. 삼각형을 붙여서 3D 모델을 만들어!
그래서 어떻게 자르는데?

이 발표의 목표:

메탈기어 라이징처럼 자유롭게, 말랑말랑하게 자르는 것!

1

기본 절단 방식: 프로시저럴 메시 + 브레이크 컨스트레인트

프로시저럴 메시가 뭐야?

프로시저럴 메시 (Procedural Mesh)

→ 실시간으로 삼각형을 넣거나 뺄 수 있는 메시

일반 메시: 미리 만들어진 모델 (수정 불가)

프로시저럴 메시: 게임 중에도 삼각형 추가/삭제 가능!

→ 평면을 주면 그 평면 기준으로 자르는 기능까지 있어!

브레이크 컨스트레인트는 뭐야?

브레이크 컨스트레인트 (Break Constraint)

→ 스켈레탈 메시의 본 (뼈대) 연결을 끊는 기능

스켈레탈 메시: 뼈대가 있는 메시 (애니메이션 가능)

→ 본 사이 연결을 끊으면 절단된 것처럼 보여!

본을 끊으면 뭐가 문제야?

문제: 메시가 늘어나 버려!

왜 늘어날까?

연결된 상태:
┌─────┐━━━━━┌─────┐
│본 A │  연결  │본 B │
└──┬──┘     └──┬──┘
   │           │
   └─────┬─────┘
       점(중간)

본을 끊으면:
┌─────┐      ┌─────┐
│본 A │      │본 B │ ← 떨어짐!
└──┬──┘      └──┬──┘
점A 복사     점B 복사

렌더링 시:
→ 두 점의 중간값 계산
→ ⚠️ 허공에 점 생성
→ 메시 전체에 적용
→ ⚠️ 쭉 늘어난 모습!

1절단 프로세스

1. 절단할 위치에서 본 선택
   예: 팔꿈치 본

2. 그 본에 영향받는 메시 범위 복사
   → 프로시저럴 메시로 복사

3. 프로시저럴 메시 절단
   → 평면 기준으로 자르기

4. 스켈레탈 메시 본 끊기
   → 브레이크 컨스트레인트 사용
   → 늘어나는 부분 발생!

5. 늘어난 부분 지우기
   → 버텍스 컬러로 숨김

6. 프로시저럴 메시 붙이기
   → 잘린 부분에 딱 맞춰서 붙임

결과: 자른 것처럼 보임!
그런데 움직이면 어떻게 돼?

문제: 움직이면 찢어져!

프로시저럴 메시는 스태틱 (정적) → 애니메이션 안 됨

스켈레탈 메시는 움직임 → 둘 사이 틈 발생!

2애니메이션 추가

어떻게 프로시저럴 메시도 움직이게 해?

수동으로 스키닝 공식 구현!

스키닝 공식:

최종 위치 = (본A 위치 × 가중치A) + (본B 위치 × 가중치B)

문제:
- 이대로 쓰면 또 늘어남 (끊어진 본 때문)

해결:
- 끊어진 본의 버텍스는 절단 당시 위치로 고정
- 나머지 버텍스만 애니메이션

결과: 늘어나지 않으면서 부드럽게 애니메이션!
절단면은요?

절단면 버텍스는 새로 만든 거라 스키닝 웨이트가 없어!

해결:

→ 절단면은 본에 직접 붙이기

→ 본을 따라 움직이게!

감쪽같이 붙어있음!

2

세로 방향 절단의 문제

가로로만 자를 수 있어?

문제: 본 하나만 자르면 세로 방향 불가

세로로 자르려면 → 본 여러 개를 걸쳐서 자르기

본 여러 개를 자르면 돼?

새로운 문제 발생!

연속으로 자르면 갑자기 또 늘어남!

원인:

→ 각 절단이 독립적으로 일어남

→ 첫 절단 때 늘어난 메시를

→ 두 번째 절단 때 모르고 그대로 복사

→ 늘어진 메시가 눈에 띔!

해결 방법:

독립적 → 연결됨

1. 첫 절단: 메시 복사 + 위치 기억
2. 두 번째 절단:
   - 모자라는 부분만 복사
   - 이전 메시에 합치기

결과: 더 이상 늘어나지 않음!
3

메시 아일랜드 문제

세로로 자르면 예쁘게 잘려?

NO! 엉망진창!

상체를 세로로 자르면:

→ 오른쪽은 잘 합쳐짐

→ 왼쪽은 각 본마다 따로 놀아!

메시 아일랜드가 뭐야?

메시 아일랜드 (Mesh Island)

→ 연결되지 않은 메시 조각들

예: 상체를 가로로 자르면

→ 사람 눈엔: 몸통 / 왼팔 / 오른팔 (3개)

→ 컴퓨터 눈엔: 하나의 메시

→ 팔이 몸통에 붙어서 같이 움직여!

해결 시도 1: 삼각형 연결 정보 이용

삼각형끼리 붙어있으면 같은 그룹
→ 그룹별로 분리

문제: 하드엣지 때문에 잘 안 됨
- 팔은 예쁘게 분리
- 어깨, 목은 불필요하게 분리

해결 시도 2: 워헤이븐 방식

팔다리에 색 칠하기
→ 색 기준으로 분리

문제: 막 잘라도 잘 될까?
메탈기어 라이징처럼 마구잡이로 자르면?
→ 자신 없음

해결 시도 3: 라티스 디포머 응용

라티스 디포머: 격자에 메시 매핑 → 격자 움직이면 메시도 움직임

아이디어:
1. 메시를 격자에 매핑
2. 각 격자 노드를 엣지로 연결 (그래프)
3. 메시 자를 때 그래프도 같이 자르기
4. 그래프에서 아일랜드 찾기

결과: 완벽하게 작동!
- 팔 예쁜게 분리
- 불필요한 분리 없음!
4

실제 게임 적용: 낙원 (좀비 게임)

낙원에서 쓰려고 했는데 뭐가 문제였어?

낙원 팀 피드백:

"절단면이 너무 날카로워. 좀비 같지 않아."

좀비는:

→ 뼈와 살점 보여야 하고

→ 뜯기고 찢긴 상처 같아야 하고

→ 피가 튀어야 해!

1데드 아일랜드 방식

어떻게 좀비처럼 만들어?

데드 아일랜드의 비법

→ 메시 두 개를 겹쳐 놓기!

데드 아일랜드 구조:

[겉 메시] - 피부 (정상)
[속 메시] - 내장, 뼈, 살점 (끔찍)

매 맞으면:
→ 겉 메시에 구멍 뚫기
→ 속 메시 보이기
→ 찢어진 것처럼 보임!
어떻게 구멍을 뚫어?

레프트포데드 기법

구멍 뚫기 프로세스:

1. 때린 위치를 GPU에 전달

2. 머티리얼(Material)에서:
   - 각 픽셀과 때린 위치의 거리 측정
   - 거리가 일정 이하면 클리핑 (잘라내기)

3. 결과:
   → 구멍 생김!
   → 안쪽 내장 메시 보임!

응용:
- 데칼: 옷 찢어진 모양
- WPO (월드 포지션 오프셋): 피부 파인 모양
절단면 버텍스는요?

문제: 레퍼런스 포즈 좌표가 없어!

해결:

→ 삼각형 자를 때 보간(interpolation)으로 계산

→ 문제 해결!

2블린 디스트럭터블 (절단면 울퉁불퉁하게)

절단면이 너무 평평해!

블린 디스트럭터블 (Blinn Destructible)

→ 크라이 엔진의 나무 파괴 기능

→ 평면이 아니라 메시 모양으로 빼기!

평면 절단 vs 메시 절단:

[기존]
평면으로 자르기
→ 날카롭고 평평

[블린 디스트럭터블]
고깃덩어리 모양 메시로 빼기
→ 울퉁불퉁하고 찢어진 느낌!

필요한 도구:
→ 다이나믹 메시 (Dynamic Mesh)
다이나믹 메시가 뭐야?

다이나믹 메시 (Dynamic Mesh)

→ 언리얼 엔진의 메시 편집용 자료구조

프로시저럴 메시:

→ 실시간으로 삼각형 추가/삭제

→ 기능 적음

다이나믹 메시:

→ 프로시저럴 메시 기능 포함

→ 메시 블링 (메시 빼기) 가능

→ 삼각형 쪼개기, 근접 삼각형 찾기 등 다양한 기능

→ 게임에서도 사용 가능! (일부 기능 제외)

3자동 보정

아무 방향으로 자르면 어색해!

문제: 경계 부분에서 잘리면 이상해

프로시저럴 메시와 스켈레탈 메시 연결 부분을 자르면:

→ 프로시저럴: 잘림

→ 스켈레탈: 안 잘림

→ 어색한 형태!

해결 방법 1: 절단면 살짝 돌리기

경계와 절단면이 만나지 않게
→ 각도 조정

문제: 돌려도 다른 데서 걸림

해결 방법 2: 최대한 밀어내기

1. 경계 부분까지 절단면 밀기
2. 반대편 걸리면:
   - 새로운 방향 찾기
   - 컨벡스 볼륨으로 양쪽 감싸기
   - 충돌 체크
   - 충돌 없는 최단 거리 벡터 구하기
   - 반으로 쪼개는 방향으로 자르기

결과: 양쪽에 걸리지 않고 예쁘게 잘림!

남은 작업

아직 완성 안 됐어?

아직 미완성!

하지만 낙원에 적용하느라 이슈 많이 해결했어.

남은 작업:

1 절단 기능 완성
- 현재: 한 부위만 복사해서 자름
- 목표: 메시 통으로 가져와서 직접 자르기
- 이유: 지금 방식은 한계가 있음

2 애니메이션 개선
- 현재: 절단 부위의 본을 한쪽이 독차지
- 문제: 반대편 애니메이션 어색함
- 해결: 메시 본 복사해서 추가
→ 더 부드럽게!

3 다이나믹 메시로 전환
- 프로시저럴 메시: 기능 부족
- 다이나믹 메시: 엔진 지원 많음
- 관리하기 편함

4 캡 생성 문제 해결
- 현재: 절단면에 캡이 안 생기는 경우 있음
- 발생: 옷과 피부가 만나는 부분
- 해결: 아이디어 구상 중

📌 핵심 정리: 메시 절단

  • 메시 (Mesh) - 3D 모델을 구성하는 삼각형들의 집합
  • 프로시저럴 메시 - 실시간으로 삼각형 추가/삭제 가능한 메시
  • 스켈레탈 메시 - 뼈대(본)가 있어서 애니메이션 가능한 메시
  • 브레이크 컨스트레인트 - 본의 연결을 끊는 기능
  • 스키닝 (Skinning) - 본의 움직임에 따라 메시를 변형시키는 것
  • 버텍스 (Vertex) - 삼각형의 꼭짓점
  • 메시 아일랜드 - 연결되지 않은 메시 조각들
  • 라티스 디포머 - 격자에 메시를 매핑해서 변형하는 기법
  • 랩돌 (Ragdoll) - 물리 엔진으로 움직이는 인형 (말랑말랑함)
  • 다이나믹 메시 - 프로시저럴 메시보다 강력한 편집용 메시
  • 블린 디스트럭터블 - 메시 모양으로 빼서 파괴하는 기법
  • 핵심 메시지 - 메탈기어 라이징처럼 자유롭게 자르면서도 말랑말랑하게 움직이는 절단은 프로시저럴 메시 + 스켈레탈 메시 + 물리 엔진의 조합으로 가능!
