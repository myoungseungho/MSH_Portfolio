Web 1.0 → 2.0 → 3.0

웹의 진화 - 읽기만 하던 시대에서 소유의 시대로

Part 1. 웹이 뭐야?

웹이 뭐야? 인터넷이랑 같은 거야?

아니! 다른 거야.

[인터넷 vs 웹] 인터넷 (Internet): → 전 세계 컴퓨터를 연결하는 "네트워크" → 도로 같은 것 (인프라) 웹 (Web = World Wide Web): → 인터넷 위에서 돌아가는 "서비스" → 도로 위를 달리는 "자동차" 같은 것 인터넷 위에서 돌아가는 서비스: - 웹 (HTTP) ← 우리가 말하는 그거 - 이메일 (SMTP) - 파일 전송 (FTP) - 게임 서버 (TCP/UDP)
그럼 Web 1.0, 2.0, 3.0은 뭐야?

웹이 진화해온 단계를 말해.

버전 업그레이드 같은 거야.

[웹의 진화] 1990년대: Web 1.0 - "읽기만" 2000년대: Web 2.0 - "읽고 쓰기" 2020년대: Web 3.0 - "읽고 쓰고 소유" → 점점 사용자의 권한이 늘어남!

Part 2. Web 1.0 - 읽기만 하던 시대

Web 1.0이 뭐야?

읽기 전용 웹이야.

1990년대~2000년대 초반.

📰 비유: 신문/잡지

Web 1.0 = 온라인 신문

- 기자(제작자)가 글 씀
- 독자(사용자)는 읽기만 함
- 댓글? 없음
- 공유? 없음
- 그냥 보기만!
[Web 1.0의 특징] 1. 정적 페이지 (Static) - HTML로 만든 고정된 페이지 - 서버에서 만들어진 그대로 보여줌 2. 일방향 소통 - 제작자 → 사용자 - 사용자는 소비만 함 3. 소수가 생산, 다수가 소비 - 웹사이트 만들려면 전문가 필요 - 일반인은 볼 수만 있음 4. 예시 - 기업 홈페이지 (회사 소개) - 뉴스 사이트 (기사 읽기) - 백과사전 (정보 검색)
그때는 유튜브 같은 거 없었어?

없었어!

영상 올리기? 댓글 달기? 좋아요? 다 없었어.

그냥 웹사이트 주인이 올린 거 보는 게 끝.

[Web 1.0 시대의 인터넷] 사용자: "네이버 접속!" 서버: "여기 HTML 페이지야. 보여줄게." 사용자: "읽었다. 끝." → 상호작용 없음 → 그냥 전자 책자 수준

Part 3. Web 2.0 - 읽고 쓰는 시대 (지금)

Web 2.0은 뭐가 달라?

사용자가 콘텐츠를 만들 수 있어!

📱 비유: SNS

Web 2.0 = 인스타그램, 유튜브, 트위터

- 누구나 글/사진/영상 올림
- 댓글, 좋아요, 공유
- 사용자끼리 소통
- 플랫폼이 중간에서 관리
[Web 2.0의 특징] 1. 동적 페이지 (Dynamic) - 사용자 행동에 따라 페이지가 바뀜 - 로그인하면 내 피드가 보임 2. 양방향 소통 - 제작자 ↔ 사용자 - 사용자 ↔ 사용자 3. 누구나 생산자 - 유튜브: 아무나 영상 업로드 - 블로그: 아무나 글 작성 - SNS: 아무나 포스팅 4. 플랫폼 중심 - 구글, 페이스북, 네이버가 중심 - 사용자 데이터를 플랫폼이 소유
지금 우리가 쓰는 게 Web 2.0이야?

맞아! 2005년쯤부터 지금까지.

[Web 2.0 서비스 예시] 소셜 미디어: - 페이스북, 인스타그램, 트위터 - 틱톡, 유튜브 플랫폼: - 구글 (검색, 지메일, 드라이브) - 네이버 (블로그, 카페) - 카카오 (카카오톡, 다음) 공유 경제: - 에어비앤비, 우버 - 배달의민족, 쿠팡 클라우드: - AWS, Azure, GCP - 드롭박스, 구글 드라이브
Web 2.0이 좋아 보이는데, 문제가 있어?

있어! 크게 세 가지.

[Web 2.0의 문제점] 문제 1: 데이터 소유권 ───────────────────── 너: 인스타에 사진 1000장 올림 인스타: "고마워! 이 데이터 내 서버에 저장할게" 인스타: "참고로 이 데이터로 광고 타겟팅 할 거야" 인스타: "그리고 계정 정지하면 사진 다 날아가" → 내 데이터인데 내 게 아님!
문제 2: 플랫폼 의존성 ───────────────────── 유튜버: 10년간 채널 키움, 구독자 100만 유튜브: "커뮤니티 가이드 위반! 채널 삭제" 유튜버: "???" (10년 노력 한순간에 증발) → 플랫폼이 갑, 사용자가 을
문제 3: 중앙 집중화 ───────────────────── 전 세계 검색: 구글이 90% 장악 전 세계 SNS: 메타(페이스북)가 장악 전 세계 클라우드: AWS가 30% 장악 → 몇 개 회사가 인터넷을 지배 → 이들이 마음먹으면 서비스 중단 가능 → 개인정보 유출 사고도 대규모
정리하면?

Web 2.0 = 읽고 쓰지만, 소유는 플랫폼

Part 4. Web 3.0 - 읽고 쓰고 소유하는 시대

Web 3.0은 뭐야?

탈중앙화 + 사용자가 데이터 소유

🏠 비유: 집

Web 2.0: 월세 (플랫폼 = 집주인)
- 집주인 맘대로 규칙 바꿈
- 쫓겨나면 끝
- 집 꾸며도 내 게 아님

Web 3.0: 자가 (내가 주인)
- 내 규칙대로 운영
- 아무도 못 쫓아냄
- 내 자산은 진짜 내 것
[Web 3.0의 핵심 개념] 1. 탈중앙화 (Decentralization) - 구글, 페이스북 같은 중앙 서버 없음 - 여러 컴퓨터가 분산해서 데이터 저장 - 한 곳이 죽어도 서비스 유지 2. 블록체인 (Blockchain) - 탈중앙화를 가능하게 하는 기술 - 데이터를 여러 곳에 복사해서 저장 - 위변조 어려움 3. 토큰 경제 (Token Economy) - 플랫폼 지분을 사용자가 소유 - 기여하면 보상 받음 - 예: 글 쓰면 토큰 받음 4. 자기주권 신원 (Self-Sovereign Identity) - 내 정보는 내가 관리 - 로그인할 때 구글/페이스북 안 거침 - 지갑 주소가 곧 신원
블록체인이 뭔데?

거래 기록을 여러 컴퓨터에 분산 저장하는 기술이야.

[블록체인 쉽게 이해하기] 전통적인 방식 (Web 2.0): ───────────────────────── 은행 서버: "A가 B에게 1만원 보냄" (기록) → 은행만 이 기록을 가지고 있음 → 은행이 조작하면? 알 수 없음 → 은행 서버 해킹되면? 큰일 블록체인 방식 (Web 3.0): ───────────────────────── 컴퓨터 1: "A가 B에게 1만원 보냄" (기록) 컴퓨터 2: "A가 B에게 1만원 보냄" (같은 기록) 컴퓨터 3: "A가 B에게 1만원 보냄" (같은 기록) ... (수천 대가 같은 기록) → 조작하려면 수천 대를 동시에 해킹해야 함 → 사실상 불가능 → "탈중앙화"의 핵심
Web 3.0 서비스 예시?
[Web 3.0 서비스 예시] 암호화폐: - 비트코인, 이더리움 - 은행 없이 돈 주고받기 NFT (Non-Fungible Token): - 디지털 자산의 소유권 증명 - 내가 만든 그림 = 진짜 내 것 DeFi (Decentralized Finance): - 은행 없는 금융 - 예금, 대출, 거래를 코드로 DAO (Decentralized Autonomous Organization): - 회사인데 사장이 없음 - 토큰 보유자들이 투표로 결정 탈중앙화 소셜: - Mastodon, Lens Protocol - 플랫폼이 내 계정 삭제 못 함 탈중앙화 저장: - IPFS, Filecoin - 구글 드라이브 대신 분산 저장
그럼 Web 3.0이 무조건 좋아?

아니! 아직 문제도 많아.

[Web 3.0의 문제점] 문제 1: 느리고 비쌈 ───────────────────── 수천 대가 같은 기록 저장 → 느림 거래마다 수수료 (가스비) → 비쌈 이더리움 송금에 $50 든 적도 있음 문제 2: 어려움 ───────────────────── 지갑 만들기, 시드 문구 관리, 가스비 계산... 일반인이 쓰기 너무 어려움 "시드 문구 잃어버리면 자산 영원히 못 찾음" 문제 3: 사기 많음 ───────────────────── 러그풀 (돈 들고 튐) 피싱 사이트 가짜 NFT 규제가 없어서 사기 치기 쉬움 문제 4: 환경 문제 ───────────────────── 채굴에 전기 엄청 씀 (비트코인) 탄소 발자국 문제 문제 5: 아직 초기 ───────────────────── 제대로 된 서비스 적음 투기 목적이 대부분 "기술은 있는데 킬러 앱이 없다"

Part 5. Web 1.0 vs 2.0 vs 3.0 비교

Web 1.0 Web 2.0 Web 3.0
시대 1990~2005 2005~현재 2020~미래
키워드 읽기 읽기+쓰기 읽기+쓰기+소유
콘텐츠 기업이 생산 사용자도 생산 사용자가 소유
데이터 서버에 저장 플랫폼이 소유 사용자가 소유
구조 중앙 집중 플랫폼 중심 탈중앙화
신원 없음 플랫폼 계정 지갑 주소
결제 은행/카드 은행/카드/페이 암호화폐
대표 서비스 야후, 네이버 구글, 페이스북 이더리움, OpenSea
한 문장으로 정리하면?
[한 문장 정리] Web 1.0: 기업 → 사용자 (일방향) "우리가 만든 거 봐" Web 2.0: 기업 ↔ 사용자 (양방향) "네가 만들어, 우리가 관리할게" Web 3.0: 사용자 ↔ 사용자 (탈중앙) "네가 만들고, 네가 소유해"

Part 6. 개발자 관점에서

개발자 입장에서 뭐가 달라?
[Web 2.0 개발] 프론트엔드: React, Vue, Angular 백엔드: Node.js, Spring, Django 데이터베이스: MySQL, MongoDB 서버: AWS, GCP, Azure 인증: 구글 로그인, 카카오 로그인 → 서버가 핵심! → 서버 죽으면 서비스 끝
[Web 3.0 개발] 프론트엔드: React + Web3.js/ethers.js 백엔드: 스마트 컨트랙트 (Solidity) 데이터베이스: 블록체인, IPFS 서버: 탈중앙화 네트워크 인증: 지갑 연결 (MetaMask) → 스마트 컨트랙트가 핵심! → 한번 배포하면 수정 어려움
스마트 컨트랙트가 뭐야?

블록체인에서 돌아가는 프로그램이야.

[스마트 컨트랙트 예시 - Solidity] // 간단한 투표 컨트랙트 contract Voting { mapping(address => bool) public hasVoted; mapping(string => uint) public votes; function vote(string memory candidate) public { require(!hasVoted[msg.sender], "Already voted"); hasVoted[msg.sender] = true; votes[candidate]++; } } → 한번 배포하면 코드 변경 불가 → 누구나 검증 가능 → 중앙 서버 없이 돌아감
게임 개발자한테는 어떤 의미야?

게임 아이템을 진짜 소유할 수 있어!

[Web 2.0 게임] 플레이어: 100시간 플레이해서 전설 무기 획득! 게임사: "서비스 종료합니다" 플레이어: (전설 무기 증발) 또는: 플레이어: 전설 무기 현금 거래하고 싶어 게임사: "약관 위반! 계정 정지" [Web 3.0 게임 (P2E, Play-to-Earn)] 플레이어: 100시간 플레이해서 NFT 무기 획득! 게임사: "서비스 종료합니다" 플레이어: NFT는 내 지갑에 그대로 있음! 다른 게임에서 쓰거나 판매 가능 → 게임 아이템 = 진짜 자산 → 게임사 마음대로 못 뺏음

Part 7. 현실적인 시각

Web 3.0이 Web 2.0을 대체해?

당장은 아니야. 공존할 가능성이 높아.

[현실적인 전망] Web 3.0이 적합한 분야: - 금융 (DeFi) - 중개인 제거 - 디지털 자산 - 소유권 증명 - 투표/거버넌스 - 투명성 필요 - 크리에이터 이코노미 - 중간 수수료 제거 Web 2.0이 여전히 좋은 분야: - 일반 웹서비스 - 빠르고 편함 - 실시간 서비스 - 블록체인은 느림 - 대용량 데이터 - 블록체인에 다 못 담음 - 규제 필요한 분야 - 탈중앙화면 책임 소재 불명확
그래서 지금 뭘 공부해야 해?

기본기가 먼저!

[추천 학습 순서] 1단계: Web 2.0 기본기 (필수) - HTML, CSS, JavaScript - React/Vue (프론트엔드) - Node.js/Python (백엔드) - 데이터베이스 2단계: 블록체인 이해 - 블록체인 원리 - 이더리움 기초 - 지갑 사용법 3단계: Web 3.0 개발 - Solidity (스마트 컨트랙트) - Web3.js / ethers.js - Hardhat / Truffle (개발 도구) → Web 2.0 잘 모르면 Web 3.0도 못 해!

핵심 정리

  • Web 1.0 = 읽기 전용, 일방향, 기업이 콘텐츠 생산
  • Web 2.0 = 읽고 쓰기, 양방향, 플랫폼이 데이터 소유 (지금!)
  • Web 3.0 = 읽고 쓰고 소유, 탈중앙화, 사용자가 데이터 소유
  • 블록체인 = 여러 컴퓨터에 분산 저장, 위변조 어려움
  • 스마트 컨트랙트 = 블록체인에서 돌아가는 프로그램
  • Web 2.0 문제 = 플랫폼 의존, 데이터 소유권 없음
  • Web 3.0 문제 = 느림, 어려움, 사기 많음, 아직 초기
  • 현실 = 당장 대체 아님, 공존 + 점진적 도입
