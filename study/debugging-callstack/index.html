호출 스택(Call Stack) 읽는 법 — 프레임 이동, 외부 코드 표시

Part 1. 호출 스택이 뭐야?

Call Stack 창에 뭐가 보여?

함수 호출 경로가 보인다. "누가 나를 불렀는지"의 역순 목록.

맨 위가 현재 위치, 아래로 갈수록 호출한 쪽이다.

// Call Stack 예시 → CPlayer::TakeDamage() Line 234 ← 현재 위치 (여기서 터짐) CMonster::Attack() Line 567 ← TakeDamage를 호출한 함수 CGameManager::ProcessCombat() L890 ← Attack을 호출한 함수 CGameManager::OnTick() Line 123 main() Line 45

Part 2. 프레임 이동

호출한 함수의 변수를 보고 싶어

Call Stack에서 다른 함수를 더블클릭하면 그 함수의 컨텍스트로 이동한다.

→ 해당 함수의 지역 변수, 파라미터를 볼 수 있다.

Part 3. 외부 코드 표시

[External Code]라고만 나와

심볼(.pdb)이 없는 DLL 코드다.

Call Stack 창 우클릭 → "Show External Code" 체크하면 주소라도 보인다.

핵심 정리

  • Ctrl+Alt+C로 Call Stack 창 열기
  • 맨 위가 현재 위치, 아래가 호출한 쪽
  • 더블클릭으로 다른 프레임의 변수 확인
  • Show External Code로 외부 코드도 표시
