Nanite - 폴리곤 무제한 시대

Unreal 5 가상화 지오메트리

Part 1. Nanite란?

나나이트가 뭐야?

Unreal Engine 5의 가상화 지오메트리 시스템

폴리곤 수 제한 없음!

수십억 폴리곤도 실시간 렌더링

기존 방식 vs Nanite: 기존: 원본 모델 (1억 폴리곤) ↓ 아티스트가 수동으로 LOD0: 10만 폴리 LOD1: 1만 폴리 LOD2: 1천 폴리 ↓ 거리에 따라 LOD 전환 (팝핑 현상) Nanite: 원본 모델 (1억 폴리곤) ↓ 자동 처리 클러스터로 분할 → GPU가 실시간으로 필요한 디테일만 렌더링 ↓ 부드러운 전환, LOD 팝핑 없음!

Part 2. 동작 원리

어떻게 가능해?

1. 메시를 작은 클러스터로 분할

2. 클러스터별 계층적 LOD 생성

3. GPU가 화면에 보이는 것만 선택

Nanite 파이프라인: 1. 메시 → 클러스터 분할 (128 삼각형 단위) 2. 클러스터 → BVH 트리 구성 3. 렌더링 시: - GPU가 화면 픽셀별로 - 필요한 클러스터 LOD 선택 - 픽셀 크기에 맞는 디테일만 렌더링

Part 3. 장점

뭐가 좋아?

• LOD 수동 제작 불필요

• 폴리곤 팝핑 없음

• 영화 수준 에셋 바로 사용

• 메모리 자동 스트리밍

핵심 정리

  • Nanite = 가상화 지오메트리
  • 폴리곤 제한 없음 (수십억 OK)
  • 자동 LOD, 팝핑 없음
  • UE5의 핵심 기술
