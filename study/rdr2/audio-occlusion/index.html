동굴에서 총 쏘면 울림이 달라요

오디오 오클루전 & 리버브 시스템

Part 1: 공간감 있는 사운드의 중요성

Q: 왜 RDR2는 소리가 이렇게 현실적이에요?

공간에 따라 소리가 변하기 때문입니다.

같은 총소리라도:

  • 야외: 탁 트인 소리, 멀리까지 퍼짐
  • 동굴 안: 울림이 심함, 여러 번 반사됨
  • 건물 내부: 벽에 막혀 답답한 소리
  • 협곡: 메아리가 돌아옴

이걸 가능하게 하는 게 Audio Occlusion & Reverb입니다.

소리 전파 시뮬레이션 야외 (Open Field): 플레이어 ))) ))) ))) ))) → 멀리까지 직진 (차폐 없음) 동굴 (Cave): [벽] 플레이어 [벽] | ))) | | ←))) )))→ | | ))) ))) | └─────────────────────────┘ (벽에 반사되어 여러 방향) 건물 (Building): ┌──────────────┐ │ 플레이어 ))) │ ))) (벽 통과) │ │ (소리 감쇠) └──────────────┘

Part 2: Audio Occlusion (차폐)

Q: 벽 너머 총소리가 왜 작게 들려요?

Occlusion(차폐) 계산 때문입니다.

Occlusion 원리

소리와 청자 사이에 장애물이 있으면:

  1. 레이캐스트로 경로 확인
  2. 가로막는 재질 분석
  3. 재질별 감쇠값 적용
  4. 최종 음량 조정
// 오클루전 계산 (의사코드) function CalculateOcclusion(soundSource, listener): ray = CreateRay(soundSource.position, listener.position) occlusionValue = 0.0 for hit in ray.CastAll(): material = hit.collider.material // 재질별 차폐 강도 if material == "Wood": occlusionValue += 0.3 elif material == "Stone": occlusionValue += 0.7 elif material == "Metal": occlusionValue += 0.9 // 최종 음량 감소 volume = originalVolume * (1.0 - occlusionValue) // Low-pass 필터 적용 (고음 차단) cutoffFrequency = 5000 * (1.0 - occlusionValue) ApplyLowPassFilter(sound, cutoffFrequency) return volume
Occlusion 레이캐스트 플레이어 [나무벽] [돌벽] 총소리 👤 ←─────────────── [Wood] ←─────── [Stone] ←─────── 💥 계산: 원본 음량: 1.0 나무 감쇠: -0.3 → 0.7 돌벽 감쇠: -0.7 → 0.0 (거의 안 들림) 고음 필터: 원본: 20,000 Hz 차폐 후: 1,500 Hz (저음만 통과)

Part 3: Audio Obstruction (가림)

Q: Occlusion이랑 Obstruction 뭐가 달라요?

완전 차단 vs 부분 차단의 차이입니다.

구분 Occlusion Obstruction
정의 직선 경로가 완전 차단 경로가 부분적으로 막힘
예시 벽 뒤 기둥 옆
효과 음량 큰 폭 감소 + 고음 제거 음량 약간 감소

Obstruction 실제 예시

플레이어가 나무 뒤에 있을 때:

  • 직선 경로는 막혔지만
  • 나무 주변으로 소리가 돌아옴
  • → 완전 차단은 아니지만 약간 작게 들림
Occlusion vs Obstruction [Occlusion - 완전 차단] 총소리 [두꺼운 벽] 플레이어 💥 ))) [██████] 👤 (거의 안 들림) [Obstruction - 부분 차단] 총소리 [기둥] 플레이어 💥 ))) [█] ))) 👤 ))) ))) (주변으로 우회)
// Obstruction 계산 function CalculateObstruction(soundSource, listener): directPath = CreateRay(soundSource, listener) if directPath.IsBlocked(): // 주변 경로 탐색 (여러 방향) alternativePaths = [] for angle in [-45, -30, 0, 30, 45]: offset = CalculateOffset(angle, 2.0) // 2m 옆 path = CreateRay(soundSource + offset, listener) if not path.IsBlocked(): alternativePaths.Add(path) // 우회 경로 비율 obstructionValue = 1.0 - (alternativePaths.Count / 5.0) return obstructionValue * 0.5 // 최대 50% 감소 return 0.0 // 차단 없음

Part 4: Reverb Zone (공간 반향)

Q: 동굴에서 목소리가 왜 울려요?

Reverb Zone 시스템 때문입니다.

Reverb란?

소리가 벽/천장/바닥에 반사되어 여러 번 들리는 현상입니다.

RDR2의 Reverb Zone 종류:

  • Cave (동굴): 긴 울림 (2~4초)
  • Forest (숲): 짧은 울림 (0.3초)
  • Saloon (술집): 중간 울림 (0.8초)
  • Canyon (협곡): 메아리 (3~6초)
Reverb 시뮬레이션 (동굴) 천장 ────────────────────── ↑ ↓ │ ))) (반사 3) │ ↙ [벽] 플레이어 →)))→ 총소리 [벽] │ 👤 💥 │ ↖ │ ))) (반사 1) │ ↙ 바닥 ────────────────────── 청자가 듣는 순서: 1. 직접음 (0.00초) 2. 첫 반사 (0.05초) - 바닥 3. 두 번째 반사 (0.10초) - 천장 4. 세 번째 반사 (0.15초) - 벽 ... N. 울림 소멸 (2초 후)
// Reverb Zone 설정 struct ReverbZone: string zoneName float roomSize // 방 크기 float decayTime // 울림 지속 시간 float reflectivity // 반사율 float dampening // 감쇠 정도 // 동굴 프리셋 caveReverb = ReverbZone{ zoneName: "Elysian_Pool_Cave", roomSize: 50.0, // 50m 규모 decayTime: 3.5, // 3.5초 울림 reflectivity: 0.9, // 90% 반사 dampening: 0.2 // 20% 감쇠 } // Reverb 실시간 적용 function ApplyReverb(sound, zone): // 초기 반사 계산 earlyReflections = [] for i in 0 to 5: delay = (zone.roomSize / 343.0) * (i + 1) // 음속 amplitude = pow(zone.reflectivity, i) earlyReflections.Add({ delay: delay, volume: amplitude }) // Late reverb (후기 잔향) lateReverb = GenerateDecayingNoise( duration: zone.decayTime, dampening: zone.dampening ) // 믹싱 return Mix(sound, earlyReflections, lateReverb)

Part 5: Ray-based 오디오 시뮬레이션

Q: 모든 소리마다 레이캐스트 하면 느려지지 않아요?

LOD(Level of Detail) 시스템으로 최적화합니다.

오디오 LOD 전략

  1. 거리별 품질 조정
    • 0~10m: 매 프레임 레이캐스트
    • 10~50m: 0.2초마다 갱신
    • 50m 이상: 1초마다 갱신
  2. 중요도 기반 우선순위
    • 총소리, 폭발: 최고 우선순위
    • 발소리, 말소리: 중간
    • 환경음(새, 바람): 낮음
  3. 청각 컬링
    • 카메라 밖 소리는 간소화
    • 청자 뒤쪽 소리는 낮은 품질
// 오디오 LOD 시스템 class AudioLODManager: function UpdateSound(sound): distance = Distance(sound.position, listener.position) // 거리별 LOD if distance < 10.0: UpdateFrequency = EveryFrame RayCount = 5 // 5방향 레이캐스트 elif distance < 50.0: UpdateFrequency = Every_0_2_Seconds RayCount = 1 // 직선만 else: UpdateFrequency = Every_1_Second RayCount = 0 // 레이캐스트 스킵 // 중요도 가중치 priority = sound.importance * (1.0 / distance) if priority < 0.1: sound.Disable() // 너무 멀고 중요하지 않으면 꺼버림 return {UpdateFrequency, RayCount} // 실제 게임에서 총소리 = { importance: 1.0, // 최고 중요도 range: 500.0 // 500m까지 들림 } 발소리 = { importance: 0.3, range: 20.0 // 20m까지만 }

Part 6: 재질별 소리 (Material-based Audio)

Q: 왜 나무 바닥이랑 돌바닥 밟는 소리가 달라요?

재질(Material)마다 오디오 프로퍼티가 다르기 때문입니다.

재질 시스템

RDR2는 모든 표면에 재질 태그를 붙입니다:

재질별 오디오 특성 Wood (나무): ━━━━━━━━━━━━ 흡음률: 40% 반사율: 30% 공명 주파수: 200~500 Hz → 따뜻한 소리 Stone (돌): ▓▓▓▓▓▓▓▓▓▓▓▓ 흡음률: 10% 반사율: 80% 공명 주파수: 800~2000 Hz → 차갑고 울리는 소리 Metal (금속): ████████████ 흡음률: 5% 반사율: 90% 공명 주파수: 2000~5000 Hz → 날카로운 소리 Mud (진흙): :::::::::::: 흡음률: 70% 반사율: 10% 공명 주파수: 100~300 Hz → 둔탁한 소리
// 재질별 오디오 정의 enum MaterialType: Wood, Stone, Metal, Mud, Grass, Snow, Water struct MaterialAudioProperty: float absorption // 흡음률 float reflection // 반사율 float resonance // 공명 주파수 AudioClip[] soundSet // 재질별 사운드 세트 // 재질 데이터베이스 materials = { Wood: { absorption: 0.4, reflection: 0.3, resonance: 350.0, soundSet: [ "wood_step_01.wav", "wood_step_02.wav", ... ] }, Stone: { absorption: 0.1, reflection: 0.8, resonance: 1400.0, soundSet: [ "stone_step_01.wav", "stone_step_02.wav", ... ] } } // 발소리 재생 시 function PlayFootstep(playerPosition): surface = RaycastDown(playerPosition) material = surface.GetMaterial() // 재질에 맞는 사운드 선택 soundClip = materials[material].soundSet.GetRandom() // 재질 특성 적용 sound = PlaySound(soundClip) sound.SetLowPassFilter(material.resonance) sound.SetReverbSend(material.reflection) return sound

실제 게임 예시

Q: 구체적으로 어디서 이 기술을 체험할 수 있어요?

1. Elysian Pool 동굴

  • 동굴 입구에서 총 쏘면: 짧은 울림
  • 깊숙이 들어가서 쏘면: 3초 이상 울림
  • 동굴 밖 소리: Occlusion으로 거의 안 들림

2. Valentine 술집

  • 바깥 총소리: Occlusion + Obstruction 적용
  • 실내 총소리: 나무 재질 반사로 따뜻한 울림
  • 2층에서 쏘면: 아래층에 바닥 재질 감쇠 적용

3. Roanoke Ridge 협곡

  • 총소리가 6초간 메아리
  • 여러 방향에서 반사음 들림
  • 협곡 깊이에 따라 Reverb 시간 변화

💡 핵심 정리

  • Occlusion: 벽에 완전히 막혀서 소리 감쇠 + 고음 제거
  • Obstruction: 부분적으로 막혀서 약간 감쇠 (우회 경로 존재)
  • Reverb Zone: 공간 크기와 재질에 따라 울림 시뮬레이션
  • Ray-based: 레이캐스트로 실시간 경로 추적 (LOD 최적화)
  • Material System: 나무/돌/금속 등 재질마다 다른 음향 특성

기술적 의의:

단순히 배경음을 깔아주는 게 아니라, 물리 기반 음향 시뮬레이션으로 플레이어가 "지금 내가 어디 있는지" 소리만으로도 느낄 수 있게 만들었습니다. 이는 몰입도를 극대화하는 핵심 기술입니다.
