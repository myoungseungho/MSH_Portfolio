물에 비친 세상이 진짜 같아요

물 반사 시스템 (SSR + Planar Reflection + Cubemap)
Red Dead Redemption 2의 물은 단순한 텍스처가 아닙니다. 하늘, 나무, 건물이 정확하게 비치고, 물결에 따라 일렁입니다. 이것은 Screen Space Reflection, Planar Reflection, Cubemap을 조합한 하이브리드 시스템의 결과입니다.

Part 1: 물 반사의 중요성

Q. 왜 물 반사가 그렇게 중요한가요?
물은 게임 월드에서 가장 많이 보이는 반사 표면입니다. 반사 품질이 곧 몰입감입니다.

나쁜 물 반사의 문제:
  • 파란색 텍스처만 (하늘이 안 비침)
  • 고정된 Cubemap (움직이는 물체 반영 안 됨)
  • 시점 변화에 반응 없음 (거울이 아닌 스티커)
  • 물결과 반사가 따로 놈 (불일치)
나쁜 물 반사 vs 좋은 물 반사: [나쁜 예 - 고정 텍스처] 🌲 나무 (실제 오브젝트) │ ━━━━┼━━━━━━━━ ← 수면 ▒▒▒▒▒▒▒▒▒▒▒▒ ← 파란색 텍스처만 ▒▒▒▒▒▒▒▒▒▒▒▒ (나무 안 비침) [좋은 예 - 실시간 반사] 🌲 나무 (실제 오브젝트) │ │ 빛 ▼ ━━━━┼━━━━━━━━ ← 수면 │ 반사광 ▼ 🌲 ← 물에 비친 나무 ∼∼∼∼∼∼∼∼∼∼∼ (정확한 반사) 시점 변화: 카메라 A: 카메라 B: 👁 👁 ╲ ╱ ╲ ╱ ━━━━━━━━━━━━━━━━ 🌲 🏠 🌲 🏠 ← 시점에 따라 (나무+집) (집만) 다르게 보임

Part 2: Screen Space Reflection 기초

Q. SSR은 어떻게 동작하나요?
Screen Space Reflection (SSR)은 이미 렌더링된 화면을 재사용합니다. 물 픽셀에서 반사 방향으로 광선을 쏴서 화면의 다른 픽셀 색상을 가져옵니다.

SSR 장점:
  • 매우 빠름 (이미 렌더링된 화면 재사용)
  • 동적 오브젝트 반영 (캐릭터, 마차 등)
  • 정확한 시점 종속성 (각도에 따라 변화)
SSR 단점:
  • 화면 밖 오브젝트 반영 불가
  • 뒷면 반영 불가 (Depth Buffer 한계)
  • 노이즈 발생 (Ray Marching 샘플링)
Screen Space Reflection 원리: 1. 화면 렌더링 (이미 그려진 장면) ┌───────────────────┐ │ 🌲 🏠 ☁ │ ← Color Buffer │ │ │ ────────────── │ ← 수면 (물) │ │ └───────────────────┘ 2. 물 픽셀에서 Ray Marching 👁 카메라 ╲ ╲ View Ray ╲ ━━━●━━━━━━━━ ← 물 표면 ╲ ╲ Reflection Ray (반사광) ╲ 🌲 ← Hit! (화면의 나무 픽셀) 3. Ray Marching 과정 Step 1: ●────→ (스크린 UV: 0.3, 0.6) Step 2: ●────→ (스크린 UV: 0.35, 0.65) Step 3: ● (Hit! Depth 일치) 4. 결과 물 픽셀 색상 = Color[0.35, 0.65] (나무 색상) SSR의 한계: 카메라 화면 영역 화면 밖 👁 ┌─────────┐ ╲ │ 🌲 │ ╲ │ │ ━━━●━━┼─────────┤ ╲ │ │ ╲│ │ 🏠 ← 화면 밖 오브젝트 └─────────┘ ╲ ╲ ❌ 반사 불가 (화면에 없음) 
// 의사코드: Screen Space Reflection

function SSR_Reflection(float2 uv, float3 worldPos, float3 normal) {
    // 1. 반사 방향 계산
    float3 viewDir = normalize(worldPos - cameraPos);
    float3 reflectDir = reflect(viewDir, normal);

    // 2. 월드 → 스크린 공간 변환
    float4 reflectPosCS = mul(viewProjectionMatrix, float4(worldPos + reflectDir, 1.0));
    float2 reflectUV = reflectPosCS.xy / reflectPosCS.w * 0.5 + 0.5;

    // 3. Ray Marching (최대 32 steps)
    float stepSize = 0.05;  // 화면의 5%씩
    float2 currentUV = uv;
    float2 uvStep = (reflectUV - uv) * stepSize;

    for (int i = 0; i < 32; i++) {
        currentUV += uvStep;

        // 화면 밖이면 실패
        if (currentUV.x < 0 || currentUV.x > 1 ||
            currentUV.y < 0 || currentUV.y > 1) {
            return float4(0, 0, 0, 0);  // 실패 (알파 0)
        }

        // 현재 UV의 Depth
        float sceneDepth = depthBuffer.Sample(currentUV).r;
        float rayDepth = reflectPosCS.z + i * stepSize * 0.1;

        // Depth 비교 (충돌 검사)
        if (abs(rayDepth - sceneDepth) < 0.01) {
            // Hit! 색상 반환
            float3 reflectedColor = colorBuffer.Sample(currentUV).rgb;
            return float4(reflectedColor, 1.0);
        }
    }

    return float4(0, 0, 0, 0);  // Miss
}

// Pixel Shader (물 표면)
float4 WaterSurfacePS(float2 uv, float3 worldPos, float3 normal) {
    // 1. SSR 시도
    float4 ssrColor = SSR_Reflection(uv, worldPos, normal);

    // 2. SSR 실패 시 폴백
    if (ssrColor.a < 0.1) {
        // Planar Reflection 또는 Cubemap 사용 (Part 4, 5)
        ssrColor = FallbackReflection(worldPos, normal);
    }

    // 3. 물결 왜곡 적용 (Part 6)
    ssrColor.rgb = ApplyWaveDistortion(ssrColor.rgb, worldPos);

    return ssrColor;
}

Part 3: SSR의 한계

Q. SSR만으로는 부족한가요?
네. 화면 밖 정보를 반영할 수 없습니다. 예를 들어, 카메라 뒤의 산이 물에 비쳐야 하는데 SSR로는 불가능합니다.
SSR 실패 케이스: 케이스 1: 화면 밖 오브젝트 카메라 화면 화면 밖 👁 ┌─────┐ │ │ │ 🏔 산 │ │ │ ▼ │ │ ━━━━━━━━━━┼─────┤━━━━━━━ │ │ 물에 산이 │ ? │ ← SSR: 데이터 없음 비쳐야 함 └─────┘ 해결: Planar Reflection (산도 렌더링) 케이스 2: 뒷면 카메라 건물 뒷면 (화면에 안 보임) 👁 ┌───┐ ╲ │ │ ╲ │ │ ╲ └───┘ ━━━━━●━━━━━━━━━━━━━━━ ╲ ╲ ← SSR: Depth가 앞면만 있음 ╲ 뒷면 정보 없음 해결: Planar Reflection 케이스 3: 급격한 각도 (Grazing Angle) 카메라 👁───────────────→ (거의 수평 시점) ╱ ╱ ━━━━━━●━━━━━━━━ ╲ ╲ ← 반사광이 화면 밖으로 ╲ 해결: Cubemap Fallback 케이스 4: 투명 오브젝트 (유리창) 🪟 유리창 (투명) │ ▼ 화면에는 뒤 배경만 ━━━━━━━━━━━━━━ 물에 유리창이 ← SSR: 유리 자체 색상 없음 비쳐야 함 (Depth만 있음) 해결: Separate Transparent Pass

Part 4: Planar Reflection (평면 거울)

Q. Planar Reflection은 뭔가요?
평면 거울 기법입니다. 물 표면을 기준으로 카메라를 대칭 이동시켜 반대편 장면을 별도로 렌더링합니다.

Planar Reflection 장점:
  • 화면 밖 오브젝트 반영 가능
  • 완벽한 반사 (모든 정보 포함)
  • 뒷면도 렌더링 가능
단점:
  • 비용 높음 (장면을 2번 그림)
  • 평면 표면만 가능 (곡면 X)
Planar Reflection 원리: 1. 실제 카메라 위치 🌲 나무 │ 카메라 │ 👁 ────────┼───────→ (Original View) │ ━━━━━━━━━━━━●━━━━━━━━ ← 수면 (Reflection Plane) │ │ 👁' ─────────┼───────→ (Mirrored Camera) (대칭 카메라) │ 🌲' (거울상) 2. Mirrored Camera로 렌더링 ┌───────────────────┐ │ 🌲' │ ← Reflection Render Target │ │ (물 아래에서 위를 봄) └───────────────────┘ 3. 물 표면에 텍스처로 매핑 ┌───────────────────┐ │ 🌲 (실제 장면) │ │ │ │ ────────────── │ ← 수면 │ 🌲 (반사) │ ← Reflection Texture 샘플링 └───────────────────┘ Mirrored Camera 계산: Original Camera: Position: (0, 10, 0) LookAt: (0, 0, -10) Water Plane: Y = 0 Mirrored Camera: Position: (0, -10, 0) ← Y 반전 LookAt: (0, 0, 10) ← 방향도 반전 
// 의사코드: Planar Reflection

struct PlanarReflection {
    RenderTexture reflectionRT;  // 512×512 ~ 1024×1024
    Camera mirroredCamera;
    Plane waterPlane;            // Y = waterHeight
}

function RenderPlanarReflection() {
    // 1. 물 평면 정의
    waterPlane = Plane(normal: vec3(0, 1, 0), distance: waterHeight);

    // 2. 미러 카메라 위치 계산
    vec3 originalPos = mainCamera.position;
    vec3 mirroredPos = ReflectPointAcrossPlane(originalPos, waterPlane);

    mirroredCamera.position = mirroredPos;

    // 3. 미러 카메라 방향 계산
    vec3 originalForward = mainCamera.forward;
    vec3 mirroredForward = ReflectVectorAcrossPlane(originalForward, waterPlane);

    mirroredCamera.SetLookDirection(mirroredForward);

    // 4. Oblique Projection (물 아래는 안 그림)
    mirroredCamera.projectionMatrix = CalculateObliqueMatrix(waterPlane);

    // 5. 반사 렌더링 (저해상도 + LOD 낮춤)
    mirroredCamera.targetTexture = reflectionRT;
    mirroredCamera.cullingMask = REFLECTION_LAYER;  // 중요한 것만
    mirroredCamera.Render();
}

// 점을 평면 기준으로 반사
function ReflectPointAcrossPlane(vec3 point, Plane plane) {
    float distance = dot(plane.normal, point) - plane.distance;
    return point - 2.0 * distance * plane.normal;
}

// 벡터를 평면 기준으로 반사
function ReflectVectorAcrossPlane(vec3 vector, Plane plane) {
    return vector - 2.0 * dot(vector, plane.normal) * plane.normal;
}

// Oblique Projection (물 아래 클리핑)
function CalculateObliqueMatrix(Plane clipPlane) {
    mat4 projection = mainCamera.projectionMatrix;

    // Clip Plane을 View Space로 변환
    vec4 clipPlaneVS = mul(mainCamera.worldToCameraMatrix, clipPlane);

    // Projection Matrix 수정 (Near Plane을 Clip Plane으로)
    projection[2] = clipPlaneVS.x;  // M[0][2]
    projection[6] = clipPlaneVS.y;  // M[1][2]
    projection[10] = clipPlaneVS.z; // M[2][2]
    projection[14] = clipPlaneVS.w; // M[3][2]

    return projection;
}

// Pixel Shader (물 표면)
float4 WaterWithPlanarPS(float2 uv, float3 worldPos) {
    // 1. 월드 좌표 → Reflection UV
    vec4 reflectionPos = mul(mirroredCamera.viewProjectionMatrix, vec4(worldPos, 1.0));
    vec2 reflectionUV = reflectionPos.xy / reflectionPos.w * 0.5 + 0.5;

    // 2. Reflection Texture 샘플링
    vec3 reflectionColor = reflectionRT.Sample(reflectionUV).rgb;

    // 3. 물결 왜곡 (Normal Map)
    vec2 distortion = normalMap.Sample(uv).rg * 2.0 - 1.0;
    reflectionUV += distortion * 0.05;  // 5% 왜곡

    reflectionColor = reflectionRT.Sample(reflectionUV).rgb;

    return float4(reflectionColor, 1.0);
}

Part 5: 하이브리드 접근 (SSR + Planar + Cubemap)

Q. RDR2는 어떤 방식을 쓰나요?
3가지를 모두 조합합니다. 상황에 따라 최적의 기법을 선택하고 블렌딩합니다.
RDR2 하이브리드 반사 시스템: 우선순위 1: SSR (가장 정확, 가장 빠름) ✓ 화면 안 오브젝트 ✓ 동적 오브젝트 (캐릭터, 마차) ✓ 날카로운 반사 (금속, 젖은 바위) 우선순위 2: Planar Reflection (중요한 물 표면) ✓ 호수, 강 (큰 평면 물) ✓ 화면 밖 풍경 (산, 하늘) ✓ 정적 환경 (나무, 건물) 우선순위 3: Cubemap (폴백) ✓ SSR 실패 (화면 밖) ✓ Planar 비활성 (성능 모드) ✓ 흐린 반사 (거친 표면) 블렌딩 전략: 픽셀 조건 선택 가중치 ───────────────────────────────────────────── 화면 안 + 각도 좋음 SSR 100% 화면 안 + 각도 나쁨 SSR 70% + 70% (Grazing Angle) Planar 30% 30% 화면 밖 Planar 80% + 80% Cubemap 20% 20% 물결 강함 Cubemap 60% + 60% (Normal 왜곡 심함) Planar 40% 40% 성능 모드 SSR 50% + 50% Cubemap 50% 50% 
// 의사코드: 하이브리드 반사

struct HybridReflectionSystem {
    bool enableSSR = true;
    bool enablePlanar = true;
    TextureCube environmentCubemap;  // 미리 베이크된 환경맵
    RenderTexture planarRT;
}

function HybridReflection(float2 uv, float3 worldPos, float3 normal) {
    vec3 viewDir = normalize(worldPos - cameraPos);
    vec3 reflectDir = reflect(viewDir, normal);

    // 1. SSR 시도
    float4 ssrResult = SSR_Reflection(uv, worldPos, normal);
    float ssrConfidence = ssrResult.a;  // 0~1 (성공도)

    // 2. Planar Reflection
    vec3 planarColor = SamplePlanarReflection(worldPos, reflectDir);

    // 3. Cubemap Fallback
    vec3 cubemapColor = environmentCubemap.Sample(reflectDir).rgb;

    // 4. 블렌딩 가중치 계산
    float grazingAngle = abs(dot(normal, viewDir));  // 0 = 수평, 1 = 수직

    // SSR 가중치 (화면 안 + 각도 좋으면 높음)
    float ssrWeight = ssrConfidence * smoothstep(0.1, 0.5, grazingAngle);

    // Planar 가중치 (화면 밖이면 높음)
    float planarWeight = (1.0 - ssrConfidence) * 0.8;

    // Cubemap 가중치 (나머지)
    float cubemapWeight = 1.0 - ssrWeight - planarWeight;

    // 5. 최종 블렌딩
    vec3 finalColor = ssrResult.rgb * ssrWeight +
                      planarColor * planarWeight +
                      cubemapColor * cubemapWeight;

    // 6. 물 고유 색상 혼합 (깊이에 따라)
    float waterDepth = GetWaterDepth(worldPos);
    vec3 waterColor = vec3(0.1, 0.3, 0.4);  // 파란빛
    float waterColorAmount = smoothstep(0.0, 5.0, waterDepth);  // 5m까지

    finalColor = lerp(finalColor, waterColor, waterColorAmount * 0.3);

    return float4(finalColor, 1.0);
}

// Cubemap 사전 베이크 (오프라인)
function BakeEnvironmentCubemap(vec3 position) {
    TextureCube cubemap = CreateCubemap(256);  // 256×256 각 면

    // 6방향 렌더링
    for each direction in [+X, -X, +Y, -Y, +Z, -Z] {
        Camera cubeCamera = CreateCamera(position, direction);
        cubeCamera.fov = 90;  // Cubemap은 90도
        cubeCamera.aspect = 1.0;

        RenderTexture face = cubeCamera.Render();
        cubemap.CopyFace(direction, face);
    }

    // Mipmap 생성 (거친 반사용)
    cubemap.GenerateMipmaps();

    return cubemap;
}

// Roughness에 따른 Cubemap Mip Level
function SampleCubemapWithRoughness(TextureCube cubemap, vec3 dir, float roughness) {
    // Roughness 0 = Mip 0 (선명)
    // Roughness 1 = Mip 8 (흐림)
    float mipLevel = roughness * 8.0;
    return cubemap.SampleLevel(dir, mipLevel).rgb;
}

Part 6: 물결에 따른 왜곡 (Normal Map)

Q. 물결은 어떻게 표현하나요?
Normal Map 애니메이션으로 물결을 표현하고, 이 노멀로 반사 방향을 왜곡시킵니다.
Normal Map 물결: 1. 평평한 물 (Normal = 위) ━━━━━━━━━━━━━━━━ ↑ ↑ ↑ ↑ ↑ ↑ ↑ ↑ ← 모든 노멀이 위 (반사 일정) 2. 물결이 있는 물 (Normal 변화) ∼∼∼∼∼∼∼∼∼∼∼∼∼∼ ↗ ↑ ↖ ↑ ↗ ↑ ↖ ↑ ← 노멀이 다양 (반사 왜곡) Normal Map 샘플링 (UV 애니메이션): 시간 T=0: UV = baseUV + time × flowSpeed = (0.5, 0.5) + 0 × 0.1 = (0.5, 0.5) 시간 T=10: UV = (0.5, 0.5) + 10 × 0.1 = (0.5, 1.5) → wrap → (0.5, 0.5) (반복) 2개 Normal Map 혼합 (더 자연스러움): Normal1 (큰 파도): UV1 = baseUV + time × 0.05 + vec2(1, 0) ∼∼∼∼∼∼∼∼ Normal2 (작은 물결): UV2 = baseUV + time × 0.15 + vec2(0, 1) ˙˙˙˙˙˙˙˙ 최종 = (Normal1 + Normal2) / 2 ∼˙∼˙∼˙∼˙ ← 복잡한 물결 반사 왜곡: 평평한 물: reflectDir = reflect(viewDir, vec3(0, 1, 0)) ────────→ (일정한 방향) 물결 있는 물: normal = NormalMap.Sample(uv) // (0.2, 0.9, 0.1) reflectDir = reflect(viewDir, normal) ──╱╲──→ (흔들림) 
// 의사코드: 물결 Normal Map

struct WaterWaveSystem {
    Texture2D normalMap1;    // 큰 파도 (2m)
    Texture2D normalMap2;    // 중간 물결 (0.5m)
    Texture2D normalMap3;    // 작은 잔물결 (0.1m)
    float time;
    vec2 flowDirection;      // 물 흐름 방향
}

function SampleWaterNormal(vec2 baseUV, float time) {
    // 1. 각 Normal Map의 UV 계산 (애니메이션)
    vec2 uv1 = baseUV * 0.1 + time * 0.03 * flowDirection;  // 느림
    vec2 uv2 = baseUV * 0.5 + time * 0.08 * vec2(-flowDirection.y, flowDirection.x);  // 중간 (직각)
    vec2 uv3 = baseUV * 2.0 + time * 0.15 * flowDirection;  // 빠름

    // 2. Normal 샘플링 (0~1 → -1~1 변환)
    vec3 normal1 = normalMap1.Sample(uv1).rgb * 2.0 - 1.0;
    vec3 normal2 = normalMap2.Sample(uv2).rgb * 2.0 - 1.0;
    vec3 normal3 = normalMap3.Sample(uv3).rgb * 2.0 - 1.0;

    // 3. 가중치 혼합 (큰 파도가 더 강함)
    vec3 blendedNormal = normal1 * 0.5 +
                         normal2 * 0.3 +
                         normal3 * 0.2;

    // 4. 재정규화
    blendedNormal = normalize(blendedNormal);

    return blendedNormal;
}

// 바람에 의한 물결 강도
function ApplyWindEffect(vec3 normal, vec3 windVelocity) {
    float windSpeed = length(windVelocity);

    // 바람 세면 물결 강함
    float waveStrength = smoothstep(0.0, 10.0, windSpeed);  // 0~10 m/s

    // Normal의 XZ 성분 증폭 (Y는 유지)
    normal.xz *= (1.0 + waveStrength);
    normal = normalize(normal);

    return normal;
}

// Pixel Shader (물 표면 최종)
float4 WaterSurfacePS(float2 uv, float3 worldPos) {
    // 1. Water Normal 계산
    vec3 waterNormal = SampleWaterNormal(uv, gameTime);
    waterNormal = ApplyWindEffect(waterNormal, windVelocity);

    // 2. Tangent Space → World Space
    vec3 tangent = vec3(1, 0, 0);
    vec3 bitangent = vec3(0, 0, 1);
    vec3 worldNormal = waterNormal.x * tangent +
                       waterNormal.y * vec3(0, 1, 0) +
                       waterNormal.z * bitangent;

    // 3. 하이브리드 반사
    vec3 reflection = HybridReflection(uv, worldPos, worldNormal);

    // 4. Fresnel 효과 (각도에 따른 반사율)
    float fresnel = Fresnel(worldNormal, viewDir);

    // 5. 최종 색상 (반사 + 물 고유색)
    vec3 waterBaseColor = vec3(0.05, 0.15, 0.25);
    vec3 finalColor = lerp(waterBaseColor, reflection, fresnel);

    // 6. Foam (물거품) - 물결 끝
    float foam = FoamMask(worldPos, waterNormal);
    finalColor = lerp(finalColor, vec3(1, 1, 1), foam);

    return float4(finalColor, 0.9);  // 약간 투명
}

// Fresnel 효과 (Schlick's Approximation)
function Fresnel(vec3 normal, vec3 viewDir) {
    float F0 = 0.02;  // 물의 반사율 (정면)
    float cosTheta = max(0.0, dot(normal, -viewDir));
    return F0 + (1.0 - F0) * pow(1.0 - cosTheta, 5.0);
}

// Foam (물거품) - 물결 정점
function FoamMask(vec3 worldPos, vec3 normal) {
    // 정점 (Y가 높은 곳)에 거품
    float height = worldPos.y - waterHeight;
    float foam = smoothstep(0.05, 0.1, height);  // 5~10cm

    // 경사가 급한 곳에도 거품
    foam += smoothstep(0.7, 0.9, abs(normal.x) + abs(normal.z));

    return clamp(foam, 0.0, 1.0);
}

💡 핵심 정리

  • SSR: 화면 재사용, 빠름, 화면 밖 불가
  • Planar Reflection: 미러 카메라, 완벽한 반사, 비용 높음
  • Cubemap: 미리 베이크, 폴백용, 정적 환경
  • 하이브리드: SSR (화면 안) + Planar (화면 밖) + Cubemap (폴백)
  • 블렌딩 가중치: SSR 성공도, Grazing Angle, 화면 위치
  • Normal Map 물결: 3개 레이어 혼합, UV 애니메이션
  • Fresnel: 각도에 따른 반사율 (정면 2%, 옆면 100%)
  • Foam: 물결 정점 + 경사면에 거품
게임 내 적용 예시:
  • 호수에 산과 하늘이 정확하게 비침 (Planar)
  • 캐릭터가 물가를 걸으면 반사에도 보임 (SSR)
  • 바람 불면 물결 강해지고 반사 흔들림 (Normal Map + Wind)
  • 물웅덩이에 빗방울 떨어지면 동심원 파문 (Ripple Simulation)
  • 석양에 물이 금빛으로 빛남 (Fresnel + Sun Color)
  • 폭포에서 물거품 많이 생김 (Foam Mask)
참고: RDR2는 물 시스템에 추가로 Underwater Caustics (물속 빛 패턴), Shoreline Waves (해안 파도), Dynamic Buoyancy (부력 시뮬레이션)도 구현되어 있습니다. 물 위에 떠 있는 통나무, 시체, 보트가 모두 실시간으로 물결에 반응합니다.
