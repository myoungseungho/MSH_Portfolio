Atmospheric Scattering

RDR2의 하늘은 단순한 텍스처가 아닙니다. 정오의 깊은 파란색, 황혼의 붉은 노을, 밤의 짙은 남색... 시간에 따라 하늘 색이 물리 법칙에 따라 변합니다. 이 모든 것은 Atmospheric Scattering(대기 산란) 시뮬레이션으로 만들어집니다. 실제 빛이 대기를 통과하며 산란되는 과정을 수학적으로 모델링한 것입니다.

Part 1: 왜 하늘은 파랗고 노을은 붉은가?

왜 낮 하늘은 파란색인가요?
태양 빛은 모든 파장의 빛(무지개 색)을 포함합니다. 대기 중 질소/산소 분자는 짧은 파장(파란색)을 더 강하게 산란시킵니다. 하늘을 보면 모든 방향에서 산란된 파란 빛이 눈에 들어오므로 하늘이 파랗게 보입니다.

Rayleigh Scattering 법칙

산란 강도는 파장의 4제곱에 반비례합니다: 

산란 강도 ∝ 1 / λ⁴

파란빛 (450nm): 1 / (450⁴) = 약 24 배
빨간빛 (650nm): 1 / (650⁴) = 약 1 배

→ 파란빛이 빨간빛보다 24배 더 강하게 산란됨

Part 2: Rayleigh Scattering (파장별 산란)

Rayleigh Scattering은 대기 분자(질소, 산소)에 의한 산란입니다. 파장이 짧을수록 강하게 산란됩니다. 

// Rayleigh Scattering 계산
float3 RayleighScattering(
    float3 viewDir,        // 시선 방향
    float3 sunDir,         // 태양 방향
    float altitude,        // 고도
    float sunIntensity
) {
    // Rayleigh 산란 계수 (RGB 파장별)
    float3 betaR = float3(
        5.8e-6,   // 빨강 (650nm)
        13.5e-6,  // 초록 (510nm)
        33.1e-6   // 파랑 (450nm)
    );

    // 대기 밀도 (고도에 따라 감소)
    float densityR = exp(-altitude / 8000.0);  // Scale height: 8km

    // 시선 방향 경로 적분
    float viewDist = RayAtmosphereIntersection(viewDir, altitude);

    // 광학 깊이 (Optical Depth)
    float3 opticalDepth = betaR * densityR * viewDist;

    // 투과율 (Transmittance)
    float3 transmittance = exp(-opticalDepth);

    // 위상 함수 (Phase Function) - 각도 의존성
    float mu = dot(viewDir, sunDir);
    float phaseR = (3.0 / (16.0 * PI)) * (1.0 + mu * mu);

    // 최종 산란 색상
    float3 scattering = betaR * phaseR * (1.0 - transmittance) * sunIntensity;

    return scattering;
}

Part 3: Mie Scattering (먼지, 안개)

Mie Scattering은 대기 중 큰 입자(먼지, 수증기, 연기)에 의한 산란입니다. 파장에 덜 민감하며, 주로 태양 방향으로 강하게 산란됩니다.

Rayleigh와 Mie의 차이는?
Rayleigh: 작은 분자 (파장 의존성 높음) → 하늘 전체 밝게
Mie: 큰 입자 (파장 의존성 낮음) → 태양 주변에 후광(Halo) 
// Mie Scattering 계산
float3 MieScattering(
    float3 viewDir,
    float3 sunDir,
    float altitude,
    float sunIntensity
) {
    // Mie 산란 계수 (파장 거의 무관)
    float3 betaM = float3(21e-6, 21e-6, 21e-6);

    // 대기 밀도 (Mie는 낮은 고도에 집중)
    float densityM = exp(-altitude / 1200.0);  // Scale height: 1.2km

    // 위상 함수 (Henyey-Greenstein)
    float g = 0.76;  // 전방 산란 계수
    float mu = dot(viewDir, sunDir);
    float phaseM = (3.0 / (8.0 * PI)) *
                   ((1.0 - g * g) * (1.0 + mu * mu)) /
                   ((2.0 + g * g) * pow(1.0 + g * g - 2.0 * g * mu, 1.5));

    // 광학 깊이
    float viewDist = RayAtmosphereIntersection(viewDir, altitude);
    float3 opticalDepth = betaM * densityM * viewDist;
    float3 transmittance = exp(-opticalDepth);

    // 최종 산란
    float3 scattering = betaM * phaseM * (1.0 - transmittance) * sunIntensity;

    return scattering;
}

Rayleigh vs Mie 산란 패턴
================================

Rayleigh (균일 산란)
         ○
      ○  │  ○      균등하게 사방으로 산란
   ○ ────●──── ○   (하늘 전체가 밝음)
      ○  │  ○
         ○

Mie (전방 산란)
         ○
      ○  │  ○
   ○ ────●────────────○○○  태양 방향으로
      ○  │  ○              강하게 산란
         ○                 (후광 효과)

Part 4: 시간에 따른 하늘 색 변화

RDR2는 하루 24시간 동안 하늘 색이 실시간으로 변합니다. 태양 고도각에 따라 대기 경로 길이가 달라지기 때문입니다. 

// 시간별 하늘 색 계산
float3 CalculateSkyColor(float3 viewDir, float timeOfDay) {
    // 태양 위치 계산 (시간 기반)
    float sunAngle = (timeOfDay / 24.0) * 2.0 * PI;
    float3 sunDir = float3(
        cos(sunAngle),
        sin(sunAngle),  // 고도각
        0
    );

    // 카메라 고도
    float altitude = cameraPosition.y;

    // 태양 강도 (밤에는 약함)
    float sunIntensity = max(0, sunDir.y) * 20.0;

    // Rayleigh + Mie 조합
    float3 rayleigh = RayleighScattering(viewDir, sunDir, altitude, sunIntensity);
    float3 mie = MieScattering(viewDir, sunDir, altitude, sunIntensity);

    // 최종 하늘 색
    float3 skyColor = rayleigh + mie;

    return skyColor;
}

하루 주기별 하늘 색

  • 새벽 (5~6시): 지평선 근처 오렌지-핑크 (낮은 태양 고도)
  • 정오 (12시): 깊은 파란색 (태양 정상, 짧은 경로)
  • 황혼 (18~19시): 붉은 노을 (긴 대기 경로)
  • 밤 (0~4시): 짙은 남색 (간접 산란만)

Tone Mapping으로 색상 조절

대기 산란 계산 결과는 HDR(High Dynamic Range)입니다. 실제 화면에 표시하려면 LDR로 변환해야 합니다. 

// Filmic Tone Mapping
float3 ToneMap(float3 hdrColor) {
    // ACES Filmic Tone Mapping
    float3 x = hdrColor;
    float a = 2.51;
    float b = 0.03;
    float c = 2.43;
    float d = 0.59;
    float e = 0.14;

    return saturate((x * (a * x + b)) / (x * (c * x + d) + e));
}

Part 5: God Rays (빛줄기) 구현

숲 속에서 나무 사이로 보이는 빛줄기, 구름 사이로 새어나오는 햇살... 이는 Volumetric Light Scattering으로 구현됩니다. 

God Rays 형성 원리
================================

       ☀️ 태양
        │││
        │││  ← 빛
    ┌───┼┼┼───┐
    │   │││   │  구름 (차폐물)
    │   ││    │
    └───││────┘
        ││
      빛││줄기  ← 대기 산란으로 가시화
        ││     (보통은 안 보임)
        ││
        ││
     👁️ 관찰자
            
// God Rays (Radial Blur 방식)
float3 GodRays(Texture2D sceneColor, float2 screenUV, float2 sunScreenPos) {
    float3 result = 0;
    int samples = 100;

    // 태양 방향으로 레이 마칭
    float2 delta = (sunScreenPos - screenUV) / samples;

    float2 uv = screenUV;
    float illuminationDecay = 1.0;

    for (int i = 0; i < samples; i++) {
        uv += delta;

        // 씬 샘플링
        float3 sample = sceneColor.Sample(sampler, uv).rgb;

        // 거리 기반 감쇠
        sample *= illuminationDecay * 0.01;
        result += sample;

        illuminationDecay *= 0.97;  // 점점 어두워짐
    }

    return result;
}

실시간 볼류메트릭 라이팅

보다 정확한 God Rays는 3D 볼륨 텍스처에 대기 산란을 누적합니다. 

// Volumetric Scattering (Voxel Grid)
float3 VolumetricScattering(float3 rayStart, float3 rayDir, float rayLength) {
    float3 scattering = 0;
    int steps = 64;
    float stepSize = rayLength / steps;

    for (int i = 0; i < steps; i++) {
        float t = i * stepSize;
        float3 pos = rayStart + rayDir * t;

        // 이 지점의 대기 밀도
        float density = GetAtmosphereDensity(pos);

        // 태양으로부터 빛 전달
        float3 sunLight = CalculateSunTransmittance(pos, sunDir);

        // 산란 누적
        scattering += density * sunLight * stepSize;
    }

    return scattering;
}

Part 6: Aerial Perspective (원경 안개)

먼 산이 흐릿하게 보이는 이유는?
멀리 있는 물체를 볼 때, 물체와 카메라 사이의 대기를 통과하는 빛은 산란되어 일부가 손실되고 대기 색상이 섞입니다. 이를 Aerial Perspective라 합니다. 
Aerial Perspective 효과
================================

카메라   →   근경    →   중경    →   원경
👁️         🏠        🏔️        ⛰️
          (선명)    (약간 흐림)  (매우 흐림)

거리별 대기 영향:

0~100m:  대기 영향 거의 없음
          원본 색상 100%

500m:    대기 색 20% 혼합
          색상 = 원본 * 0.8 + 하늘색 * 0.2

2km:     대기 색 60% 혼합
          색상 = 원본 * 0.4 + 하늘색 * 0.6

10km+:   거의 하늘색
          색상 ≈ 하늘색
            
// Aerial Perspective 적용
float3 ApplyAerialPerspective(
    float3 objectColor,
    float3 objectPosition,
    float3 cameraPosition
) {
    // 거리 계산
    float distance = length(objectPosition - cameraPosition);

    // 대기 색상 (현재 하늘 색)
    float3 viewDir = normalize(objectPosition - cameraPosition);
    float3 atmosphereColor = CalculateSkyColor(viewDir, timeOfDay);

    // 거리 기반 혼합 비율 (지수 감쇠)
    float fogDensity = 0.0001;  // 대기 밀도
    float fogAmount = 1.0 - exp(-distance * fogDensity);

    // 최종 색상 = 원본 + 대기
    float3 finalColor = lerp(objectColor, atmosphereColor, fogAmount);

    return finalColor;
}

Height Fog (고도별 안개)

계곡 바닥에는 안개가 짙고, 산 정상은 맑게 보입니다. 이는 고도에 따른 대기 밀도 변화로 시뮬레이션합니다. 

// Height Fog
float CalculateHeightFog(float3 position, float3 cameraPos) {
    float fogHeight = 100.0;     // 안개 기준 고도
    float fogFalloff = 0.01;     // 고도별 감쇠

    // 평균 고도
    float avgHeight = (position.y + cameraPos.y) * 0.5;

    // 고도 기반 밀도
    float heightDensity = exp(-max(0, avgHeight - fogHeight) * fogFalloff);

    return heightDensity;
}

📌 핵심 요약

  • Rayleigh Scattering: 짧은 파장(파란색) 강하게 산란 → 파란 하늘
  • Mie Scattering: 큰 입자, 전방 산란 → 태양 주변 후광
  • 시간별 변화: 태양 고도각 → 대기 경로 길이 → 하늘 색 변화
  • God Rays: Radial Blur 또는 Volumetric Scattering으로 빛줄기 표현
  • Aerial Perspective: 거리에 따라 대기 색 혼합하여 원경 안개 효과
왜 이렇게 복잡한 물리 시뮬레이션을 하나요?
단순한 그라데이션 텍스처로는 RDR2의 다양한 시간대와 날씨를 표현할 수 없습니다. 새벽의 차가운 푸른빛, 석양의 따뜻한 오렌지, 폭풍 전의 어두운 하늘... 물리 기반 대기 산란은 이 모든 변화를 하나의 수식으로 표현합니다. 결과적으로 플레이어는 "살아있는 세계"를 경험합니다.
