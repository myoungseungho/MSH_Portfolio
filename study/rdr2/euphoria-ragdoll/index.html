죽은 NPC가 계단에서 굴러요

Euphoria 래그돌 물리엔진

Part 1: 기존 래그돌의 문제

Q: 일반 게임에서 적 죽이면 왜 인형처럼 늘어져요?

기존 래그돌은 단순 물리 시뮬레이션이기 때문입니다.

전통적 래그돌(Ragdoll)의 한계

  • 즉시 힘 상실: 죽는 순간 모든 근육이 사라짐
  • 부자연스러운 자세: 물리만 적용되어 이상한 포즈
  • 상황 무시: 계단이든 절벽이든 똑같은 반응
  • 생존 본능 없음: 떨어질 때 손으로 잡지 않음

→ "죽은 마네킹" 같은 느낌

전통 Ragdoll vs Euphoria [전통 Ragdoll - 즉시 힘 상실] 살아있음 죽음 (즉시) 🧍 💀 ╱|╲ ╱ | \ ⟋ | ⟍ (완전히 늘어짐) [Euphoria - 점진적 힘 상실] 살아있음 → 중상 → 사망 🧍 😵 💀 ╱ | |╲ (버티려 함) (천천히 쓰러짐) Euphoria는 "죽어가는 과정"을 시뮬레이션

Part 2: Euphoria란?

Q: Euphoria가 뭐예요?

NaturalMotion사의 Procedural Animation 엔진입니다.

핵심 개념

Euphoria는 Active Ragdoll 기술입니다.

구분 Passive Ragdoll Active Ragdoll (Euphoria)
근육 없음 (죽으면 즉시 사라짐) 있음 (점진적으로 약해짐)
의식 없음 생존 본능 (Balance, Protect)
반응 물리만 적용 상황 인식 + 물리
자연스러움 낮음 매우 높음

Euphoria의 3대 요소

  1. Motor System: 근육 시뮬레이션 (힘 제어)
  2. Behavior System: 행동 결정 (균형 잡기, 보호하기)
  3. Physics Integration: 물리 엔진과 통합
// Euphoria Active Ragdoll 구조 (의사코드) struct EuphoriaCharacter: RigidBody[] bones // 뼈대 (물리 바디) Joint[] joints // 관절 Motor[] motors // 근육 모터 Behavior[] behaviors // 행동 컨트롤러 float consciousness // 의식 수준 (0~1) struct Motor: Joint targetJoint float maxForce // 최대 근력 float currentStrength // 현재 근력 (의식에 비례) Quaternion targetRotation // 목표 각도 function UpdateEuphoria(character, deltaTime): // 1. 의식 수준 업데이트 (데미지에 따라 감소) character.consciousness -= character.damage * deltaTime // 2. 행동 선택 if character.consciousness > 0.5: behavior = SelectBehavior("Balance") // 균형 유지 elif character.consciousness > 0.2: behavior = SelectBehavior("Protect") // 머리 보호 else: behavior = SelectBehavior("Collapse") // 쓰러지기 // 3. 모터 제어 for motor in character.motors: targetAngle = behavior.GetTargetAngle(motor.targetJoint) actualStrength = motor.maxForce * character.consciousness // PD 컨트롤러로 관절 회전 ApplyTorque(motor.targetJoint, targetAngle, actualStrength) // 4. 물리 시뮬레이션 PhysicsStep(character.bones, deltaTime)

Part 3: Active Ragdoll (근육 시뮬레이션)

Q: 근육을 어떻게 시뮬레이션해요?

Motor(모터)로 관절에 토크를 가합니다.

Motor System

각 관절마다 모터가 있어서 목표 각도로 회전시킵니다.

예시: 팔꿈치 관절

  • 목표 각도: 90도 (팔 구부리기)
  • 현재 각도: 30도
  • 모터가 60도 회전시키는 토크 가함
  • 근력: 의식 수준에 비례 (0.8 → 80% 힘)
// PD 컨트롤러 (Proportional-Derivative) function ApplyMotorTorque(joint, targetAngle, strength): // 현재 각도 currentAngle = joint.GetCurrentAngle() // 각도 차이 (Proportional) error = targetAngle - currentAngle // 각속도 (Derivative) angularVelocity = joint.GetAngularVelocity() // PD 제어 kP = 100.0 // Proportional gain kD = 10.0 // Derivative gain torque = (kP * error - kD * angularVelocity) * strength // 최대 토크 제한 maxTorque = joint.maxMotorForce torque = Clamp(torque, -maxTorque, maxTorque) joint.ApplyTorque(torque) // 의식 수준에 따른 근력 변화 function UpdateMotorStrength(character): for motor in character.motors: // 의식이 떨어지면 근력도 감소 motor.currentStrength = motor.maxForce * character.consciousness // 부위별 차등 적용 if motor.bodyPart == "Legs": motor.currentStrength *= 0.3 // 다리는 먼저 힘 빠짐 elif motor.bodyPart == "Arms": motor.currentStrength *= 0.7 // 팔은 상대적으로 유지 elif motor.bodyPart == "Neck": motor.currentStrength *= 1.0 // 목은 끝까지 버팀
Motor 시뮬레이션 (팔 예시) 의식: 100% (건강) 어깨 ───┐ │ Motor (100% 힘) 팔꿈치 ───┐ │ Motor (100% 힘) 손목 → 팔을 들어올릴 수 있음 의식: 50% (중상) 어깨 ───┐ │ Motor (50% 힘) 팔꿈치 ╲ ╲ Motor (50% 힘) 손목 → 팔이 떨리며 천천히 내려옴 의식: 0% (사망) 어깨 ───┐ ╲ Motor (0% 힘) 팔꿈치 ╲ 손목 → 중력만 작용 (늘어짐)

Part 4: 상황 인식 (Behavior System)

Q: 쓰러질 때 왜 손으로 바닥을 짚어요?

Behavior Controller가 상황을 판단하기 때문입니다.

주요 Behavior 종류

  1. Balance Behavior: 균형 유지
    • 중심 잡기 (CoM 제어)
    • 넘어지지 않으려고 발 디딤
  2. Protect Behavior: 보호 반응
    • 얼굴/머리 팔로 가림
    • 급소 보호
  3. Brace Behavior: 충격 대비
    • 떨어질 때 손으로 바닥 짚기
    • 무릎 구부려 충격 완화
  4. Grab Behavior: 잡기
    • 절벽에서 떨어질 때 난간 잡으려 함
// Behavior 선택 시스템 function SelectBehavior(character): // 우선순위 기반 선택 // 1. 균형 체크 if character.consciousness > 0.5: CoM = character.GetCenterOfMass() groundContact = character.GetGroundContact() if not IsStable(CoM, groundContact): return BalanceBehavior() // 2. 충격 감지 if character.velocity.y < -5.0: // 5m/s 이상 낙하 중 if RaycastDown(character, 2.0): // 2m 이내 바닥 return BraceBehavior() // 착지 준비 // 3. 위험 감지 threatDirection = DetectThreat(character) if threatDirection != null: return ProtectBehavior(threatDirection) // 4. 기본: 쓰러지기 return CollapseBehavior() // Balance Behavior 구현 class BalanceBehavior: function GetTargetAngles(character): CoM = character.GetCenterOfMass() groundPoint = character.feet.GetAveragePosition() // 중심이 앞으로 쏠리면 if CoM.x > groundPoint.x: // 뒤로 기울이기 targets["Spine"] = Quaternion(-15, 0, 0) targets["Hips"] = Quaternion(10, 0, 0) // 발 앞으로 디디기 targets["LeftKnee"] = Quaternion(30, 0, 0) targets["RightKnee"] = Quaternion(30, 0, 0) return targets // Brace Behavior (착지 준비) class BraceBehavior: function GetTargetAngles(character): // 무릎 구부리기 targets["LeftKnee"] = Quaternion(60, 0, 0) targets["RightKnee"] = Quaternion(60, 0, 0) // 팔 앞으로 뻗기 (바닥 짚을 준비) targets["LeftShoulder"] = Quaternion(90, 0, 0) targets["RightShoulder"] = Quaternion(90, 0, 0) targets["LeftElbow"] = Quaternion(-45, 0, 0) targets["RightElbow"] = Quaternion(-45, 0, 0) return targets
Behavior 전환 흐름 1. 건강 (의식 100%) [Balance] ─→ 계속 서 있으려 함 │ ↓ (총 맞음 - 의식 70%) │ [Balance + Protect] │ ㄴ 한 손으로 상처 감싸기 │ ↓ (또 맞음 - 의식 30%) │ [Brace] ─→ 넘어지는 중 │ ㄴ 손으로 바닥 짚으려 함 │ ↓ (의식 0%) │ [Collapse] ─→ 완전 쓰러짐

Part 5: 지형 반응 (환경 인식)

Q: 계단에서 굴러떨어질 때 왜 이렇게 현실적이에요?

Euphoria가 주변 지형을 실시간으로 분석하기 때문입니다.

지형 인식 시스템

  • Raycast로 주변 5m 탐색
  • 경사면 감지: 계단, 언덕, 절벽
  • 장애물 감지: 난간, 벽, 기둥

지형별 반응

지형 Euphoria 반응
평지 앞으로 쓰러지며 손으로 바닥 짚기
계단 (위→아래) 구르며 팔/다리로 충격 흡수 시도
경사면 미끄러지며 손으로 땅 긁기
절벽 난간 잡으려는 애니메이션
물 수영 동작 → 익사
// 지형 분석 function AnalyzeTerrain(character): terrain = {} // 전방 레이캐스트 (5m) forwardRay = Raycast(character.position, character.forward, 5.0) if forwardRay.hit: // 경사도 계산 slope = Angle(forwardRay.normal, Vector3.Up) terrain.type = DetermineType(slope) terrain.distance = forwardRay.distance // 하방 레이캐스트 downRay = Raycast(character.position, Vector3.Down, 10.0) if not downRay.hit: terrain.type = "Cliff" // 10m 이내 바닥 없음 = 절벽 elif downRay.distance > 2.0: terrain.type = "Fall" // 낙하 중 return terrain // 지형 기반 Behavior function GetTerrainBehavior(terrain): switch terrain.type: case "Flat": return BraceBehavior() case "Stairs": // 계단에서 굴러떨어짐 behavior = RollBehavior() behavior.SetProtectHead(true) // 머리 보호 강화 return behavior case "Slope": // 경사면에서 미끄러짐 behavior = SlideBehavior() behavior.SetGrabGround(true) // 땅 긁기 return behavior case "Cliff": // 절벽 - 난간 잡기 시도 return GrabBehavior() case "Water": return SwimBehavior() // Roll Behavior (계단) class RollBehavior: function GetTargetAngles(character): // 몸을 웅크리기 (충격 최소화) targets["Spine"] = Quaternion(45, 0, 0) // 등 구부리기 targets["Hips"] = Quaternion(30, 0, 0) // 팔로 머리 감싸기 targets["LeftShoulder"] = Quaternion(120, 0, 45) targets["RightShoulder"] = Quaternion(120, 0, -45) return targets
계단 낙하 시뮬레이션 프레임 0: [평지] 😊 ← 건강 프레임 30: [계단 감지] 😐 └─ RaycastDown: 계단 발견 └─ Behavior: RollBehavior() 프레임 60: [굴러떨어지기 시작] 😵 ╱ ↓ ═══ ← 계단 프레임 90: [충격 흡수] 💫 ╱| ═══ ← 팔/무릎으로 충격 받음 ═══ 프레임 120: [멈춤] 💀 ← 의식 상실 ════ 전체 과정에서 Euphoria가: - 계단 감지 → RollBehavior - 머리 보호 (팔로 감싸기) - 팔/다리로 충격 분산

Part 6: NPC 피격 리액션

Q: 같은 총인데 맞는 부위마다 반응이 왜 달라요?

히트 존(Hit Zone)별로 다른 Behavior가 적용됩니다.

히트 존 시스템

  • 머리: 즉사 + 뒤로 쓰러짐
  • 가슴: 뒤로 비틀거림 + 가슴 감싸기
  • 팔: 팔 늘어짐 + 한쪽으로 회전
  • 다리: 해당 다리 힘 빠짐 + 무릎 꿇기
  • 배: 앞으로 구부림 + 고통 애니메이션
// 피격 처리 function OnHit(character, hitInfo): hitZone = DetermineHitZone(hitInfo.bodyPart) bulletForce = hitInfo.direction * hitInfo.damage * 100.0 switch hitZone: case "Head": character.consciousness = 0 // 즉사 ApplyImpulse(character.head, bulletForce) // 머리 뒤로 젖히기 behavior = HeadshotBehavior() case "Chest": character.consciousness -= 0.5 ApplyImpulse(character.spine, bulletForce) // 가슴 움켜쥐기 behavior = ChestHitBehavior() behavior.SetProtectWound(hitInfo.position) case "RightArm": // 오른팔 모터 비활성화 DisableMotors(character.rightArm) ApplyImpulse(character.rightHand, bulletForce) // 팔 늘어뜨리기 behavior = ArmHitBehavior("Right") case "LeftLeg": // 왼다리 근력 50% 감소 ReduceMotorStrength(character.leftLeg, 0.5) // 무릎 꿇기 behavior = LegHitBehavior("Left") character.SetBehavior(behavior) // Leg Hit Behavior (다리 피격) class LegHitBehavior: function GetTargetAngles(character): if hitLeg == "Left": // 왼쪽 다리 접기 targets["LeftHip"] = Quaternion(90, 0, 0) targets["LeftKnee"] = Quaternion(120, 0, 0) // 오른쪽 다리로 버티기 targets["RightKnee"] = Quaternion(30, 0, 0) // 균형 잡으려고 팔 흔들기 targets["LeftShoulder"] = Quaternion(45, 0, 30) targets["RightShoulder"] = Quaternion(45, 0, -30) return targets // Chest Hit Behavior (가슴 피격) class ChestHitBehavior: function GetTargetAngles(character): // 등 구부리기 (고통) targets["Spine"] = Quaternion(30, 0, 0) // 상처 부위 손으로 감싸기 woundPos = woundPosition // IK로 손 위치 계산 targets["LeftShoulder"] = IK_Solve(character.leftHand, woundPos) targets["RightShoulder"] = IK_Solve(character.rightHand, woundPos) return targets

실제 게임 예시

Q: 어디서 Euphoria를 확인할 수 있어요?

1. Valentine 술집 2층

  • NPC를 2층에서 밀면
  • 난간 잡으려는 애니메이션
  • 계단으로 굴러떨어지며 팔로 머리 보호
  • 바닥에 닿으면 천천히 힘 빠짐

2. 절벽에서 밀기

  • NPC를 절벽 끝으로 밀면
  • 팔을 휘저으며 균형 잡으려 함
  • 떨어질 때 손을 뻗어 뭔가 잡으려 함
  • 물에 빠지면 수영 동작 (의식 있으면)

3. 다리 쏘기

  • NPC 다리를 쏘면
  • 해당 다리로 무릎 꿇음
  • 한쪽 다리로 버티려 함
  • 다시 쏘면 완전히 쓰러짐

4. 말 위에서 총 맞기

  • 말 탄 NPC를 쏘면
  • 말고삐 잡으려 함 (의식 높을 때)
  • 옆으로 기울며 떨어짐
  • 땅에 떨어지면서 구르기

💡 핵심 정리

  • Active Ragdoll: 근육(Motor)이 있어 죽어가는 과정 시뮬레이션
  • Motor System: PD 컨트롤러로 관절 토크 제어 (의식에 비례)
  • Behavior System: 상황 인식 (Balance, Protect, Brace, Grab)
  • 지형 반응: Raycast로 계단/경사/절벽 감지 후 다른 행동
  • 히트 존: 피격 부위별 근력 조정 + 전용 Behavior
  • 점진적 붕괴: 의식 0~100%로 자연스러운 죽음

기술적 의의:

단순 물리 시뮬레이션이 아니라 생존 본능을 가진 캐릭터를 구현했습니다. NPC가 죽어가면서도 "살려고 발버둥치는" 모습이 플레이어에게 강한 몰입감과 죄책감을 동시에 줍니다. 이는 Euphoria만의 독보적인 기술입니다.
