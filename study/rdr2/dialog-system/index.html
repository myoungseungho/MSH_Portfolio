왜 NPC랑 대화가 자연스러워요?

Context-Aware 다이얼로그 시스템

Part 1: 기존 대화 시스템의 한계

Q: 일반 게임 NPC는 뭐가 문제예요?

고정된 대사만 반복하기 때문입니다.

전통적 대화 시스템의 문제점

  1. 상황 무시
    • 비 오는데 "좋은 날씨네요"
    • 방금 총싸움 했는데 "평화로운 마을이죠"
  2. 관계 무시
    • 100번 만났는데 "처음 뵙겠습니다"
    • 생명의 은인인데 "누구세요?"
  3. 기억 부재
    • 어제 한 이야기를 오늘 또 함
    • 과거 행동을 전혀 기억 못함
  4. 제한된 선택지
    • "예 / 아니오" 만 가능
    • 다양한 태도 표현 불가
전통 시스템 vs RDR2 [전통 시스템 - 고정 대사] 플레이어 접근 ↓ NPC: "안녕하세요" (항상 동일) ↓ 선택: [예 / 아니오] ↓ 종료 [RDR2 - Context-Aware] 플레이어 접근 ↓ 컨텍스트 분석: - 시간: 밤 - 날씨: 비 - 관계: 친구 - 최근 행동: 도움 줌 - 평판: 선량함 - 위치: 술집 ↓ NPC: "Arthur! 비 오는데 들어와. 아까 도와줘서 고마워." (동적 생성) ↓ 선택: [인사 / 대화 / 위협 / 강도] ↓ 관계 업데이트

Part 2: Context-Aware 대화

Q: 컨텍스트를 어떻게 파악해요?

다층 컨텍스트 시스템으로 상황을 종합 분석합니다.

컨텍스트 레이어

  1. 환경 컨텍스트 (Environmental)
    • 시간대 (새벽/낮/저녁/밤)
    • 날씨 (맑음/비/눈/폭풍)
    • 위치 (도시/야생/술집/캠프)
  2. 사회적 컨텍스트 (Social)
    • 관계 수준 (적/낯선이/지인/친구)
    • 평판 (악명/중립/명예)
    • 파벌 (법 집행자/범죄자/시민)
  3. 행동 컨텍스트 (Behavioral)
    • 최근 행동 (구출/살인/강도)
    • 현재 상태 (무장/부상/취함)
    • 동행자 (혼자/갱단/가족)
  4. 스토리 컨텍스트 (Narrative)
    • 진행도 (챕터)
    • 완료한 미션
    • NPC별 퀘스트 상태
// 컨텍스트 수집 시스템 (의사코드) struct DialogContext: // 환경 TimeOfDay timeOfDay Weather weather Location location // 사회적 Relationship relationship Reputation reputation Faction faction // 행동 RecentAction[] recentActions PlayerState state Companion[] companions // 스토리 int chapter Mission[] completedMissions QuestState questState function GatherContext(player, npc): context = DialogContext{} // 1. 환경 분석 context.timeOfDay = GetTimeOfDay() // 0~24시 context.weather = GetCurrentWeather() context.location = GetLocationTag(npc.position) // 2. 사회적 관계 context.relationship = npc.GetRelationshipWith(player) context.reputation = player.GetReputation(npc.faction) context.faction = npc.faction // 3. 최근 행동 (지난 5분) context.recentActions = player.GetActionHistory(300) // 4. 플레이어 상태 context.state = { isArmed: player.HasWeaponDrawn(), isWounded: player.health < 50, isDrunk: player.intoxication > 0.5, isMasked: player.HasMask(), isBounty: player.bounty > 0 } // 5. 스토리 상태 context.chapter = story.currentChapter context.questState = npc.GetQuestState(player) return context // 컨텍스트 점수 계산 function EvaluateContext(context): scores = {} // 우호도 점수 if context.relationship == "Friend": scores.friendliness = 1.0 elif context.relationship == "Enemy": scores.friendliness = -1.0 else: scores.friendliness = 0.0 // 위험도 점수 scores.threat = 0.0 if context.state.isArmed: scores.threat += 0.3 if context.reputation == "Outlaw": scores.threat += 0.5 if context.state.isBounty: scores.threat += 0.7 // 시간대 점수 (밤이면 경계) if context.timeOfDay > 22 or context.timeOfDay < 6: scores.alertness = 0.8 else: scores.alertness = 0.3 return scores
컨텍스트 점수 예시 시나리오 1: 낮에 Valentine 술집 환경: 낮(12시) + 맑음 + 술집 관계: 친구 상태: 비무장 평판: 선량함 ──────────────────── friendliness: 1.0 ← 친근하게 threat: 0.0 ← 위협 없음 alertness: 0.3 ← 편안함 ──────────────────── 선택된 대사: "Arthur! 술 한잔 어때?" 시나리오 2: 밤에 외딴 길 환경: 밤(23시) + 안개 + 야생 관계: 낯선이 상태: 무장 + 마스크 평판: 악명 ──────────────────── friendliness: -0.5 ← 불신 threat: 1.5 ← 위험! alertness: 1.0 ← 경계 ──────────────────── 선택된 대사: "뭐... 뭐 하는 거야? 가까이 오지 마!" 시나리오 3: 생명 구해준 직후 환경: 낮 관계: 지인 → 친구 recentActions: [SavedLife] ──────────────────── friendliness: 2.0 ← 감사! gratitude: 1.0 ──────────────────── 선택된 대사: "당신이 날 구해줬군요! 평생 은혜 잊지 않겠습니다!"

Part 3: 관계 시스템 (Relationship Dynamics)

Q: NPC와 관계는 어떻게 변해요?

행동에 따라 실시간으로 관계가 변합니다.

관계 단계

단계 점수 범위 반응
적대 (Enemy) -100 ~ -50 도망가거나 공격
불신 (Distrust) -50 ~ -10 경계하며 짧게 대답
낯선이 (Stranger) -10 ~ 10 중립적 태도
지인 (Acquaintance) 10 ~ 50 친근하게 인사
친구 (Friend) 50 ~ 100 기꺼이 도와줌

관계 변화 요인

  • 긍정적 행동: +5~+30
    • 구출: +30
    • 도움: +10
    • 인사: +5
  • 부정적 행동: -10~-50
    • 살해: -50 (돌이킬 수 없음)
    • 위협: -20
    • 강도: -30
// 관계 시스템 class RelationshipManager: // NPC별 관계 점수 Dictionary relationships function GetRelationship(npc): score = relationships[npc] if score < -50: return "Enemy" elif score < -10: return "Distrust" elif score < 10: return "Stranger" elif score < 50: return "Acquaintance" else: return "Friend" function ModifyRelationship(npc, action): delta = 0 switch action: case "SaveLife": delta = 30 // 특별 이벤트 플래그 npc.SetFlag("LifeDebt", true) case "Help": delta = 10 case "Greet": delta = 5 case "Threaten": delta = -20 case "Rob": delta = -30 case "Kill": delta = -100 npc.SetFlag("Dead", true) NotifyFaction(npc.faction, "Killed", npc) relationships[npc] += delta // 범위 제한 relationships[npc] = Clamp(relationships[npc], -100, 100) // 주변 NPC에게 전파 PropagateReputation(npc, action, delta * 0.3) // 평판 전파 (목격자) function PropagateReputation(sourceNPC, action, amount): witnesses = GetNearbyNPCs(sourceNPC, radius: 50.0) for witness in witnesses: // 같은 파벌이면 영향 큼 if witness.faction == sourceNPC.faction: relationships[witness] += amount * 2.0 else: relationships[witness] += amount * 0.5 // 목격 기억 witness.AddMemory({ event: action, target: sourceNPC, perpetrator: player, time: currentTime }) // 관계 기반 대사 선택 function SelectDialog(npc, context): relationship = GetRelationship(npc) // 관계별 대사 풀 dialogPool = dialogs[npc.archetype][relationship] // 컨텍스트 필터링 validDialogs = [] for dialog in dialogPool: if MeetsConditions(dialog, context): validDialogs.Add(dialog) // 최근 사용하지 않은 대사 우선 return PickLeastRecent(validDialogs)

[인사] Arthur: "안녕하세요" ──────────────────── 관계: 0 + 5 = 5 (Stranger) 대사: "좋은 하루 보내세요" [도움 (물건 찾아줌)] Arthur: [미션 완료] ──────────────────── 관계: 5 + 10 = 15 (Acquaintance) 대사: "고마워요, 당신은 좋은 사람이네요" [생명 구조 (곰에게 습격)] Arthur: [곰 처치] ──────────────────── 관계: 15 + 30 = 45 (Acquaintance → Friend 직전) Flag: LifeDebt = true 대사: "당신이 날 구해줬어요! 평생 갚겠습니다!" [재회 (1주 후)] Arthur: "안녕하세요" ──────────────────── 관계: 45 (Acquaintance) Memory: LifeDebt 대사: "Arthur! 생명의 은인이시죠. 뭐 필요한 거 없으세요?" [배신 (강도)] Arthur: [위협 + 강탈] ──────────────────── 관계: 45 - 30 = 15 Flag: Betrayed = true 대사: "믿었던 내가 바보였어..." [목격자 전파] 주변 NPC 3명 ──────────────────── 각자 관계: -30 * 0.5 = -15 Memory: "Arthur가 친구를 강도질함" 이후 만나면 경계함

Part 4: 대화 선택지 (Dynamic Choices)

Q: 대화 옵션은 왜 상황마다 달라요?

컨텍스트에 따라 동적으로 생성되기 때문입니다.

기본 선택지

  1. 인사 (Greet)
    • 우호적 제스처
    • 관계 +5
    • 대부분 상황에서 가능
  2. 대화 (Chat)
    • 일상 대화
    • 정보 획득
    • 친구 이상일 때 활성화
  3. 위협 (Threaten)
    • 무기 겨누기
    • 관계 -20
    • 무장 상태에서만
  4. 강도 (Rob)
    • 금품 강탈
    • 관계 -30
    • 위협 성공 후

조건부 선택지

특정 상황에서만 나타남:

  • 도움 요청: 퀘스트 진행 중
  • 정보 구매: 술집에서
  • 고용: 특정 NPC (마차꾼 등)
  • 도발: 술 취했을 때
// 선택지 생성 시스템 function GenerateDialogOptions(npc, context): options = [] // 1. 인사 (거의 항상 가능) if context.relationship != "Enemy": options.Add({ type: "Greet", text: GetGreetingText(context), condition: true }) // 2. 대화 (친구 이상) if context.relationship in ["Acquaintance", "Friend"]: options.Add({ type: "Chat", text: "이야기 좀 해요", condition: true }) // 3. 위협 (무장 상태) if context.state.isArmed and not npc.IsLawman(): options.Add({ type: "Threaten", text: "가만히 있어!", condition: context.state.isArmed }) // 4. 강도 (위협 성공 후) if npc.state == "Threatened": options.Add({ type: "Rob", text: "돈 내놔!", condition: true }) // 5. 퀘스트 관련 if npc.HasActiveQuest(player): quest = npc.GetQuest(player) options.Add({ type: "Quest", text: quest.dialogPrompt, condition: true }) // 6. 위치별 특수 옵션 if context.location == "Saloon": options.Add({ type: "BuyDrink", text: "술 한잔 사줘요 ($5)", condition: player.money >= 5 }) options.Add({ type: "BuyInfo", text: "정보 좀 물어볼게요 ($10)", condition: player.money >= 10 }) // 7. 상황별 특수 옵션 if npc.state == "Injured": options.Add({ type: "Help", text: "괜찮으세요?", condition: true }) if context.state.isDrunk: options.Add({ type: "Taunt", text: "시비 걸기", condition: true }) return options // 인사 텍스트 동적 생성 function GetGreetingText(context): if context.timeOfDay >= 5 and context.timeOfDay < 12: return "좋은 아침이에요" elif context.timeOfDay >= 12 and context.timeOfDay < 18: return "안녕하세요" elif context.timeOfDay >= 18 and context.timeOfDay < 22: return "좋은 저녁이에요" else: return "안녕하세요" // 밤에는 이상하니 평범하게
선택지 트리 예시 상황: Valentine 술집, 낮, 친구 관계 [플레이어가 NPC에게 접근] │ ├─ 인사 → "Arthur! 어서 와" │ │ │ └─ 대화 → 일상 대화 │ └─ 술 사기 → 관계 +5 │ ├─ 대화 → "무슨 이야기 할까?" │ │ │ ├─ 날씨 → "비가 많이 오네요" │ ├─ 소식 → "Valentine에 새 보안관이..." │ └─ 헤어지기 │ └─ [위협] (무장 안 해서 비활성화) ────────────────────────────── 상황: 외딴 길, 밤, 낯선이, 무장 [플레이어가 NPC에게 접근] │ ├─ 인사 → "...안녕하세요" (경계) │ │ │ └─ "조심히 가세요" (빨리 떠남) │ ├─ 위협 → "손 들어!" │ │ │ ├─ NPC 도망 (용기 낮음) │ └─ NPC 항복 (용기 중간) │ │ │ └─ 강도 → 돈 $12 획득 │ 관계 -30 │ 목격자에게 전파 │ └─ [대화] (관계 부족으로 비활성화)

Part 5: 기억 시스템 (Memory & History)

Q: NPC가 과거 일을 왜 기억해요?

각 NPC마다 메모리 버퍼를 가지고 있기 때문입니다.

기억 종류

  1. 단기 기억 (Short-term)
    • 최근 5분 이내 사건
    • 예: "방금 총소리 들었어"
  2. 장기 기억 (Long-term)
    • 중요한 사건 영구 저장
    • 예: "당신이 날 구해줬죠"
  3. 관계 기억 (Relationship)
    • 플레이어와의 모든 상호작용
    • 예: "지난주에 술 사줬잖아요"
// 기억 시스템 struct Memory: string eventType // "SavedLife", "Robbery", "Fight" 등 Actor involved // 관련 인물 Vector3 location // 발생 장소 float timestamp // 시간 int importance // 중요도 (1~10) bool isPermanent // 영구 기억 여부 class NPCMemory: Memory[] shortTermMemory // 최대 20개 Memory[] longTermMemory // 중요한 것만 function AddMemory(event, involved, importance): memory = Memory{ eventType: event, involved: involved, location: this.position, timestamp: currentTime, importance: importance, isPermanent: importance >= 7 } // 단기 기억에 추가 shortTermMemory.Add(memory) // 중요하면 장기 기억에도 if memory.isPermanent: longTermMemory.Add(memory) // 단기 기억 오버플로우 처리 if shortTermMemory.Count > 20: // 가장 오래되고 중요하지 않은 것 삭제 oldest = FindLeastImportant(shortTermMemory) shortTermMemory.Remove(oldest) // 기억 조회 function RecallMemory(eventType, maxAge): currentTime = GetCurrentTime() for memory in shortTermMemory: if memory.eventType == eventType: age = currentTime - memory.timestamp if age < maxAge: return memory // 장기 기억 검색 for memory in longTermMemory: if memory.eventType == eventType: return memory return null // 기억 기반 대사 생성 function GetMemoryDialog(player): // 생명 구조 기억 saved = RecallMemory("SavedLife", Infinity) if saved and saved.involved == player: if saved.timestamp < 86400: // 24시간 이내 return "어제 날 구해줘서 정말 고마워요!" else: return "당신은 내 생명의 은인이죠" // 최근 강도 기억 robbed = RecallMemory("Robbery", 604800) // 1주일 if robbed and robbed.involved == player: return "당신... 저번에 날 털었던..." // 최근 대화 기억 chat = RecallMemory("Chat", 3600) // 1시간 if chat: return "또 왔네요? 무슨 일이에요?" return null // 특별한 기억 없음 // 목격 시스템 (간접 기억) function OnWitnessEvent(witness, event, perpetrator, victim): importance = CalculateImportance(event) witness.AddMemory(event, perpetrator, importance) // 심각한 사건이면 경찰에 신고 if event in ["Murder", "Robbery"] and witness.faction == "Law": ReportToCops(event, perpetrator, witness.position) function CalculateImportance(event): switch event: case "Murder": return 10 // 최고 중요도 case "Robbery": return 8 case "Fight": return 5 case "Greet": return 1 default: return 3

Part 6: 700,000줄 대사 관리 (Tag System)

Q: 대사가 70만 줄이나 되는데 어떻게 관리해요?

태그 시스템으로 자동 필터링합니다.

태그 구조

각 대사에 여러 개의 태그를 붙여서 상황에 맞는 대사만 선택합니다.

태그 카테고리:

  • NPC 타입: CITIZEN, OUTLAW, LAWMAN, SHOPKEEPER
  • 관계: FRIEND, STRANGER, ENEMY
  • 시간: MORNING, AFTERNOON, EVENING, NIGHT
  • 날씨: SUNNY, RAIN, SNOW, STORM
  • 위치: TOWN, WILDERNESS, SALOON, CAMP
  • 감정: HAPPY, SCARED, ANGRY, GRATEFUL

Q: 구체적으로 어디서 체험할 수 있어요?

  • → 관계 시스템 우회 가능 (신원 미확인)

💡 핵심 정리

  • Context-Aware: 환경/사회/행동/스토리 4개 레이어 종합 분석
  • 관계 시스템: -100~100 점수로 5단계 관계 (Enemy → Friend)
  • 동적 선택지: 상황에 따라 인사/대화/위협/강도 등 동적 생성
  • 기억 시스템: 단기(20개) + 장기(중요 사건) 기억
  • 태그 시스템: 70만 줄 대사를 태그로 필터링 (NPC/관계/시간/날씨/위치/감정)
  • 평판 전파: 목격자를 통해 행동이 주변 NPC에게 전파

기술적 의의:

단순 스크립트 대화가 아니라 상황을 이해하는 NPC를 구현했습니다. 플레이어의 모든 행동이 기억되고 관계에 영향을 주며, 이는 대사로 자연스럽게 반영됩니다. 70만 줄이라는 방대한 대사량을 태그 시스템으로 효율적으로 관리한 것도 주목할 점입니다. 이는 게임 세계가 "살아있다"고 느끼게 하는 핵심 기술입니다.
