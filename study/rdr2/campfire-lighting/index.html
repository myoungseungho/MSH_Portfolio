캠프파이어 불빛이 얼굴에 번지는 법

실시간 GI와 Area Light

RDR2의 캠프 씬에서 캐릭터가 모닥불 주위에 둘러앉아 있을 때, 불빛이 얼굴에 자연스럽게 번지며 주변 나무와 땅에도 간접광이 퍼지는 모습을 볼 수 있습니다. 이는 단순한 점광원(Point Light)으로는 절대 만들 수 없는 효과입니다. Area Light(면적 광원)과 Real-time GI(실시간 전역 조명)의 조합이 만들어낸 결과입니다.

Part 1: 점광원의 한계 (딱딱한 그림자)

왜 점광원만으로는 자연스러운 불빛을 못 만드나요?
점광원(Point Light)은 무한히 작은 점에서 빛이 나온다고 가정합니다. 이 경우 그림자 경계가 칼처럼 날카로워집니다(Hard Shadow). 하지만 실제 불은 면적을 가진 광원이므로 그림자가 부드럽게 번집니다(Soft Shadow). 
점광원 vs 면적 광원 그림자
================================

점광원 (Point Light)
           ●  ← 광원 (점)
          / \
         /   \
        ┌─────┐  ← 장애물
        │     │
        ▓▓▓▓▓▓▓  ← 그림자 (경계가 날카로움)

--------------------------------

면적 광원 (Area Light)
        ┌─────┐  ← 광원 (면적)
        │🔥🔥🔥│
        └─────┘
         /│ │\
        / │ │ \
       ┌─────┐  ← 장애물
       │     │
       ▓▓▒▒░░░  ← 그림자 (점진적으로 흐려짐)
       (Umbra → Penumbra)

Umbra와 Penumbra

  • Umbra (본그림자): 광원이 완전히 가려진 영역 (어두움)
  • Penumbra (반그림자): 광원이 부분적으로 가려진 영역 (점진적으로 밝아짐)

면적 광원일수록 Penumbra 영역이 넓어져 자연스러운 소프트 섀도우를 만듭니다.

Part 2: Area Light 개념 (면적이 있는 광원)

캠프파이어는 점이 아니라 면적을 가진 광원입니다. RDR2는 이를 시뮬레이션하기 위해 여러 기법을 조합합니다.

1. Representative Point Lights

면적 광원을 여러 개의 작은 점광원으로 근사하는 방법입니다. 불꽃의 면적을 8~16개의 점광원으로 대체합니다. 

// 면적 광원 샘플링
struct AreaLight {
    float3 center;      // 중심 위치
    float3 tangent;     // 면적 방향
    float3 bitangent;
    float radius;       // 반지름
    int sampleCount;    // 샘플 개수 (8~16)
};

float3 EvaluateAreaLight(AreaLight light, float3 position) {
    float3 totalLight = 0;

    // 면적 위에 여러 샘플 배치
    for (int i = 0; i < light.sampleCount; i++) {
        // Poisson Disk 샘플링 (균일한 분포)
        float2 offset = PoissonDisk[i] * light.radius;

        // 샘플 위치 계산
        float3 samplePos = light.center +
                          light.tangent * offset.x +
                          light.bitangent * offset.y;

        // 각 샘플을 점광원으로 처리
        float3 L = samplePos - position;
        float distance = length(L);
        L /= distance;

        float attenuation = 1.0 / (distance * distance);
        totalLight += light.color * attenuation;
    }

    return totalLight / light.sampleCount;
}

Part 3: 소프트 섀도우 구현 (PCF, PCSS)

소프트 섀도우는 어떻게 만드나요?
가장 기본적인 방법은 Percentage Closer Filtering(PCF)입니다. 섀도우 맵을 여러 번 샘플링하여 부드러운 그림자를 만듭니다.

PCF (Percentage Closer Filtering)

// PCF 소프트 섀도우
float PCF_SoftShadow(Texture2D shadowMap, float4 shadowCoord, float filterSize) {
    float shadowSum = 0;
    int sampleCount = 0;

    // 5x5 커널 샘플링
    for (int x = -2; x <= 2; x++) {
        for (int y = -2; y <= 2; y++) {
            float2 offset = float2(x, y) * filterSize;
            float2 uv = shadowCoord.xy + offset;

            // 깊이 비교
            float shadowDepth = shadowMap.Sample(sampler, uv).r;
            float currentDepth = shadowCoord.z;

            // 그림자 안 = 0, 밖 = 1
            shadowSum += (currentDepth <= shadowDepth) ? 1.0 : 0.0;
            sampleCount++;
        }
    }

    return shadowSum / sampleCount;  // 0 (완전 그림자) ~ 1 (완전 밝음)
}

PCSS (Percentage Closer Soft Shadows)

PCF의 개선 버전으로, 그림자 거리에 따라 커널 크기를 조절합니다. 가까운 그림자는 날카롭게, 먼 그림자는 부드럽게 표현됩니다. 

// PCSS - 거리 기반 커널 크기 조절
float PCSS_SoftShadow(Texture2D shadowMap, float4 shadowCoord, float lightSize) {
    // 1단계: Blocker 거리 검색
    float blockerDistance = FindBlockerDistance(shadowMap, shadowCoord);

    if (blockerDistance == -1)
        return 1.0;  // 그림자 없음

    // 2단계: Penumbra 크기 계산
    float receiverDistance = shadowCoord.z;
    float penumbraSize = (receiverDistance - blockerDistance) * lightSize / blockerDistance;

    // 3단계: PCF (동적 커널 크기)
    return PCF_SoftShadow(shadowMap, shadowCoord, penumbraSize);
}

float FindBlockerDistance(Texture2D shadowMap, float4 shadowCoord) {
    float blockerSum = 0;
    int blockerCount = 0;

    // 3x3 샘플로 평균 blocker 거리 찾기
    for (int x = -1; x <= 1; x++) {
        for (int y = -1; y <= 1; y++) {
            float2 offset = float2(x, y) * 0.01;
            float depth = shadowMap.Sample(sampler, shadowCoord.xy + offset).r;

            if (depth < shadowCoord.z) {  // Blocker 발견
                blockerSum += depth;
                blockerCount++;
            }
        }
    }

    return (blockerCount > 0) ? (blockerSum / blockerCount) : -1.0;
}

Part 4: 불빛의 깜빡임 (Noise 기반 강도 변화)

실제 불은 계속 흔들리며 밝기가 변합니다. RDR2는 이를 시뮬레이션하기 위해 Perlin Noise 기반 강도 변조를 사용합니다. 

// 불빛 깜빡임 시뮬레이션
float FlickerIntensity(float time, float3 position) {
    // 3D Perlin Noise (시간 + 공간)
    float noise1 = PerlinNoise3D(position * 2.0 + float3(time * 3.0, 0, 0));
    float noise2 = PerlinNoise3D(position * 5.0 + float3(0, time * 5.0, 0));

    // 주파수 조합
    float flicker = noise1 * 0.7 + noise2 * 0.3;

    // 범위 조절 [0.8, 1.2]
    return 0.8 + flicker * 0.4;
}

// 캠프파이어 최종 라이팅
float3 CampfireLighting(float3 position, float time) {
    // 기본 감쇠
    float3 lightPos = float3(0, 1, 0);  // 불 위치
    float distance = length(position - lightPos);
    float attenuation = 1.0 / (1.0 + distance * distance);

    // 깜빡임 적용
    float flicker = FlickerIntensity(time, position);

    // 불빛 색상 (오렌지)
    float3 fireColor = float3(1.0, 0.6, 0.2);

    return fireColor * attenuation * flicker;
}

Part 5: 간접광 바운스 (Screen Space GI)

불빛이 땅에 반사되어 얼굴 아래를 비추는 효과

직접광만으로는 불가능한 효과입니다. RDR2는 Screen Space Global Illumination(SSGI)을 사용하여 실시간으로 1차 바운스를 시뮬레이션합니다. 

간접광 바운스 효과
================================

      캐릭터 얼굴
      ┌───────┐
      │  👁️ 👁️ │ ← 얼굴 아래가 밝아짐
      │   👃   │   (간접광)
      └───┬───┘
          ↑
       ░░░│░░░  ← 간접광 (1차 바운스)
          │
     ═════▓═════  ← 땅 (불빛을 반사)
          ↑
        🔥불🔥  ← 직접광
            
// Screen-Space GI (간단 버전)
float3 ScreenSpaceGI(
    float3 worldPos,
    float3 normal,
    Texture2D sceneColor,
    Texture2D depthBuffer
) {
    float3 indirectLight = 0;
    int sampleCount = 16;

    // 반구 샘플링 (코사인 분포)
    for (int i = 0; i < sampleCount; i++) {
        // 노멀 주변 랜덤 방향
        float3 sampleDir = CosineSampleHemisphere(normal, i);

        // 레이 마칭 (화면 공간)
        float3 hitPos;
        if (RayMarch(worldPos, sampleDir, depthBuffer, hitPos)) {
            // 히트 지점의 색상 가져오기
            float2 hitUV = WorldToScreenUV(hitPos);
            float3 hitColor = sceneColor.Sample(sampler, hitUV).rgb;

            // 코사인 가중치
            float NdotL = max(0, dot(normal, sampleDir));
            indirectLight += hitColor * NdotL;
        }
    }

    return indirectLight / sampleCount;
}

Part 6: 얼굴 조명과 분위기 연출

RDR2의 캠프파이어 씬은 단순한 기술 시연이 아니라 분위기 연출입니다. 불빛이 얼굴에 번지며 만드는 효과들:

  • Rim Lighting: 불빛이 얼굴 윤곽을 따라 흐르는 효과
  • Under Lighting: 땅 반사로 턱 아래가 밝아지는 효과 (으스스한 느낌)
  • Color Temperature: 따뜻한 오렌지 빛으로 야영 분위기
  • Shadow Contrast: 얼굴 한쪽은 밝고 한쪽은 어두워지는 극적 대비

캠프파이어 라이팅 조합

// 최종 캠프파이어 씬 라이팅
float3 CampfireSceneLighting(float3 position, float3 normal, float time) {
    // 1. 직접광 (Area Light)
    float3 directLight = EvaluateAreaLight(campfire, position);

    // 2. 깜빡임 변조
    directLight *= FlickerIntensity(time, position);

    // 3. 간접광 (SSGI)
    float3 indirectLight = ScreenSpaceGI(position, normal, ...);

    // 4. Rim Light (불빛 윤곽)
    float3 viewDir = normalize(cameraPos - position);
    float rim = pow(1.0 - abs(dot(viewDir, normal)), 3.0);
    float3 rimLight = campfireColor * rim * 0.5;

    // 5. 조합
    return directLight + indirectLight * 0.3 + rimLight;
}

📌 핵심 요약

  • Area Light: 면적 광원을 여러 Point Light로 샘플링하여 소프트 섀도우 구현
  • PCSS: 거리에 따라 그림자 부드러움이 변하는 물리 기반 소프트 섀도우
  • 불빛 깜빡임: Perlin Noise로 시간/공간에 따른 강도 변화
  • 간접광: Screen Space GI로 1차 바운스 실시간 시뮬레이션
  • 분위기 연출: Rim Light + Under Light + 색온도로 야영 분위기 극대화
왜 이렇게 복잡하게 만드나요?
캠프파이어는 RDR2에서 스토리텔링의 핵심 공간입니다. 갱단원들이 모여앉아 이야기를 나누는 순간, 불빛의 흔들림과 얼굴에 번지는 빛은 플레이어를 그 순간에 몰입시킵니다. 기술은 궁극적으로 감정을 전달하기 위한 도구입니다.
