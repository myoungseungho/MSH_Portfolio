피부가 촉촉해 보이는 이유

Subsurface Scattering in RDR2

Red Dead Redemption 2의 캐릭터들은 마치 살아있는 듯한 피부를 가지고 있습니다. 햇빛에 비친 귀가 붉게 투과되고, 촛불 앞에서 손가락이 은은하게 빛나는 모습은 단순한 텍스처 매핑으로는 절대 만들 수 없는 것입니다. 이 모든 것의 비밀은 Subsurface Scattering(SSS), 즉 피부 속으로 들어간 빛이 다시 나오는 현상을 시뮬레이션하는 기술에 있습니다.

Part 1: 피부가 플라스틱처럼 보이는 이유

왜 예전 게임의 캐릭터 피부는 플라스틱 인형처럼 보였나요?
기존의 Lambert 또는 Phong 라이팅 모델은 빛이 표면에서만 반사된다고 가정합니다. 하지만 실제 피부는 반투명 매질(translucent material)로, 빛이 표면 아래로 침투하여 산란된 후 다시 나옵니다. 이 과정을 무시하면 피부가 딱딱한 플라스틱처럼 보이게 됩니다. 
기존 라이팅 (표면 반사만)        SSS 라이팅 (피부 투과)
================================  ================================

      빛 ↓                              빛 ↓
       │                                 │
       ▼                                 ▼
    ┌─────┐ ← 표면 반사              ┌─────┐
    │█████│   (딱딱함)               │░░░░░│ ← 표면 투과
    │█████│                          │ ○ ○ │   (산란)
    │█████│                          │○ ○ ○│
    └─────┘                          └──┬──┘
                                        │
                                        ▼
                                     재방출 (부드러움)

    결과: 플라스틱 질감              결과: 피부 질감

Part 2: 빛의 피부 투과 (SSS 물리)

Subsurface Scattering은 3단계로 이루어집니다:

  1. 입사(Incidence): 빛이 피부 표면을 통과하여 내부로 침투
  2. 산란(Scattering): 피부 속 콜라겐, 혈관 등과 충돌하여 방향이 바뀜
  3. 출사(Exitance): 산란된 빛이 다른 위치에서 피부 밖으로 나옴

핵심 개념: Mean Free Path

빛이 매질 속에서 평균적으로 이동하는 거리를 Mean Free Path(MFP)라고 합니다. 피부의 MFP는 파장에 따라 다릅니다:

  • 적색광: ~1.5mm (가장 깊이 침투)
  • 녹색광: ~0.5mm
  • 청색광: ~0.2mm (표면 근처에서 산란)

이 때문에 햇빛에 비친 귀가 붉게 보입니다. 적색광만 귀를 완전히 투과할 수 있기 때문입니다.

Part 3: Pre-integrated SSS (LUT 방식)

실시간으로 피부 속 산란을 정확히 계산하는 것은 너무 비쌉니다. RDR2는 Pre-integrated Skin Shading 기법을 사용합니다.

Pre-integration이 뭔가요?
다양한 조명 각도와 표면 곡률에 대해 미리 SSS 결과를 계산해서 Look-Up Table(LUT)에 저장해둡니다. 런타임에는 (NdotL, Curvature)를 인덱스로 LUT를 샘플링하여 즉시 SSS 색상을 얻습니다. 
// Pre-integrated SSS 의사코드
float3 PreIntegratedSkinSSS(
    float3 normal,
    float3 lightDir,
    float curvature,
    Texture2D sssLUT
) {
    float NdotL = dot(normal, lightDir);

    // LUT 샘플링 좌표
    float2 uv;
    uv.x = NdotL * 0.5 + 0.5;      // [-1, 1] → [0, 1]
    uv.y = curvature;               // 곡률 (0 = 평면, 1 = 강한 곡률)

    // SSS 기여도
    float3 sss = sssLUT.Sample(sampler, uv).rgb;

    return sss;
}

SSS Look-Up Table 구조
================================

      Curvature →
      (곡률)
    1 ┌──────────────┐
      │▓▓▓▓▓▒▒▒░░░░░│ ← 강한 곡률 (코, 턱)
  0.5 │▓▓▓▒▒▒▒░░░░░░│   SSS 효과 강함
      │▓▒▒▒▒░░░░░░░░│
    0 └──────────────┘ ← 평평한 부분
      -1   0   +1       SSS 효과 약함
         NdotL →
      (빛 방향)

▓ = 강한 SSS (빨간 빛 투과)
▒ = 중간 SSS
░ = 약한 SSS

곡률(Curvature) 계산

표면의 곡률은 노멀 맵의 변화율로 계산합니다: 

// 곡률 계산 (화면 공간)
float CalculateCurvature(float3 normal, float2 screenUV) {
    // 주변 픽셀의 노멀 가져오기
    float3 nX = normalTexture.Sample(sampler, screenUV + float2(pixelSize, 0)).xyz;
    float3 nY = normalTexture.Sample(sampler, screenUV + float2(0, pixelSize)).xyz;

    // 노멀 변화량
    float3 dnX = nX - normal;
    float3 dnY = nY - normal;

    // 곡률 = 변화량의 크기
    float curvature = length(dnX) + length(dnY);

    return saturate(curvature);
}

Part 4: Screen-Space SSS (Blur 기반)

Pre-integrated SSS는 로컬한 효과만 시뮬레이션합니다. 더 넓은 범위의 산란 (예: 뺨 전체가 붉게 물드는 효과)을 위해 화면 공간 SSS 블러를 추가합니다.

Separable Gaussian Blur

피부 영역만 선별하여 Gaussian Blur를 적용합니다. 효율을 위해 수평 패스와 수직 패스로 분리하여 실행합니다. 

// Screen-Space SSS Blur
float3 ScreenSpaceSSS(Texture2D sceneColor, float2 uv, float sssStrength) {
    float3 result = 0;
    float totalWeight = 0;

    // Gaussian 가중치 샘플
    const int kernelSize = 5;
    const float weights[5] = {0.227, 0.194, 0.121, 0.054, 0.016};
    const float offsets[5] = {0.0, 1.3, 3.2, 5.2, 7.2};

    // 수평 방향 블러
    for (int i = 0; i < kernelSize; i++) {
        float offset = offsets[i] * sssStrength;
        float weight = weights[i];

        result += sceneColor.Sample(sampler, uv + float2(offset, 0)) * weight;
        result += sceneColor.Sample(sampler, uv - float2(offset, 0)) * weight;
        totalWeight += weight * 2;
    }

    return result / totalWeight;
}

Screen-Space SSS 파이프라인
================================

1. 피부 마스크 생성
   ┌──────────┐
   │  Albedo  │ → Skin Detection → ┌──────┐
   └──────────┘   (색상 범위)       │ Mask │
                                    └──────┘

2. SSS Blur (수평)
   ┌──────┐    Gaussian      ┌──────┐
   │Scene │ → Blur (H) ────→ │Temp  │
   └──────┘   (Mask 영역만)   └──────┘

3. SSS Blur (수직)
   ┌──────┐    Gaussian      ┌──────┐
   │Temp  │ → Blur (V) ────→ │Final │
   └──────┘                   └──────┘

4. 원본과 혼합
   Scene * (1 - strength) + Final * strength

Part 5: 피부 외 적용 (귀, 손가락, 촛불)

귀가 햇빛에 붉게 빛나는 건 어떻게 만드나요?
얇은 부위(귀, 손가락)는 Transmission(투과) 항을 추가합니다. 빛이 표면 반대편에서 들어와 관통하는 효과입니다. 
// Transmission 계산
float3 CalculateTransmission(
    float3 viewDir,
    float3 lightDir,
    float3 normal,
    float thickness
) {
    // 표면 반대편에서 오는 빛
    float3 transmissionDir = -normal;
    float transmissionDot = dot(-lightDir, transmissionDir);

    // 두께에 따른 감쇠
    float attenuation = exp(-thickness * 5.0);

    // Transmission 강도
    float transmission = saturate(transmissionDot) * attenuation;

    // 적색광이 가장 잘 투과
    return float3(1.0, 0.5, 0.3) * transmission;
}

촛불 앞 손가락 효과

RDR2의 실내 씬에서 캐릭터가 촛불 앞에 손을 가져가면 손가락이 붉게 빛납니다. 이는 Transmission + SSS의 조합입니다. 

촛불 Transmission 효과
================================

        손가락
         │││
         │││  ← 피부 (두께: 1cm)
         │││
         ▼▼▼

    🕯️ 촛불 (광원)
         ↑↑↑
         │││  ← 빛이 손가락 관통
         │││

→ 관찰자가 보는 빛:
  - 직접 반사 (표면)
  - SSS (피부 산란)
  - Transmission (관통) ← 붉은 빛!

Part 6: RDR2의 캐릭터 피부 품질

RDR2는 다음 요소들을 조합하여 실사에 가까운 피부를 구현합니다:

  • Pre-integrated SSS: 기본 피부 산란 (곡률 기반)
  • Screen-Space SSS Blur: 넓은 범위 산란 (뺨 붉어짐)
  • Transmission: 얇은 부위 투과 (귀, 손가락)
  • Detail Normal Map: 피부 미세 주름 (모공, 주근깨)
  • Specular Roughness Variation: 피부 부위별 광택 차이

성능 최적화

SSS는 비용이 높은 효과입니다. RDR2는 다음 전략으로 최적화합니다:

  • 거리별 LOD: 원거리 캐릭터는 SSS 생략
  • Quarter Resolution Blur: SSS 블러를 1/4 해상도로 수행
  • Temporal Reprojection: 이전 프레임 결과 재사용
  • 중요 캐릭터만: 주인공, 주요 NPC에만 Full SSS

📌 핵심 요약

  • SSS의 본질: 빛이 피부 속으로 침투 → 산란 → 재방출되는 과정 시뮬레이션
  • Pre-integrated SSS: LUT로 미리 계산, (NdotL, Curvature)로 샘플링
  • Screen-Space Blur: 넓은 범위 산란을 Gaussian Blur로 근사
  • Transmission: 얇은 부위(귀, 손가락)의 빛 투과 효과
  • 실시간 최적화: LOD, Quarter Res, Temporal 기법 활용
왜 SSS가 중요한가요?
SSS는 캐릭터가 "살아있다"는 느낌을 주는 핵심 기술입니다. 플라스틱 같은 딱딱한 피부와 실제 사람 피부의 차이는 바로 SSS 구현 여부에 달려있습니다. RDR2의 놀라운 캐릭터 퀄리티는 세심한 SSS 튜닝에서 비롯됩니다.
