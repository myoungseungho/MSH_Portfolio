진흙에 발자국이 남고 마르는 법

지형 변형 시스템 (Terrain Deformation)
Red Dead Redemption 2에서 진흙탕을 걸으면 발자국이 남고, 마차가 지나가면 바퀴 자국이 생깁니다. 시간이 지나면 발자국은 서서히 마르고, 비가 오면 다시 부드러워집니다. 이 "살아있는 땅"이 게임의 몰입감을 극대화합니다.

Part 1: 정적 지형의 몰입 파괴

Q. 기존 게임의 지형은 왜 "죽어있는" 느낌일까요?
대부분의 게임에서 지형은 절대 변하지 않습니다. 캐릭터가 진흙을 밟아도, 폭탄이 터져도 땅은 그대로입니다.

정적 지형의 문제점:
  • 물리적 상호작용 없음 (발자국, 자국, 구멍)
  • 재질의 특성 무시 (진흙 = 바위 = 모래)
  • 흔적이 남지 않아 "세계에 영향을 주지 못한다"는 느낌
  • 날씨/시간과 무관하게 항상 동일
기존 게임의 정적 지형: 캐릭터 이동 전: ┌────────────────┐ │ ░░░░░░░░░░░ │ ← 진흙 텍스처 │ ░░░░░░░░░░░ │ └────────────────┘ 캐릭터가 걸은 후: ┌────────────────┐ │ ░░👣░░░░░░░ │ ← 발자국 없음 (텍스처만) │ ░░░░░░░░░░░ │ └────────────────┘ RDR2의 동적 지형: 캐릭터 이동 전: ┌────────────────┐ │ ░░░░░░░░░░░ │ ← Height Map: 평평 │ ░░░░░░░░░░░ │ └────────────────┘ Height: 0 0 0 0 0 캐릭터가 걸은 후: ┌────────────────┐ │ ░▼▼░░░░░░░ │ ← Height Map: 파임 │ ░░░░░░░░░░░ │ └────────────────┘ Height: 0 -3 -3 0 0

Part 2: Height Map 변형

Q. 발자국은 어떻게 "실시간으로" 남나요?
Height Map (높이맵)을 실시간으로 수정합니다. 각 지형 타일마다 R16F 텍스처를 유지하며, 충돌 지점에서 높이값을 감소시킵니다.

Height Map 변형 프로세스:
  1. 충돌 감지 (발, 바퀴, 폭탄 등)
  2. 충돌 지점 주변 영역 계산
  3. Height Map에 변형 적용 (Gaussian Blur)
  4. Vertex Shader에서 Height Map 샘플링하여 지형 변형
  5. Normal Map 재계산 (음영 업데이트)
Height Map 변형 과정: 1. 원본 Height Map (단면도): ━━━━━━━━━━━━━━━━ ← 평평한 지형 Height: [0, 0, 0, 0, 0, 0, 0, 0] 2. 충돌 지점 (발) 감지: 👞 │ ━━━━━┼━━━━━━━━━━ ↓ 충돌! 3. Stamp 패턴 적용 (발자국 모양): ╱▔╲ ╱ ╲ ╱ 👞 ╲ └────────┘ [-0.5, -2, -3, -2, -0.5] ← 중앙이 깊게 파임 4. Height Map 업데이트: ━━━━▂▄█▄▂━━━━━━ ← 발자국 모양으로 파임 Height: [0, -0.5, -2, -3, -2, -0.5, 0, 0] 5. Normal Map 재계산: ╱╲╱╲╱╲╱╲╱╲╱╲╱╲ ▼▼▼ ← 발자국 부분 노멀 변경 (음영 변화) 
// 의사코드: 지형 변형
struct TerrainDeformation {
    Texture2D heightMap;        // R16F (높이값)
    Texture2D normalMap;        // RGB (법선)
    float recoverySpeed = 0.01; // 회복 속도
}

// 충돌 시 호출
function ApplyFootprint(worldPosition, footRotation, pressure) {
    // 1. 월드 좌표 → UV 좌표 변환
    vec2 uv = WorldToUV(worldPosition);
    if (OutOfBounds(uv)) return;

    // 2. 발자국 Stamp 텍스처 (미리 제작된 발 모양)
    Texture2D footStamp = LoadFootStamp();  // 256×128 텍스처

    // 3. 회전 적용
    mat2 rotation = Rotate2D(footRotation);

    // 4. Height Map에 Stamp 적용
    int stampRadius = 64;  // 64cm 반경
    for (int y = -stampRadius; y <= stampRadius; y++) {
        for (int x = -stampRadius; x <= stampRadius; x++) {
            vec2 offset = rotation * vec2(x, y) / 100.0;  // cm → m
            vec2 sampleUV = uv + offset / terrainSize;

            // Stamp 샘플링 (0~1)
            vec2 stampUV = (vec2(x, y) + stampRadius) / (stampRadius * 2);
            float stampDepth = footStamp.Sample(stampUV).r;

            // 압력에 비례한 깊이 (무게, 속도 반영)
            float depth = stampDepth * pressure * 0.05;  // 최대 5cm

            // 현재 높이값 감소
            float currentHeight = heightMap.Sample(sampleUV).r;
            float newHeight = currentHeight - depth;

            heightMap.Write(sampleUV, newHeight);
        }
    }

    // 5. Normal Map 재계산
    UpdateNormalMap(uv, stampRadius);
}

// 압력 계산
function CalculatePressure(character) {
    float weight = character.weight;          // 70kg
    float speed = length(character.velocity); // 5 m/s
    float footArea = 0.02;                    // 200 cm² (한 발)

    // 동적 압력 = 정적 압력 + 운동량
    float staticPressure = weight / footArea;            // 3500 Pa
    float dynamicPressure = 0.5 * weight * speed * speed; // 운동 에너지

    return (staticPressure + dynamicPressure) / 10000.0;  // 정규화
}

// Normal Map 재계산 (중앙 차분)
function UpdateNormalMap(centerUV, radius) {
    for each pixel in radius {
        float heightL = heightMap.Sample(uv + vec2(-1, 0) / resolution).r;
        float heightR = heightMap.Sample(uv + vec2(+1, 0) / resolution).r;
        float heightD = heightMap.Sample(uv + vec2(0, -1) / resolution).r;
        float heightU = heightMap.Sample(uv + vec2(0, +1) / resolution).r;

        vec3 tangent = vec3(2, 0, heightR - heightL);
        vec3 bitangent = vec3(0, 2, heightU - heightD);
        vec3 normal = normalize(cross(tangent, bitangent));

        normalMap.Write(uv, normal * 0.5 + 0.5);  // -1~1 → 0~1
    }
}

Part 3: 재질별 반응

Q. 진흙, 모래, 눈은 왜 반응이 다른가요?
각 재질마다 물리적 파라미터가 다릅니다. 압축률, 복원력, 점성 등을 시뮬레이션합니다.

재질별 특성:
  • 진흙 (Mud): 높은 점성, 느린 복원, 젖을수록 부드러움
  • 모래 (Sand): 낮은 점성, 빠른 복원 (바람), 건조 시 단단
  • 눈 (Snow): 압축 가능, 온도에 따라 변화
  • 바위 (Rock): 변형 불가 (Height Map 변경 없음)
재질별 변형 차이: 진흙 (Mud): 압력 ━━━━━━━━━━ ░░░░░░░░░░ ← 부드러움 (높은 변형) ░▓▓▓▓▓▓░░ 변형: ▂▄███▄▂ 깊게 파임 (3-5cm) 복원: 10분 이상 느리게 마름 모래 (Sand): 압력 ━━━━━━━━━━ ▒▒▒▒▒▒▒▒▒▒ ← 알갱이 (중간 변형) ▒▓▓▓▓▓▒▒▒ 변형: ▁▂▄▄▂▁ 얕게 파임 (1-2cm) 복원: 1분 바람에 빠르게 복원 눈 (Snow): 압력 ━━━━━━━━━━ ∴∵∴∵∴∵∴∵ ← 결정 (높은 압축) ∴▓▓▓▓▓∴∵ 변형: ▂▅███▅▂ 매우 깊음 (5-10cm) 복원: 없음 녹거나 새 눈이 쌓일 때까지 바위 (Rock): 압력 ━━━━━━━━━━ ▓▓▓▓▓▓▓▓▓▓ ← 단단함 (변형 없음) ▓▓▓▓▓▓▓▓▓ 변형: ━━━━━━━━━━ 변화 없음 
// 의사코드: 재질 속성
enum TerrainMaterial {
    MUD,
    SAND,
    SNOW,
    ROCK,
    GRASS
}

struct MaterialProperties {
    float deformability;     // 변형 가능성 (0~1)
    float viscosity;         // 점성 (높을수록 느림)
    float recoverySpeed;     // 복원 속도
    float compressionRatio;  // 압축률
}

MaterialProperties materials[] = {
    // MUD
    {
        deformability: 0.9,
        viscosity: 0.8,
        recoverySpeed: 0.001,    // 매우 느림
        compressionRatio: 0.6
    },
    // SAND
    {
        deformability: 0.7,
        viscosity: 0.2,
        recoverySpeed: 0.05,     // 빠름 (바람)
        compressionRatio: 0.4
    },
    // SNOW
    {
        deformability: 1.0,
        viscosity: 0.1,
        recoverySpeed: 0.0,      // 복원 없음
        compressionRatio: 0.8    // 높은 압축
    },
    // ROCK
    {
        deformability: 0.0,      // 변형 불가
        viscosity: 0.0,
        recoverySpeed: 0.0,
        compressionRatio: 0.0
    }
};

function ApplyDeformation(position, pressure, material) {
    MaterialProperties props = materials[material];

    if (props.deformability < 0.01) return;  // 바위는 변형 안 함

    // 1. 실제 변형량 계산
    float deformation = pressure * props.deformability * props.compressionRatio;

    // 2. 점성에 따른 시간 지연 (다음 프레임에 적용)
    float delay = props.viscosity * 0.1;  // 0~0.08초
    ScheduleDeformation(position, deformation, delay);

    // 3. 젖음 상태 반영 (진흙)
    if (material == MUD) {
        float wetness = GetWetness(position);  // 0~1 (비, 물웅덩이)
        deformation *= (1.0 + wetness);        // 젖을수록 더 변형
        props.recoverySpeed *= (1.0 - wetness * 0.5);  // 젖을수록 느린 복원
    }

    ApplyHeightMapChange(position, deformation);
}

// 젖음 상태 계산
function GetWetness(position) {
    float rainAmount = currentWeather.rainIntensity;  // 0~1
    float waterDistance = DistanceToWater(position);  // 물웅덩이까지 거리

    float wetness = rainAmount * 0.5;  // 비에 의한 젖음
    wetness += max(0, 1.0 - waterDistance / 5.0);  // 물웅덩이 근처 젖음

    return clamp(wetness, 0.0, 1.0);
}

Part 4: 시간에 따른 회복

Q. 발자국이 영원히 남으면 메모리가 터지지 않나요?
맞습니다. 시간에 따른 복원 시스템이 필요합니다. 진흙은 마르고, 모래는 바람에 날아가고, 눈은... 녹습니다.
시간에 따른 복원 과정: T=0초 (발자국 직후): ━━━━▂▄█▄▂━━━━ Height: -3cm T=60초 (1분 후 - 진흙 건조 시작): ━━━━▁▃▅▃▁━━━━ Height: -2cm (표면 마름) T=300초 (5분 후 - 부분 복원): ━━━━▁▂▃▂▁━━━━ Height: -1cm T=600초 (10분 후 - 거의 복원): ━━━━▁▁▁▁▁━━━━ Height: -0.3cm 날씨 영향: ☀ 맑은 날 (빠른 건조): 복원 속도 × 2.0 ☁ 흐린 날 (보통): 복원 속도 × 1.0 🌧 비 오는 날 (복원 정지): 복원 속도 × 0.0 오히려 더 부드러워짐 💨 바람 (모래만): 복원 속도 × 5.0 
// 의사코드: 시간 복원 시스템
struct DeformationCell {
    vec2 position;
    float currentHeight;
    float originalHeight;
    float timestamp;      // 변형된 시간
    TerrainMaterial material;
}

// 매 프레임 업데이트
function UpdateTerrainRecovery(deltaTime) {
    for each cell in deformedCells {
        if (cell.currentHeight >= cell.originalHeight) continue;

        MaterialProperties props = materials[cell.material];
        float timeSinceDeform = currentTime - cell.timestamp;

        // 1. 기본 복원량
        float recovery = props.recoverySpeed * deltaTime;

        // 2. 날씨 영향
        if (currentWeather == SUNNY) {
            recovery *= 2.0;  // 햇빛에 빠르게 마름
        } else if (currentWeather == RAIN) {
            recovery = 0.0;   // 비 오면 복원 정지
            // 오히려 더 부드러워짐
            if (cell.material == MUD) {
                cell.currentHeight -= 0.001 * deltaTime;
            }
        }

        // 3. 바람 영향 (모래만)
        if (cell.material == SAND) {
            float windSpeed = currentWeather.windSpeed;
            recovery += windSpeed * 0.1 * deltaTime;
        }

        // 4. 온도 영향 (눈)
        if (cell.material == SNOW) {
            float temperature = currentWeather.temperature;
            if (temperature > 0) {
                // 녹음 (복원 아님, 물이 됨)
                ConvertSnowToWater(cell);
            }
        }

        // 5. Height Map 업데이트
        cell.currentHeight = min(cell.currentHeight + recovery,
                                 cell.originalHeight);

        heightMap.Write(cell.position, cell.currentHeight);

        // 6. 완전 복원 시 목록에서 제거
        if (abs(cell.currentHeight - cell.originalHeight) < 0.001) {
            RemoveFromDeformedList(cell);
        }
    }
}

// 건조 시뮬레이션 (진흙)
function SimulateDrying(cell, sunIntensity, airTemperature) {
    // 표면만 빠르게 마름 (깊이 구배)
    float surfaceDryingRate = sunIntensity * 0.01;
    float depthFactor = abs(cell.currentHeight) / 0.05;  // 0~1

    // 깊은 부분은 느리게 마름
    float dryingRate = surfaceDryingRate * (1.0 - depthFactor * 0.8);

    // 온도가 높을수록 빠름
    dryingRate *= (1.0 + airTemperature / 30.0);

    return dryingRate;
}

Part 5: 메모리 최적화 (Sparse Storage)

Q. 넓은 맵 전체의 Height Map을 저장하면?
10km × 10km 맵을 1cm 해상도로 저장하면 1,000,000 × 1,000,000 = 1조 픽셀입니다. 불가능합니다. Sparse Storage를 사용합니다.

최적화 전략:
  • 변형된 영역만 저장: 원본은 유지, 변경분만 메모리
  • 타일 기반 LOD: 멀리 있는 발자국은 저장 안 함
  • 시간 임계값: 10분 이상 된 발자국 자동 삭제
  • 플레이어 근처만 활성: 100m 밖은 시뮬레이션 중단
Sparse Storage 구조: 전체 맵 (10km × 10km): ┌────────────────────────────────────┐ │ │ │ 타일 0,0 타일 1,0 │ │ ┌─────┐ ┌─────┐ │ │ │ │ │ 👣 │ ← 변형 있음 │ └─────┘ └─────┘ │ │ │ │ 타일 0,1 타일 1,1 │ │ ┌─────┐ ┌─────┐ │ │ │ │ │ │ │ │ └─────┘ └─────┘ │ │ │ └────────────────────────────────────┘ 메모리 사용: 원본 Height Map: 없음 (프로시저럴 생성) 변형 데이터: 타일 1,0만 저장 (1MB) 타일 1,0의 내부 구조: ┌────────────────┐ │ ▓ ▓ ▓ ▓ ▓ ▓ │ ← Sparse Bitmap (변형 있는 셀만 1) │ ▓ █ █ █ ▓ ▓ │ █ = 변형 있음 │ ▓ █ █ █ ▓ ▓ │ ▓ = 변형 없음 (원본 사용) │ ▓ ▓ ▓ ▓ ▓ ▓ │ └────────────────┘ 실제 저장: Bitmap: 256×256 bits = 8KB 변형 데이터: (3×3) × 16 bytes = 144 bytes 총: 8.14KB (전체 타일이 아닌 변형 부분만) 
// 의사코드: Sparse Storage
struct DeformationTile {
    int tileX, tileY;
    Bitmap changedCells;          // 256×256 bits (변형 여부)
    HashMap heights;  // 실제 높이값
    float lastAccessTime;
}

HashMap activeTiles;

function GetHeight(worldPosition) {
    vec2 tileCoord = floor(worldPosition / TILE_SIZE);
    vec2 localCoord = fract(worldPosition / TILE_SIZE);

    // 1. 타일이 활성화되어 있는지 확인
    if (!activeTiles.Contains(tileCoord)) {
        // 원본 높이 반환 (프로시저럴)
        return GenerateOriginalHeight(worldPosition);
    }

    DeformationTile tile = activeTiles[tileCoord];

    // 2. 이 셀이 변형되었는지 확인
    if (!tile.changedCells.Get(localCoord)) {
        return GenerateOriginalHeight(worldPosition);
    }

    // 3. 변형된 높이 반환
    return tile.heights[localCoord];
}

function SetHeight(worldPosition, newHeight) {
    vec2 tileCoord = floor(worldPosition / TILE_SIZE);
    vec2 localCoord = fract(worldPosition / TILE_SIZE);

    // 1. 타일 활성화 (없으면 생성)
    if (!activeTiles.Contains(tileCoord)) {
        activeTiles[tileCoord] = CreateNewTile(tileCoord);
    }

    DeformationTile tile = activeTiles[tileCoord];

    // 2. 변형 기록
    tile.changedCells.Set(localCoord, true);
    tile.heights[localCoord] = newHeight;
    tile.lastAccessTime = currentTime;
}

// 메모리 관리
function CleanupOldDeformations() {
    float timeout = 600.0;  // 10분

    for each tile in activeTiles {
        if (currentTime - tile.lastAccessTime > timeout) {
            activeTiles.Remove(tile);  // 메모리 해제
        }
    }
}

// LOD 기반 활성화
function UpdateActiveTiles(playerPosition) {
    float activationRadius = 100.0;  // 100m

    vec2 playerTile = floor(playerPosition / TILE_SIZE);

    // 플레이어 주변 타일만 활성
    for (int y = -2; y <= 2; y++) {
        for (int x = -2; x <= 2; x++) {
            vec2 tileCoord = playerTile + vec2(x, y);
            EnsureTileActive(tileCoord);
        }
    }

    // 먼 타일 비활성화
    for each tile in activeTiles {
        float distance = length(tile.position - playerPosition);
        if (distance > activationRadius) {
            tile.Deactivate();  // 시뮬레이션 중단, 메모리 유지
        }
    }
}

Part 6: 다른 오브젝트와 상호작용

Q. 마차 바퀴는 어떻게 연속적인 자국을 남기나요?
연속 샘플링을 사용합니다. 바퀴의 이전 위치와 현재 위치 사이를 보간하여 여러 지점에 Stamp를 찍습니다.

// 의사코드: 바퀴 자국
struct Wheel {
    vec3 position;
    vec3 previousPosition;
    float rotation;
    float radius;
    float width;
}

function UpdateWheelTracks(wheel, deltaTime) {
    vec3 movement = wheel.position - wheel.previousPosition;
    float distance = length(movement);

    if (distance < 0.01) return;  // 움직이지 않음

    // 1. 샘플 개수 계산 (1cm마다)
    int samples = ceil(distance / 0.01);

    // 2. 각 샘플 지점에 Stamp
    for (int i = 0; i < samples; i++) {
        float t = i / float(samples);
        vec3 samplePos = lerp(wheel.previousPosition, wheel.position, t);

        // 바퀴 회전 각도 (굴러간 거리에 비례)
        float rolledAngle = wheel.rotation + (distance / wheel.radius) * t;

        // 바퀴 Stamp (타이어 패턴 포함)
        ApplyWheelStamp(samplePos, rolledAngle, wheel);
    }

    wheel.previousPosition = wheel.position;
}

function ApplyWheelStamp(position, rotation, wheel) {
    // 1. 바퀴 압력 (차량 무게 / 바퀴 개수)
    float pressure = vehicleWeight / numberOfWheels / wheel.width;

    // 2. 타이어 패턴 Stamp
    Texture2D tirePattern = LoadTirePattern();  // 트레드 패턴

    // 3. 지형 재질 확인
    TerrainMaterial material = GetTerrainMaterial(position);

    if (material == ROCK) return;  // 바위는 자국 안 남

    // 4. 타이어 패턴대로 Height Map 수정
    for each pixel in tirePattern {
        vec2 offset = RotateOffset(pixel, rotation);
        vec2 worldPos = position.xz + offset;

        float depth = tirePattern[pixel] * pressure * 0.03;  // 최대 3cm
        ModifyHeightMap(worldPos, -depth);
    }
}

// 폭탄 크레이터
function ApplyExplosionCrater(position, explosionForce) {
    float radius = explosionForce * 2.0;  // 폭발력에 비례

    for each point in radius {
        float dist = length(point - position);
        float falloff = 1.0 - (dist / radius);  // 중심에서 멀수록 약함

        // Crater 모양 (중앙 깊고, 가장자리 융기)
        float depth;
        if (dist < radius * 0.5) {
            depth = -explosionForce * 0.5 * falloff;  // 중앙 파임
        } else {
            depth = explosionForce * 0.1 * (1.0 - falloff);  // 가장자리 솟음
        }

        ModifyHeightMap(point, depth);
    }

    // 파편 흩어짐 (Debris)
    SpawnDebris(position, explosionForce);
}

💡 핵심 정리

  • Height Map 변형: R16F 텍스처에 실시간 높이값 수정
  • Stamp 패턴: 발자국, 바퀴 자국 등 미리 제작된 텍스처 적용
  • 재질별 반응: 진흙 (점성 높음), 모래 (빠른 복원), 눈 (높은 압축)
  • 시간 복원: 날씨(햇빛, 바람)에 따라 자동 복원
  • Sparse Storage: 변형된 영역만 저장, 타일 기반 LOD
  • 압력 계산: 무게 + 속도 → 동적 압력
  • 연속 샘플링: 바퀴처럼 빠른 오브젝트는 중간 지점 보간
게임 내 적용 예시:
  • 진흙탕을 달리면 깊은 발자국, 걸으면 얕은 발자국
  • 마차가 지나간 길은 바퀴 자국이 선명함
  • 비 오기 전 발자국이 마르면 금 → 비 오면 다시 부드러워짐
  • 눈 위를 걸으면 뽀드득 소리 + 깊게 파임
  • 폭탄 터지면 크레이터 생성 (중앙 깊고, 가장자리 솟음)
참고: RDR2는 이 시스템을 Dynamic Wetness, Decal System과 연동합니다. 발자국이 있는 곳에 물웅덩이가 생기면 반사 효과가 추가되고, 진흙 Decal이 신발에 붙습니다. 모든 시스템이 유기적으로 연결되어 있습니다.
