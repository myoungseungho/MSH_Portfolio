말 털이 바람에 흔들리는 건 어떻게 만들어요?

실시간 털/갈기 시뮬레이션

Q: 말 갈기가 바람에 흔들리는 게 그렇게 어려운가요?
매우 어렵습니다. 말 한 마리의 갈기에는 수천 가닥의 털이 있고, 각 가닥은 독립적으로 중력, 바람, 충돌에 반응해야 합니다. 실시간으로 이를 시뮬레이션하면서 60fps를 유지하는 것은 게임 그래픽스의 가장 큰 도전 중 하나입니다.

Part 1: 털 렌더링의 어려움

Q: 왜 털은 다른 것보다 어려운가요?
3가지 주요 문제:
  1. 개수: 말 한 마리 = 갈기 5,000가닥 + 꼬리 3,000가닥 + 몸털 100,000가닥
  2. 물리: 각 가닥이 중력, 바람, 마찰, 충돌에 실시간 반응
  3. 렌더링: 반투명 + Self-Shadow + 셰이딩 = GPU 부하 폭증
털 렌더링 파이프라인 ┌─────────────────┐ │ 1. 물리 시뮬 │ 각 가닥의 위치 계산 (CPU/GPU) │ 레이션 │ - 중력, 바람, 충돌 └────────┬────────┘ │ ▼ ┌─────────────────┐ │ 2. 지오메트리 │ 스트랜드를 실제 3D 메쉬로 변환 │ 생성 │ - 카메라 방향으로 빌보드 생성 └────────┬────────┘ │ ▼ ┌─────────────────┐ │ 3. 셰이딩 │ 빛 반사, 투명도, 색상 │ │ - Kajiya-Kay 모델 └────────┬────────┘ │ ▼ ┌─────────────────┐ │ 4. Self-Shadow │ 털끼리 그림자 │ │ - Deep Opacity Map └────────┬────────┘ │ ▼ ┌─────────────────┐ │ 5. 안티앨리어싱 │ 픽셀보다 가느다란 털 처리 │ │ - MSAA + TAA └─────────────────┘ 각 단계마다 GPU 부하 ↑↑↑

Part 2: Shell/Fin vs Strand 기법

Q: 10만 가닥을 어떻게 렌더링하나요?
실제로는 10만 가닥을 전부 그리지 않습니다. RDR2는 두 가지 기법을 혼용합니다:
  • Shell Texturing: 몸털 (멀리서 보기)
  • Strand-based: 갈기/꼬리 (가까이서 보기)
Shell Texturing (몸털) Strand-based (갈기) ┌───────┐ │││││││ │ Layer 3│ ← 투명 텍스처 │││││││ ← 실제 3D 가닥 ├───────┤ │││││││ │ Layer 2│ │││││││ ├───────┤ │││││││ │ Layer 1│ └┬┬┬┬┬┘ ├───────┤ │││││ │ 피부 │ 머리 메쉬 └───────┘ - 3~5개 레이어 - 500~2000 가닥 - 정적 텍스처 - 동적 물리 시뮬레이션 - 저부하 - 고부하 - 원거리용 - 근거리용 
// 의사코드: LOD 기반 털 렌더링
class HorseFurRenderer {
    void RenderFur(Horse horse, Camera camera) {
        float distance = Distance(horse.position, camera.position);

        // LOD 0: 매우 가까움 (0-5m)
        if (distance < 5.0f) {
            RenderManeStrand(horse.mane, 2000);  // 갈기 2000가닥
            RenderTailStrand(horse.tail, 1500);  // 꼬리 1500가닥
            RenderBodyShell(horse.body, 5);      // 몸 5레이어
        }

        // LOD 1: 중간 거리 (5-15m)
        else if (distance < 15.0f) {
            RenderManeStrand(horse.mane, 800);   // 갈기 800가닥
            RenderTailStrand(horse.tail, 600);   // 꼬리 600가닥
            RenderBodyShell(horse.body, 3);      // 몸 3레이어
        }

        // LOD 2: 먼 거리 (15-50m)
        else if (distance < 50.0f) {
            RenderManeStrand(horse.mane, 200);   // 갈기 200가닥
            RenderTailStrand(horse.tail, 150);   // 꼬리 150가닥
            RenderBodyShell(horse.body, 2);      // 몸 2레이어
        }

        // LOD 3: 매우 멀거나 화면 밖
        else {
            RenderBodyShell(horse.body, 1);      // 몸 1레이어만
            // 갈기/꼬리 생략
        }
    }
}

Part 3: 바람 시뮬레이션 (Verlet Integration)

Q: 각 가닥이 바람에 어떻게 반응하나요?
각 털 가닥을 체인 형태의 파티클로 모델링합니다. 뿌리는 고정, 끝은 자유롭게 움직이며, Verlet Integration으로 물리를 계산합니다.
털 가닥 = 파티클 체인 뿌리 (고정) ●────────> 파티클 0 (고정, 머리에 붙음) │ ● ────────> 파티클 1 (거리 제약: L) │ ● ────────> 파티클 2 (거리 제약: L) │ ● ────────> 파티클 3 (거리 제약: L) │ ● ────────> 파티클 4 (자유) 끝 (바람에 흔들림) 각 파티클에 작용하는 힘: - 중력 ↓ - 바람 → - 댐핑 (마찰) - 거리 제약 (늘어나지 않음) 
// 의사코드: Verlet Integration
class HairStrand {
    struct Particle {
        Vector3 position;
        Vector3 prevPosition;
        float mass;
        bool isFixed;  // 뿌리 파티클은 true
    };

    List particles;
    float segmentLength = 0.05f;  // 각 세그먼트 길이 5cm

    void Simulate(float deltaTime, Vector3 wind, Vector3 gravity) {
        // 1. 힘 적용 (Verlet)
        for (int i = 0; i < particles.Count; i++) {
            if (particles[i].isFixed) continue;

            Vector3 velocity = particles[i].position - particles[i].prevPosition;

            // 이전 위치 저장
            Vector3 oldPos = particles[i].position;

            // 새 위치 계산: Verlet Integration
            // newPos = pos + velocity + acceleration * dt^2
            Vector3 acceleration = (gravity + wind) / particles[i].mass;
            particles[i].position += velocity * 0.98f + acceleration * deltaTime * deltaTime;

            // 댐핑 (공기 저항)
            // 0.98f = 2% 속도 손실

            particles[i].prevPosition = oldPos;
        }

        // 2. 거리 제약 (Constraint Solving)
        for (int iteration = 0; iteration < 5; iteration++) {  // 5번 반복으로 안정화
            for (int i = 0; i < particles.Count - 1; i++) {
                if (particles[i].isFixed && particles[i+1].isFixed) continue;

                Vector3 delta = particles[i+1].position - particles[i].position;
                float distance = delta.Length();
                float error = distance - segmentLength;

                // 거리 오차의 50%씩 양쪽으로 분배
                Vector3 correction = delta.Normalized() * error * 0.5f;

                if (!particles[i].isFixed)
                    particles[i].position += correction;
                if (!particles[i+1].isFixed)
                    particles[i+1].position -= correction;
            }
        }

        // 3. 충돌 처리 (말 몸체와 충돌)
        for (int i = 0; i < particles.Count; i++) {
            if (particles[i].isFixed) continue;

            if (IsInsideHorseBody(particles[i].position)) {
                // 몸체 표면으로 밀어냄
                particles[i].position = GetNearestSurfacePoint(particles[i].position);
            }
        }
    }
}

Part 4: GPU 가속 (Compute Shader)

Q: CPU로 수천 가닥을 계산하면 느리지 않나요?
매우 느립니다. 그래서 RDR2는 물리 시뮬레이션을 GPU Compute Shader로 옮깁니다. GPU는 수천 개의 코어로 병렬 계산이 가능해서 털 시뮬레이션에 이상적입니다.
CPU vs GPU 시뮬레이션:
  • CPU (순차): 2000가닥 × 5파티클 = 10,000 계산 → 10ms (100 FPS)
  • GPU (병렬): 2000가닥 병렬 처리 → 0.5ms (2000 FPS)
성능 향상: 20배! 
// 의사코드: GPU Compute Shader (HLSL 스타일)
// HairPhysics.compute

struct Particle {
    float3 position;
    float3 prevPosition;
    float mass;
    int isFixed;
};

RWStructuredBuffer particles;  // GPU 메모리
cbuffer SimParams {
    float3 gravity;
    float3 wind;
    float deltaTime;
    float segmentLength;
    int particleCount;
};

[numthreads(256, 1, 1)]  // 256개 스레드 = 한 그룹
void SimulateHair(uint3 id : SV_DispatchThreadID) {
    int i = id.x;
    if (i >= particleCount || particles[i].isFixed) return;

    // 1. Verlet Integration
    float3 velocity = particles[i].position - particles[i].prevPosition;
    float3 acceleration = (gravity + wind) / particles[i].mass;

    float3 oldPos = particles[i].position;
    particles[i].position += velocity * 0.98 + acceleration * deltaTime * deltaTime;
    particles[i].prevPosition = oldPos;
}

[numthreads(256, 1, 1)]
void SolveConstraints(uint3 id : SV_DispatchThreadID) {
    int i = id.x;
    if (i >= particleCount - 1) return;
    if (particles[i].isFixed && particles[i+1].isFixed) return;

    // 거리 제약
    float3 delta = particles[i+1].position - particles[i].position;
    float distance = length(delta);
    float error = distance - segmentLength;

    float3 correction = normalize(delta) * error * 0.5;

    // 원자적 쓰기 (Race Condition 방지)
    if (!particles[i].isFixed)
        InterlockedAdd(particles[i].position, correction);
    if (!particles[i+1].isFixed)
        InterlockedAdd(particles[i+1].position, -correction);
}

// C# 호출 코드
void Update() {
    // 1단계: Verlet Integration
    hairPhysicsShader.Dispatch(kernelSimulate, particleCount / 256, 1, 1);

    // 2단계: Constraint Solving (5회 반복)
    for (int i = 0; i < 5; i++) {
        hairPhysicsShader.Dispatch(kernelConstraints, particleCount / 256, 1, 1);
    }
}

Part 5: 바람 필드 시스템

Q: 바람은 어떻게 만드나요?
RDR2는 3D 바람 필드를 사용합니다. 맵 전체를 그리드로 나누고, 각 셀마다 바람 벡터를 저장합니다. Perlin Noise로 바람의 난류(turbulence)를 시뮬레이션합니다.
3D 바람 필드 맵 그리드 (10m × 10m × 5m 셀) Y (높이) ↑ │ ┌──→┐ ┌──→┐ ┌──→┐ │ │ │ │ │ │ │ ← 각 셀의 바람 벡터 │ └────┘ └────┘ └────┘ │ ┌←───┐ ┌──→┐ ┌↗──┐ │ │ │ │ │ │ │ │ └────┘ └────┘ └────┘ └─────────────────────────→ X / / Z 바람 계산: 1. 기본 바람 (날씨 시스템) 2. + Perlin Noise (난류) 3. + 지형 영향 (산 뒤 = 약함) 4. + 로컬 이벤트 (폭발, 마차 지나감) 
// 의사코드: 바람 필드
class WindFieldSystem {
    struct WindCell {
        Vector3 baseWind;      // 기본 바람 방향
        float turbulence;      // 난류 강도
    };

    WindCell[,,] windGrid;  // 3D 그리드
    float cellSize = 10.0f;
    float time = 0.0f;

    Vector3 GetWindAt(Vector3 position) {
        // 1. 그리드 좌표 계산
        int x = (int)(position.x / cellSize);
        int y = (int)(position.y / cellSize);
        int z = (int)(position.z / cellSize);

        // 범위 체크
        if (!IsValidCell(x, y, z)) return Vector3.Zero;

        WindCell cell = windGrid[x, y, z];

        // 2. 기본 바람
        Vector3 wind = cell.baseWind;

        // 3. Perlin Noise로 난류 추가
        float noiseX = PerlinNoise(position.x * 0.1f, time * 0.5f);
        float noiseY = PerlinNoise(position.y * 0.1f, time * 0.5f + 100);
        float noiseZ = PerlinNoise(position.z * 0.1f, time * 0.5f + 200);

        Vector3 turbulence = new Vector3(noiseX, noiseY, noiseZ) * cell.turbulence;
        wind += turbulence;

        // 4. 지형 영향 (산 뒤는 바람 약함)
        float terrainFactor = GetTerrainWindFactor(position);
        wind *= terrainFactor;

        return wind;
    }

    void UpdateWindField(Weather weather, float deltaTime) {
        time += deltaTime;

        // 날씨에 따라 기본 바람 조정
        Vector3 weatherWind = weather.GetWindDirection() * weather.GetWindStrength();

        for (int x = 0; x < gridSizeX; x++) {
            for (int y = 0; y < gridSizeY; y++) {
                for (int z = 0; z < gridSizeZ; z++) {
                    windGrid[x,y,z].baseWind = weatherWind;

                    // 고도에 따라 바람 강해짐
                    float altitudeFactor = 1.0f + y * 0.2f;
                    windGrid[x,y,z].baseWind *= altitudeFactor;

                    // 난류는 날씨에 따라
                    windGrid[x,y,z].turbulence = weather.turbulence;
                }
            }
        }
    }
}

Part 6: 다른 게임과의 비교

Q: RDR2 말고 다른 게임은 어떻게 하나요?
주요 털 렌더링 기술:
  • AMD TressFX: Tomb Raider (2013) - Compute Shader 기반
  • NVIDIA HairWorks: The Witcher 3 - PhysX 물리
  • Rockstar RAGE: RDR2 - 커스텀 Verlet + LOD
기술별 특징:
  • TressFX (AMD):
    • 장점: 오픈소스, GPU 최적화 우수
    • 단점: AMD GPU에 최적화 (NVIDIA에서 느림)
    • 사용: 주로 사람 머리카락
  • HairWorks (NVIDIA):
    • 장점: PhysX 통합, 퀄리티 최상급
    • 단점: 폐쇄적, 성능 부하 큼
    • 사용: 사람/동물 모두
  • RAGE (Rockstar):
    • 장점: LOD 시스템 탁월, 콘솔 최적화
    • 단점: 자체 엔진 전용
    • 사용: 오픈월드 대량 동물

핵심 요약

  1. 렌더링 기법: Shell Texturing (몸털) + Strand-based (갈기/꼬리)
  2. 물리 시뮬레이션: Verlet Integration으로 파티클 체인 계산
  3. GPU 가속: Compute Shader로 수천 가닥 병렬 처리 (20배 빠름)
  4. 바람 시스템: 3D 그리드 + Perlin Noise로 난류 시뮬레이션
  5. LOD 최적화: 거리별로 가닥 개수 동적 조절 (200~2000가닥)

게임 내 예시: Valentine 마을에서 말을 타고 질주할 때, 말의 갈기가 바람에 날리며 머리 움직임에 따라 자연스럽게 흔들립니다. 폭풍우가 치면 갈기가 더 격렬하게 움직이고, 물에 젖으면 무거워져 덜 흔들립니다. 이 모든 것이 실시간으로 계산됩니다.

기술적 의의: RDR2의 털 시스템은 오픈월드에서 수백 마리 동물을 동시에 렌더링하면서도 60fps를 유지하는 최적화의 정점입니다.
