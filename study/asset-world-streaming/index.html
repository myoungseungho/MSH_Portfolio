플레이어 위치 기반 청크

Part 1. 오픈월드의 비밀

100GB 맵이 어떻게 돌아가?

맵을 청크(Chunk)로 나눔

플레이어 주변 청크만 메모리에

멀어지면 언로드, 가까워지면 로드

월드를 청크로 분할: ┌───┬───┬───┬───┬───┐ │ A │ B │ C │ D │ E │ ├───┼───┼───┼───┼───┤ │ F │ G │ H │ I │ J │ ├───┼───┼───┼───┼───┤ │ K │ L │ M │ N │ O │ ← 플레이어가 M에 있으면 ├───┼───┼───┼───┼───┤ │ P │ Q │ R │ S │ T │ ├───┼───┼───┼───┼───┤ │ U │ V │ W │ X │ Y │ └───┴───┴───┴───┴───┘ 로딩된 청크 (플레이어 주변): ┌───┬───┬───┐ │ G │ H │ I │ ├───┼───┼───┤ │ L │ M │ N │ ← M = 플레이어 위치 ├───┼───┼───┤ │ Q │ R │ S │ └───┴───┴───┘ = 9개 청크만 메모리에!

Part 2. 스트리밍 반경

얼마나 로딩해?

로딩 반경: 플레이어 중심 N개 청크

언로딩 반경: 로딩 반경보다 큼 (히스테리시스)

반경 설정: 언로딩 반경 (200m) ┌─────────────────────┐ │ │ │ 로딩 반경 (100m) │ │ ┌─────────────┐ │ │ │ │ │ │ │ ● │ │ ● = 플레이어 │ │ Player │ │ │ │ │ │ │ └─────────────┘ │ │ │ └─────────────────────┘ → 100m 안: 로딩 → 100~200m: 유지 → 200m 밖: 언로드

Part 3. 심리스 전환

로딩 화면 없이 어떻게?

1. 예측 로딩 - 이동 방향 예측

2. 시야 가림 - 동굴, 좁은 통로

3. LOD - 멀리는 저품질

핵심 정리

  • 맵을 청크로 분할
  • 플레이어 주변만 로딩
  • 언로드 반경 > 로드 반경
  • 예측 로딩으로 심리스
