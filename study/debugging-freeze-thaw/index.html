다른 스레드 멈춰놓고 디버깅

Freeze/Thaw — 특정 스레드만 실행

Part 1. 문제 상황

F10 누르면 다른 스레드가 끼어들어서 헷갈려

기본적으로 F5/F10/F11 누르면 모든 스레드가 실행된다.

타이밍 버그 재현이나 특정 스레드만 추적할 때 문제.

Part 2. Freeze (얼리기)

특정 스레드를 멈출 수 있어?

Threads 창에서 스레드 우클릭 → Freeze

얼린 스레드는 F5 눌러도 실행되지 않는다.

// Threads 창 (Ctrl+Alt+H) ID Name Status ----------------------------------- 1234 Main Thread Running 5678 Worker Thread 1 Frozen ❄️ ← 얼림 9012 Worker Thread 2 Frozen ❄️ ← 얼림 3456 Network Thread Running ← 실행됨 // F5 누르면 Main Thread와 Network Thread만 실행

Part 3. Thaw (녹이기)

다시 실행시키려면?

얼린 스레드 우클릭 → Thaw

다시 정상적으로 실행됨.

Part 4. 활용 예시

언제 쓰면 좋아?

1. 레이스 컨디션 재현: 한 스레드씩 순차 실행

2. 특정 스레드 집중: 다른 스레드가 방해 안 하게

3. 데드락 분석: 락 획득 순서를 제어

// 레이스 컨디션 재현 시나리오 // 상황: Thread A와 B가 동시에 counter 접근 시 버그 1. Thread A, B 모두 중단점에서 멈춤 2. Thread B를 Freeze 3. Thread A만 F10으로 진행 (counter 읽기) 4. Thread A를 Freeze, Thread B를 Thaw 5. Thread B만 F10으로 진행 (counter 읽기) 6. 둘 다 같은 값을 읽음! → 버그 재현

Part 5. 주의사항

조심할 점?

1. 락을 들고 있는 스레드를 얼리면 다른 스레드가 데드락

2. 디버깅 끝나면 모든 스레드 Thaw하기

3. 실제 동작과 다른 타이밍이 됨을 인지

핵심 정리

  • Freeze = 스레드 얼리기 (실행 안 됨)
  • Thaw = 스레드 녹이기 (다시 실행)
  • 레이스 컨디션 재현에 유용
  • 락 든 스레드 얼리면 데드락 주의
