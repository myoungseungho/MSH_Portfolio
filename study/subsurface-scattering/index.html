Subsurface Scattering (SSS)

캐릭터 피부가 왜 실제처럼 보이는 걸까?

Part 1. 왜 피부는 플라스틱처럼 안 보여?

3D 캐릭터 피부가 진짜처럼 보이는 비결이 뭐야?

Subsurface Scattering (표면하 산란) 덕분입니다.

피부는 빛이 표면에서 바로 반사되지 않고, 내부로 들어가서 산란되다가 다시 나옵니다.

빛의 반사 방식 비교: ┌─────────────────────────────────────────────────────────────┐ │ │ │ [금속/플라스틱] - 표면 반사만 │ │ │ │ 빛 \ / 반사광 │ │ \ / │ │ \ / │ │ -----------*----------- 표면 │ │ ######################## 불투명 내부 │ │ │ │ -> 딱딱하고 인공적인 느낌 │ │ │ ├─────────────────────────────────────────────────────────────┤ │ │ │ [피부/왁스/대리석] - 표면하 산란 │ │ │ │ 빛 \ / 일부 반사 │ │ \ / │ │ -----------*----------- 표면 │ │ /|\ │ │ / | \ 빛이 내부로 침투 │ │ *--*--* 산란 (여러 방향으로 퍼짐) │ │ \ | / │ │ -----------*----------- 다시 표면으로 나옴 │ │ \ │ │ \ 부드러운 확산광 │ │ │ │ -> 따뜻하고 생생한 느낌! │ │ │ └─────────────────────────────────────────────────────────────┘
왜 빛이 내부로 들어가?

피부는 반투명 매질이기 때문입니다.

피부의 층 구조: ┌─────────────────────────────────────────────────────────────┐ │ │ │ [피부 단면도] │ │ │ │ =========================== 표피 (Epidermis) 0.1mm │ │ ~~~~~~~~~~~~~~~~~~~~~~~~~~~ 각질층 - 대부분 반사 │ │ │ │ ::::::::::::::::::::::::::: 진피 (Dermis) 1-2mm │ │ :::: 혈관 :: 콜라겐 ::::::: 빨간색 흡수/산란 (피) │ │ ::::::::::::::::::::::::::: │ │ │ │ ########################### 피하지방 │ │ │ │ [파장별 침투 깊이] │ │ │ │ 빨강 (650nm): ################ 깊이 침투 -> 피부가 붉게 │ │ 초록 (550nm): ########## 중간 │ │ 파랑 (450nm): #### 얕게 -> 정맥이 파랗게 보임! │ │ │ └─────────────────────────────────────────────────────────────┘

Part 2. SSS의 물리적 원리

빛이 피부 안에서 어떻게 움직여?

산란(Scattering)과 흡수(Absorption) 두 가지가 일어납니다.

SSS의 물리 현상: ┌─────────────────────────────────────────────────────────────┐ │ │ │ 1. 산란 (Scattering) │ │ 빛이 입자(세포, 콜라겐)에 부딪혀 방향이 바뀜 │ │ │ │ ------* 입자에서 │ │ /|\ 여러 방향으로 퍼짐 │ │ │ │ 산란 계수: 얼마나 자주 산란되는가 │ │ 피부: ~2.0 /mm (1mm당 2번 산란) │ │ │ │ 2. 흡수 (Absorption) │ │ 빛 에너지가 열로 변환되어 사라짐 │ │ │ │ ------* -> X (사라짐) │ │ │ │ 흡수 계수: 파장마다 다름! │ │ - 멜라닌: 짧은 파장(파랑) 많이 흡수 │ │ - 헤모글로빈: 녹색/파랑 흡수 -> 피부가 붉어 보임 │ │ │ │ 3. Diffusion Profile │ │ 입사점에서 얼마나 퍼져서 나오는지를 나타내는 함수 │ │ │ │ 밝기 ^ │ │ | ## │ │ | #### │ │ |###### <- 빨간색: 멀리까지 퍼짐 │ │ |################ │ │ | .... <- 파란색: 빨리 소멸 │ │ +-------------------------> 거리 │ │ │ └─────────────────────────────────────────────────────────────┘

Part 3. 실시간 SSS 구현 기법들

물리 시뮬레이션은 너무 느리잖아. 실시간으로 어떻게 해?

여러 근사 기법들이 있습니다.

SSS 구현 방식 비교: ┌─────────────────────────────────────────────────────────────┐ │ │ │ 방식 성능 품질 메모리 사용처 │ │ ───────────────────────────────────────────────────────── │ │ Pre-integrated ***** *** 낮음 모바일 │ │ Screen-Space SSS **** **** 중간 PC 게임 │ │ Texture-Space *** ***** 높음 영화 │ │ Ray Marching * ***** 낮음 오프라인 │ │ │ └─────────────────────────────────────────────────────────────┘
Pre-integrated SSS가 뭐야?

미리 계산해둔 룩업 테이블(LUT)을 사용하는 방식입니다.

// Pre-integrated SSS: 라이팅 결과를 LUT에서 찾기 // 1. 오프라인에서 Diffusion Profile을 적분해서 LUT 생성 // LUT 축: x = NdotL (노말.라이트), y = 곡률(Curvature) // 2. 런타임에서 LUT 샘플링만! float4 PS_PreIntegratedSSS(VS_OUTPUT input) : SV_Target { float3 N = normalize(input.Normal); float3 L = normalize(LightDirection); float NdotL = dot(N, L); // 곡률 계산 (메시 굴곡 정도) float curvature = input.Curvature; // 0 = 평평, 1 = 볼록 // LUT 샘플링 (핵심!) float2 lutUV = float2(NdotL * 0.5 + 0.5, curvature); float3 diffuse = SkinLUT.Sample(sampler, lutUV).rgb; // 스펙큘러는 일반 BRDF 사용 float3 specular = CalculateSpecular(N, L, V); return float4(diffuse * albedo + specular, 1.0); } // Wrap Lighting만으로 간단히 구현하는 경우 float WrapDiffuse(float NdotL, float wrap) { // wrap = 0.5면 반대편까지 약간 밝아짐 return saturate((NdotL + wrap) / (1.0 + wrap)); }
Screen-Space SSS는 어떻게 달라?

렌더링 후 스크린 공간에서 블러를 적용합니다.

Screen-Space SSS 파이프라인: ┌─────────────────────────────────────────────────────────────┐ │ │ │ 1. 일반 렌더링 (Deferred or Forward) │ │ ┌───────────────────────┐ │ │ │ Diffuse + Specular │ -> 피부만 마스킹 │ │ └───────────────────────┘ │ │ | │ │ v │ │ 2. Separable Blur (가로 + 세로) │ │ ┌───────────────────────┐ │ │ │ 피부 영역에만 블러 │ -> 깊이 기반 가중치 │ │ │ 빨강: 많이 퍼짐 │ │ │ │ 초록: 중간 │ │ │ │ 파랑: 적게 퍼짐 │ │ │ └───────────────────────┘ │ │ | │ │ v │ │ 3. 최종 합성 │ │ ┌───────────────────────┐ │ │ │ 블러된 피부 + 스펙큘러│ │ │ └───────────────────────┘ │ │ │ └─────────────────────────────────────────────────────────────┘
// Screen-Space SSS (Jorge Jimenez 방식) // Diffusion Profile을 여러 가우시안의 합으로 근사 static const float4 kernel[] = { float4(0.560, 0.560, 0.560, 0.000), // 중앙 float4(0.100, 0.360, 0.260, 0.048), // 샘플 1 float4(0.080, 0.230, 0.100, 0.238), // 샘플 2 float4(0.220, 0.010, 0.010, 0.572), // 샘플 3 (빨강 퍼짐!) }; // Separable SSS Blur (가로 패스) float4 PS_SSS_BlurH(float2 uv : TEXCOORD) : SV_Target { float4 colorM = DiffuseTexture.Sample(sampler, uv); float depthM = DepthTexture.Sample(sampler, uv).r; // 피부가 아니면 스킵 if (SkinMask.Sample(sampler, uv).r < 0.5) return colorM; // 거리에 따른 블러 크기 조절 float scale = sssWidth / depthM; float4 colorBlurred = colorM * kernel[0].rgb; for (int i = 1; i < KERNEL_SIZE; i++) { float2 offset = float2(kernel[i].a * scale, 0); float4 color1 = DiffuseTexture.Sample(sampler, uv + offset); float4 color2 = DiffuseTexture.Sample(sampler, uv - offset); float depth1 = DepthTexture.Sample(sampler, uv + offset).r; float depth2 = DepthTexture.Sample(sampler, uv - offset).r; // 깊이 차이가 크면 가중치 감소 (실루엣 보존) float w1 = saturate(1.0 - abs(depthM - depth1) * threshold); float w2 = saturate(1.0 - abs(depthM - depth2) * threshold); // RGB 채널별 다른 가중치! colorBlurred.rgb += kernel[i].rgb * (color1.rgb*w1 + color2.rgb*w2); } return colorBlurred; }

Part 4. 다양한 재질에 적용

피부 말고 다른 재질에도 SSS를 써?

네! 왁스, 대리석, 우유, 식물 잎 등 반투명 재질에 모두 적용됩니다.

재질별 SSS 특성: ┌─────────────────────────────────────────────────────────────┐ │ │ │ 재질 산란색 산란 거리 사용 예시 │ │ ───────────────────────────────────────────────────────── │ │ 피부 붉은색 1-3mm 캐릭터 │ │ 왁스/양초 노란색 5-10mm 소품 │ │ 우유 흰색 10-20mm 음식 │ │ 대리석 분홍/흰색 2-5mm 건축물 │ │ 식물 잎 초록색 0.5-2mm 자연환경 │ │ 귀/손가락 진한 붉은색 3-5mm 역광 표현! │ │ │ │ [역광에서의 투과 (Transmission)] │ │ │ │ * 빛 │ │ \ │ │ +----\-----+ │ │ | \ | │ │ | O---|----- 빛이 귀를 통과하며 │ │ | 귀 | 붉게 빛남! │ │ +-----------+ │ │ │ └─────────────────────────────────────────────────────────────┘
// Translucency (역광 투과) 구현 float3 CalculateTranslucency(float3 L, float3 V, float3 N, float thickness) { // 빛이 오브젝트를 통과하는 방향 float3 transLightDir = L + N * distortion; // 뷰와 투과광의 정렬 정도 float VdotTL = pow(saturate(dot(V, -transLightDir)), power); // 두께에 따른 감쇠 float attenuation = exp(-thickness * extinctionCoeff); // 투과색 (피부면 붉은색) float3 transColor = float3(1.0, 0.2, 0.1); return transColor * VdotTL * attenuation * lightColor; } // 두께 맵 사용 (미리 베이크하거나 실시간 계산) float CalculateThickness(float2 shadowUV) { // Shadow Map에서 두께 추정 float frontDepth = ShadowMapFront.Sample(sampler, shadowUV).r; float backDepth = ShadowMapBack.Sample(sampler, shadowUV).r; return backDepth - frontDepth; }

Part 5. 최적화 팁

SSS가 성능에 영향이 크지 않아?

최적화 전략이 필요합니다.

SSS 성능 최적화: ┌─────────────────────────────────────────────────────────────┐ │ │ │ 1. 마스킹으로 영역 제한 │ │ - 피부/반투명 재질만 SSS 처리 │ │ - G-Buffer에 SSS 플래그 저장 │ │ │ │ 2. 해상도 스케일링 │ │ - 1/2 해상도에서 블러 후 업스케일 │ │ - 품질 vs 성능 트레이드오프 │ │ │ │ 3. 샘플 수 조절 │ │ - PC: 25개 샘플 │ │ - 모바일: 9개 샘플 │ │ - Pre-integrated로 대체 (모바일 최적) │ │ │ │ 4. LOD 적용 │ │ - 먼 캐릭터: Wrap Lighting만 │ │ - 중간: Pre-integrated SSS │ │ - 가까움: Screen-Space SSS │ │ │ │ [비용 비교] │ │ Wrap Lighting: 0.05ms │ │ Pre-integrated: 0.1ms │ │ Screen-Space SSS: 0.5-1.0ms │ │ │ └─────────────────────────────────────────────────────────────┘

핵심 정리

  • SSS = 빛이 반투명 매질 내부에서 산란되어 부드럽게 나오는 현상
  • Pre-integrated = LUT 샘플링으로 빠르게 구현 (모바일 적합)
  • Screen-Space SSS = 스크린 블러로 고품질 구현 (PC 적합)
  • Translucency = 역광에서 빛이 투과하는 효과 (귀, 손가락)
  • 재질별 커스터마이징 = 산란색/거리를 재질에 맞게 조절
  • LOD 전략 = 거리에 따라 기법 전환으로 성능 최적화
