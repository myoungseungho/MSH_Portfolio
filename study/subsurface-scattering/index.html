손전등 비추면 손이 빨갛게 보이는 이유

Subsurface Scattering (표면하 산란) - 피부가 진짜처럼 보이는 비밀

Part 1. 일상의 경험부터

어릴 때 손전등 손에 대보면 손이 빨갛게 빛나지 않았어?

기억나지? 어두운 방에서 손전등을 손바닥 뒤에 대면...

손가락 사이로 빨간 빛이 새어 나와!

왜 빨갛게 보이는 거야?

빛이 피부 속으로 들어갔다가 다시 나오기 때문이야!

그 과정에서 피 속의 혈색소가 빨간색 외의 빛을 흡수해.

🔦 실험해보기

1. 어두운 방에서 손전등을 켜
2. 손전등을 손바닥 뒤에 대
3. 손가락 끝을 봐

결과: 손가락이 빨갛게 빛나!

이게 바로 Subsurface Scattering이야!
빛이 피부 표면을 통과해서 내부에서 산란되다가 다시 나오는 현상.

Part 2. 왜 피부가 특별할까?

왜 피부만 그래? 철판에 손전등 비추면 안 그러잖아

물질마다 빛이 통과하는 방식이 달라:

물질별 빛의 반응: 금속 (철, 알루미늄) ─────────────────────────────────────────────────── 빛 → ☆ 반사! ───────── █████████ ← 내부로 전혀 못 들어감 → 100% 표면 반사. 빛이 내부로 못 들어감. 유리 ─────────────────────────────────────────────────── 빛 → ───────→ 투과! ───────── → 거의 100% 통과. 산란 없이 직진. 피부/왁스/우유 ─────────────────────────────────────────────────── 빛 → ☆ 일부 반사 ───────── ↘ ↓ ↙ ← 내부로 들어가서 ○→○→○ ← 이리저리 부딪히며 산란! ↗ ↑ ↖ ← 다시 표면으로 나옴 ───────── → 반투명! 빛이 들어가서 산란 후 다시 나옴.
왜 산란이 일어나?

피부 내부에 작은 입자들이 있기 때문이야:

- 세포

- 콜라겐 섬유

- 지방 방울

- 혈관

빛이 이것들에 부딪히면서 방향이 바뀌어 (산란).

Part 3. 피부의 구조

피부 안에서 빛이 어떻게 움직여?

피부는 여러 층으로 되어있어:

피부 단면도: 빛 ↓ ━━━━━━━━━━━━━━━━━━━━━━━━━━━━ 표피 (0.1mm) ↓ 일부 통과 - - - - - - - - - - - - - - 진피 (1~2mm) ↙ ↓ ↘ 혈관 🔴 ○→○→○ 콜라겐 ↗ ↑ ↖ 산란! ━━━━━━━━━━━━━━━━━━━━━━━━━━━━ 피하지방 ↓ 대부분 흡수 빛의 여정: 1️⃣ 표피 통과 (각질층에서 일부 반사) 2️⃣ 진피에서 산란 시작 (콜라겐에 부딪힘) 3️⃣ 혈관 만남 → 빨간색 외 흡수! 4️⃣ 여러 번 산란 후 다시 표면으로 5️⃣ 부드러운 빨간빛으로 나옴
왜 하필 빨간색만 남아?

혈액 속 헤모글로빈이 특정 색만 흡수해:

파장별 피부 투과: 흡수도 ↑ 높음 │ ○ ← 파란색 (대부분 흡수) │ ○ ← 초록색 (많이 흡수) │ 낮음 │ ○ ← 빨간색 (투과!) └───────────────→ 파장 파랑 초록 빨강 결과: 빨간빛만 피부를 통과해서 나옴! 이것이 귀가 빛에 비치면 빨갛게 보이는 이유!

Part 4. 게임에서 왜 중요해?

게임 캐릭터도 이걸 시뮬레이션해?

안 하면 플라스틱 인형처럼 보여!

SSS 없는 캐릭터 vs SSS 있는 캐릭터: SSS 없음: ┌─────────────────────────────────────────────────┐ │ │ │ 빛 → ☆ ← 표면에서 전부 반사 │ │ ○○○ │ │ ○ ○ ← 딱딱한 플라스틱 느낌 │ │ ○○○ │ │ │ │ - 그림자 경계가 날카로움 │ │ - 피부가 마네킹처럼 보임 │ │ - "언캐니 밸리" 현상 │ │ │ └─────────────────────────────────────────────────┘ SSS 있음: ┌─────────────────────────────────────────────────┐ │ │ │ 빛 → ☆ ← 일부 반사 │ │ ○○○ ↙ 내부 산란 │ │ ○ * ○ ← 부드러운 빨간빛 │ │ ○○○ ↗ 다시 나옴 │ │ │ │ - 그림자 경계가 부드러움 │ │ - 피부가 따뜻하고 생동감 있음 │ │ - 귀, 코, 손가락 끝이 빛에 비침 │ │ │ └─────────────────────────────────────────────────┘
구체적으로 어디서 차이가 나?

특히 역광 상황에서 드라마틱하게 달라져:

역광 상황 비교: ☀️ (뒤에서 오는 빛) ↓ ┌─────┐ │ 귀 │ └─────┘ ↓ 카메라 SSS 없음: 귀가 그냥 검은 실루엣 SSS 있음: 귀 가장자리가 빨갛게 빛남! (진짜처럼) 실제 효과가 큰 부위: - 귀 (얇아서 빛이 잘 통과) - 코 끝 - 손가락 끝 - 입술 - 피부가 얇은 곳들

Part 5. 게임에서 어떻게 구현해?

실시간으로 산란을 계산해?

진짜 산란을 시뮬레이션하면 너무 느려!

그래서 "근사(Approximation)" 기법을 써.

주요 SSS 구현 방법: 1️⃣ Pre-Integrated SSS (가장 빠름) ─────────────────────────────────────────────────── - 미리 계산된 LUT(룩업 테이블) 사용 - 빛 방향과 표면 각도로 테이블 조회 - 모바일 게임에서 많이 사용 2️⃣ Screen-Space SSS (중간) ─────────────────────────────────────────────────── - 렌더링된 화면에서 블러 적용 - 피부 픽셀 주변을 부드럽게 번지게 - 빠르지만 정확도 낮음 3️⃣ Separable SSS (고품질) ─────────────────────────────────────────────────── - 가우시안 블러를 피부색에 맞게 변형 - 빨간색 채널은 더 멀리 퍼지게 - PS4/Xbox One 세대 게임에서 사용 4️⃣ Ray-Traced SSS (최고 품질) ─────────────────────────────────────────────────── - 실제로 빛 경로 추적 - RTX 그래픽카드 필요 - 영화 수준의 품질
제일 많이 쓰는 방법은?

Separable SSS가 품질/성능 균형이 좋아서 많이 써.

핵심 아이디어: 색상 채널별로 다르게 블러!

Separable SSS 원리: 원본 피부 렌더링: ┌─────────────────────────────────────────────────┐ │ 밝음 ← 빛 → 어둠 │ │ ████████████████▒▒▒▒░░░░ │ └─────────────────────────────────────────────────┘ ↓ 채널별 분리 블러 ↓ ┌─────────────────────────────────────────────────┐ │ 빨강: ████████████████████████████░░░░ (많이 번짐)│ │ 초록: ████████████████████▒▒▒▒░░░░░░░ (적당히) │ │ 파랑: ████████████████▒▒░░░░░░░░░░░░░ (조금) │ └─────────────────────────────────────────────────┘ ↓ 합성 ↓ ┌─────────────────────────────────────────────────┐ │ 밝음 ← 빛 → 붉은 번짐 │ │ ████████████████▓▓▓▓▒▒░░ │ └─────────────────────────────────────────────────┘ 그림자 경계에 붉은 빛이 번지는 효과!

Part 6. 피부만 사용해?

SSS는 피부에만 쓰는 거야?

아니! 빛이 내부로 들어가는 물질은 다 써:

SSS를 사용하는 재질들: 인체 ─────────────────────────────────────────────────── - 피부 (가장 중요!) - 귀 (특히 역광에서) - 입술 - 눈 (홍채, 흰자) 자연물 ─────────────────────────────────────────────────── - 나뭇잎 (햇빛에 비치면 연두색) - 꽃잎 (빛에 비치면 반투명) - 과일 (사과, 포도 등) 인공물 ─────────────────────────────────────────────────── - 왁스 (양초) - 비누 - 젤리/구미 - 우유/유리컵의 우유 무기물 ─────────────────────────────────────────────────── - 대리석 - 옥 - 눈/얼음

Part 7. 정리

처음 질문으로 돌아가면?

손전등을 손에 대면 빨갛게 보이는 이유:

손전등 실험의 원리: 손전등 → 손바닥 뒤 ↓ 1️⃣ 빛이 피부 속으로 들어감 ↓ 2️⃣ 진피층에서 산란 ↓ 3️⃣ 혈액이 빨간색 외 흡수 ↓ 4️⃣ 빨간빛만 다시 나옴 ↓ 손가락 앞에서 빨간 빛 관찰! 게임에서의 적용: - 같은 원리를 셰이더로 시뮬레이션 - 피부가 플라스틱이 아닌 살아있는 느낌 - 역광, 그림자 경계에서 붉은 번짐 효과 - 현실감 있는 캐릭터 렌더링!

📌 핵심 정리

  • SSS - 빛이 반투명 물질 내부로 들어가 산란 후 다시 나오는 현상
  • 피부가 빨간 이유 - 혈액이 빨간색 외의 빛을 흡수
  • SSS 없으면 - 플라스틱 마네킹처럼 보임
  • 효과가 큰 부위 - 귀, 코, 손가락, 입술 (역광에서 특히)
  • 구현 방법 - 채널별 다른 블러 (빨강 > 초록 > 파랑)
  • 다른 재질 - 나뭇잎, 왁스, 대리석, 눈 등에도 사용
