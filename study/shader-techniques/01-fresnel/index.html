01. Fresnel (프레넬 효과)

Fresnel 효과 - Power 값 변화에 따른 가장자리 집중도 변화

이런 효과 본 적 있나요?

게임에서 캐릭터가 보호막을 쓰면 푸른빛 테두리가 생기고, 홀로그램 NPC는 가장자리가 빛나면서 투명하게 보이죠. 유령이나 영혼 캐릭터도 비슷한 느낌입니다.

이 효과들의 공통점이 뭘까요? 바로 "가장자리만 빛난다"는 겁니다.

이걸 어떻게 구현할까요? 정답은 Fresnel(프레넬) 효과입니다.

Fresnel 효과란?

물체를 정면에서 보면 반사가 약하고, 비스듬히 보면 반사가 강해지는 현상입니다. 호수를 위에서 내려다보면 바닥이 보이지만, 멀리 수평선 쪽을 보면 하늘이 반사되어 보이는 것과 같은 원리예요.

게임에서는 이 원리를 응용해서 "가장자리가 빛나는" 효과를 만듭니다.

원리: 어떻게 가장자리만 빛나게 할까?

1단계: 정면과 가장자리를 구분하기

컴퓨터는 "가장자리"가 뭔지 몰라요. 숫자로 알려줘야 해요.
"여기는 정면이야" → 0, "여기는 가장자리야" → 1 이런 식으로요.

구체를 바라본다고 생각해보세요:

  • 정면: 표면이 나를 똑바로 바라봄 (노말과 시선이 같은 방향)
  • 가장자리: 표면이 옆을 향함 (노말과 시선이 수직)

dot(N, V)는 "두 방향이 얼마나 같은지"를 숫자로 알려주는 도구예요.

  • 같은 방향 → 1
  • 수직 → 0

그래서 dot(N, V)를 계산하면:

  • 정면 → 1
  • 가장자리 → 0

2단계: 값 뒤집기

근데 우리가 원하는 건 가장자리가 밝은 것이에요.

위치dot(N,V) 결과원하는 값
정면10 (어둡게)
가장자리01 (밝게)

숫자가 반대로 나오고 있어요! 해결법은 간단해요. 1에서 빼면 뒤집어져요. 

1 - 1 = 0  (정면: 1이었는데 → 0으로)
1 - 0 = 1  (가장자리: 0이었는데 → 1로)

그래서: fresnel = 1 - dot(N, V)

3단계: 가장자리에만 집중시키기 (pow)

지금은 정면에서 가장자리까지 서서히 밝아지는 그라디언트예요.
근데 보호막 효과는 딱 테두리만 빛나잖아요?

여기서 제곱(pow)을 써요. 0.5를 제곱하면?

power0.5^power결과
10.5그대로
20.25작아짐
30.125더 작아짐
50.03거의 0

가장자리(원래 1)는 몇 제곱해도 1이에요. 1^5 = 1
그래서 power가 높을수록 가장자리만 살아남고 나머지는 어두워져요.

최종 공식

fresnel = pow(1 - dot(N, V), power)

정리

  • dot(N, V): 정면인지 가장자리인지 숫자로 알려줌
  • 1 - dot(N, V): 값을 뒤집어서 가장자리를 밝게
  • pow(..., power): 가장자리에만 집중시킴 (power 높을수록 얇은 테두리)

단계별 구현 과정 (레이어 쌓기)

Fresnel 효과는 한 번에 만들어지는 것이 아닙니다. 각 단계마다 레이어를 쌓아가면서 최종 효과가 완성됩니다.

Step 1: 기본 단색 구체

Step 1: 기본 회색 구체 - 렌더링 확인

목적: 기본 렌더링이 잘 되는지 확인

코드:

float4 main(PS_INPUT input) : SV_TARGET
{
    return float4(0.5f, 0.5f, 0.5f, 1.0f);  // 단순 회색
}

결과: 회색 구체가 렌더링됩니다.

Step 2: dot(N, V) 시각화

Step 2: dot(N,V) 시각화 - Power 0.5 → 5.0 변화 (Intensity 3.0 고정)

목적: 노말과 시선 벡터의 내적 값을 확인

코드:

float3 N = normalize(input.Normal);
float3 V = normalize(CameraPos - input.WorldPos);
float NdotV = saturate(dot(N, V));

return float4(NdotV, NdotV, NdotV, 1.0f);  // 회색조로 시각화

결과: 정면은 밝고(1.0), 가장자리는 어둡습니다(0.0).

이유: 정면에서는 노말과 시선이 평행 → dot = 1

Step 3: 1 - dot(N, V) 반전

Step 3: 반전 (1 - dot) - Power 0.5 → 5.0 변화 (Intensity 3.0 고정)

목적: 가장자리를 밝게 만들기 (반전)

코드:

float NdotV = saturate(dot(N, V));
float fresnel = 1.0f - NdotV;  // 반전!

return float4(fresnel, fresnel, fresnel, 1.0f);

결과: 정면은 어둡고(0.0), 가장자리는 밝습니다(1.0).

핵심: 1에서 빼면 값이 뒤집힙니다!

Step 4: pow() 적용 - 가장자리 강조

Step 4: pow() 적용 - Power 0.5 → 5.0 변화로 가장자리 집중도 확인

목적: Power 값으로 곡선을 조절해서 가장자리만 강조

코드:

float fresnel = 1.0f - NdotV;
fresnel = pow(fresnel, FresnelPower);  // 0.5 ~ 5.0
fresnel *= FresnelIntensity;           // 3.0

return float4(fresnel, fresnel, fresnel, 1.0f);

결과: 가장자리만 훨씬 더 강하게 빛납니다.

Power 값의 의미

  • Power 낮음 (0.5~1.0): 넓고 부드러운 그라디언트, 전체적으로 밝아짐
  • Power 중간 (2.0~3.0): 가장자리에 집중되기 시작
  • Power 높음 (4.0~5.0+): 얇고 날카로운 외곽선만 빛남

→ GIF에서 Power가 증가할수록 효과가 가장자리로 집중되는 것을 확인하세요!

Step 5: 최종 색상 적용

Step 5: 청록색 글로우 완성 - Power 변화에 따른 최종 효과

목적: 예쁜 색상을 입혀서 최종 효과 완성

코드:

float fresnel = pow(1.0f - NdotV, FresnelPower);
fresnel *= FresnelIntensity;

float4 finalColor = FresnelColor * fresnel;  // (0.3, 0.8, 1.0, 1.0) 청록색
finalColor.a = fresnel;  // 알파값도 프레넬 적용

return finalColor;

결과: 밝은 청록색 외곽 글로우 효과 완성!

추가 기술: 알파 블렌딩 활성화로 투명한 느낌

🎨 단계별 요약

  • Step 1: 기본 렌더링 확인 (회색)
  • Step 2: dot(N,V) 값 시각화 (정면 밝음)
  • Step 3: 반전으로 가장자리 밝게 (1 - dot)
  • Step 4: pow()로 가장자리 강조 (곡선 조절)
  • Step 5: 색상 적용해서 완성! (청록색 글로우)

→ 이렇게 레이어가 쌓여서 최종 효과가 만들어집니다!

구현

Vertex Shader (VS)

// 01_Fresnel_VS.hlsl
cbuffer PerFrame : register(b0)
{
    matrix ViewProj;
    float3 CameraPos;
    float Time;
};

cbuffer PerObject : register(b1)
{
    matrix World;
    float4 Color;
};

struct VS_INPUT
{
    float3 Position : POSITION;
    float3 Normal : NORMAL;
};

struct PS_INPUT
{
    float4 Position : SV_POSITION;
    float3 WorldPos : POSITION;
    float3 Normal : NORMAL;
};

PS_INPUT main(VS_INPUT input)
{
    PS_INPUT output;

    // 월드 공간 변환
    float4 worldPos = mul(float4(input.Position, 1.0f), World);
    output.WorldPos = worldPos.xyz;

    // 투영 공간 변환
    output.Position = mul(worldPos, ViewProj);

    // 노말 월드 공간 변환 (정규화)
    output.Normal = normalize(mul(input.Normal, (float3x3)World));

    return output;
}

Pixel Shader (PS)

// 01_Fresnel_PS.hlsl
cbuffer PerFrame : register(b0)
{
    float3 CameraPos;
    float FresnelPower;     // 프레넬 강도 (1.0 ~ 5.0 추천)
    float FresnelIntensity; // 밝기 배율 (1.0 ~ 3.0)
};

cbuffer PerObject : register(b1)
{
    float4 FresnelColor; // 외곽 글로우 색상
};

struct PS_INPUT
{
    float4 Position : SV_POSITION;
    float3 WorldPos : POSITION;
    float3 Normal : NORMAL;
};

float4 main(PS_INPUT input) : SV_TARGET
{
    // 노말 벡터 (이미 정규화되었지만 보간으로 인해 다시 정규화)
    float3 N = normalize(input.Normal);

    // 시선 벡터 (픽셀 → 카메라)
    float3 V = normalize(CameraPos - input.WorldPos);

    // Fresnel 계산
    float NdotV = saturate(dot(N, V));
    float fresnel = pow(1.0 - NdotV, FresnelPower);
    fresnel *= FresnelIntensity;

    // 최종 색상
    float4 finalColor = FresnelColor * fresnel;

    // 알파도 프레넬 값 적용 (투명도)
    finalColor.a = fresnel;

    return finalColor;
}

파라미터 조정

Power vs Intensity - 핵심 차이점

두 파라미터는 완전히 다른 역할을 합니다:

  • Power (곡선의 형태): 효과가 "어디에" 집중되는지 결정
    → 낮으면 넓게 퍼지고, 높으면 가장자리에만 집중
  • Intensity (밝기 배율): 효과가 "얼마나" 밝은지 결정
    → 단순히 최종 값에 곱해지는 배율

위의 GIF들은 Intensity를 3.0으로 고정하고 Power만 0.5→5.0으로 변화시킨 것입니다.
Power가 증가할수록 효과가 가장자리로 "집중"되는 것을 확인하세요!

파라미터 설명 권장 범위 효과
FresnelPower 프레넬 곡선의 가파름 0.5 ~ 5.0 높을수록 가장자리만 빛남 (분포 조절)
FresnelIntensity 전체 밝기 배율 1.0 ~ 5.0 높을수록 더 밝게 (밝기 조절)
FresnelColor 글로우 색상 RGB (0~1) 청록/보라 계열이 이쁨

추천 설정값

// 쉴드 효과
FresnelPower = 3.0
FresnelIntensity = 2.0
FresnelColor = (0.3, 0.8, 1.0, 1.0) // 밝은 청록색

// 에너지 필드
FresnelPower = 2.0
FresnelIntensity = 2.5
FresnelColor = (0.5, 0.0, 1.0, 1.0) // 보라색

// 홀로그램
FresnelPower = 1.5
FresnelIntensity = 1.5
FresnelColor = (0.0, 1.0, 0.8, 0.5) // 반투명 청록

학습 포인트

✅ 핵심 개념

  • Dot Product: 두 벡터의 방향 유사도를 -1 ~ 1로 표현
  • View Vector: 픽셀에서 카메라로 향하는 방향
  • Power Function: 값을 비선형적으로 조절 (곡선 만들기)
  • saturate(): 0~1 클램핑으로 안전한 연산 보장

응용 기법

  • 시간 기반 펄스: fresnel *= (1.0 + sin(Time * speed) * 0.2)
  • 색상 그라디언트: lerp(InnerColor, OuterColor, fresnel)
  • 노이즈 결합: fresnel + noise로 불규칙한 외곽선
  • 다중 레이어: 여러 프레넬을 다른 power로 합성

실전 활용 예시

게임에서의 사용

  • 보호막/쉴드: 캐릭터 주변 반구형 쉴드 효과
  • 홀로그램: SF 게임의 홀로그램 베이스 효과
  • 에너지 필드: 마법 장벽, 힘장
  • 유령/영혼: 반투명 영체 캐릭터
  • 스킬 이펙트: 버프 효과 표시

다른 기법과의 조합
