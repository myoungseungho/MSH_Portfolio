자주 쓰는 단축키만 엄선 — 이것만 외우면 된다

실행 제어

디버깅 시작 / 계속 실행 F5
디버깅 중지 Shift + F5
디버깅 다시 시작 Ctrl + Shift + F5
모두 중단 (Break All) Ctrl + Alt + Break
디버깅 없이 실행 Ctrl + F5

스테핑 (한 줄씩 실행)

Step Over (현재 줄 실행, 함수 안으로 안 들어감) F10
Step Into (함수 안으로 들어감) F11
Step Out (현재 함수 빠져나감) Shift + F11
커서 위치까지 실행 Ctrl + F10
다음 문장 설정 (실행 위치 변경) Ctrl + Shift + F10

중단점

중단점 설정/해제 F9
중단점 활성화/비활성화 Ctrl + F9
모든 중단점 삭제 Ctrl + Shift + F9
중단점 창 열기 Ctrl + Alt + B

디버그 창

Watch 창 (변수 감시) Ctrl + Alt + W, 1
Locals 창 (지역 변수) Ctrl + Alt + V, L
Autos 창 (자동 변수) Ctrl + Alt + V, A
Call Stack 창 Ctrl + Alt + C
Threads 창 Ctrl + Alt + H
Parallel Stacks 창 Ctrl + Shift + D, S
Memory 창 Ctrl + Alt + M, 1
Disassembly 창 Ctrl + Alt + D
Registers 창 Ctrl + Alt + G
Exception Settings Ctrl + Alt + E
Diagnostic Tools Ctrl + Alt + F2

빠른 조사

QuickWatch (선택한 변수 빠르게 확인) Shift + F9
DataTip 고정 (변수에 마우스 올렸을 때) Ctrl + D, Q

실무 팁: 필수 5개만 외우기

F5 - 실행/계속

F9 - 중단점 토글

F10 - Step Over

F11 - Step Into

Shift+F9 - QuickWatch

이 5개로 90%의 디버깅이 가능하다. 나머지는 필요할 때 찾아 쓰면 된다.
