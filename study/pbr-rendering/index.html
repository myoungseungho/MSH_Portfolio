왜 플라스틱과 금속은 빛나는 방식이 다를까?

PBR (Physically Based Rendering)의 원리

Part 1. 플라스틱 볼펜 vs 금속 열쇠

책상 위에 볼펜이랑 열쇠가 있어. 뭐가 달라 보여?

둘 다 빛나긴 하는데 빛나는 방식이 다르지.

플라스틱 볼펜: - 빨간색 볼펜이면 전체가 빨갛게 보임 - 하이라이트(반짝이는 점)는 흰색 - 색깔 + 흰색 반짝임 금속 열쇠: - 금색 열쇠면 반짝이는 부분도 금색 - 하이라이트도 금색 - 전체가 금속 색으로 반짝임
왜 그런 차이가 생기는 거야?

빛이 재질에 "들어갔다 나오는지" vs "바로 튕기는지" 차이야.

🏓 비유: 탁구공과 스펀지

탁구공을 벽에 던지면? 바로 튕겨 나와. → 금속
탁구공을 스펀지에 던지면? 들어갔다가 옆으로 나와. → 비금속

금속은 빛이 표면에서 바로 반사되고,
플라스틱은 빛이 안으로 들어갔다가 여기저기서 나와.
[비금속 - 플라스틱] 빛 → \ ↘ (4%만 표면에서 반사 - 흰색 하이라이트) ───────*─────── |\ | ↘ (96%가 안으로 들어감) | / \ |/ \ 내부에서 산란 ↙ ↘ (색소에 의해 빨간빛만 나옴) 결과: 빨간색 물체 + 흰색 하이라이트 [금속] 빛 → \ ↘ (70~100%가 표면에서 반사) ───────*─────── X (안으로 못 들어감) 결과: 반사 자체가 금색/은색/구리색

Part 2. 옛날 그래픽의 문제

옛날 게임은 왜 좀 어색해 보였어?

물리 법칙을 무시하고 "느낌"으로 조절했기 때문이야.

옛날 방식 (Phong/Blinn-Phong): 아티스트: "이 금속을 더 반짝이게 하고 싶어" Specular Power = 128로 올리자! Specular Color = 흰색으로 하자! → 실내에서는 괜찮아 보여 → 실외로 나가면? 이상해! 왜? 실제 금속은 그렇게 안 반짝여. 조명 환경마다 다르게 보여야 하는데 아티스트가 수동으로 조절해서 맞지 않는 거야.
그래서 어떻게 해결했어?

물리 법칙을 따르게 만들었어. 그게 PBR이야.

PBR = Physically Based Rendering (물리 기반 렌더링)

PBR 방식: 아티스트: "이건 금속이야" Metallic = 1.0 Roughness = 0.3 Base Color = 금색 (0.95, 0.8, 0.4) → 실내에서 금속처럼 보임 → 실외에서도 금속처럼 보임! → 밤에도 금속처럼 보임! 왜? 물리 법칙대로 계산하니까 어떤 조명에서든 "물리적으로 맞는" 결과가 나와.

Part 3. PBR의 3가지 규칙

물리 법칙이라는 게 뭔데?

PBR은 크게 3가지 규칙을 따라.

첫 번째 규칙은?

에너지 보존: 나간 빛 ≤ 들어온 빛

에너지 보존 (Energy Conservation): 들어온 빛 = 100% │ ▼ ┌─────────┐ │ 재질 │ └────┬────┘ │ ┌────┴────┐ 반사 흡수 60% 40% 60% + 40% = 100% ✓ 에너지 보존! 만약 반사가 120%라면? → 빛이 없어도 빛나는 괴물체! → 물리적으로 불가능 PBR은 이걸 자동으로 지켜줌.
두 번째 규칙은?

프레넬 효과: 비스듬히 보면 더 반사됨

🌊 비유: 호수

호수를 위에서 내려다보면? 물속이 보여.
호수를 비스듬히 보면? 하늘이 반사돼서 보여.

이게 프레넬 효과야. 보는 각도에 따라 반사량이 달라져.
프레넬 효과 (Fresnel Effect): [정면에서 볼 때] [비스듬히 볼 때] 👁 👁 │ ╲ ▼ ╲ ═══════ ═══════ 반사 약함 반사 강함 (4% 정도) (거의 100%!) 모든 재질에서 이 효과가 일어나! (금속은 원래 반사가 높아서 차이가 덜 눈에 띔)
세 번째 규칙은?

미세면(Microfacet) 이론: 표면은 작은 거울들의 집합

미세면 이론: [매끄러운 표면] Roughness 낮음 ─────────────── ← 평평 ╲ ● 선명한 하이라이트 거울처럼 빛이 한 방향으로 쫙 반사 [거친 표면] Roughness 높음 /\/\/\/\/\/\/\ ← 울퉁불퉁 ╱│╲╱│╲╱│╲╱│╲ ░░░░░░░░░░░░░ 퍼진 하이라이트 작은 거울들이 제각각 방향을 향해서 빛이 여러 방향으로 흩어짐

Part 4. PBR 텍스처 세트

PBR 쓰려면 어떤 텍스처가 필요해?

기본적으로 5가지 맵이 필요해.

PBR 텍스처 세트 (Metallic-Roughness 워크플로우): 1. Base Color (Albedo) ┌──────────────┐ │ 빨강, 파랑 │ ← 재질의 고유 색상 │ 등 RGB 색상 │ 금속이면 반사색이 됨 └──────────────┘ 2. Metallic ┌──────────────┐ │ 흰색 = 금속 │ ← 0 또는 1 │ 검정 = 비금속│ 중간값은 거의 안 씀 └──────────────┘ 3. Roughness ┌──────────────┐ │ 검정 = 매끄러움│ ← 0~1 연속 │ 흰색 = 거칠음 │ 광택 정도를 결정 └──────────────┘ 4. Normal Map ┌──────────────┐ │ RGB = XYZ │ ← 표면의 울퉁불퉁함 │ 방향 정보 │ 디테일 추가용 └──────────────┘ 5. AO (Ambient Occlusion) ┌──────────────┐ │ 검정 = 틈새 │ ← 구석의 어둠 │ 흰색 = 노출 │ 간접광 차폐 └──────────────┘
Metallic이 왜 0 아니면 1이야?

현실에서 "반쯤 금속인 물질"은 없기 때문이야.

Metallic 값 예시: ┌─────────────────────────────────┐ │ 물질 │ Metallic │ 설명 │ ├─────────────────────────────────┤ │ 순수 금 │ 1.0 │ 금속 │ │ 순수 은 │ 1.0 │ 금속 │ │ 녹슨 철 │ 0.0 │ 녹은 비금속화│ │ 플라스틱 │ 0.0 │ 비금속│ │ 나무 │ 0.0 │ 비금속│ │ 피부 │ 0.0 │ 비금속│ └─────────────────────────────────┘ 0.5 같은 중간값은 언제? → 금속 위에 먼지가 쌓인 경계 부분 → 픽셀 단위로 섞이는 곳에서만 사용

Part 5. 금속과 비금속의 차이 (코드 관점)

셰이더에서 금속/비금속을 어떻게 다르게 처리해?

핵심은 F0 (정면 반사율)과 Diffuse의 처리야.

금속 vs 비금속 처리: [비금속] F0 = 0.04 (4% 반사, 흰색) Diffuse = Base Color (확산광 있음) 최종 색상 = 확산광 + 반사광 = 빨간색 + 흰색 하이라이트 [금속] F0 = Base Color (70~100% 반사, 금속색) Diffuse = 없음 (빛이 안으로 못 들어가니까) 최종 색상 = 반사광만 = 금색 하이라이트
// 핵심 로직 (간략화) // F0: 정면에서의 반사율 // 비금속 = 0.04 고정, 금속 = Base Color float3 F0 = lerp(0.04, baseColor, metallic); // 반사광 (Specular) float3 specular = CookTorranceBRDF(F0, roughness); // 확산광 (Diffuse) - 금속은 0 float3 diffuse = baseColor * (1 - metallic); // 최종 = 확산 + 반사 float3 finalColor = diffuse + specular;

Part 6. IBL - 환경 반사

금속에 주변 환경이 비치는 건 어떻게 해?

IBL (Image-Based Lighting)을 써. 환경을 이미지로 저장해두고 반사에 사용해.

IBL 구성: [Irradiance Map] - 확산광용 환경맵을 아주 흐리게 블러 각 방향의 "평균 밝기" 저장 비금속의 Ambient에 사용 [Prefiltered Map] - 반사광용 환경맵을 여러 레벨로 블러 Mip 0: 선명 (Roughness 0용) Mip 1: 약간 흐림 Mip 2: 더 흐림 ... Mip N: 아주 흐림 (Roughness 1용) 거친 표면 = 흐린 반사 매끄러운 표면 = 선명한 반사
📷 비유: 흐린 거울

깨끗한 거울은 선명하게 비춰.
서리 낀 거울은 흐릿하게 비춰.

Roughness가 높으면 서리 낀 거울처럼
환경이 뿌옇게 반사돼.

Part 7. PBR의 장점

결국 PBR의 장점이 뭐야?

어떤 환경에서든 일관되게 보인다는 거야.

PBR의 장점: 1. 환경 일관성 ┌────────────────────────────────────┐ │ 같은 에셋이 │ │ 낮/밤, 실내/실외 어디서든 │ │ "그 재질답게" 보임 │ └────────────────────────────────────┘ 2. 아티스트 친화적 ┌────────────────────────────────────┐ │ "금속이야" → Metallic = 1 │ │ "좀 거칠어" → Roughness = 0.7 │ │ 직관적인 파라미터! │ └────────────────────────────────────┘ 3. 에셋 재사용 ┌────────────────────────────────────┐ │ 한 번 만든 에셋을 │ │ 다른 게임/씬에서도 그대로 사용 │ │ 조명 바뀌어도 다시 조절 안 해도 됨│ └────────────────────────────────────┘ 4. 실사와의 통합 ┌────────────────────────────────────┐ │ 사진 배경 + 3D 오브젝트 │ │ 자연스럽게 합성 가능 │ │ (영화 VFX에서 많이 사용) │ └────────────────────────────────────┘

📌 핵심 정리

  • 비금속 - 빛이 들어갔다 나옴, 하이라이트 흰색, Diffuse 있음
  • 금속 - 빛이 표면에서 반사, 하이라이트도 금속색, Diffuse 없음
  • 에너지 보존 - 나가는 빛 ≤ 들어오는 빛
  • 프레넬 - 비스듬히 보면 반사 증가
  • 미세면 - Roughness에 따라 하이라이트 선명도 결정
  • IBL - 환경맵으로 반사 표현 (Roughness별 블러)
